# 油库里世界 · MCyukkuri

[![Build](https://github.com/Longshou/MCyukkuri/actions/workflows/build.yml/badge.svg)](https://github.com/Longshou/MCyukkuri/actions/workflows/build.yml)

为 Minecraft Java 还原油库里（ゆっくり）的世界：有种族、习性、家庭和巢穴，涵盖饲养、野外生态与聚落、人类商店与工厂。私用项目，持续开发中，版本 `0.1.0-dev`。

Minecraft **1.21.1** · NeoForge **21.1.250** · Java **21**

## 玩法概览

- **生活与家庭**：饥饿、睡眠、卫生等需求；茎生、胎生、卵生；成长、亲缘、离巢；家油巢卵。
- **身体与心理**：伤口、馅料、中枢馅与遗体；性格、不安与甜化、认知教学；头饰即身份。
- **野外生态**：天然住所、森林聚落与族长、季节与越冬、野外事件、捕食种、水生魔理沙帽船。
- **饲养与人类世界**：设施与照料工具、冷冻收容，宠物店与铜银金徽章考核、三类工厂和人类 NPC。

各系统的现状与入口见[文档索引](docs/README.md)，后续顺序见[完善计划](docs/DEVELOPMENT_PLAN.md)。

## 获取与试玩

- **开发版**：在 [GitHub Actions](https://github.com/Longshou/MCyukkuri/actions/workflows/build.yml) 选 `main` 上成功的运行，下载 `mcyukkuri-<提交号>`，把 Jar 放进匹配版本 NeoForge 实例的 `mods/`。
- **试玩场**：双击根目录 `启动动作博物馆.cmd`，进入[油库里试玩场](docs/EXPERIMENTAL_MAP.md)。这是唯一的试玩与测试入口，CI 只编译。
- **素材检查**：双击 `打开素材检查.cmd` 查看各形态的动作与表情。
