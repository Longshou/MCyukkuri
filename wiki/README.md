## 来源与记录边界

- [L36《饅饅來大講堂》](hakkei-reference/sources-lore.md)是常用设定的高优先级综述，与其他社区资料冲突时优先采用其明示内容。项目需要取舍时，以用户最新明确修改为准，游戏当前规则见[游戏文档索引](../docs/FEATURES.md)。
- 讲堂的台湾圈名词在使用前按[术语表](glossary.md)换成项目名词。讲堂楼层、作品编号、同源别名和各来源范围只在[世界观与生态来源](hakkei-reference/sources-lore.md)、[对白与情节来源](hakkei-reference/sources-events.md)登记。
- 社区 Wiki [yukkuri.fandom.com](https://yukkuri.fandom.com/) 的十一个分类（Pet Yukkuri、Places、Meta、Memes、Behavior、Biology、Yukkuri、Characters、Other Characters、Text Stories、Cartoon Stories）共 445 条分类记录、按页面去重后 271 个条目，分类与页数见 [fandom 条目来源](hakkei-reference/sources-fandom.md)，不入 L 编号。页面自述没有统一标准、通行写法与个人方案混排，因此按页保留范围。Meta 分类多为社区史、题材惯例与站务资料，只作写作与用词参考，不当作设定（[社区史与外站资料](fandom-history.md)）。Characters 与两个故事分类里的人类角色和单篇作品只作母题与检索，标题、作者与一句前提见 [fandom 故事目录](hakkei-reference/events/fandom-stories.md)。站点图片受 Cloudflare 质询，本库只从源码登记图片名与说明，不取图、不以图作结论。
- 八景原作来自用户提供的本机 `油库里八景ver1.12/`（不入库），可读 `start.utf8.hsp` 与 `text/<角色>/` 台词还原行为骨架，它与社区 Wiki、小说和漫画的异说并列，不改写作品原文。
- **A** 为具体作品，**W** 为社区整理，**I** 为整理推断，**P** 为项目改编或原创。A 只证明该作品，W 必须保留版本范围，I、P 不冒充原文。转载、译版和改编关系不重复计作独立见证。
- 图片保留作品出处、署名、原字节和来源限制，未明确的信息保留说明。外部参考不直接成为游戏资源或已认可造型。
