# 制作画面证据

[证据索引](evidence.json) · [标注约定](production-reference-format.md) · [小说片段](../novel-reading/evidence.md) · [作品对白](../hakkei-reference/dialogue/evidence.md)

从 `pages[].units` 按 `subjects`、`action`、`expression`、`body_state`、`prop_scene` 或 `view` 查找。每条有稳定 ID、制作用途和一句可借鉴的细节。沿同页 `path` 打开原图；`crop` 为原图像素坐标，`null` 代表使用整图。有些 `path` 指向本机留存的来源，出处在 `sources`。

| 要找的画面 | 优先查找 |
| --- | --- |
| 胎生、出壳、茎果 | `胎生分娩`、`孵化`、`茎上`；`EH37-001`、`EH34-010`、`EH16-005` |
| 首便、如厕、清洁、厕坑布局 | `首便`、`如厕`、`清洁`、`厕坑`；`EH08-008`、`EH32-006`、`M04-006`、`M15-011`。角色的如厕想象见 `M03-005`。 |
| 交配与贴靠 | `交配`、`问候蹭脸`、`贴靠`；`EH16-002` 的并排贴颊是该篇的表现参考。 |
| 亲子、安抚、搬运、登船 | `照料幼体`、`贴靠`、`辫子持物`、`帽船活动`；`EH30-006`、`EH28-004`、`EH22-005` |
| 爱丽丝、玩偶与相对尺度 | `爱丽丝`＋`玩偶`；`M06-001`、`M06-002`、`M06-009` |
| 表情与身体形变 | `expression` 下的 `喜悦`、`悲伤`、`惊讶` 等；八景表情图层可按 `通用油库里` 和表情查找。 `压扁`、`拉伸`、`贴地` 等形状见 `body_state`。 |

逐图核对的画面和批次抽查所得候选分别用 `review` 标出。遇到 `crop_status: 估算` 时，按 `crop_hint` 回查原图边界；`image_review` 记录需要重标的来源。
