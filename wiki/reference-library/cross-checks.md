## 住所、食物与季节

2026-10-17 补充的宠物材料另见[宠物生活](../pet-life.md)：EH31／EH33／EH34 的衣物用途与 EH30 约束型分列；EH32 幼体如厕失败和 N29 后天失能分别记录；N30／M15 为同一故事的小说与漫画，不是两个独立见证。N27 的争宠与 EH33 的训练后恐惧只能支持具体情境，不能泛化成种族性格。

## 分类时纠正的误读

| 题名或画面容易造成的误读 | 核对后的分类 |
| --- | --- |
| 《油库里的育儿》就是油库里新生儿 | EH29 实际是油库里照料人类儿童；归人类互动，不作为普通幼体成长图 |
| “一家都穿裹布”就是保暖衣教程 | EH30 第 3、8 页有约束繁殖的服饰背景；归器具结构和家庭互动，保留用途限制 |
| 一本标题带“观察记录”就能提供统一生理实验结论 | EH16 是带伤害情节的设定图文；发育外观、受损状态、叙述概率分别处理 |
| 图集叫《一起生活》便已读完小说 | EH18 是长条插图小说合辑；本轮只看插图，密集正文待核读，不增加小说已读数 |
| 多个站点、多个卡号就有多个独立作者 | N09／N13 同作者；N21／N22 同作者；M09 是 L24 改编。见来源关系登记 |
| 夏日作品能泡水就说明普通种普遍耐水 | [N39](../novel-reading/cards/N39.md)保留其作品版本；不能覆盖 N09、EH35 的进水风险，更不能仅凭体型叫作家油 |
| 修窝和赠屋意愿足以证明普通群体共同建造 | [N40](../novel-reading/cards/N40.md)有能力强化背景，且未展示正式交接；只索引已写出的检查、修整和粮库整理 |

## 下一批要补的证据

帽船还缺连续登离、靠岸和载幼睡眠的多角度画面；茎果还缺不受伤害干扰的连续发育图；家油缺自然破壳完整过程；身体恢复缺同一作者连续前后对照。现有参考不填充这些空白。普通巨型 DOS、角色背面与翼根、各季修窝和储粮继续按内容寻找不同作者作品。
