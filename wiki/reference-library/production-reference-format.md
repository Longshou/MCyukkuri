# 单图与画格参考

[游戏参考库](README.md) · [造型与动作参考](production-briefs.md) · [术语表](../glossary.md)

制作代理可按种族、动作、表情、身体状态或场景查[画面证据](image-evidence.md)。对白气泡另按[作品对白证据](../hakkei-reference/dialogue/evidence.md)登记。

一条参考对应一幅独立画面。原页只有一幅画时直接引用原图。同页有上下两幅独立画面时按两格处理，留白也可作分界。一格内的多人互动或同一动作的连续示意保留在一起。每页最多选两格，每格单独裁出，保留主体和判断姿态、接触点或道具结构所需的部分。裁图与索引放在一起，索引保留原图路径和裁框，方便回查原页。

| 字段 | 标注内容 |
| --- | --- |
| `subjects` | 主体的 `species` 和 `stage` 成对填写。种族沿用实体索引的油库里名称，如灵梦、魔理沙、橙、壳魔理沙、水上魔理沙。混合种族按参与参考的主体列出各自可辨的种族，同一组合只记一次。可辨为油库里而种族不明时用「通用油库里」。阶段用胎体、实子、赤油、子油、亚成油、成油，只有相对体型时可在说明里写大小差，阶段留空。纯道具或场景图的主体留空。 |
| `action` | 沿用行为动作标签，如移动跳跃、嘴叼搬运、辫子持物、帽船活动、照料喂食、进食、问候蹭脸、休息睡眠。 |
| `expression` | 沿用情绪标签，如喜悦、安心、恐惧、担忧、期待。 |
| `body_state` | 肉眼可见的身体状态，如鼓腮、拉伸、压扁、离地、贴地、失饰、茎上。 |
| `prop_scene` | 与制作要点有关的场景或正在使用的道具，如帽船、草窝、软窝、树叶襁褓、水面、岸边、洞口。书、书架和勺子只在参与动作或形成具体场景时登记。 |
| `view` | 正面、前侧、侧面、后侧、背面、俯视、仰视；局部有需要时加「特写」。 |
| `usefulness` | `art` 用于轮廓、比例、表情、附件或场景结构；`motion` 用于读得出的动作姿态、方向、受力或接触点；`both` 用于两类要点均可直接观察的画面。 |
| `copy_note` | 一句中文写明可照着做的细节，例如「起跳时本体前倾，运动线从帽檐接触点斜向上。」 |

标签针对入选画面中的制作要点填写。对白、旁白和背景人物无需登记。草图中能看清的轮廓、表情或接触点同样可作参考，辨不清的标签留空。主体和制作要点都无法读清或仅靠剧情文字才能说明的画面跳过。动作画格可提供一个清楚的关键姿态，速度和完整时序需另有依据。

画面须有油库里，或提供可直接参考的场景或器具使用方式。无主体的条目可记录场景布局、构造和用途，例如连接各巢室的观察屋；单独摆放的普通物件省略。

每个原图路径 `path` 对应一组 `units`。完整图的 `crop` 为 `null`；裁格的 `crop` 用原图像素 `[left, top, right, bottom]`，左上角为原点，右下边界不包含在裁图内。裁框只能估算时，用 `crop_hint` 简述画格位置供复核。跳过时 `units` 为空数组，`skip_reason` 写一句原因。

用 `python scripts/wiki_reference_topics.py production wiki/reference-library/evidence.json --output-dir <预览目录>` 生成筛选页。页面、裁图和供回查的原图副本都保存在预览目录。
