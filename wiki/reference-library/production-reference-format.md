# 单图与画格参考

[游戏参考库](README.md) · [造型与动作参考](production-briefs.md) · [术语表](../glossary.md)

一条参考对应一幅独立画面。原页只有一幅画时直接引用原图。漫画页最多选两格，每格单独裁出，保留主体和判断姿态、接触点或道具结构所需的部分。裁图与索引放在一起，索引保留原图路径和裁框，方便回查原页。

| 字段 | 标注内容 |
| --- | --- |
| `subjects` | 主体的 `species` 和 `stage` 成对填写。种族沿用实体索引的油库里名称，如灵梦、魔理沙、橙、壳魔理沙、水上魔理沙；可辨为油库里而种族不明时用「通用油库里」。阶段用胎体、实子、赤油、子油、亚成油、成油，无法从画面判断时留空。 |
| `action` | 沿用行为动作标签，如移动跳跃、嘴叼搬运、辫子持物、帽船活动、照料喂食、进食、问候蹭脸、休息睡眠。 |
| `expression` | 沿用情绪标签，如喜悦、安心、恐惧、担忧、期待。 |
| `body_state` | 肉眼可见的身体状态，如鼓腮、拉伸、压扁、离地、贴地、失饰、茎上。 |
| `prop_scene` | 与制作要点有关的物件或环境，如帽饰、帽船、草窝、纸箱、软窝、树叶襁褓、书本、木棍、水面、岸边、洞口。 |
| `view` | 正面、前侧、侧面、后侧、背面、俯视、仰视；局部有需要时加「特写」。 |
| `usefulness` | `art` 用于轮廓、比例、表情、附件或场景结构；`motion` 用于读得出的动作姿态、方向、受力或接触点；`both` 用于两类要点均可直接观察的画面。 |
| `copy_note` | 一句中文写明可照着做的细节，例如「起跳时本体前倾，运动线从帽檐接触点斜向上。」 |

标签针对入选画面中的制作要点填写。对白、旁白和背景人物无需登记。保留能单独指导一项造型或动作工作的画面；过小、遮挡严重或仅靠剧情文字才能说明的画面跳过。动作画格可提供一个清楚的关键姿态，速度和完整时序需另有依据。

每个原图路径 `path` 对应一组 `units`。完整图的 `crop` 为 `null`；裁格的 `crop` 用原图像素 `[left, top, right, bottom]`，左上角为原点，右下边界不包含在裁图内。跳过时 `units` 为空数组，`skip_reason` 写一句原因。
