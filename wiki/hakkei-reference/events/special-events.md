# 八景与作品事件

[世界背景与设定](../world/README.md) · [生活情景](../world/events.md) · [传统母题](traditional-motifs.md)

本页保留八景 U 的故事题材与其他作品的情节见证。八景部分按已有资料概括，不把社区暂称、未明确的季节或发生率写成统一规则；其他作品的结局只属于相应篇章。

## 八景故事

| 事件 | 人物、情景与后果 | 设定边界 |
| --- | --- | --- |
| 魔理沙探险队 | 队长带着队员出发、搜索并遭遇外界危险；队员与队长有不同反应 | 不固定为三只，也不保证每次遇到同种敌人；队长身份不等于超能力 |
| 森林偶像与观众 | 偶像表演，观众回应；偶像被带走时，观众可能震惊、哭喊，受到攻击也可能逃跑 | 不据此设定固定演出日程、任意点歌或长期追星制度 |
| 相扑挑战 | 两只个体相互挑战，经过准备、交锋与胜负反应 | 败者可能受伤或发生致命事故，不能一概称为无伤游戏；锦标赛和奖品不是必备背景 |
| 姐妹乞食与恳求 | 两只幼体姐妹在巷道中发抖、乞食，投喂后继续产生回应与恳求 | 社区常联系“纸箱姐妹”或圣诞题材，不能据名称认定固定节日和全部布景 |
| 单亲家庭求食 | 母亲带着幼体向人类求食，投食与不同回应影响后续态度 | 并非所有选择都是救助，也不保证正向结局 |
| 帽船漂流与岸边追赶 | 魔理沙蜷在帽船中漂流，同伴沿岸追赶、呼唤；落水或目标消失会造成危险和分离 | 帽船提供浮力，本体仍怕水；河流与湖泊情景分别理解，不预设必然获救 |
| 家庭求饲养与分离 | 个体请求饲养，亲属对其被带走作出请求或分离反应，放回后可能再次求养 | 个体被收养不等于全家同时获得收容，也不保证家人能够一路跟随 |
| 弃养后的醒悟或离去 | 原先家养的个体被放出，有的得意离去，有的惊讶哭喊；认知、亲近程度、性格和年龄影响反应 | 不预设会找回主人、跨地点追踪或再次重逢 |

八景社区[《外出》](https://wikiwiki.jp/yukkuri8kei/外出)提供偶像、求食、漂流和姐妹题材的名称线索；其名称、季节描述属于该页版本。探险队另有作者[历史问答](https://marshmallow-qa.com/messages/65af0e0c-8868-4985-8523-c900a685830c)及[《まりさ探検隊!》第 1 话](https://yukkurimanga.blog.jp/archives/11775887.html)的作品见证。该漫画中的具体编制与后果不视为八景的通用剧情。

## 其他作品中的连续故事

| 题材 | 具体作品中的过程与结局 | 阅读边界 |
| --- | --- | --- |
| 多种族接力 | [《都会生态·工作（后篇）》](https://w.atwiki.jp/yukkuri_gyakutai/pages/5043.html)有跑动、魔理沙交棒、帕秋莉解题与橙冲刺的分工，另含游泳和残酷淘汰赛 | 游泳属于该篇能力，全篇不能概括成友好运动会 |
| 离巢与第一次造屋 | [《第一次独居》](https://w.atwiki.jp/yukkuri_gyakutai/pages/1626.html)描写家人送别、造屋受风雨破坏、调整方案建成，随后住所被夺，主角遇害 | 离巢者尚未完全生殖成熟，离巢情节不是统一成年标准 |
| 街头卖艺与演出邀约 | [《乞食灵梦的歌》](https://w.atwiki.jp/yukkuri_gyakutai/pages/5226.html)包含灵梦唱歌、魔理沙卖艺；魔理沙受邀参加危险电视表演后坠落死亡，同伴继续街头求生 | 不是必然成名的故事，高空技巧也非全种天赋 |
| 流浪油强盗团 | [《一些流浪油库里的故事》](https://w.atwiki.jp/futabayukkuriss/pages/59.html)描写结伙袭击、尾随宠物、企图侵入住宅，入侵者最后遭人类杀害 | 文末关联テンタクルあき作品集并注明基于ありす13あき的图；文字记录不替代图片证据，流浪身份不等于强盗本性 |
| 集体建屋与塌巢 | [《油库里公寓》](https://w.atwiki.jp/futabayukkuriss/pages/1558.html)中个体驱走原住者、集体挖掘多层巢，繁殖增加空间需求，长雨中继续扩挖，最终崖体坍塌 | 是一篇事故故事，不代表所有群居住所必然坍塌 |

探险、送行、表演、家庭求助和聚落危机都可作为创作母题。另写救援、返家、重逢或撤离结局时，应视为原创情景，不反过来替换原篇后果。
