# 事件与生活情景

[世界背景与设定](README.md) · [性格与社会关系](personality-social.md) · [资源与生活生态](resources-ecology.md)

生活情景连接真实的个体、关系、地点与资源。下列日常情景是本设定的原创素材，不作为传统原作引文；八景故事和其他作品另列于[作品事件](../events/special-events.md)。

## 觅食、家庭与相处

| 情景 | 背景与展开 |
| --- | --- |
| 闻嗅觅食 | 饥饿的个体寻找当地仍有的零星食物 |
| 把一口分给同伴 | 亲属、亲近或体贴的个体在饥饿中让出一部分食物 |
| 抢走发现的食物 | 食物被贪占者或敌对个体看见，引发争抢 |
| 亲代回头等孩子 | 亲代发现幼体落在后面，停下回望 |
| 同胞模仿游戏 | 有体力的同胞幼体互相模仿动作 |
| 伴侣相互确认 | 没有陷入敌对的配偶彼此靠近、回应 |
| 停下来陪弱者 | 有余力的同伴放慢脚步，陪体力不足者休息 |
| 大个子让出空隙 | 体型较大的个体给小个体留出位置 |
| 相看两厌 | 已有敌意的个体在相遇时表现不满或回避 |
| 三只挤在一起 | 狭小空间中的同伴协商位置，也可能互相嫌挤 |
| 跟着做一次 | 幼体跟随较有经验的个体学习，尝试不保证成功 |
| 异种互学口癖 | 没有敌意的不同种族因好奇模仿对方的声音 |
| 陪着寻找饰物 | 失饰个体得到关照，旁人能否认出它仍看观察者的金章 |
| 等慢慢跟上的它 | 亲近或体贴的同伴等待行动较慢的不足油 |
| 这块地方归谁 | 大胆且贪占的个体与不亲近者争执领地 |
| 孩子叫住亲代 | 幼体呼唤走远的实际亲代，识别条件另看饰品 |
| 饿着肚子的请求 | 饥饿者向附近个体求食，结果取决于对方意愿和食物 |
| 同伴轮流张望 | 不安的个体与熟悉同伴互相照应 |
| 争执后的试探 | 争抢之后，仍有体贴余地的一方试探着缓和关系 |
| 同群成员商量先后 | 同一族群按饥饿、关系与社会地位商量顺序 |

亲子、同胞、配偶和族群称呼依照实际关系。亲友失饰时，无金章者仍不能认出；关照陌生人并不需要先把对方认作自己的家人。

## 人类介入后的回应

| 情景 | 背景与展开 |
| --- | --- |
| 投食后的回望 | 真正接受投食后，个体回看人类或旁边同伴 |
| 劝说后的缓和 | 正在争执的个体听到温和说话，可能逐渐停下来 |
| 被喝斥后停止争抢 | 争抢者因冷言或喝斥停手，可能害怕、委屈或不服 |

这些后续来自实际发生的投食或说话。请求食物不是已经吃到，安慰也不能代替食物、治疗或庇护。

## 宝物被夺

| 情景 | 背景与展开 |
| --- | --- |
| 收藏物被夺走 | **[L36 楼中补充 No. 11518880](https://komicolle.org/c/40720#r11518880)：** 失主可能哭泣、害怕或不信任夺物者；同族间还可能留下怨恨。物件必须先被个体认作宝物，失去才带有这层关系后果；这是单条社区补充，不规定固定反应或一套普遍冲突流程 |

## 地点中的遭遇

| 情景 | 背景与展开 |
| --- | --- |
| 小屋门口让位 | 小屋旁的两只个体互相让路或争位置 |
| 一起试探人偶 | 对同一人偶，好奇程度不同的同伴各自观察 |
| 墓地里放轻动作 | 来访者安静观察、放轻活动；不据此补造死者亲缘 |
| 街边短小表演 | 活泼个体与附近观众相互回应 |
| 街边争一口碎食 | 饥饿者争夺街边有限的食物碎屑 |
| 巷口嫌弃与饥饿 | 污脏或饥饿的个体在嫌恶与求生之间取舍 |
| 墙角能挤几只 | 两三只个体在角落里协商依偎、空间与距离 |
| 观众接上一声 | 观众响应正在表演的偶像 |
| 林中找食物与误判 | 觅食判断可能成功，也可能认错或找不到 |
| 林间清点家人 | 一家人逐个呼唤、回应，确认有谁仍在附近；失散后的搜索者、接回者与结果分类见[失散、搜寻与重聚](../../wild-life.md#失散后的临时落脚与同伴回应) |
| 探险队互相报到 | 队长和队员相互应声，继续面对实际的外界危险 |
| 公园里商量跟随 | 家人对亲近人类的意愿不同，彼此商量去留 |
| 公园动作比试 | 体力充足的个体比较动作与速度 |
| 岸边追赶者与漂流者 | 同伴沿岸追赶帽船中的个体，距离与水流影响回应 |
| 雨里挨近一点 | 雨中同伴愿意靠拢，也可能因关系而拒绝 |
| 湖上别乱动 | 漂流者为了帽船稳定而缩紧身体，仍有进水风险 |
| 热得停下来的同伴 | 炎热让个体疲惫、停步，健康和体型影响表现 |
| 姐妹互相让一口 | 饥饿的姐妹等待投食，得到食物后可能互让 |

## 认屋与住所宣称

**W：[F07](https://yukkuri.fandom.com/wiki/Home_Declaration)** 把认屋写成野生、侧沟与宠物都会出现的宣称行为，并给出一套围绕空巢、屏障与原住户展开的规矩；下文为该页的写法。

| 主题 | 作品记录 |
| --- | --- |
| 宣称内容 | 单只或一家宣称某处「悠闲之地」归自己；亲代宣称时幼体为它欢呼，即使体型使它无法实际参与 |
| 两个用途 | 一是了结所有可能的争议；二是以占有的住所自夸比同类更「悠闲」、地位与食物更好 |
| 空巢判断 | 发现无人使用的巢穴便带家人搬入，宣称后无人应答即认定为空巢，包括只是暂离的巢 |
| 屏障 | 枝条与石子屏障被当作产权标记，成体每次外出都应重设；没有屏障的巢被视为空巢或无人照料 |
| 守家 | 无力或不愿设屏障的个体把尚不能远行的幼体留在家看守，风险是入侵者把拒绝承认入侵的幼体压死 |
| 主动夺取 | shithead 个体以原住户「是垃圾」为由入侵；已经建好的石泥小屋会被强势个体直接占走 |
| 侧沟版本 | 巢穴换成垃圾箱、涂蜡纸板箱与自动售货机缝隙；纸板箱忘记盖护层便受潮失去住所 |
| 人类住宅 | 破窗进入空屋并宣称所有权、拒绝承认回来的住户；人类以「一起悠闲一下」取得信任后再处理 |
| 宠物版本 | 刚买入的幼体首次进入笼舍即宣称该处为自己的悠闲之地，并允许主人共享 |

**I：** 该页把认屋的冲突来源分成三处：空巢判断、屏障是否成立与入侵者的自我正当化；后续可以是交涉、驱逐、共同使用或人类介入。

**P：** 项目里的家是被勘测认可的区域（门洞格有顶、两面以上土石岸、洞内可站格 ≥5），门洞格保持空着，储粮堆在入口外的侧格；细枝屏风由聪明自制的野生灵梦用嘴推塞，不挡雨也不防御。家园宣言采用破窗进入空屋的情节，范围限野生成体与玻璃板；具体选择、权限与后果见[功能说明](../../../docs/FEATURES.md#野外事件)。
