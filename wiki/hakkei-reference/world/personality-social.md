# 性格与社会关系

[世界背景与设定](README.md) · [个体与生命过程](individuals.md)

本设定以先天倾向和后天经历共同解释个体差异。性格、认知能力、当下情绪与社会待遇分别记录；不能用一个标签代替四者。

游戏已采用利己性、攻击性、依恋性、自制力四轴，见[当前实现与历史设计](../../../docs/PERSONALITY_DESIGN.md)及[实现状态导航](../../implementation-status.md)。旧六倾向与十六型是设计历史，不再作为当前数值体系或游戏人格分类；好奇／大胆等历史偏好仍可能保留，不能误称所有旧字段均已删除。

## 当前四项倾向

| 倾向 | 影响的行为 |
| --- | --- |
| 利己性 | 资源分配时优先自己还是愿意分享；不等于认知高低 |
| 攻击性 | 冲突中威吓、反击的倾向；不等于勇敢或体型 |
| 依恋性 | 接近熟悉对象、寻求陪伴和支持的倾向；不代替具体好感关系 |
| 自制力 | 等待、克制即时冲动与教学耗时；不等于固定善恶 |

子代的先天倾向受亲代影响，同时保留自身差异；亲代后来学到的性格变化不直接视为遗传。经历可以缓慢改变当前倾向，种族和口癖不会随人格标签一同改变。

## 成长经历与情绪

下表是叙事上的可能反应，不是每个事件都必然改变同名数值的承诺。当前事件如何更新四轴，以实现文档为准；作品例证见[学习、识别与社会评价](../lore/learning-social.md)。

| 经历 | 常见影响方向 |
| --- | --- |
| 被照料 | 更愿意亲近，对环境和同伴更有安全感 |
| 受伤 | 更谨慎、退缩，耐心和交往意愿可能下降 |
| 受惊 | 更警觉，探索和冒险意愿可能降低 |
| 正向交往 | 更愿意接近、分食或等待同伴 |
| 探索 | 可能积累环境知识和行动信心 |
| 教育 | 提供练习、规则与反馈；效果受个体和环境影响 |
| 被拒斥 | 减少主动接近，可能更冷淡或缺乏耐心 |
| 持续饥饿 | 更急躁，交往与体贴可能让位于求生 |
| 安稳生活 | 安全感、耐心和亲近意愿逐渐恢复 |

幼体通常更容易受成长经历影响；成体仍可改变。恐惧、紧张、恶心与人格分别理解：暂时害怕不等于先天胆小，臭味引起的不适也不等于恶劣个性。

饥饿、明显恶心或高度紧张时，探看、玩耍和教学可能暂缓，觅食、求助和避险更迫切。能够认出的亲友在场并实际回应，有助于缓解不安；敌意、距离或对方自身的恐惧会妨碍这种支持。

## 饰品、金章与身份识别

以下是本项目采用的识别规则。小说中的失饰排斥与徽章制度是不同证据，不能说所有原作都实行“金章观察者例外”；见[失饰与评价的证据边界](../lore/learning-social.md)。

无金章的观察者依靠饰品认人，不能认出失去饰品的个体。例外看的是观察者是否有金章，目标自己的金章不能替别人完成识别。金章资格与单纯的聪明程度也不是同一件事。

亲子、配偶、朋友和同族群成员同样受此限制。饰品恢复后可以重新认出；真实血缘、过去的相处和已有感情并未消失。记得某位亲友与认出眼前这只油库里，是两个不同问题。

无饰品个体更容易遇到困惑、轻蔑、嫌弃或鄙视，也可能被当成“嗯嗯奴隶”。被对待的一方可能委屈、退缩、自卑或出言反抗，反应受性格和处境影响。这是一种可能的社会态度，不表示所有失饰个体都必然获得同一身份。

## 亲缘、好感与族群

| 关系 | 含义 |
| --- | --- |
| 血缘 | 亲子、同胞、半同胞、祖孙与堂表亲，依照实际家系确定 |
| 配偶 | 配对关系，与血缘或朋友关系分开 |
| 好感 | 可以不对称：甲喜欢乙，不保证乙也同样喜欢甲 |
| 朋友 | 经过长期、双向、反复的有效相处形成；同种、同住或一时高好感不足以等同友谊 |
| 敌意 | 可单方面存在，争执或伤害可能破坏友好，但不会抹去血缘 |
| 族群 | 共同生活与组织关系，家庭可以形成群体，同场出现不等于同群 |
| 职位 | 自由个体、成员、首领、被排斥者与嗯嗯奴隶等社会处境 |

体型大或属于 DOS 不自动成为首领。族群职位、个人品行与种族名称分开；流浪或贫困也不等于天生恶劣。

因失饰而被蔑称“嗯嗯奴隶”，与反复被迫食糞形成的受压迫处境有所区别。普通搬运、自由觅食不能一概视为同一种经历。摆脱强迫、获得持续温和对待可以改变处境，亲缘不会因此被取消。

冲突中的畏缩、顶嘴、反击或退让，取决于双方体型、健康、性格、恐惧和信心，不是只按种族或单一人格标签决定。
