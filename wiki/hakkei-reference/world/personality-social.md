# 性格与社会关系

[世界背景与设定](README.md) · [个体与生命过程](individuals.md)

个体性格由先天倾向与后天经历共同形成，并与认知能力、当下情绪和社会待遇一起塑造具体行动。

游戏当前采用智力、友善、胆量、依恋、自制五项行为属性；旧六倾向、十六型和四轴表述均为此前设计资料。现行数据、公式和试玩边界见[行为、成长、遗传与认知](../../../docs/FEATURES.md#行为性格与成长)。

## 项目当前行为属性

| 倾向 | 影响的行为 |
| --- | --- |
| 智力 | 影响学习、食物辨识和失饰辨识 |
| 友善 | 影响分享、照料、帮助、救援与冲突升级倾向 |
| 胆量 | 影响面对陌生和危险时的退避与探索 |
| 依恋 | 影响接近熟悉对象、寻求陪伴与支持的倾向 |
| 自制 | 影响等待、已学规则的遵守和练习段数 |

子代的先天倾向受亲代影响并保留个体差异；成长经历逐渐改变当前倾向，种族和口癖沿自身设定发展。

## 成长经历与情绪

成长经历常见的影响方向如下；具体事件如何更新五项属性，以[行为、成长、遗传与认知](../../../docs/FEATURES.md#行为性格与成长)为准。作品例证见[学习、识别与社会评价](../lore/learning-social.md)。

| 经历 | 常见影响方向 |
| --- | --- |
| 被照料 | 更愿意亲近，对环境和同伴更有安全感 |
| 受伤 | 更谨慎、退缩，耐心和交往意愿可能下降 |
| 受惊 | 更警觉，探索和冒险意愿可能降低 |
| 正向交往 | 更愿意接近、分食或等待同伴 |
| 探索 | 可能积累环境知识和行动信心 |
| 教育 | 提供练习、规则与反馈；效果受个体和环境影响 |
| 被拒斥 | 减少主动接近，可能更冷淡或缺乏耐心 |
| 持续饥饿 | 更急躁，交往与体贴可能让位于求生 |
| 安稳生活 | 安全感、耐心和亲近意愿逐渐恢复 |

幼体通常更容易受成长经历影响，成体也会改变。恐惧、紧张与恶心是当下状态；稳定倾向则描述较长期的行为模式。

饥饿、明显恶心或高度紧张时，探看、玩耍和教学可能暂缓，觅食、求助和避险更迫切。能够认出的亲友在场并实际回应，有助于缓解不安；敌意、距离或对方自身的恐惧会妨碍这种支持。

## 不安、甜化与非油症

**W：[F01](https://yukkuri.fandom.com/wiki/Anti-yukkuritis)** 把「不能慢慢来」的持续处境写成抑郁：住在脏污的嗯嗯堆里、长时间独处、被迫吃不合口的食物、被口头辱骂，甚至被叫错名字都可能引起；表现是越来越不愿行动、只想躺着等死，末期压力还会让它吐出馅料。页面给出的解法是改善住所与食物、让它重新被安慰，并提醒安慰孤单幼体可能养大脾气、长成 shithead。项目把不安记成 0–100 的连续值，≥60 甜化、≥95 持续发病为非油症，发病后不可逆，见[情绪链](../../../docs/FEATURES.md#情绪链)。

**W：[F20](https://yukkuri.fandom.com/wiki/Yukkuri_insanity)** 是写给饲主的症状清单：不停哭、躲在角落不玩、说看见不存在的东西被列作「疯了」的迹象，建议交给油库里兽医处理、术后每周复诊，或者直接退回商店。项目没有兽医治疗与非油症的痊愈路径：发病后进入狂乱与衰竭，最后由病变损坏中枢死亡；发病前的不安可由安抚、进食和取回饰物等降低。

## 饰品、金章与身份识别

饰品是常见的身份标记；作品中的失饰待遇与徽章制度各有写法。本项目采用的识别规则见[失饰与评价的作品依据](../lore/learning-social.md)。

无金章的观察者依靠饰品辨认个体；识别例外取决于观察者持有金章，金章资格由综合考核形成。

恢复原饰物后，亲友可以重新辨认；亲缘、共同经历与感情关系保持连续。

无饰品个体更容易遇到困惑、轻蔑、嫌弃或鄙视，也可能被当成“嗯嗯奴隶”。被对待的一方可能委屈、退缩、自卑或出言反抗，反应受性格和处境影响。这是一种可能的社会态度，不表示所有失饰个体都必然获得同一身份。

## 亲缘、好感与族群

| 关系 | 含义 |
| --- | --- |
| 血缘 | 亲子、同胞、半同胞、祖孙与堂表亲，依照实际家系确定 |
| 配偶 | 配对关系，与血缘或朋友关系分开 |
| 好感 | 可以不对称：甲喜欢乙，不保证乙也同样喜欢甲 |
| 朋友 | 在长期、双向、反复的共同相处中形成，可跨越种族与居住地点 |
| 敌意 | 可单方面存在；争执与伤害会改变交往，血缘关系仍按家系记录 |
| 族群 | 以共同生活与组织关系界定，家庭也可以形成群体 |
| 职位 | 自由个体、成员、首领、被排斥者与嗯嗯奴隶等社会处境 |

族群首领职位通过群体关系形成；体型、DOS 身份、品行和种族名称各自记录。流浪与贫困描述生活处境。

“嗯嗯奴隶”一词既用于失饰后遭蔑视的个体，也用于反复被迫食糞、处于受压迫关系的个体；后者经历强迫劳动与支配。摆脱强迫并获得持续温和对待，可以改变其社会处境，亲缘关系仍然延续。

冲突中的畏缩、顶嘴、反击或退让，取决于双方体型、健康、性格、恐惧和信心，不是只按种族或单一人格标签决定。

## 品行评价与族群组织

**W：[F15](https://yukkuri.fandom.com/wiki/Shithead)** 用 shithead 统称品行恶劣的个体：自私、无礼、不听人类、亲代、幼体和 DOS 的话，反面对应是 nicehead；页面称这类个体常占友善家庭的便宜，也会联手闯入别人的家，还说近年城市里的数量增多、容易被人类和清除行动针对。项目不设固定的品行类别，只有友善、自制等连续属性与实际行为记录，评价由在场个体按行为与关系给出。

**W：[F19](https://yukkuri.fandom.com/wiki/Yukkuri_Clan)** 把族群写成数个家庭的合作单位：各家自行掘巢、围出中央空地，有特殊能力的个体得到更大的巢，油库里艾琳的巢兼作诊所，部分族群另设幼体托育处。首领 DOS 体型更大，页面称其可使用「大师火花」一类能力，由帕秋莉筹划、魔理沙管狩猎与配给、四季映姬任裁决的议会协助；首领职位多为世袭，违规者常被判死刑或流放，并称多数族群约三代而衰。城市族群沿用同样规则，人工族群以饲主充当 DOS、由成员推选议会。项目聚落的族长按智力、自制与在场时长继任，设族规、公仓、共同狩猎与迁徙，处罚到驱逐加欺负为止，也不设超自然能力，见[聚落、族规与迁徙](../../../docs/FEATURES.md#聚落族规与迁徙)。
