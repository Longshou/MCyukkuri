# 资源与生活生态

[世界背景与设定](README.md) · [基本设定](rules.md)

油库里的生活依赖食物、庇护、清洁、同伴与身体状态。不同地点的资源和危险不同，食物、筑巢材料与身体产出的馅也各有来源。

## 食物与馅料

普通种杂食，草、昆虫和人类食物是作品中常见的食物来源；适口性、营养与个人偏好并不相同。共同觅食可能发展成分食、争抢、教学或求助，食物不足时也可能引发矛盾。

| 来源种族 | 本设定的馅料称呼 |
| --- | --- |
| 灵梦、魔理沙 | 豆沙馅 |
| 爱丽丝 | 卡仕达馅 |
| 橙 | 巧克力馅 |
| 尚未明确的种族或亚种 | 馅 |

成分与产出方式分开。伤口漏馅、呕出、遗体中的馅、亲代献身及排便不是五种新的馅料成分；眼睛、鬓发等身体部位也不能自动视为可食的馅。中枢馅和甜点材质的异作描述见[身体与馅料出处](../lore/entities-sources.md)。

一份馅的数量、甜度、营养和气味各有区别，不用“越多就一定越甜”解释一切。产出者后来长大，不会让已经离体的旧馅同步增大。取食会消耗实际食物，搬运或含在嘴里不会凭空多出一份。

新鲜漏馅、受伤吐馅和亲代献身馅不臭。真正有臭味的馅可引起嫌恶，但极度饥饿仍可能使个体勉强进食。角色是否知道其来源，取决于目击或告知；一个未目击的后来者可能先尝到甜味，再听到熟人的提醒。

“请吃了我”属于亲代在危机中献身的母题，牵涉亲子、饥饿、告别和食用禁忌的例外。具体作品有不同过程与结果，也有同句用于喜剧增殖的版本，不能全部合为同一种生理规律。详见[相关作品记录](../lore/entities-sources.md)。

## 家油、巢与卵

家油是寄居人类室内的微小非宠物油库里，常见灵梦和魔理沙形象。它们躲在家具缝隙或角落，夜间寻找碎食，收集棉絮、灰尘等筑巢材料。食物碎屑与筑巢材料用途不同。

家油在巢内产卵，卵与亲代及所属巢相关；幼体从卵内破壳后成为独立个体。部分资料描述糖壳状卵、睡眠区与卵区分开，这些细节的来源可信度与作品范围见[家油、巢穴与卵](../lore/house-nest-sources.md)。

巢受到清扫、损坏或环境变化会影响其中的卵；已经出生的幼体仍有自己的去向，不能因原巢消失就认定全部死亡。捕捉、迁出、失散与死亡也是不同结果。普通宠物不会仅因进入室内就成为家油。

## 住所与环境

具体作品的离巢、材料、巢址、季节与迁徙见[住所与季节生活](../lore/habitat-seasonal-life.md)；可直接查阅的漫画画格见[住所与设施参考](../../art-references/visual-guide.md#住所道具与人类设施)。

| 环境 | 生活条件与情景 |
| --- | --- |
| 饲养环境与小屋 | 投食、休息、接近人类、邻居让位、探索物品 |
| 家具缝隙与室内角落 | 家油藏身、搜寻碎食、筑巢、育卵与清扫风险 |
| 森林 | 采集、辨认食物、清点家人、探险与外界危险 |
| 街道与小巷 | 零星食物、争抢、污脏、求食、卖艺与有限庇护 |
| 公园 | 家庭活动、接近人类、求饲养与动作比试 |
| 河岸与湖面 | 帽船漂流、沿岸呼唤、失散与落水风险 |
| 雨中与炎热地点 | 寻找遮蔽、挨近同伴、停步休息与环境伤害 |
| 墓地 | 来访、安静观察和放轻动作；不能仅凭来访认定与死者有亲缘 |

野外食物有限，采集和争抢改变当地余量；一次安慰不会产生食物，呼唤也不会消除落水伤害。帽船提供浮力，本体耐水另看种类与个体条件。

季节故事常围绕新芽、亲子采集、躲雨、秋日备粮、修窝、冬季分粮与迁居展开。住所质量、拥挤、食物消耗和持续风雨会共同影响家庭；巢穴不必然坍塌，也不能保证有屋顶就完全安全。

## 叶片、草与枝条的用途

多篇作品把植物材料放进日常生活，但具体用途不同，不能合成一种“叶子道具”：

| 材料用途 | 作品证据 | 能确认的范围 |
| --- | --- | --- |
| 睡床与保温 | [N35](../../novel-reading/cards/N35.md) | 一家用软草铺入口和深草床，粮食、睡位与铺层分别安排；不代表所有巢穴布局相同 |
| 采集后封巢 | [N38](../../novel-reading/cards/N38.md) | 家庭秋季收集叶枝备巢；未展示施工细节或防水效果 |
| 编织载物 | [N37](../../novel-reading/cards/N37.md) | 行商用编叶包袱携带交换物资；包袱不是穿戴衣物或襁褓 |
| 贴身包覆幼体 | [EH37 第 6 页](../../art-references/ehentai/works/EH37.md) | 两只幼体身上的叶片包层与下方承托大叶可区分；细节见[树叶襁褓资源](../../leaf-swaddle.md) |
| 临时挡水 | [N25](../../novel-reading/cards/N25.md) | 人类发现关入口仍渗水后加叶阻挡；不是油库里自主修窝或已验证的排水结构 |

**I：** 多个来源显示草木材料可进入睡眠、筑巢、搬运、育幼和临时遮护等生活环节；材料用途仍由具体形状和行为决定。贴身叶片襁褓目前只有 EH37 一处画面，属于已存在的作品变体，不能称为跨作品通行款，也不能由外形推定保温、防水、卫生或穿脱方式。

## 库存与食物知识的作品对照

**A：** [N59](../../novel-reading/cards/N59.md)把现成存粮和继续取得食物的能力分开：占巢者吃完库存才发现，不掌握原住者利用当地材料的知识。另一群落则会向有经验者提问。它补的是临冬消耗与误判，没有植物辨认特征、完整处理全程或冬季配给方案。

**P：** 可分别记录原料、可食状态、现有库存、已知处理办法与实际补充行动；住进旧巢不自动获得前住户的技能。这是制作归纳，本轮没有修改食物规则或新增配方。

[N67](../../novel-reading/cards/N67.md)进一步补到亲子问答后实际分拣、搬运的环节；库存也支撑了暂停外出采食的施工。**P：** 分类决定、库存来源和可持续补给分开；本例是夺巢所得物资，没有食物辨认特征与储后检验，不直接生成配方或保存期。

城市资源另见[专题](../../city-life.md)：N69 区分垃圾中存在食物与住户取得食物的能力；N37 区分持有商品与仍能联系客户。**P：** 资源点的可达性和交换对象的可用性可以变化，不以同一地点持续存在就推定稳定供给。

[N70](../../novel-reading/cards/N70.md)新增找到另一丰产地点并实际补足物资的例子。这里改变的是采集地点，不是食物种类；没有提供植物辨认特征或保存期限。**P：** 搜寻成本、地点产出、运回数量和后续消耗应各自有状态，不将“增加采集时长”设为必然解决短缺。

[N84](../../novel-reading/cards/N84.md)写到亲代分别传授食物知识和狩猎技能，幼体之后在外采集、筛选可食草，并将药草另存；这是知识应用的叙事结果，不是可复用的植物辨认指南。主角是罕见的まちょりー变异；其活动能力不能外推到普通帕秋莉。**P：** 可以分别记录讲解、外出尝试、分类与反馈，不从作品空缺处补造植物特征或处理配方。

[N71](../../novel-reading/cards/N71.md)的家庭按制作先后调整食物前后位置，叙述说明其目的是安排食用并避免腐坏；没有实际腐坏、辨识或处理结果。**P：** 可记录批次与摆放次序，但不据此设定保存期限、保鲜加成或严格跨食材先进先出规则。该家庭位于人为控制的实验室。
