# 个体与生命过程

[世界背景与设定](README.md) · [基本设定](rules.md)

一只油库里同时具有种族、身体、年龄、认知、性格、经历与社会关系。这些特征互相影响，但不能彼此替代。同名、同种或长得相像，不意味着是同一个体。

| 方面 | 设定内容 |
| --- | --- |
| 种族与亚种 | 外形及分类关系；魔理沙下的螺壳、被炉、DOS，以及灵梦下的多毛灵梦分别区分 |
| 先天外观 | 毛发、面部或豆形细长身体等差异；后天剃发、失饰和伤病不变成先天不足 |
| 年龄与体型 | 成长阶段与身体大小分别理解，普通大个体不自动成为 DOS |
| 身体与需求 | 饱食、体力、睡眠、伤病、健康与饰物状态决定当下活动能力 |
| 认知与语言 | 学习、判断与表达高度相关，但幼语和特殊声线允许跨年龄保留 |
| 性格与品行 | 好奇、合群、大胆、体贴、守序、耐心等倾向；骄蛮或恶劣行为另看个体 |
| 经历与情绪 | 照料、教育、探索、受伤、受惊、拒斥、饥饿与安稳生活会留下影响 |
| 亲缘与社会身份 | 父母、同胞、配偶、朋友、族群与职位分别成立，外观或种族不授予职位 |

出生与成长形成个体的生命历程，亲代影响先天倾向，后续相处与生存经历缓慢塑造性格。未知父母仍是未知，不能仅凭同巢、相似外观或附近的成体补造亲缘。

失去饰物可能使它暂时无法被亲友认出，也会改变它的社会处境和情绪；这不会改变其种族或实际父母。恢复饰物可以恢复识别，但不能把真实发生过的受伤、拒斥和失散当作从未发生。

家油是生活生态类别，不是宠物进屋后的新名字。不足油是先天外观类别，不是智力等级；多毛灵梦虽属于不足油，仍保留其独立的外形和性格定义。详见[形态与生态类别](../lore/species/forms.md)。
