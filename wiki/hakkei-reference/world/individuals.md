# 个体与生命过程

[世界背景与设定](README.md) · [基本设定](rules.md)

一只油库里同时具有种族、身体、年龄、认知、性格、经历与社会关系；这些面向共同形成个体。同名、同种或外形相似的油库里仍有各自的生活经历与关系。

| 方面 | 设定内容 |
| --- | --- |
| 种族与亚种 | 外形及分类关系；魔理沙下的螺壳、被炉、DOS，以及灵梦下的多毛灵梦分别区分 |
| 先天外观 | 毛发、面部或豆形细长身体等差异；后天剃发、失饰和伤病不变成先天不足 |
| 年龄与体型 | 成长阶段与身体大小分别理解，普通大个体不自动成为 DOS |
| 身体与需求 | 饱食、体力、睡眠、伤病、健康与饰物状态决定当下活动能力 |
| 认知与语言 | 学习、判断与表达高度相关，但幼语和特殊声线允许跨年龄保留 |
| 性格与品行 | 当前采用利己性、攻击性、依恋性、自制力四轴；骄蛮或恶劣行为另看个体，不按种族直接定性 |
| 经历与情绪 | 照料、教育、探索、受伤、受惊、拒斥、饥饿与安稳生活会留下影响 |
| 亲缘与社会身份 | 父母、同胞、配偶、朋友、族群与职位分别成立，外观或种族不授予职位 |

出生与成长形成个体的生命历程：亲代影响先天倾向，后续相处与生存经历逐渐塑造性格。亲缘以已知父母、同胞与共同生活关系为依据。

## 称名与个体认同

**W：** 高优先级综述 [L36 No. 11518829](../sources-lore.md)记录了「灵梦是灵梦」式的自我认同表达；有些作品里，外界给个体命名会被理解成否定其自我身份，带来强烈不适，甚至令幼体吐馅死亡。

称呼场景可呈现自称、种类称谓、亲昵称呼和外界命名，以及角色如何接受或抗拒。这些互动让名字成为家庭关系、群体归属与个体身份表达的一部分。

## 死亡信念与临终表达

**W：** 高优先级综述 [L36](../sources-lore.md)把“死后仍能在幸福之地继续慢慢来”列为常见信念，也记录了角色临终时表达仍想活着、继续慢慢来的愿望。它是家庭安慰、面对死亡和表达留恋时可用的信仰与对白母题。

**A（N117）：** 一篇单篇写到一只帕秋莉自然老衰离世，依她生前愿望安葬在山中；主人此后每周借休息日上山扫墓，带上她生前喜欢的咖啡果冻。故事把墓地、定期探望和喜爱食物的供奉写作这户家庭的纪念方式，可作为“老衰—安葬愿望—持续悼念”这一行为链的实例。

见 [N117](../../novel-reading/cards/N117.md)。

失去饰物可能使个体暂时无法被亲友认出，并改变其社会处境和情绪。恢复饰物有助于重建辨认；受伤、拒斥和失散仍属于它此后的生活经历。

家油描述室内微型栖居生态，宠物油描述与人类共同生活的关系；不足油则描述先天外观差异。多毛灵梦在不足形态之外还保有独立的外形与性格母题。详见[形态与生态类别](../lore/species/forms.md)。
