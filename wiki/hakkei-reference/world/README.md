个体的身体与需求决定它当下能做什么；性格、亲缘和相处经历影响它愿意接近谁、怎样回应。地点提供有限的食物与庇护，活动又改变资源、关系和后续生活。一次受伤、一次分食或一次失散，都可能成为之后行为的背景。

资料分为本设定、具体作品记录和原创情景示例。五项行为属性与饰品识别例外等项目采用不代表所有作品共同采用；现行数值见[行为、成长、遗传与认知](../../../docs/BEHAVIOR_BALANCE_DESIGN.md)。未明确的寿命换算、耐性阈值、繁殖率与特殊能力不补造数字。读游戏现状时另查[游戏文档索引](../../../docs/README.md)。
