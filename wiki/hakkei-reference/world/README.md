## 作品地点母题

社区 Wiki 的 Places 分类把幻想乡的地点当作油库里故事的活动舞台，与本设定的人类世界不同：

**W：[F47](https://yukkuri.fandom.com/wiki/Bamboo_Forest)** 写竹林在东方原作里对人类是危险地带，但油库里故事里几乎从不如此；少数作品写人从竹林捕一只油库里带回家。**W：[F48](https://yukkuri.fandom.com/wiki/Scarlet_Devil_Mansion)** 写红魔馆的馆主、住人与女仆，以及它在油库里故事里的用法：蕾米莉亚型与芙兰型的故事在这里发生，带胴体的蕾米莉亚型受女仆宠养、芙兰型以折磨蕾米莉亚型为乐，野生咲夜型会赶来见真馆主，蕾米莉亚型也会逃来求保护，东方人物帕秋莉·诺蕾姬则对油库里做实验。

**项目采用：** 幻想乡与东方人物身份不存在（[基本设定](rules.md)），地点也就不作为世界设施：可用的地形按真实群系（森林、竹林群系）和玩家或村庄实际建造的建筑，故事里的“某处”改由具体地形、建筑与个体关系承担。两页的地点母题与旧写法的差别记在[设定差异](../lore/conflicts.md)。

个体的身体与需求决定它当下能做什么；性格、亲缘和相处经历影响它愿意接近谁、怎样回应。地点提供有限的食物与庇护，活动又改变资源、关系和后续生活。一次受伤、一次分食或一次失散，都可能成为之后行为的背景。

资料分为本设定、具体作品记录和原创情景示例。五项行为属性与饰品识别例外等项目采用不代表所有作品共同采用；现行数值见[行为、成长、遗传与认知](../../../docs/FEATURES.md#行为性格与成长)。未明确的寿命换算、耐性阈值、繁殖率与特殊能力不补造数字。读游戏现状时另查[游戏文档索引](../../../docs/FEATURES.md)。
