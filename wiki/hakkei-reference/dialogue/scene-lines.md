## 日常群体

| 事件 | 两句短交换（均 P） | 拒绝/中止（P） |
| --- | --- | --- |
| 家园协商 | 新来者：“这里软软的，能做我的家先生吗？” 现住者：“这边可以，里面有人在油库里呢。” | “现在有点挤，先去旁边看看。” |
| 欢迎会 | 老住民：“油库里洗跌一跌捏！” 新住民：“油……可以坐近一点吗？” | “现在想先在这里油库里。” |
| 排队 | 幼灵梦：“窝也想吃介一块惹哟！” 同伴：“等我分开，就都有啦。” | “刚才分完了，我们等下一轮。” |
| 收藏 | 成体爱丽丝：“这片叶子的颜色，和你的很配哇。” 同伴：“给你看看，不过我还想留着。” | “今天先不换，下次再一起看哇。” |
| 歌唱 | 灵梦：“叶子摇呀摇，小窝暖呀暖。” 橙：“大家坐一起，瓦卡鲁哟，暖暖呀！” | “有人睡着了，我们轻一点。” |
| 运动会 | 魔理沙：“我先去终点等你贼！” 帕秋莉：“姆啾，这次走短的那边。”（P 场景候选；“姆啾”为音译候选） | “有点累啦，我来帮你们数。” |
| 找帽子 | 成体魔理沙：“油油？我的帽子在哪里贼？” 同伴：“在树根旁边，看见啦！” | “先别急，再看看附近贼。” |
| 配合步调 | 幼壳体魔理沙式：“窝会跟上惹杰，慢一点惹杰。” 同伴：“好，一起到那片叶子旁。” | “介条路太窄惹杰，换个地方。” |
| 花圃约定 | 幽香：“小花还在长，别从这里过去。” 觅食者：“那我走旁边，这样对吗？” | “这个记号还不懂，再指给我看吧。” |
| 陌生影子 | 幼体：“那里有什么在动……” 领队：“先别过去，我们一起退回来。” | “看不清，就先离远一点。” |
| 和好 | 一方：“刚才我拿得太快了，对不起。” 另一方：“下次记得等我一下。” | “我还想安静一会儿，晚点再说吧。” |
| 轮流带路 | 新手：“前面那一小段，让我试试好吗？” 熟人：“好，我就跟在你旁边。” | “先停一下，这里我也不认得。” |

歌唱例句为本库原创短韵文，识别短语单独保留；没有引用歌曲。普通内容不强行全音译，只有固定口癖保留其词形。

## 状态一致性替换（P）

- 食物为零：把“分你一块”换为“找到之后一起分”，避免与故事中的食物余量矛盾。
- 对象不在：用“等它回来再说吧”，不让空气回复；已经离开世界则“这次见面先结束吧”。
- 未知种族或变体：用意图相同的中性句；不追加猜测的口癖。
- 语言阶段未知：用简短完整句；不能凭外形把角色写成婴幼。
- 未建立亲属：用名字或“你”，不自动称“妈妈”“姐姐”。
