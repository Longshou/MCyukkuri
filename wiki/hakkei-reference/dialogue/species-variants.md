# 种族口吻与特殊变体

中文整句为本库原创示例（P）；固定词形及作品口吻见[对白来源](../sources-events.md)。幼语与种族语尾保留声音差异，不能仅凭口音判断智力。

种族归属、亚种关系及美术统一见[种族目录](../lore/species/README.md)；本页维护口吻、发音变体和对白候选。

口吻资料见[对白来源](../sources-events.md)。日文用于词语检索，中文整句为原创示例；旧版汉化词形与新拟音译分别标注。

本资料采用橙的成体音译“瓦卡鲁哟／瓦卡拉奈哟”、幼语“瓦卡呜哟／瓦卡呐奈哟”，称呼区分“蓝大人／蓝大银”。这些是原创中文表达（P），不是已确认的旧版汉化词形；称呼本身不说明东方人物存在。

不足油的原创声线可用“油嗶”短鸣和细长型的“油呜”节奏短句；面部不足仍保留原种与相应年龄的口癖。短鸣不等于低智，多毛灵梦的性格与教育困难也不等于失去认知或语言能力。

| わさ種 / わされいむ | E05 对成年形态有疑问，未提供唯一语尾 | 本资料沿用不足油分类及教育困难的性格版本，其他作品有不同写法；保留个体经历与相应年龄口吻 | “软软的介里……一起来惹哟。” |

| 细长不足油 | 豆形身体与长条种分开，短鸣为原创表达 | 可用“油呜”节奏短句，保留基础种族与语言阶段 | “油呜……等等窝惹杰。” |

| 紧张 / 疲劳 / 饥饿 / 亲近 | 属即时状态，不应伪装成新物种 | 先调句长、音量、动作；同一角色仍可辨认 | “我有点累……在这里歇歇吧。” |
| 独特昵称 / 单篇主角 | 昵称不能自动成为全变体通称 | 尊重个体偏好，使用相应称呼 | “今天也和你一起去。” |

## 组合优先级（P）

1. 对象有效性和当前意图：若目标食物不存在，不能说“真好吃”。
2. 个体称呼与真实关系：亲友称呼还需能认出对方，无金章者不能认出无饰品个体，不能凭血缘绕过。
3. 个体明确语言设定：例如已记录选择一种螺壳魔理沙口吻。
4. 基础种族口吻＋语言阶段。
5. 变体有证据的覆盖项；没有就继承。
6. 情绪与当前场景角色；一个领队可以害怕，一个幼体可以清楚说“不”。

例：“幼体＋魔理沙＋壳体＋胆怯＋跟队”可写“等等窝……窝也想看看惹杰。”；“成体＋帕秋莉＋健壮＋谨慎＋整理粮食”可写“姆啾，今天吃的分出来，剩下的收好。”；“成体＋橙＋不理解＋新住民”可写“瓦卡拉奈哟……这个记号，能教教我吗？”整句均 P；“惹杰”来自 D01，幼体沿用赤体为本库写作规则；“姆啾”为音译候选，橙的词形采用上述原创音译。
