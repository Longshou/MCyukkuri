# 通用短语与中文风格

中文整句为本库原创示例（P）；固定词形及作品口吻见[对白来源](../sources-events.md)。幼语与种族语尾保留声音差异，不能仅凭口音判断智力。

这里收录固定音译词形、阶段差异与 P 中文用法。来源：[E03、E04、E06、E10、E12、D01](../sources-events.md)。沿用旧版八景汉化的固定音译与刻意幼语，保留声音特征；D01 是旧版中文译形的历史记录。

## 短语索引

| 日文索引 / 来源 | 中文词形 / 身份 | 使用场景与避免误读 |
| --- | --- | --- |
| `ゆっくりしていってね`，D01 | **油库里洗跌一跌捏！**（旧版成体） | 识别性欢迎语保留音译，不替换成“一起悠闲吧” |
| `ゆっくち しちぇいっちぇにぇ`，D01 | **油库气洗切一切捏！**（旧版赤体） | “气/切”体现幼语，不修正成成体“里/跌” |
| `ゆ` / `ゆぅ` / `ゆゆっ`，D01 | **油…… / 油呜…… / 油油？**（旧版） | 保留声音，不换成“呦/唔”；标点按情绪 |
| `のぜ` / `のじぇ`，D01 | **贼 / 惹杰**（旧版魔理沙成体 / 赤体） | 同一种族也要区分成长口音，不一律用“呢/吧” |
| `わ` / `ぢゃよ`，D01 | **哇 / 惹哟、哟**（旧版爱丽丝成体 / 灵梦赤体） | 不跨物种硬套，不作为普通书面词纠错 |
| `ゆっくりしてる`，D01 | **可以油库里 / 能油库里**（旧版） | 保留“油库里”核心词；否定句依原意写“不能油库里”（P 构句） |
| `むーしゃむーしゃ`，D01 | **嚼嚼**（旧版，成体/赤体皆见） | 沿用既有固定译法；幼态整句其他词形仍保留，不自行重译为新音节 |
| `すーりすーり`，E06 | **擦擦脸／渣渣脸**（成体／幼体，D01 已核验） | 亲昵动作；本资料沿用旧版固定词形 |
| `ぷくー`，E04 | **噗咕——**（D01 已核验） | 配鼓脸动作；不是默认战斗宣言 |
| `あまあま`，D01 | **好甜好甜 / 搞甜搞甜**（旧版成体 / 赤体用例） | “搞”是刻意近音；不是错字，不统一成“好” |
| `しあわせ`，D01 | **幸福 / 粉幸福、幸胡**（旧版成体 / 赤体用例） | 保留原句选择；不把一个变体替代所有赤体句子 |
| `おちびちゃん`，D01 | **小贝比酱**（旧版） | 需要真实年龄/照看关系；体型小不必然是赤体 |
| `うんうん` / `おうちさん` / `いやだ`，D01 | **嗯嗯 / 家先生 / 不要哒**（旧版） | 定型词形保持 |
| `ごはんさん`，E03 | **饭先生**（中文译形） | 保留物品拟人；幼体保留“饭鲜笋”等近音变体 |
| `おうち宣言`，E10–E12 | **家园宣言**（术语）；“这里能做我的家先生吗？”（P 句） | 术语不是角色口癖；整句新写需说明身份 |
| `ゆっくりプレイス`，E12 | **油库里普雷斯／油库气普雷啾**（D01 成体／幼体译形） | 角色固定词不改成地盘或游乐场 |

表内日文仅用于定位。`むーしゃ` 的拖长、幼语替换以及同一词的汉字/假名写法均可能因作品变化。[E06 的作品](https://w.atwiki.jp/yukkuri_gyakutai/pages/4130.html)开头明确尝试汉字对白，故“只能用平假名”不是跨作品硬规则。

## 三阶段固定词形组合

| 概念 | 婴幼/赤体 | 幼体/子体 | 成体 | 证据/策略 |
| --- | --- | --- | --- | --- |
| 欢迎 | 油库气洗切一切捏！ | 油库气洗切一切捏！ | 油库里洗跌一跌捏！ | 两端来自 D01；幼体沿用赤体是本库写作选择 |
| 魔理沙语尾 | 惹杰 | 惹杰 | 贼 | 两端 D01；幼体 P 策略；不得全改“贼” |
| 核心词 | 油库气 | 油库气 | 油库里 | 从旧版欢迎语提取词形；扩展到新句为 P |
| 甜食/满足 | 搞甜搞甜、幸胡 | 搞甜搞甜、幸胡 | 好甜好甜、幸福 | 两端 D01 用例；幼体 P 策略，不能全局删错音 |
| 简单近音词 | 介里、先森、窝 | 介里、先森、窝（密度可低于婴幼） | 这里、先生、我 | **P 编辑候选，非旧版实证**；每条先审核，不做任意字符替换 |

## 不同意图的最小句（全部 P，保留固定口音）

| 意图 | 平静 | 紧张 | 亲近 |
| --- | --- | --- | --- |
| 打招呼 | “油库里洗跌一跌捏！” | “油……你要过来吗？” | “给你留了能油库里的位置！” |
| 要食物 | “还有好甜好甜吗？” | “油……能分一点吗？” | “这一份一起吃贼。” |
| 提议 | “去树根那边看看贼。” | “一起去，好吗……惹杰？” | “你带路，窝跟着惹杰。” |
| 拒绝 | “今天想先油库里。” | “先不要靠这么近哒……” | “等歇好了，再一起玩哟。” |
| 感谢 | “谢谢，已经收好贼。” | “油呜……可以油库里了。” | “下次也给你留一份哇。” |
| 不懂 | “油油？这个怎么做？” | “再说一遍，可以吗哟？” | “慢慢教窝惹杰。” |
| 失败 | “今天没找到多少贼。” | “油……有点走不动了。” | “一起回家先生，下次再来哇。” |

角色自称优先使用用户给定的呼名，只有事件明确演出幼称或自报种族才切换。不要通过拼接任意名称造成语尾重复。角色称呼应由真实关系选“妈妈/爸爸/姐姐/队长/名字”，没有关系就叫名字或“你”。
