## 外形与分类

双叶系普通种之一；常见描写突出身体素质、勇气与棒状武器。

## 习性与作品差异

《赤い眼のみょん》将普通个体写为熟悉采食的劳动者；红眼个体遭遇群落迷信。[A，L05](https://w.atwiki.jp/yukkuri_gyakutai/pages/2826.html) “红眼招来灾祸”是群落信念，不是已证实的自然规律。

**W：** 高优先级综述[L36](../../../sources-lore.md)将妖梦种概括为身体强健、勇敢、智能偏低，常带木棒或类似物作武器，称为「観楼剣」；《ゆっくり解体新書》的[妖梦种章节](https://w.atwiki.jp/yukkuri_gyakutai/pages/3102.html)也写到棒状武器用于狩猎、战斗和群体护卫。木棒武器因此成为妖梦种常见的行动物件母题。

- **内馅：** 现有项目登记依据 komicolle 40720 No.11518905 采用白巧克力馅；该称呼只用于身体材质与配色，不另设独立机制，RGB 色值为项目美术选择。

## 作品图片参考

补充：[M03-011 妖梦头像](../../../../art-references/images/M03/011-023228d5.png)位于中间左格，可见短发与头饰；该格接到收集群外消息的任务。出处：[合体あき《節分と赤いまめ》](../../../../art-references/works/M03.md)。这是头像和单篇分工例证，仍不足以建立完整全向造型。

补充：[EH01-007 右栏](../../../../art-references/ehentai/images/EH01/007.jpg)显示妖梦与橙同窝，能看见短发、黑蝴蝶结、无胴体侧面及俯身轮廓。[EH01 目录](../../../../art-references/ehentai/works/EH01.md)记录转载署名としあき（牙疼）及机翻标记。洞口交叉枝条和铺层可供场景参考，幽灵相关笑话不当作半灵能力证明。仍缺背视及统一多方向图。

**W：[F193](https://yukkuri.fandom.com/wiki/Yukkuri_Youmu)** 写妖梦型被叫作 Myon，比其他油库里都软，饰物为黑蝴蝶结，有时带一把剑，身边常有“幽灵”状的东西跟着；馅为白巧克力。同页写受训个体极忠于伴侣与饲主，一旦配上就再不看别人，常为让伴侣与幼体逃走而送命；它会用嘴里叼着的木棍、短剑或小刀攻击，而不是跳撞，因此常被当看守。同页另写行为一板一眼、见人先礼貌招呼，却总想找机会“英勇”一次；也有胆小、欺负别的个体又临阵逃走的个体。幽灵的来历没有定论，有说法是分身，也有说法是连体伙伴或年幼的同族。

**项目采用：** 妖梦按普通种自然生成，生命 14、移速 0.20、先天认知 ×0.6、数到 3，相扑 ×1.8、对战 ×1.4、觅草间隔 ÷1.5；觀樓劍是真实木棍，丢失后会捡，或走到树边拔一根树枝，非赤油、胆量≥35 且生命高于阈值时持棍迎战（见[妖梦与稀有变体](../../../../../docs/FEATURES.md#妖梦与稀有变体)）。项目没有幽灵与刀剑（无手工艺，只有捡来的木棍），红眼妖梦是独立稀有变体、被其他成员视为不祥之兆，见[设定差异](../../conflicts.md)。
