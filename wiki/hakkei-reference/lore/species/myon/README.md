## 习性与作品差异

《赤い眼のみょん》将普通个体写为熟悉采食的劳动者；红眼个体遭遇群落迷信。[A，L05](https://w.atwiki.jp/yukkuri_gyakutai/pages/2826.html) “红眼招来灾祸”是群落信念，不是已证实的自然规律。水与温度耐性未证实。
