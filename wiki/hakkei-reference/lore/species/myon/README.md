## 外形与分类

保留的独立种族资料，不从同名东方角色继承职业、半灵或其他能力。

## 习性与作品差异

《赤い眼のみょん》将普通个体写为熟悉采食的劳动者；红眼个体遭遇群落迷信。[A，L05](https://w.atwiki.jp/yukkuri_gyakutai/pages/2826.html) “红眼招来灾祸”是群落信念，不是已证实的自然规律。

**W：** 高优先级综述[L36](../../sources-lore.md)将妖梦种概括为身体素质较强、勇敢但智能偏低，并记录其常带木棒或类似物作武器，称为「観楼剣」。这是该综述归纳的种族母题；现有本地图证尚未清楚展示该物件，不能据名称推定其尺寸、剑形、材质、携带方式或统一战斗动作。水与温度耐性未证实。
