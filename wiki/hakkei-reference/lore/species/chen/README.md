## 外形与分类

以猫耳、绿帽及尾部识别。常通过短口癖和姿态交流，不能因此推定整个种族智力低下。

## 习性与作品差异

《ゆっくりちぇんを飼ってみた》描写有限句式交流、双尾表达开心、偷吃后的回避眼神。[A，L03](https://w.atwiki.jp/slowlove/pages/400.html) 这支持用姿态表达情绪，不证明整个种族没有学习能力。

《にっき》资料写有绿帽、猫耳、巧克力馅、速度快但身体较弱。[W，L10](https://w.atwiki.jp/ykansatu/pages/39.html) 这些特征限该游戏资料，不能直接推广到其他作品。
