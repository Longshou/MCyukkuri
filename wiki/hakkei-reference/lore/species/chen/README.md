## 习性与作品差异

《ゆっくりちぇんを飼ってみた》以有限句式、双尾表达开心及偷吃后的回避眼神呈现橙的交流方式。[A，L03](https://w.atwiki.jp/slowlove/pages/400.html)

《にっき》资料写有绿帽、猫耳、巧克力馅、速度快但身体较弱。[W，L10](https://w.atwiki.jp/ykansatu/pages/39.html) 这些特征限该游戏资料，不能直接推广到其他作品。

**W：双叶系母题（[L36](../../../sources-lore.md)）。** 高优先级综述将橙概括为体型娇小、行动敏捷、生存能力较强、难以正面对抗其他油库里；她在普通种中的创作出场率也较低。《にっき》则补充了速度快、身体较弱的游戏版本。

**W：[F74](https://yukkuri.fandom.com/wiki/Yukkuri_Chen)** 把橙写成受欢迎的型，饰物为帽与耳环，牛奶巧克力馅；多数个体温顺友善，被逼时也会咬人。同页写它先与 Ran 型配对（找不到才多为妖梦型，页面推测与馅料相近有关），发情期非常活跃并以嘘嘘标记物件，不让人排尿会引发膀胱问题；天生爱爬高，被抱高时高兴。它也常出现在聚落中却不承担特殊职责，与 Orin 型常因猫性争吵、追 Nazrin 型、悄悄接近 Mystia 型。口癖上它很少说 take it easy，而是用 “I get it”／“I don't get it”，并会喊 “Ran-sama!”。同页另列 Fluffy Chen：一名画师起的、只剩一大团绒毛加脸与帽子的写法，通常带非人类胴体。

**项目采用：** 橙移速 ×1.2、被欺负权重 ×1.5、对战 ×0.75；长尾橙与圆尾橙各 1/10（亲本同型 1/2），只改外观；两条尾巴各托一只幼体，见[运输](../../../../../docs/FEATURES.md#聚落族规与迁徙)。发情与求偶按成体发情规则结算，嘘嘘不单独成为物品、也不标记领地；Fluffy Chen 与 Ran、Orin 等型都没有实现，见[设定差异](../../conflicts.md)。台词与口癖按制作源和阶段选句。
