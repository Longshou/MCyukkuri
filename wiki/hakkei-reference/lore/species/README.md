**W：主流创作种类框架（L36）。** 高优先级综述归纳了双叶系常见的八类：六种普通种（灵梦、魔理沙、爱丽丝、帕秋莉、橙、妖梦）与两种捕食种（蕾米莉亚、芙兰）；其他种族多归入稀有种。

[水生魔理沙](marisa/aquatic-marisa.md)单列为帽船漂浮类型，与螺壳型区分。

## 类型总表

**W：[F36](https://yukkuri.fandom.com/wiki/Yukkuri_Types)** 记录一张 138 行的类型表，列为名称、爱称、馅料、口癖、性格、特殊性质与能力、知名度、稀有度；页面自称只是粗略指南，并说明 `?` 表示未知或不止一种说法，知名度指该型在故事中出现的频率，稀有度指野外预期数量并随作者与作品变化，`Unique` 不表示只有一只。能力栏写 Body 的表示该型有时带胴体，但总有不带胴体的个体。

表内与项目十个已实现种族同名的是灵梦、魔理沙、爱丽丝、橙、帕秋莉、蕾米莉亚、芙兰与妖梦（爱称 Myon）；家油灵梦与家油魔理沙没有对应行，螺壳、水生、被炉、多毛、长／圆尾等亚种以及稀疏毛发、面部不足、豆形等先天形态也没有对应行。其余各行取自其他东方角色与其他作品的梗，超出现有实现范围。各行不逐条转录，需要具体一行时按页内名称回查。

## 站点另收录的未实现类型

以下条目自成一个型，项目没有对应种族，也没有它们的特殊能力；外形与口癖只作检索与写作参考。

**W：[F45](https://yukkuri.fandom.com/wiki/Yukkuri_Sagume)** 写稀神型（爱称 Yugume、Yusagume）：月球系油库里，单翼饰物、曲奇奶油馅；说话会反转局面，因此总说出与意愿相反的意思，野生个体因能力少有天敌，其他个体多半躲避，清兰、铃瑚与多莉米例外，偶与正邪型来往；页面给出的台词是「Take it difficult, yu!」「Take it quietly!」。

**W：[F46](https://yukkuri.fandom.com/wiki/Yukkuri_Hecatia)** 写赫卡提亚型（爱称 Yukkatia）：黑色帽、锁链与三颗球（异界／地球／月球）作饰物，无胴体；能在三种形态间切换，馅料随形态分草莓、蓝莓与柠檬；仇视嫦娥，对月球系个体不友善，常与纯狐型来往；页面另写它们会谈论并不存在的「T 恤」，自述台词是「Wayon~」「My T-shirt isnt weird, yu!」。

**W：[F42](https://yukkuri.fandom.com/wiki/Yukkuri_Akiko)** 是 Key 作品联动的秋子型（爱称 Akiyukkuri）：以人类志愿者 DNA 注入灵梦型而来的写法，长蓝发与辫子可当手用，馅料味道怪但健康；写它们收养孤儿与失饰幼体、极为护幼，能把馅吐给幼体而不死或吐向敌人，被人与多数个体喜爱，孤独或失去孩子时会拒食崩溃。

**W：[F57](https://yukkuri.fandom.com/wiki/Su----per_Cute)** 是单一画师起源的迷因亚种：页面形容为羊驼与油库里的混合、疑似觉型的近缘，容易受惊、见人便跑，多独居，信息很少；页面自己注明这一型由画师 Twumi 起头、其他作者随后跟进。

**项目采用：** 已实现者为[类型总表](#类型总表)里的十个种族与各自的亚种、先天形态；上列类型、它们的超自然能力与外作联动一律未实现。站点另有“各型继承原作人物能力、会飞的型都能飞”的写法，项目只让蕾米莉亚与芙兰飞行，见[设定差异](../conflicts.md)。
