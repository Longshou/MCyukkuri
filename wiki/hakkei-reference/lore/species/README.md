**W：主流创作种类框架（L36）。** 高优先级综述把六种普通种（灵梦、魔理沙、爱丽丝、帕秋莉、橙、妖梦）与两种捕食种（蕾米莉亚、芙兰）作为当时主流的八类；其他种族多归为稀有种。这是该综述对双叶系创作重心的归纳，不是所有作者都采用的固定名单或生态分类法。
