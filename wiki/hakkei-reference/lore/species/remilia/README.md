## 外形与分类

独立种族，部分作品将其描写为能够飞行的捕食类型。

## 习性与作品差异

《观察日记》攻略将其列为飞行捕食种，捕食还受该游戏等级及开关影响。[W，L12](https://w.atwiki.jp/ykansatu/pages/16.html) 飞行不等于必定捕食同伴；食性与能力仍需区分作品。
