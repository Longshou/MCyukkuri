## 外形与分类

独立种族，部分作品将其描写为能够飞行的捕食类型。

## 习性与作品差异

《观察日记》攻略将其列为飞行捕食种，捕食行为受该游戏的等级及开关控制。[W，L12](https://w.atwiki.jp/ykansatu/pages/16.html)

**W：双叶系母题（[L36](../../../sources-lore.md)）。** 蕾米莉亚是常见捕食种。作品既写低智能、难以对话的个体，也有狩猎时展现高智慧的版本；普通种造成的环境压力也使部分创作对捕食种采取较宽容的态度。

- **内馅：** 用户明确指定捕食种为肉包；本项目据此采用肉包馅配色，具体 RGB 为项目美术，不改变捕食行为。
