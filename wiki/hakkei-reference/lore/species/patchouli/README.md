## 外形与分类

独立种族。爱读书、知识型、身体较弱，并常在群体中承担记录、指导或传递知识的角色。

## 习性与作品差异

**双叶系常见母题：** 高优先级综述[L36](../../../sources-lore.md)将帕秋莉概括为爱读书、知识型但身体较弱；作品会写到识字、数数、指导同伴，也会让她把错误知识传给群体，形成知识声望与实际经验并存的角色面貌。

《ゆっくり飼育書》也写到喜爱阅读、记忆较强、常担任指导、偶尔不懂装懂且身体脆弱的帕秋莉。[A，L11](https://w.atwiki.jp/yukkuri_gyakutai/pages/4249.html)

**W：[F147](https://yukkuri.fandom.com/wiki/Yukkuri_Patchouli)** 把帕秋莉写成最弱的型之一，体力与力量都差，略微活动就会猛烈咳嗽或吐出 “mukyu” 声，馅为生奶油、身体是泡芙皮；稀有度仍记常见，带胴体的少见。同页写部分作品里它只会说 mukyu，另一些作品里它比其他型聪明得多、个别接近人类，记忆与长期规划突出，懂营养与越冬准备，常在聚落里当没人听的军师；有的会读书，有的不会，但对书的执着一致，会为了书闯屋。聪明个体常被工厂与商店留作助手或宠物，也有为做实验而折磨别人的写法；少数据说会施法，但不会的远多于会的。同页还记与魔理沙、爱丽丝、Nitori、Koakuma、Sakuya、灵梦的配对，并把 Koakuma 写成仆人甚至宠物。

**项目采用：** 帕秋莉的易吐实现为冷却 3600 tick、不扣血、最多耗 2 精力、吐后压力 +3；体力消耗 ×1.25、对战 ×0.8，数数能到 9（项目设计，见[种族与亚种](../../../../../docs/FEATURES.md#种族与亚种)）。项目没有施法、接近人类的智力分级、读书与闯屋取书的规则，也没有 Koakuma 型；台词只按制作源选句，见[设定差异](../../conflicts.md)。
