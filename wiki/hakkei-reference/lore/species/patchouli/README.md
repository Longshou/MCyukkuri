## 外形与分类

独立种族。阅读、记忆、指导同伴与身体脆弱是部分作品中的特征，具体表现因作品和个体而异。

## 习性与作品差异

《ゆっくり飼育書》将帕秋莉写为喜爱阅读、记忆较强、常担任指导，也可能不懂装懂且身体脆弱。[A，L11](https://w.atwiki.jp/yukkuri_gyakutai/pages/4249.html) 知识与脆弱仅是该篇的设定；不能推成所有意见都正确或确定温度耐性。
