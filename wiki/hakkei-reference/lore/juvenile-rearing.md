# 幼体照料与发育

[Wiki 总入口](../../README.md) · [fandom 来源登记](../sources-fandom.md) · [家油、巢与卵](house-nest-sources.md) · [受伤、照护与恢复](../world/health-care.md)

本页按来源登记幼体的体型、进食、发育、学习与社会关系，每个来源的范围各自保留，表中的写法只在原页成立。“幼体”在各来源指的分界不同，项目使用的阶段与门槛见[项目采用](#项目采用)。

## 体型、面皮与馅料

**W：[F09](https://yukkuri.fandom.com/wiki/Koyukkuri)** 把幼体写作与两名出生亲代之一同种、仅更小的个体，并以体型、面皮与馅料容量判断其状态；该页的尺寸范围与喂食间隔属它自己的写法。

| 主题 | 作品记录 |
| --- | --- |
| 体型范围 | 平均幼体不小于樱桃番茄、不大于橘子；迷你油库里与营养不足导致生长停滞者为例外；超过橘子即视为成年 |
| 面皮 | 初生个体的面皮比幼年、成年更薄、更不易伸展，容易破皮受伤 |
| 馅料容量 | 一次只能容纳很少的馅，须频繁进食留出消化时间，否则呈葫芦形或撑死 |
| 牙齿与食物 | 牙齿小，咬硬物会断，食物须软 |
| 存活 | 体型小、技能不足，生存率极低；该页以高出生率解释种族延续 |

## 初食、喂食与清洁

**W：[F09](https://yukkuri.fandom.com/wiki/Koyukkuri)** 记录幼体不能自行进食、排泄与照料自己，全部依赖亲代；该页另列人工饲养的替代动作，属饲主建议，不是世界内通例。

| 主题 | 作品记录 |
| --- | --- |
| 初食 | 茎生繁殖时第一餐必须是母体咀嚼软化后的茎，页内称茎含强化免疫的成分 |
| 喂食节奏 | 约每两小时一次，避免过食与葫芦形 |
| 固体食物 | 更大的幼体可以吃固体食物与碎屑 |
| 排泄与清洁 | 幼体不能自己排泄，须被舔净；人工饲养以湿布按腹部模拟舔舐、以湿布从身后清理，防止霉变 |
| 自主移动 | 出生后至少三天不能自行移动，之后学会短跳与爬行，多用于和亲代摩擦；飞行类型之后可与亲代同飞 |
| 亲近动作 | 摩擦、被舔净与被举高都是幼体日常，人工饲养以抚摸与湿布代替 |

## 先天记忆与发音

**W：[F09](https://yukkuri.fandom.com/wiki/Koyukkuri)** 写幼体出生即了解周围，并从遗传记忆得到「悠闲」的驱动、成年生活的基本规则与说话能力；词汇母题的综述来源另见[出生时已有的词汇与记忆](learning-social.md#出生时已有的词汇与记忆)。

| 主题 | 作品记录 |
| --- | --- |
| 含混发音 | 幼体总是含混地说话，与受惊成体的发音相近；页内说明这不是绝望，而是尚未练熟 |
| 学会说话 | 靠模仿亲代或人类练出正常说话；孤立的幼体可能终生说不清，整族只剩一种叫声的类型须尽早接触语言 |
| 突然成形 | 极小的与早产的个体只发出「yu」「eajy」；有些作品里幼体会一下子把话说全，仍带稚气 |
| 自称排行 | 幼体按自己离开茎并打招呼的时刻计算排行，自称大姊、中姊、小妹，并催促后出生的同胞「好好地出生」 |
| 学习方式 | 野外幼体以游戏完成教育，模仿亲代捕小虫、带回草叶给更小的同胞 |
| 夸大的模仿 | 幼体把成体的无意义部分放大：对粪便鼓起身体威吓，或追咬自己的前发 |

## 同胞、亲代与偏爱

**W：[F09](https://yukkuri.fandom.com/wiki/Koyukkuri)** 记录家庭内的偏爱与排斥，并把它写成幼体存活的主要风险；这些情节属该页的写法。

| 主题 | 作品记录 |
| --- | --- |
| 依恋 | 幼体与亲代形成类似印痕的联系；人工饲养时会把人类当作亲代，喊「妈妈」「爸爸」 |
| 同胞 | 大姊像代理亲代一样照顾小妹并展示所学，小妹以夸张的称赞回应 |
| 同型偏爱 | 一窝幼体分属父母两型；亲代与幼体都可能偏向同型、冷淡异型，极端时虐待或杀死异型幼体 |
| 特殊类型 | 少见的类型被过度关注，同胞可能因嫉妒施暴，亲代再以「不悠闲」为由处死施暴者 |
| 失饰亲代 | 亲代缺饰或带伤残时，shithead 幼体会据遗传记忆判定它「不是油库里」而拒绝它 |
| 独处 | 幼体离不开持续的照看；长期独处会出现不吃不喝、喊亲代、呕吐馅料与僵直 |
| 私有小空间 | 幼体也会认屋，常宣称已有住户的小空间而争吵；狭暗的小盒、纸杯被当作自己的悠闲之地 |

## 项目采用

项目用四个阶段描述成长：赤油、子油、亚成油、成油，一生约 44 个游戏日；体型分别为标准成体的 0.10–0.20、0.20–0.80、0.80–1.20。新生儿都是赤油，只能由仍认领它的亲油喂咀嚼过的糜；年龄 84000 且成长营养 63000 之前不能吃固体食物，首餐与首便都需要亲油照护；168000 起才有第一次共睡与一处自己的小叶片巢。取名在项目中是否定身份，幼体会吐出一份馅，不因此死亡。数值与流程见[子代生命周期与离家](../../../docs/FEATURES.md#子代生命周期与离家)。
