# 身体与馅料

馅料、中枢馅、眼睛、辫子、气味、记忆与亲代献身在不同作品中有不同描述。下面保留具体出处及其局限，不把单篇设定推广为所有油库里的生理规律。

本设定的成分称呼、鲜馅与献身馅气味、来源识别和进食关系见[食物与馅料](../world/resources-ecology.md#食物与馅料)。本页提供作品出处，不能将其中互不相同的生理版本全部叠加。

## L36 的常见身体构造与护理线索

高优先级综述 [L36](../sources-lore.md)专门整理常见的身体构造，可作为角色外观、身体互动和日常护理的统一参考底稿：

| 身体部分／状态 | 综述所述的常见写法 | 可补进世界表现的内容 |
| --- | --- | --- |
| 身体与面皮 | 馒头状身体；面皮柔软、有弹性和韧性，行走用的下部表面更粗糙 | 受压、弹动、行走摩擦和清洁状态可分别表现；不从“柔软”推断任何伤害都无效 |
| 足部与行动 | 足部非常敏感；综述称烧灼若使其失去弹性，个体会永久丧失行动能力 | 可将足部状态与跳跃、贴地移动和伤后行动分别关联；这是 L36 的身体损伤写法，不推出通用伤害阈值或所有作品里的不可逆结果 |
| 眼、齿、发 | 眼睛像珍珠状果冻；牙齿为硬糖；发丝像糖线 | 角色特写和材质可按眼、齿、发分开制作，不将三者合并为一种糖材质 |
| 馅与中枢馅 | 馅料随种类变化；身体中央较深处称中枢馅，综述称其最甜，并作为重要生命部位 | 角色内部构造、受伤与身体检查可呈现不同区域；颜色、甜度与受损后果仍按采用的作品版本记录 |
| 情绪、甜化与非油症（非ゆっくち症） | L36 将一般不适与馅料甜化相连，并写到过度痛苦可导致非油症、只会重复「ゆっくち」叫喊，馅料转为难吃；社区汇编 E02 收录的同名病症版本则称馅料美味 | 优先保留 L36 概括的常用组合，同时将相反版本并列为设定分歧；不把甜度当作情绪计量器，也不补病程阈值或统一诊断 |
| 辫子 | 通常有可灵活动作的辫子，内部有馅流经 | 辫子是可主动参与取物、搬运和交流的身体部位，不只是静态装饰 |
| 液体与口腔 | 身体液体多作糖水，口内多作翻糖 | 可用于味觉和口部表现；不等于所有液体、排泄物或受伤分泌物都相同 |
| 卫生与情绪 | 面皮需保持清洁，综述把霉变列为严重健康风险；情绪剧烈波动时可能不自觉排泄，成体也有此写法 | 身体清洁与压力反应可进入日常状态和照料，不只用于幼体；不补统一发病时长或清洁步骤 |
| 代谢与恢复 | 综述称代谢较快，足够糖分可迅速促进伤口恢复 | 补充食物与受伤恢复的设定联系；不推导固定治疗速度、糖量或任何伤口都能立即愈合 |

**随身收纳也是身体构造的一部分。** L36 记载采来的食物可放在头顶／头饰内或短暂含在口中；灵梦种的颊囊是明确列出的种类特征，可容纳更多物品。取物、临时储存与外部容器应区分表现；颊囊不推广到普通种全体。

这些是 L36 归纳的高优先级常用设定，可作为外观和生态扩展的共同起点；图像制作仍应对照清晰的作品画格，不从文字描述臆造形状、颜色或受伤尺度。身体和馅料的其它来源差异继续见上表。

## 「油库里感」与直觉表达

[L36](../sources-lore.md)楼中补充（No. 11519618）举出角色面对危险事物时“总觉得很不能油库里”、面对没见过的可口食物时“好像很能油库里”的说法；评论者因此建议把这里理解为主观的“感觉”，而不是直接等同于闻到气味。该评论还把头饰与同类识别联系起来，但没有证明存在统一的感官器官或识别机制。

**W／边界：** 可把“能不能油库里”作为表达舒适、期待、警觉或厌恶的常用主观判断；危险判断可能出错，甜食期待也要由实际尝试确认。楼中解释属于讨论者假说，不提升为项目生理规则，也不替代[基本设定中的饰物识别采用](../world/rules.md#个体识别与分类)。对白词形见[通用短语](../dialogue/common-phrases.md)。
