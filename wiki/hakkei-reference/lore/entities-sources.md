# 身体与馅料

本页汇集馅料、中枢馅、眼睛、辫子、气味、记忆与亲代献身的创作写法，来源包括作者作品、社区汇编和游戏攻略。共通身体表现集中列于下文，具体版本则依出处阅读。

食物称呼、馅料来源、气味与进食情景见[食物与馅料](../world/resources-ecology.md#食物与馅料)。

## L36 的常见身体构造与护理线索

高优先级综述 [L36](../sources-lore.md)整理了身体外观、身体互动和日常护理中的常见写法：

| 身体部分／状态 | 综述所述的常见写法 | 可补进世界表现的内容 |
| --- | --- | --- |
| 身体与面皮 | 馒头状身体；面皮柔软、有弹性和韧性，行走用的下部表面更粗糙 | 受压、弹动、行走摩擦和清洁状态都可成为身体表现 |
| 足部与行动 | 足部很敏感；烧灼导致弹性丧失时，个体会永久失去行动能力 | 足部伤情会改变移动能力；常见移动方式见[共通生态](ecology.md#常见移动方式与工具使用) |
| 眼、齿、发 | 眼睛像珍珠状果冻；牙齿为硬糖；发丝像糖线 | 眼、齿、发各有对应的形状与材质表现 |
| 馅与中枢馅 | 馅料随种类变化；身体中央较深处称中枢馅，综述称其最甜，并作为重要生命部位 | 角色内部构造、受伤与身体检查可呈现不同区域；颜色、甜度与受损后果仍按采用的作品版本记录 |
| 情绪、甜化与非油症（非ゆっくち症） | L36 将一般不适与馅料甜化相连；过度痛苦时可出现非油症，反复喊「ゆっくち」，馅料变得难吃。社区汇编 E02 收录了馅料变美味的另一版本 | L36 主文与 E02 的表现并列保留 |
| 辫子 | 通常有可灵活动作的辫子，内部有馅流经 | 辫子是可主动参与取物、搬运和交流的身体部位，不只是静态装饰 |
| 液体与口腔 | 身体液体多作糖水，口内多作翻糖 | 糖水与翻糖是身体液体、口腔材质的常见写法 |
| 卫生与情绪 | 面皮需保持清洁，霉变是严重健康风险；情绪剧烈波动时可能不自觉排泄，成体也有此写法 | 将身体清洁与压力反应纳入日常护理 |
| 代谢与恢复 | 综述称代谢较快，足够糖分可迅速促进伤口恢复 | 食物补充与伤口恢复相连 |

**W：组织再生范围（L36 No. 11520402）。** 多数作品以橙汁恢复面皮和馅料；头饰、头发、牙齿、舌头与眼睛等则通常靠移植处理。游戏攻略 L55 另有头发由橙汁促生的版本。

**随身收纳也是身体构造的一部分。** L36 记载采来的食物可放在头顶／头饰内或短暂含在口中；灵梦种还具有可储存更多物品的颊囊。身体部位与外部容器共同构成随身搬运方式。

这些身体线索构成从外观、移动、携物、卫生到修复的日常生活链条。具体异作的身体与馅料写法见下列来源索引。

## 「油库里感」与直觉表达

[L36](../sources-lore.md)楼中补充（No. 11519618）举出角色面对危险事物时“总觉得很不能油库里”、面对没见过的可口食物时“好像很能油库里”的说法。讨论者建议将它理解为主观感受，并联系到食物期待、危险判断和头饰识别。

**W（楼中解释）：** “能不能油库里”可表达舒适、期待、警觉或厌恶，是角色联系自身经验与周围事物的一种感受。其对白词形见[通用短语](../dialogue/common-phrases.md)，头饰参与辨认的项目采用见[基本设定](../world/rules.md#个体识别与分类)。
