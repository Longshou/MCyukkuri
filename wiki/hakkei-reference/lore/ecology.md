# 共通生态

以下按作品记录生命过程与环境习性，保留分歧；没有统一的寿命、成长时长或耐性数值。

本 Wiki 沿用的成长、家油卵生、普通种杂食、水与寒冷规则见[基本设定](../world/rules.md)；食物、馅料和住所间的联系见[生活生态](../world/resources-ecology.md)。本页各作品的记录保留其各自范围。

| 主题 | 作品记录 |
| --- | --- |
| 成长阶段 | 八景社区用“赤→子→成”描述圈内概念，具体阶段和时长随作品变化。[W，L01](https://wikiwiki.jp/yukkuri8kei/ゆっくりとは) |
| 食物 | 《ゆっくりについて》的普通种生活包含草、昆虫、人类食物等杂食描写。[A，L02](https://w.atwiki.jp/yukkuri_gyakutai/pages/1026.html) |
| 食性分歧 | 社区《设置集》并列了只吃甜食、杂食、捕食等互不相容的写法。[W，L07](https://w.atwiki.jp/yukkuri_gyakutau2/pages/63.html) |
| 水 | 八景社区同时记录普通种怕大量雨水或落水、洗澡却会高兴，以及螺壳魔理沙较耐水。[W，L01](https://wikiwiki.jp/yukkuri8kei/ゆっくりとは) |
| 冷与热 | 《解体新书》把极端高低温列为死亡原因，但没有可移植的摄氏温度阈值。[A，L06](https://w.atwiki.jp/yukkuri_gyakutai/pages/3102.html) |
| 生病与死亡 | 八景社区记录潮湿/不洁与霉病、长期压力与精神异常或死亡、饰物丧失的压力。[W，L01](https://wikiwiki.jp/yukkuri8kei/ゆっくりとは) |
| 繁殖与亲属 | 八景社区记载成体结伴、配对时确定父母角色、茎上实子后落地的过程；不是种族固定性别。[W，L01](https://wikiwiki.jp/yukkuri8kei/ゆっくりとは) |
| 离巢与筑巢 | S03 有家庭送别与三次建屋，L21 则是室内幼体合作搭窝；年龄、环境与目的分别记录。见[住所专题](habitat-seasonal-life.md) |
| 储粮与越冬 | E08 与 L27 分别呈现各家余粮差异和食物足仍受寒；项目采用储粮暖巢方向，不能推出免食冬眠或统一成功率。见[小说 N02、N07](../../novel-reading/README.md) |
| 学习与群体信息 | L03 的尾部表达、L17 的认人和排斥、L27 的广告理解是不同问题。见[学习与社会判断](learning-social.md) |
