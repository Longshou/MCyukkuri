# 油库里是什么

本 Wiki 介绍生态创作中的油库里：能够说话、活动的馒头状生物。它与实况解说使用的头像角色需要区分；各创作者会自由改变其设定。[八景社区概述](https://wikiwiki.jp/yukkuri8kei/ゆっくりとは)

“灵梦种”“魔理沙种”等是外形与命名类别，不能仅凭同名就赋予东方角色的职业、身份或魔法。

## 世界背景与作品差异

本 Wiki 沿用人类与油库里共处、东方人物不存在的背景。成长、繁殖、饰品识别等见[基本设定](../world/rules.md)，个体与生活关系见[世界设定入口](../world/README.md)。下列异作背景保留为作品差异。

《ゆっくりについて》采用幻想乡拟自然史的背景；《ゆっくりちぇんを飼ってみた》描写与人类共处的饲养生活。这些都是具体作品的版本，并不存在本 Wiki 可以代替所有作者宣布的统一正史。[自然史设定文](https://w.atwiki.jp/yukkuri_gyakutai/pages/1026.html)、[橙的饲养故事](https://w.atwiki.jp/slowlove/pages/400.html)

“悠闲”可表达舒服、安全、开心和满足，也可能被角色用来合理化占有或逃避，不能一律解释为动作缓慢。饰物常兼具外观识别与情感意义；失去饰物的后果在作品间不同。

## 创作体系与作品类型

L36 将ゆっくり创作归为四种传播／表现体系：以东方人物和世界为中心的东方系、脱离东方并将油库里作为生物描写的双叶系、以 Softalk 等语音视频为代表的 NICO 系，以及由 AA 图和安价小故事构成的 ASCII 系。它们是作品来源和表现形式，不是油库里世界内的种族分类；本 Wiki 的生态设定以双叶系生物创作为主。

双叶系作品常按侧重点标为爱系、虐系、观察系、杀系、自然系、制裁系、混沌系和稀有系：爱／虐描述作品表现与对虐待的态度，观察／自然突出生态视角，杀／制裁聚焦极端行为与后果，混沌与稀有则分别偏离常见生物设定或加入少见类型。标签用于找材料、理解写作重心，不当作作品世界里的阵营或油库里的身份。[小说核读目录](../../novel-reading/README.md)按具体作品记录其内容与范围。

L36 也将常见设定的形成描述为集体创作：作者会沿用和扩写已有点子，反复出现的写法逐渐成为共通母题；互相冲突的版本也能长期并存。中枢馅与无中枢馅就是综述举出的并行例子。本站依此分别整理常见母题、项目采用和作品异说，详见[编辑口径](../../EDITORIAL_GUIDE.md#高优先级综述与共识形成)。

## 资料怎么读

- A：作者或具体作品的记录，只证明该篇的写法。
- W：社区百科或攻略整理，留意作品和版本差异。
- I：阅读归纳或推测。
- P：本库原创示例，不是传统原话。

同一作品的转载不算独立证据。历史核读范围和未确认事项保留在来源页；图片旁保留篇名、署名和出处。
