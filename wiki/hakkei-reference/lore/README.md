# 油库里是什么

本 Wiki 介绍生态创作中的油库里：能够说话、活动的馒头状生物。它与实况解说使用的头像角色需要区分；各创作者会自由改变其设定。[八景社区概述](https://wikiwiki.jp/yukkuri8kei/ゆっくりとは)

“灵梦种”“魔理沙种”等是外形与命名类别，不能仅凭同名就赋予东方角色的职业、身份或魔法。

## 世界背景与作品差异

《ゆっくりについて》采用幻想乡拟自然史的背景；《ゆっくりちぇんを飼ってみた》描写与人类共处的饲养生活。这些都是具体作品的版本，并不存在本 Wiki 可以代替所有作者宣布的统一正史。[自然史设定文](https://w.atwiki.jp/yukkuri_gyakutai/pages/1026.html)、[橙的饲养故事](https://w.atwiki.jp/slowlove/pages/400.html)

“悠闲”可表达舒服、安全、开心和满足，也可能被角色用来合理化占有或逃避，不能一律解释为动作缓慢。饰物常兼具外观识别与情感意义；失去饰物的后果在作品间不同。
