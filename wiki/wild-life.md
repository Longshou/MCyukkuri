# 野外生存、事件与交互

[Wiki](README.md) · [全领域覆盖](life-settings-coverage.md) · [树叶襁褓](leaf-swaddle.md) · [传统事件母题](hakkei-reference/events/traditional-motifs.md) · [群落](yukkuri-communities.md)

2026-10-17 扩充。**A** 是具体作品描写，**I** 是编辑归纳，**P** 是可供开发的方案。本页把环境、活动、关系和结果一起登记；“经典事件”指本库可回查的母题，不代表做过频率调查，也不自动变成游戏必发事件。

## 环境不是一张背景图

| 环境与资源 | A：作品中的条件和变化 | I／P：可供制作的区分 |
| --- | --- | --- |
| 树根洞、连续降雨 | [EH35 3–7](art-references/ehentai/works/EH35.md)：亲代未归，幼体靠存粮；无法外出处理排泄物，洞内脏污、同伴虚弱，食物继续减少 | 有顶棚与能长期生活分开；分别记录储粮、出口可达、清洁和照料能力 |
| 洞口落果 | EH35 7–10：香味吸引取食，帽子临时承托身体；果实取回，却被旁白揭为青梅，帽缝也进水 | 食物可见、可达、识别正确、运输成功、可安全食用是不同阶段；不把作品当现实植物指南 |
| 林冠、树洞与群体洞穴 | [N31](novel-reading/cards/N31.md)：叶片挡不住暴雨，水滴反而变大；小树洞不足以容纳一家，群体洞内拥挤 | 遮挡物不等于绝对避难所；体型、同行人数、路程、排水另列 |
| 雨后河岸 | N31：雨停后洗泥、晒干；新首领提醒幼体勿下水，但之后洪流仍来 | 停雨与水域安全分开；不要把洗净、暖和、资源恢复绑定成一个状态 |
| 山与草原之间的人家床下 | [N32](novel-reading/cards/N32.md)：先是雨歇即走，后来出现草垫与待产家庭，双方协商居留边界 | 临时避雨、筑巢、获准寄居和被收养是不同关系；不能从出现次数推为同一家庭 |
| 夜间森林、河边和浓荫 | [N33](novel-reading/cards/N33.md)：幼体错过归家时间；飞行者也怕夜鸟，当地合作有时间和地点限制 | 按时段、路线和当地关系判断风险，不能只按种族写固定敌我 |
| 城郊公园 | [N34](novel-reading/cards/N34.md)：弃养个体汇聚，群落提供支援，同伴回访送食；等待者未能脱险 | 有同伴、有食物和接受安置分开；公园并不自动是安全收容所 |
| 野外育幼用叶材 | [EH37 6](art-references/ehentai/works/EH37.md)：幼体身上叶片包层与下方承托叶并存 | 已纳入[树叶襁褓资源](leaf-swaddle.md)；贴身包覆、临时承托、地面叶床分别制作 |
| 冬季巢内布局 | [N35](novel-reading/cards/N35.md)：储粮、入口软草与深草床各有位置，幼体睡内侧；醒来仍需吃东西 | 将保温、存粮和照护分列；不能把冬眠等同于停止消耗 |
| 人类提供的木屋 | [N36](novel-reading/cards/N36.md)：试住后制作、搬运并安排多户入住 | 试住满意与长期适居分开；两周观察只是计划，未有结果 |

## 交互过程索引

| 互动 | A：角色、信号与回应 | 边界与可制作目标 |
| --- | --- | --- |
| 欢迎新来者 | N31：林地成员围观，魔理沙先问候、表示接纳，其他成员随后欢迎 | 只属于该群落；可分为观察、引介、群体回应，不是“任何陌生者必被驱赶” |
| 姐妹分工与让食 | EH35 7–9：妹妹担忧冒雨，姐姐用帽取果，回来先让妹妹吃 | 善意不保证正确判断；同一事件同时索引关心、冒险与分享 |
| 与人类一起玩 | [EH36 2–3](art-references/ehentai/works/EH36.md)：幼体主动问候，得到邀请，玩纸板滑坡后表达开心 | 有邀请和回应；纸板尺寸与坡度不能从漫画直接定安全数值 |
| 熟人再访与赠食 | EH36 4：幼体口衔果实来找前日朋友；成体到场后关系急转 | 礼物、记住熟人和第三方冲突分别记录；前篇后续报复未读 |
| 临时共处的约定 | N32：对床下居留、禁止上楼、安静与清洁作约定，人类也承诺保护 | 原文夹有暴力威胁，不称作温和协商；可提取双方责任，惩罚不直接照搬 |
| 熟人救助与报答 | N33：送迷路幼体回家，成年同伴问候、贴脸；历史上用果蜜致谢并谈判互助 | 地方盟约不外推全种；幼体不知道约定而恐惧，不能把成年人的认可代替幼体理解 |
| 集体娱乐 | N33：共同唱歌跳舞，亲代提醒别吵醒幼体 | 可把共同活动、噪声和睡眠需求并列，夜间集会有当地边界 |
| 陪寻、回访与劝住 | N34：新朋友帮找主人，多次回访送食并邀请同住，对方仍坚持等待 | 物资帮助与信任建立不等价；不要把拒绝一次邀请写成永久不可救助 |
| 巢口检查与哄睡 | N35：魔理沙离开睡圈查看入口，返回时避免吵醒家人；灵梦唱摇篮曲 | 是不同照护动作，没有轮班巡逻描写；音色、节奏与游戏效果仍需原创制作 |
| 入住与邻里交谈 | N36：人类运送木屋、邀请入住，家庭在相邻住所交流 | 不等于野生个体已掌握木工或共同修窝；后续稳定性尚未验证 |
| 载物与交换 | [N37](novel-reading/cards/N37.md)：编叶包袱用于携物交换 | 包袱与襁褓用途不同；后半剥削情节不能归为互惠贸易 |

## 可回查的事件链

以下对应母题目录新增 TM14–TM19；每行结果都是已读作品的结果，P 列才是项目可以调整的内容。

| 事件 | 触发 → 过程 → 已读结果（A） | 项目候选（P） |
| --- | --- | --- |
| 雨困家庭 | 亲代失联 → 无计划耗粮、卫生恶化 → 姐姐冒雨取果却误判食物与帽子防水，姐妹死亡（EH35） | 留粮、清洁、求助、风险提示可分别改变进程；不强制复刻悲剧 |
| 暴雨撤离 | 预警过迟 → 树冠失效、幼体难搬、让帽避难 → 洞中幸存者雨后又遇洪流（N31） | 预警时间、同行者能力、避难容量、雨后等待分别参与事件 |
| 供食者失联 | 一只承担外出供食 → 留守待产者无储备 → 人类寻回伤者并开始同居照护（N32） | 记录最后目击、供食依赖、守候与救援；正文没证明完全康复 |
| 跨种互助形成 | 共同天敌 → 升树救援 → 送礼、谈判、地方盟约；后代过度依赖援助（N33） | 关系可以由事件积累；盟约条件和求援范围需明确 |
| 朋友与第三方 | 邀玩 → 共同玩耍、翌日带果 → 成体伤害朋友，前篇以人类报复意图结束（EH36） | 可提取玩耍、记忆、回访，保留未读后篇标记 |
| 弃养后的接纳困难 | 假借出游离开 → 新友陪寻、群落邀住 → 等待者拒绝迁居，最终未获救（N34） | 用多次接触表现适应，不以瞬时“好感”解决全部关系 |

## 来源范围与下一步

此前保存 EH35 10 张、EH36 6 张、EH37 7 张选页，共 23 张；14 张有明确游戏参考用途，其余保留出处与叙事背景。EH35、EH36 为本图集全篇联系表核读。现已续读 EH37 春季主篇至第 16 页，第 17–27 页仅视觉总览，日文附篇未逐句核读；第 6 页此前另细看原图。**本图集没有证明夏秋冬的连续生活，撤回按题名安排的“后段季节变化”待读项。** 后段侵害情节不作为日常交互制作参考。

另补读 EH15 第 9–21 页联系表，未新增选页：后段家庭包含未纳入游戏的早苗，第 21 页演化附录是作者私设。小说补 N35–N37 三张卡，实际范围逐卡登记；评论不当正文，未知作者不算独立作者数。检索候选《おや、ぱちゅりーの様子が…》后文明示主角为特殊型「まちょりー」，未拿它替代普通帕秋莉的采食教学证据。

下一批优先补：树叶襁褓穿脱与替换；独立作品的夏季避热与秋储；食物辨认的正常教学；共同修窝、排水和灾后重建；问候、道歉、赠礼、轮流玩和陌生群落的接纳。EH35 与 EH34 同署ウカイグイ，N31 与已有 D.O 作品同作者，不增加独立作者见证数。续读 EH15、EH37 同样不算新增作者或图集。
