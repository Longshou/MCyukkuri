`yu_base.cs:23491` 的 `うんうんグラ設定` 默认使用下标 0，种族标志 2 改为 1；`23500` 的 `うんうん開始` 包含不同姿势分支。寝姿分支在反应计时 45 起使用排出物层，随后在 1／2／3 层间反复切换，185 使用第 4 层，195 调用生成并清空附加层，同时切换完成表情。这支持“反复用力 → 排出物脱离 → 表情恢复”的顺序。

本次制作选择：保持项目选定的魔理沙基础外观，采用前倾坐姿；表情适配成像素挤眼、圆嘴张合与轻松微笑，不加入原作泪水。X 标记按用户指定绘制，不声称取自原作。馅料沿三维后臀方向横向挤出，使用深紫褐色、前细后鼓的连续团块形体和少量自绘颗粒；原作颜色与二维轮廓提供参考，三维厚度、45 个方块的分层方式、颗粒纹理和落地压缩是制作选择。7° 前倾、约 9.5% 压缩、6.4 秒节奏与落地路径均为本项目适配。
