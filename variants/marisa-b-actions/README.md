# 已选 B 体型：三动作自由视角

[打开预览](index.html) · [模型](marisa.bbmodel)

使用 B 躯干长度、整体增高 6%、油臀逃跑收稳后的模型，提供噗咕、伸长、受惊逃跑三个入口。模型文件与 marisa-b-taller/b/marisa.bbmodel 一致，内含原五套骨骼动作。

鼠标拖动或触屏单指旋转；滚轮或双指缩放。相机角度与动作时间完全独立，播放、暂停、切换动作时均保留用户角度；正面、侧面、背面和重置是额外快捷入口。逃跑为跟随观察。

浏览器验证：三个动作播放中拖动均不暂停动画；暂停时可旋转；切换动作保留视角；滚轮缩放、移动端宽度与页面无异常检查通过，见 verification.json。
