# 表情与刘海合并试验

[交互选择页](index.html) · [三组合并对比](combined-options.png) · [12 组单项试验](component-trials.png)

先固定其余参数，分别比较眼皮开合、共同视线、嘴巴开合、刘海轮廓，每项三种；再形成三组合并候选：

- 01 活泼开心：略向上看、圆底笑口、收尖中分。推荐作为八景活泼方向的候选。
- 02 悠闲亲近：放松眼皮、小笑嘴、错落偏分。推荐作为温和默认表情。
- 03 好奇期待：轻瞟、提眉、中等笑口、收尖中分。适合关注某物的状态。

三个目录均含 Blockbench 模型、几何 JSON、128×128 贴图、静态预览和 Java 1.21.1 物品展示资源包。全部采用去底层的 53 方块体型，底面 Y=0；保留此前版本。本批为表情候选，不代表用户已选定，也未合并另一个任务的摇摆动作。

借鉴《油库里日记》分别控制眼、眼皮和嘴的思路，用原创像素绘制器实现预览中的参数变化；未导入 APK 的纹理、网格或动画。预览中的滑块与眨眼不写回模型，导出对应三组默认静态表情，尚未接入 Minecraft 动态实体。

验证：真实 Chrome 浏览器检查三版画面不同、四个面部滑块改变画面、刘海切换、眨眼开关、视角和拖动缩放、390px 窄屏，无页面异常。静态检查确认三版均为 53 方块且无 lower_curve，嵌入贴图与 PNG 一致，面部与生成器输出一致，资源包 ZIP 完整且贴图一致。未进行 MC 实机验证；眨眼完整周期未作逐帧断言。

重建：从项目根目录运行 `python tools/build_diary_combinations.py`，需要 Pillow 和 Node.js。交互页面由本目录 index.html / lab.js 驱动；绘制器源文件为 tools/face_layers.js。
