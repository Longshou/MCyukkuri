伸长/侧弯的已核读原始图与映射在 `../../marisa-stretch-source/reference/source-comparison.png`、`../../marisa-stretch-source/reference/exercise/source-exercise.png`。它们显示持续饱满的伸高体型、左右中间/极限角度；不支持细脖子或夸张沙漏腰。

这次制作选择：14 秒演示编排、32° 三维转向、前部支点上 12° 抬臀、轻微压低、平滑补间及闭眼小嘴像素改绘。未重放原作音频，也未模拟游戏结束后的排便事件。参考图未嵌入交付模型或贴图。

## 本轮后臀与笑眼修正

此前已核读同一 v8.3 的 [原始闭眼笑脸 Sprite 6604](../../marisa-expressions/reference/sprite-6604.png)，字段 `基本綴じ笑顔グラベース[0]`，并尝试扩大成双弧。用户随后要求恢复原样，因此当前交付恢复为约 8 像素的小闭眼，像素与体操初版完全一致。

已核读 [身体与后臀原图对照](../../marisa-rump/reference/evidence-sheet.png)，后臀中立／两侧源图为 Sprite 4638、8566、6376，详细映射见 [对应参考记录](../../marisa-rump/reference/README.md)。源图支持独立后臀轮廓、中心小叉标记和侧摆方向；三维厚度、分段与动作混合属于本次制作选择。

三维实施以魔理沙当前体操模型的前身／上后身／后臀核心／后臀末端为输入快照，调整灵梦后发下缘以露出油臀。为减轻拉长底部的堆叠感，前身保持统一深度、减半宽度收窄量；没有增加骨骼层数来掩盖台阶。新增骨骼来自补齐此前缺少的后身和后臀，以及对应部位的源曲线。
