# 魔理沙体型 / 油臀比例：逃跑观察

[交互对比](index.html) · [并排动画](flee-comparison.gif) · [静态图](comparison.png)

修改前的动作数据已经独立归档，压缩包及 SHA256 索引见项目 archives 目录。原有动作与上一版模型没有覆盖。

| 版本 | 全身体型 | 油臀宽 / 高 / 深（相对身体） |
|---|---:|---|
| A 当前比例 | 100% | 100 / 100 / 100% |
| B 小体型、紧凑臀 | 85% | 90 / 95 / 90% |
| C 小体型、饱满臀 | 85% | 115 / 105 / 125% |
| D 原体型、饱满臀 | 100% | 115 / 105 / 125% |
| E 大体型、紧凑臀 | 115% | 90 / 95 / 90% |

每版修改真实油臀几何及相应骨骼 pivot，并同比缩放位移动画；全身大小也写入模型。不是只缩放截图。腮部、头发、帽子保留原设计；油臀相对体型变形以底部 Y=0、臀部连接位置 Z=0.4 为基准。较大油臀会更多露出头发，这是比较目标。

逃跑观察复用已存甩臀动作的 1.8 倍速、转身与小跳节奏，镜头跟随角色、保持固定缩放。初始可看受惊转身，之后循环奔跑段。各版模型都包含 stretch、waddle、exercise_vertical、exercise_sides、puff 五套已存在动作。逃跑组合编排保存在 proportions.js；未宣称导出独立 flee 骨骼片段或接入 MC 实体 AI。

验证：五版浏览器画面互异、切换镜头、重播、移动端宽度、每版 210 方块 / 五套动作，见 verification.json。尚未选定新比例。
