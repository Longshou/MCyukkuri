# 神态与刘海实验 A–D

用户保留版和独立体型任务不受影响。本轮4套资产、模型和预览分别保存在 a/b/c/d；统一底部体型与拍摄角度，避免干扰判断。

- A：只缩小主高光，去下方亮点，保留原眼形和刘海。
- B：改为局部眼白与单块高光，放松眼线，柔和张嘴；保持原刘海。
- C：脸部贴图与 B 完全相同，仅收窄错落的刘海末端，减少头发纹理。
- D：沿用 C 的眼睛和头发，仅改为闭口小笑。

## 独立 agent 观察

参考图眼睛偏横圆、黑瞳占主导，高光是上方一块斜形，眼白只在局部露出；略向上的视线和紧凑笑嘴显得兴奋天真。憨厚版小眼睛和细笑嘴比较安静亲近。上一版高光横贯瞳孔，眼白环与下方碎亮点叠加，容易像含泪瞪眼。直垂等宽刘海和密条纹又强化了整齐假发感。

候选审核：A仍显惊讶；B像开心等待回应；C发束错落，眉眼更清楚；D安静乖巧。优先比较B/C判断头发影响，再比较C/D选择张嘴或闭嘴。审核指出张嘴偏尖，最终将B/C下缘改得更宽圆。

四版均通过Chrome无头浏览器显示、正侧视角、复位、拖动、缩放检查，无页面错误；见browser-check.json和各目录browser-front.png。已有静态资产检查通过；没有Minecraft实机或Blockbench应用导入验证。构建脚本 tools/build_expression_trials.py。
