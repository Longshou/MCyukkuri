# 身体纵深 / 尾部轮廓

[四版逃跑对比](index.html) · [并排动画](flee-comparison.gif) · [侧面图](comparison.png)

保持前脸、帽子和整体身高，延伸后身并让臀部成为后身的尾端。A 原版；B/C/D 后身纵深分别 125%、150%、175%。百分比以臀部连接区域 Z=0.4 之后的后身为基准，不是全模型前后包围盒。默认展示 C，尚未选定。

臀部沿纵向拆段，越靠后越收窄、降低，顶面形成阶梯式下降。上方身体适度延伸，后发小幅跟随，骨骼 pivot 与后身位移动画同步适配。五套原有动作和历史归档均保留；新模型放在本目录 a–d 子目录。

同一逃跑循环、固定镜头尺度，默认侧面，可切换后侧与背面。各版可下载含五套动作的 Blockbench 模型。此处仍是模型行为预览，未接入 MC 实体 AI。

验证：A 元素完全保留，B/C/D 面部几何保持（坐标浮点精度 1e-6）、方块体积为正；浏览器四版画面、镜头切换、播放与移动端检查通过。
