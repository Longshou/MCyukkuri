# B 稍增高与逃跑修正

[交互对比](index.html) · [动画](comparison.gif) · [新版模型](b/marisa.bbmodel)

用户选择前一轮 B 躯干长度。新版保持这一长度，整体高度增加 6%（包含帽子与面部同比增高），宽度、前后长度不变。旧 B 留在 a，新版在 b。

旧 waddle 的 rump_roll.scale.z 为 1–1.04，实际有最多 4% 的前后伸缩；rump_sway 左右旋转达 ±16°，宽臀部转动时侧面投影也会显得更长。逃跑复用这段动作的 1.8 倍速，因此变化更明显。

修正：Z 缩放固定 1；扭动缩到 ±6°；横向位移从 ±1.1 缩到 ±0.45。保留小幅上下弹动。浏览器与导出 BB 的动画同步修改，原档案不覆盖。

检查：前后坐标与宽度未变，高度为旧 B 的 1.06 倍；导出 Z 缩放固定 1、扭角不超过 6°；浏览器两版、视角、重播和移动端检查通过。五套动作均保留。
