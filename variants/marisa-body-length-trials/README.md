# 躯干加长：油臀保持原尺寸

[逃跑观察](index.html) · [侧面对照](comparison.png) · [并排动画](flee-comparison.gif)

修正上一轮误解：延长前脸到后身之间的主体，油臀所有方块的宽、高、深完全不变，只整体向后平移。主体、侧发、后发和帽子后部沿纵向延展；前脸、表情、宽度和高度保持原样。没有给油臀做拉伸或锥形处理。

A 原版，B/C/D 主体纵深分别增加 25%、50%、75%。新增长度以原主体前后 9.1 模型单位为基准，即后移 2.275、4.55、6.825 单位。臀部及骨骼 pivot 一同平移，躯干保持连接重叠。使用相同逃跑节奏和固定镜头。

验证：四版油臀尺寸一致、仅 Z 坐标发生统一位移；面部坐标保持；原五套动画关键帧完全一致。浏览器切换、播放、四个视角和移动端检查通过。每版可下载独立模型。旧模型及动作归档未覆盖；上一轮 marisa-depth-trials 属于已被用户指出方向错误的历史试验。
