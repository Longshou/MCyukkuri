# 魔理沙之间的噗咕较量

[打开互动预览](index.html) · [GIF](encounter.gif)

沿用用户选定的 A 完整闭眼线与贴脸泄气模型。两只魔理沙身体大小相同，鼓腮幅度独立，默认左 125%、右 80%。滑块可调整，交换强弱可验证反向互动。

演出：同时鼓腮 → 1.95 秒比较幅度 → 较弱者快速泄气、睁大眼和张嘴吃惊、后缩 → 转身 → 加速跳着逃离。获胜者稍后泄气并露出得意表情。幅度差小于 0.12 时不触发逃跑。对抗距离和时间在本演示中固定，幅度是本次预览的行为参数，不是八景原作 AI 数值。

更大的噗咕主要扩大宽度与深度，上缘高度设限以保留闭眼线。眼睛不向腮部前移，受惊睁眼在快速泄气完成后发生。

实现：scene.js 为确定性互动状态与两个角色骨骼姿态；同一深度缓冲渲染两只角色。build.py 从 marisa-puff-eye-a-clear 生成离线单文件页面。render.cjs 生成实际渲染帧。

验证：浏览器播放、强弱互换、弱方逃离、平局不逃、移动端宽度、无页面错误；见 verification.json。

范围：这是可交互的模型行为原型，尚未接入 Minecraft 实体 AI、寻路或联网同步。原单体 Blockbench 模型保留。
