## 观察与适配

- `ケツ振り顔()` 根据阶段切换四张身体图片，而面部、头发、帽饰维持对应固定图组；身体从隆起到压低，外轮廓发生变化。它是独立甩臀表现，不能当作普通行走的完整证据。
- `後ろケツ振り()` 中，后臀前景图按中间→左1→左2→左1→中间→右1→右2→右1切换。实际核读图中后臀本身改变方向和轮廓，不只是头发在摆。
- 普通目标移动还会根据移动模式调用不同形态、跳跃或爬行；本轮阅读了相关代码，未将其一概替换成上述甩臀动作。
- 本次改编采用独立臀部形体，主体前部保持朝前，后部横向甩动并压缩回弹；后发下缘让出可见空间。±16°、±1.1 单位和 1.2 秒均为适配本 MC 模型的设计值，不声称从原作测量得出。
