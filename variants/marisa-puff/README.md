# 魔理沙：噗咕鼓腮

[播放动画](preview.html) · [GIF](puff.gif) · [阶段对比](puff-stages.png) · [Blockbench 模型](marisa.bbmodel)

基于 marisa-expressions 增加左右独立实体腮部，每侧恢复原版九层轮廓；正常时压平在脸部表面，鼓起时从脸面向外膨胀。脸红随腮部前移。噗咕眼形与嘴形使用独立骨骼及自绘贴图，动画导出包含这些演出，不依赖浏览器切图。

6.4 秒循环：准备吸气 → 约 1 秒充气 → 赌气噘嘴鼓脸、轻颤 → 泄气与帽子轻摆 → 眨眼恢复。时间与三维厚度是本次适配选择。点“鼓嘴”表情可停在鼓腮姿态；“噗咕”动作按钮从头播放。210 方块、178 骨骼、5 段动作；已保留此前四套动作，左右体操仍为用户确认的半速。

验证：浏览器实际播放与按钮、移动端无横向溢出；Blockbench 导入后逐方块对比五套动作各 41 个采样姿态，并核对官方 Bedrock 动画导出。尚未接入 MC 实体；Java 包仍仅静态展示。

复现：`python generate.py`，`node render-puff.cjs`。参考来源见 [reference/README.md](reference/README.md)。

泄气修正：腮部背面固定在 Z=-4.62，九层分别压平回脸面，前表面始终处于皮肤之外，不再整体向后缩进头部。双眼固定在原有脸面深度；泄气保持赌气眼形，腮部在 4.5 秒压平后，于 4.5–4.95 秒自然睁眼。鼓满轮廓、6.4 秒节奏保留。[泄气逐帧图](deflation-stages.png)。

闭眼线微调：噗咕闭眼线沿脸面向上移动 0.35 模型单位，深度保持不变，增加与鼓腮上缘的间距。

可爱生气调整：噗咕改为带高光的小眼睛和轻压内眼睑，嘴收成小小的不满嘴形；眉毛倾角减半，腮部横向、高度及深度略收敛，轻颤减弱。眼睛仍贴原脸面，泄气压平方式保留。预设与动画共用新自绘表情。[对比](cute-comparison.png)。

最新：按用户要求撤回带高光赌气眼，恢复八景式挤眼、原鼓腮幅度与抖动。用户已选定 [A 眼形](../marisa-puff-eye-a/preview.html)，B/C/D 已弃用；[A 完整眼线](../marisa-puff-eye-a-clear/preview.html)仍为现用场景依赖。
