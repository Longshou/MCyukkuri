# 八景 U 噗咕参考

来源：本机 eightSight.v8.3 / ゆっくり八景U_Data/sharedassets0.assets。字段映射沿用 marisa-rump/reference/graphic-map.json；资源元数据见 sprite-index.json。

实际打开核读：基本ぷくー１頬グラベース[0] / 6589、基本ぷくー２頬グラベース[0] / 5948；基本ぷくー１顔グラベース[0] / 6547、基本ぷくー２顔グラベース[0] / 5600、基本ぷくー２B顔グラベース[0] / 7819。两组腮图都是独立的双颊圆鼓轮廓，中间留嘴部缺口，外上侧带脸红。第一组脸是用力挤眼，第二组眼睛张开；初版选择挤眼憋气演出；用户认为太用力后，改为自绘带高光的赌气眼形，属于后续风格适配。

代码：Eight景U-ModLab/analysis/decompiled/yu_base.cs，正面ぷくー１（32823 行）、正面ぷくー２（32922 行）。独立前面ボディ显示对应頬 sprite，位置跟随顔面位置；scale 从 0.7 加上一时标记 × 0.01，标记每次增加 3 直到约 30，后段反转震え幅。第二组按待機待ち切换 2 / 2B 脸图。调用频率未在本次核定，不能把这些计数当作秒数。

本次三维适配：原版九层轮廓，分层压平到脸面，深度、正向鼓出距离和 6.4 秒演出是原创制作参数；没有照搬原作帧速。导出贴图均为项目自绘像素，原作提取素材只存此参考目录。
