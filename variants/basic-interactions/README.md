## 制作与复用边界

- 魔理沙复用 `marisa-b-refined/marisa.bbmodel`，灵梦复用 `reimu-exercise/reimu.bbmodel`；源文件 SHA-256 在 `build-info.json`。
- 保留源模型的几何、UV 与编辑旋转，排除备用噗咕、用力、泪水图层；新增的小幅动作、笑脸／舔脸透明色素、舌头与双手示意由项目代码制作。
- 时间、相向路径、双手示意、友好回应、爱心、中文对白均为本次适配，未宣称逐帧复刻。未加入原生数值奖励与性格系统。
- 新互动在 `interactions.js` 中按绝对时间取样，`viewer.js` 负责模型表面接触与渲染。复制的 `.bbmodel` 保留原有动作；这六项新互动未烘焙到 Blockbench／GeckoLib 动画轨道。
- 所有贴图和 Three.js 已内嵌 `index.html`，无 CDN、远程图片或原作图层依赖。保留 Three.js 文件自身的许可证声明。

## 验证与重建

`node verify.cjs` 检查六项互动的恢复、打断重播、暂停、循环、速度、帧率独立性和 2,824 个采样。`browser-check.cjs` 通过本项目已有 Playwright 与本机 Chrome，检查两种角色的六项互动、接触极限、身体与饰品落地、恢复待机、视角保持及手机宽度，并输出截图和 `browser-report.json`。

`python build.py` 生成便携单文件预览。完整工作树优先读取当前选定模型；独立恢复时使用包内 `.bbmodel` 与 `three.min.js`。Node 行为检查无需额外依赖；浏览器检查需本机 Playwright 与 Chrome。
