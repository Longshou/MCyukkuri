# B 魔理沙：油菊、底部与脸部衔接修正

[自由视角预览](index.html) · [模型](marisa.bbmodel) · [前后对比](comparison.png) · [背面](rear.png)

明确参考 `../reimu-exercise/generate.py` 的解决方式，输入文件 SHA256 和面部映射保存在 build-info.json。

- 油菊：用同样的低像素交叉标记写入后臀皮肤贴图的 UV，随臀部一起摆动与变形，不用独立悬浮薄片。
- 前腹：伸长、上下体操、左右体操的前身 Z 缩放固定 1；底部宽度收窄幅度减半，减少重复水平小台面。未增加皮肤分层来掩盖问题。
- 脸部：删除 face_surface 整块肤色面板，保留原透明底表情部件；眼、眉、嘴、脸红等分别绑定相应高度的皮肤位移与转动，不施加局部拉伸。可见色素距前表面约 0.003–0.00372 单位。
- 噗咕：保留已选 A 眼形、上移量和实体鼓腮；伸长/体操期间收起备用鼓腮皮肤层，防止再形成前面板。逃跑沿用已收稳的臀部曲线。

当前 277 方块、191 骨骼，五套骨骼动作保留。预览可播放噗咕、伸长、逃跑及左右体操，播放时可随时旋转和缩放。

验证文件：geometry-verification.json 检查三个伸缩动作共 243 个姿态的五官与皮肤距离、前腹深度与后臀贴图；verification.json 检查播放中的自由旋转；blockbench-verification.json 检查五套动作逐方块姿态与官方导出一致性。旧版本与原归档保留，尚未接入 MC 实体 AI。

后续修正：逃跑眼神改为完整眼白加小瞳孔，修正收平腮部遮住眼睛下半圈的问题；侧辫、末端和发带按身体相同高度分段，并直接使用对应皮肤骨骼，消除侧弯时整块头发跟随头顶导致的穿模。当前 277 方块、191 骨骼。
