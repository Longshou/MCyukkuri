# 普通魔理沙 · 辫子互动

已按用户要求保存当前七项动作为 **v1**（2026-09-11）。[动作登记](saved-action.json) · [独立快照与 SHA-256 清单](approved-snapshots.json)。快照包含可编辑模型、动画、预览、验证结果及重建所需的普通魔理沙版本和共享运行代码；后续编辑不会改写这份快照。解压到新目录，打开 `interactions/marisa-braids/index.html`；在解压根目录运行 `python interactions/marisa-braids/build.py` 可重建（需要 Pillow）。

[打开七项互动预览](index.html)。捡拾石头、挥舞宝剑、拔草、取下帽子、护理帽子、挥辫道别、托子油到帽子上。可自由旋转、缩放、暂停、逐阶段定位、调速与重播；默认播放一次并保持完成状态，循环为可选项。

本模块复用当前统一库 `assembled/marisa` 的普通魔理沙几何、贴图与五官。身体、后发保持原样，侧辫分节弯曲并由辫梢形成卷握，帽子独立运动。子油是普通魔理沙模型的 0.30 倍实例。帽沿在托子油动作中向前展开，子油落稳后双辫收回，保留承托状态。

辫身以绷直为主：不再为保持长度而反复拱起、折回，改用轴向伸缩与浅弧到达接触点，卷握只保留在辫梢。探出和收回围绕辫根平稳转向。旋转采用最短转向并连续展开角度，避免跨越 ±180° 时突然转圈。摘帽放慢前移、翻转和收辫，时长为 9.2 秒。验证包括全动作辫身直线偏差、相邻帧转角和帽子转速。

最新调整保留原有拾石、挥剑、拔草、道别及托子油的物品轨迹。辫子向内收拢时，辫根沿侧发前缘前移，并略收窄辫身，减少切进脸侧的情况；摘帽保持原节拍，仅在托帽阶段增加 0.35 单位前向间距和 0.25 单位高度。该调整减少穿模，未建立完整物理碰撞系统，辫根连接和抓握处仍允许少量相交。

护理帽子已重新编排为 26.3 秒：取下 → 在身体上方缓慢转向自己 → 放低到身前地面 → 左辫扶稳、右辫擦帽带和理顺蝴蝶结 → 托起 → 转回佩戴方向 → 戴正。帽子转向期间，两辫沿帽沿内侧的平滑路径换位，不交叉穿过帽冠。实际擦拭发生在帽子降低并转过 180° 之后，帽带与蝴蝶结朝向魔理沙。帽子转向、落地高度、脸前间距和帽沿接触点均纳入验证。

构建整个统一库时会自动重建本模块。也可在统一库已构建后单独执行：

```powershell
python standards/yukkuri-library/interactions/marisa-braids/build.py
node standards/yukkuri-library/interactions/marisa-braids/verify.cjs
```

Python 需要 Pillow；验证使用项目已有 Playwright 和本机 Chrome。可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 指定其他安装。搬运整个 `yukkuri-library` 后仍可构建，无需旧 variants、冻结互动任务或八景游戏目录。

这里完成的是动作、模型与道具预览，尚未接入 Minecraft 实体 AI、物品栏、方块破坏、碰撞物理、存档或联机。导出为完整演示场景，打开模型后请选择动画查看；静态绑定姿态可能显示全部道具。接入引擎时角色与独立物品应拆为实体，抓握期间使用 `grip_left/right` 挂点，交接后转给地面或帽沿挂点，并由服务端控制拾取、拔草与子油乘坐状态。几何和动画保持统一库的坐标转换约定。

托子油完成状态保持子油在帽沿上；重播会重置到地面，这是预览重新开始，不是运行中掉落。其余动作收辫恢复；护理后灰尘保持清除，拔出的草保留在旁边。常态与其他动作仍使用原帽沿尺寸。
