# 标准美术素材

当前制作入口为 [yukkuri-library](yukkuri-library/README.md)。角色组件、表情、动作、派生资产和配套模型均在该目录内维护；它们不会自动打包进 Minecraft 模组。

| 入口 | 用途 |
| --- | --- |
| [素材库目录与约定](yukkuri-library/AGENTS.md) | 查找制作源、导出与草稿 |
| [标准帕秋莉](yukkuri-library/assembled/patchouli/patchouli.bbmodel) | 已确认的宽厚刘海、完整侧发与贴地小束尾造型 |
| [帕秋莉独立预览](yukkuri-library/assembled/patchouli/index.html) | 由用户打开并查看当前导出 |
| [游戏接入素材](../art/README.md) | 查看游戏选用的源文件和运行资源关系 |
| `yukkuri-library/body-standard/` | 当前圆润标准体型的配方、输入与合并组件；家油、DOS 与豆形保留各自体型 |
| `yukkuri-library/presentation/placement-fit/` | 帽子、头饰与头发位置适配的制作源，游戏接入见 [art/source/placement-fit](../art/source/placement-fit/README.md) |
| `yukkuri-v1/` | 仍被读取的成长规格（`profiles/growth.json`）、茎（`components/common/stem.json`）、出生行为与对应运行脚本 |

角色是否已确认，以各自登记和适用的文件指纹为准；位于标准库中并不表示所有草稿、表情和派生设计都已通过确认。执行边界遵循项目根目录的 [AGENTS.md](../AGENTS.md)。
