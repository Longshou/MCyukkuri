# 成长体型与标准灵梦茎生

[打开离线预览](lifecycle/index.html)

以当前标准灵梦为底，身体、油臀、头发、饰物和五官直接读取现有组件，使用普通静止姿态。成长采用整体等比缩放；没有重新塑造幼体比例，也没有改写原有动作。标准魔理沙可复用成长范围，本次茎生展示只装配灵梦。

## 成长范围

| 阶段 | 标准成体倍率 | 身体宽度（格） | 身体高度（格） | 身体深度（格） |
| --- | --- | --- | --- | --- |
| 赤体 / 茎上实子 | 0.10–0.20（胎生新生 0.14） | 0.083–0.166 | 0.053–0.106 | 0.071–0.142 |
| 子体 | 0.20–0.80 | 0.166–0.665 | 0.106–0.424 | 0.142–0.569 |
| 成体 | 0.80–1.20 | 0.665–0.998 | 0.424–0.636 | 0.569–0.853 |

2026-10-15 按用户要求调小新生：胎生 0.18→0.14，茎生落地 0.30→0.20，见[体型规范](../../docs/GROWTH_BALANCE.md#体型规范)。

基准身体包围盒为 13.30 × 8.48 × 11.375 模型单位，16 单位为一格；1 倍身高为 0.53 格。测量只用共用身体，不含油臀、辫子、头发和饰物。上表是项目分配的美术范围，不是 Wiki 原文数值，也尚不是游戏碰撞箱。

`profiles/growth.json` 是范围的单一来源；`runtime/growth.js` 提供阶段内连续插值与尺寸换算。个体差异参数改变成长曲线，不在每帧重新抽体型，阶段交界共用 0.20 和 0.80 两个端点。阶段由生命过程显式记录，不能仅看大小、幼语或饰品来反推年龄；普通大个体不自动属于 DOS。

## 参考与适配

本地 Wiki 的[基本设定](../../wiki/hakkei-reference/world/rules.md)沿用八景 U 年龄体系。[八景社区页](https://wikiwiki.jp/yukkuri8kei/ゆっくりとは)记载赤→子→成，实子在额头长出的茎上发育、落地即子体。该页写茎上约 2 期、营养良好时子体最快约 8 期成熟。这里保留阶段关系，不将其写成所有个体的固定成熟日，更不换算成现实月龄。

本项目按用户明确要求采用**每胎 1–5 只**，受孕时抽取一次并保存。公开概述页及当前核读的 U 基础挂接对象为三只，但不能据此把本项目数量锁为三只。其他数量选择或插值同一弯茎上的挂接点；四、五只放大同一弧线以留出空间，这属于三维适配。预览可指定数量，也可点“随机一胎”。

**新增记录（用户确认，2026-09-11）：母体大小影响子油数量，子油数量影响茎长度和粗细，并存在个体差异。** 此关系同时保存在 `behaviors/stem-birth.json` 的 `recorded_relationships`。具体函数、分布、系数与差异范围待定；当前预览保留均匀随机抽数和固定容量布局，不宣称已完整实现该规则。

核读本机 `eightSight.v8.3` 的 `sharedassets0.assets`：`基本茎成長` 下标 0 / 2 / 4 / 6 对应 Sprite 7456 / 8358 / 6197 / 7478。实际打开了下标 2 与 6：绿色茎从较粗的根部向尖端变细，成熟茎呈弯曲线形。其余两张已提取保留，可继续核读。原图与裁剪元数据保存在本地 `archives/reimu-stem-reference/`，未进入可移植包。该组是茎图层，不能单独当作完整亲子比例图或游戏截图。

连接子油头顶的部分按最新要求改为有体积的短细茎：八边截面、有端盖，朝头顶略微收尖，根部半径最多为挂接处主茎的 60%，尖端为自身根部的 78%。参考宽度由 0.01 调至 0.04，并受主茎比例限制。长度保留 **0.30** 参考单位，标准亲代下为 **1.86 模型单位（约 0.116 格）**，随亲代比例缩放。三维厚度、深度避让、四五只的空间扩展和落下轨迹为项目适配。来源核查记录和完整挂接树保存在本地参考目录，所有交付画面仍使用项目灵梦贴图及程序几何。

## 茎生过程

1. 0–4 秒：单根细茎从额头朝前上方伸长，位于身体正前方的竖直平面，没有侧枝。
2. 4–19 秒：本胎的 1–5 只实子从 0.10 倍连续长至 0.20 倍，闭眼沉睡，借细悬线与萼挂在弯茎下方，按悬线方向轻摆。
3. 20–22 秒：按数量均分脱落时点；只有一只时在 20 秒脱落。进入子体时大小连续，每只用 1.6 秒落到地面，脚底最终为 Y=0，落地才换成苏醒表情。
4. 出生后：子体留在地面，流程停止。预览暂保留茎，已移除“变枯并缩回额头”的错误表现。可循环或重播同一胎，数量不会每帧重抽。

### 出生后茎的处理（仅记录，暂不实现）

出生时，茎会**从根部自动脱落**。将来接入 Minecraft 时表现为生成物品 **“油库里的茎”**。本轮仅记录设定，没有实现根部脱落动画、物品注册或掉落物生成；此待办同时记录于 `behaviors/stem-birth.json` 与项目开发路线。

28 秒只是压缩后的演示时间。网页可拖动进度、旋转、缩放、检查亲代 0.80–1.20 倍体型，支持当前预览的本地保存与恢复。切换成长对照后可独立调整三个阶段的体型，地面与镜头保持统一比例。

### 胎生预览

[打开胎生](viviparous/index.html)。沿用标准灵梦，过程为孕体下部膨大、临产用力、赤体从正面嘴巴下方依次产出、母体恢复。生殖行为位于后侧，生产使用前侧独立挂点，按用户明确说明实现。漫画画格、来源差异及适配范围见[胎生参考](references/viviparous-comics.md)。

胎生出生阶段为赤体，当前演示体型为 0.18 倍；茎生出生进入子体的已确认规则保持独立。胎内子体不显示，产出时逐步显露，出生后落地清醒。32 秒节奏、1–5 数量控制和形变幅度为预览参数。

生产出口采用闭合、有厚度的皮肤网格。母体前侧几何留出开口，边缘跟随赤体在出口平面的截面；赤体只在接触带内收窄、圆化，脱离后回弹。颜色读取标准贴图的肤色与既有麻姆内缝色。点“挤压接触”再点“出口近景”可检查。此处是确定性接触形变，尚未接入 Minecraft 物理系统。参数在 `outlet_surface`，胎生构建额外使用 Pillow 读取贴图颜色。

`node tests/viviparous-contact.cjs` 检查闭合边缘、开口与赤体截面不相交、局部挤压与恢复，以及不同胎数和母体比例。构建时生成专用母体开口网格和细分赤体网格，不改写标准角色组件。

运行 `python build_viviparous.py`，并以 `node tests/viviparous.cjs` 检查出生事件、轨迹和保存恢复。`node tests/viviparous-browser.cjs` 核对页面与截图。胎生使用 `runtime/viviparous-birth.js` 的 `sample / geometry / create` 接口；数据字段为 `data.viviparous`。`create(data, mother, {count, random})` 只在创建时确定胎数，`advance(dt)` 在赤体完全产出时发送一次出生事件，事件 ID 带母体 ID。恢复时先用存档的母体和胎数创建行为，再 `restore(saved)`。进度拖动和几何渲染不发送出生事件。网页存档与茎生使用不同键，Minecraft 服务器存档与实体生成尚未接入。

```sh
python build_lifecycle.py
node tests/lifecycle.cjs
```

构建只依赖 Python 标准库，读取本目录组件与参数，生成内嵌数据的 `lifecycle/index.html`，直接打开即可；不会覆盖两角色原有装配成果。`lifecycle/source-provenance.json` 记录来源文件 SHA-256。

`runtime/stem-birth.js` 分离确定性 `sample(data, seconds, motherScale, count)`、场景几何和可推进的 `create(data, mother, {count, random})` 状态。未指定 `count` 时只在创建时随机一次。`advance(dt)` 接受外部时钟；跨过多个出生点时逐只返回事件，保存/恢复会保留数量和已发送的出生 ID，避免重载重复生成。行为恢复时用存档的 `mother` 与 `{count: saved.count}` 创建，再调用 `restore(saved)`。网页进度拖动仅采样展示，不产生真实游戏实体。预览存档与行为存档分别处理。

浏览器检查：从项目根运行 `node standards/yukkuri-v1/tests/lifecycle-browser.cjs`，使用项目现有 Playwright 与 Chrome，亦可用 `CHROME_PATH` 指定路径。检查全部 1–5 只、闭眼状态、阶段、侧后视角、体型端点、数量保存恢复、播放结束和窄屏布局，并写入截图与 `lifecycle/verification.json`。

这是美术与行为原型，尚未接入 Minecraft：没有实体注册、服务器存档、多人同步、营养成长或自然配对 AI。将来由服务器拥有生命时钟和出生事件，客户端只接收状态渲染；普通成体且采用茎生方式才可启动本行为，家油卵生不可套用。
