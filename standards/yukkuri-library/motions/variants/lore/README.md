2026-10-14 新增，待复查。依据 Wiki 中有作品或社区资料支持的身体动作，为已有的生态行为补上对应动作。之前这些行为大多只是待机加少量客户端摆动。设定出处见 [Wiki 总入口](../../../../../wiki/README.md)；编号 L、E、TM、N、W 与 Wiki 一致。

种族细节：
- 魔理沙问候时用粗辫挥一下，只在由 `hand_right` 带动辫子的形态（普通、螺壳、歪脸、家油）上生效。
- 灵梦系问候和しあわせー时鬓发ぴこぴこ（E02），只在鬓发由手部骨骼带动的形态上生效。
- 魔理沙的前倾、侧倾类新动作沿用[单辫跟随](../contact-safe/README.md#魔理沙单辫跟随)，辫子不进皮肤、不入地面。

## 做法

- `recipe.json` 写时长、循环、幅度和出处；`author.py` 的 `state()` 给出每个时刻的整体变换，与修正动作一样只驱动 `root`，包括缩放、旋转（Rz·Ry·Rx）、抬升和水平位移。
- 由 [contact-safe](../contact-safe/README.md) 第 9 版的 `compile_revision` 逐形态编译：每 0.04 秒采样一次，按可见网格最低点落地，所以前倾时绕着地面接触点倾斜，不会陷进地面。
- 产物写入 `yukkuri_presentation/motion_corrections.json`，作为新的片段名合并进 19 种形态。基础模型、指纹、伤口和徽章数据不变。
- 服务器按行为选动作：`social/EcologyPresentation` 的 `action`、`group`、`reaction` 三张映射表，由 `entity/YukkuriEntity` 选用。优先级为：命令动作、移动时走路、乘帽船、群体互动、行为、短反应、无饰品时低落。
- 客户端在模型带有 `sleep` 片段时，不再做旧的睡眠压扁；擦脸、唱歌和跟拍的摇摆也交给片段，擦脸时贴近对方的位移仍保留。

重新导出：

```powershell
python scripts/export_motion_corrections.py
python standards/yukkuri-library/motions/variants/lore/preview.py
```

导出需要 numpy 与 Pillow，19 种形态约 7 分钟；`preview.py` 输出离线动图和预览页。

## 限制

- 动作是整体刚体变换，加手部骨骼的小幅摆动，没有分段扭动；表情沿用各行为已有的表情。
- 服务器端判定伤口落点时，仍按伤口数据里的基础片段摆姿势，新片段在这里视为待机。客户端绘制伤口时跟随新片段。
- 蹦床本身已有物理弹跳，不叠加 `hop`。人类擦脸（`RUB` 接触姿势）沿用原有的客户端摆动。
- 本机未编译、未运行游戏；动作只做了离线采样与渲染。游戏内效果待用户查看。
