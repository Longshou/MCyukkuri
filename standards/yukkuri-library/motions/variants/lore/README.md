# 世界观动作

2026-10-14 新增，配方第 4 版，待复查。依据 Wiki 中有作品或社区资料支持的身体动作，为已有生态行为补上动作，并补上分娩、接生和水生魔理沙的帽船动作。设定出处见 [Wiki 总入口](../../../../../wiki/README.md)；编号 L、E、TM、N、W 与 Wiki 一致。Wiki 没有记载的部分写明是本项目设计。

**预览**
- 世界观动作预览：`births.py` 在本机生成单个静态网页，输出到 `.local/previews/lore/index.html`，不入库，分两页。
  - “出生与接生场景”：夫妻、接生者和出生的子油都在场——陆生胎生（父亲用辫子摘帽接）、陆生茎生、水生帽船分娩与夜里在帽内睡、水生靠岸接生与失误落水、夜里帽船上睡、单亲魔理沙自己接，另有体型规范与茎长对照。孕体、收缩、茎与实子按游戏的几何绘制；帽子是[帽子容器](../../../interactions/marisa-hat-vessel/README.md)；新生儿的路线与游戏相同（[孩子怎么进帽子](../../../interactions/marisa-hat-vessel/README.md#孩子怎么进帽子)）。孕期的表情面片按游戏 `PregnancyFaces` 的做法贴在鼓起的身体前表面上。
  - “单个动作”：选择动作后播放，可旋转、缩放、调速或拖动时间；每个动作只显示适用的形态（例如缩壳只显示螺壳魔理沙，帽船动作只显示水生魔理沙），表情按动作内的编排切换。
- 素材检查室的模型页也能选择这些动作。
- 回复里展示的截图也渲染到 `.local/`，不入库。

- **依据**
  - 分娩：母体用力、闭眼、张嘴，一次推出一只（[胎生漫画记录](../../../../yukkuri-v1/references/viviparous-comics.md)，CADあき、無声あき、AVあき）。
  - 新生：实子闭眼沉睡，落地才醒（八景素材与本项目规则）。
  - 接生：Wiki 没有记载帮手，接生是本项目设计；擦脸依据すーりすーり（E06）。
- **接生规则**（用户设计）：
  - 只有魔理沙接生：这一胎的父亲若是戴帽的魔理沙，由他接；单亲时母体若是戴帽的魔理沙，就自己接。灵梦×魔理沙夫妻一律灵梦为母、魔理沙为父。
  - 用户：父油用辫子和帽子交互。接生者走到站位，用辫子摘帽、倒过来按在出口前，帽冠压扁（用户 2026-10-15：“巢”只是比喻，帽子倒过来、底部压扁就行），帽子在出口正前方，近侧帽檐离孩子 3 格；孩子被推出后划一道弧线落进帽里，在帽里初醒，之后先跳出帽子，接生者再回到原位用辫子拿回帽子戴好。茎生时父亲把帽子顺着茎放在实子正下方，实子直直落进帽里。
  - 帽子就是头上那顶，[倒过来、帽冠压扁](../../../interactions/marisa-hat-vessel/README.md)；站位、抓握点和帽子落点由容器的 `hat_vessel.json` 给出，辫子动作由 `hat.py` 求解：辫子绕辫根转动、沿辫长伸缩去够抓握点，辫梢卷住帽檐，帽子作为整体绕抓握点转动，经辫子一侧摆出，不穿过头部。离线核算辫长伸缩在 0.67–1.33 倍（岸边浮帽 1.0–1.5 倍），相邻采样插值误差不超过 2°。
  - 用力过猛时（原创 12%）孩子越过帽子，落水或落地而死，父母播放 `bereaved` 并说“油库里……油库里——！”。
  - 动作与母体的收缩同步，每次出生都去迎接。
- **呆滞脸**：标准表情 `blank_confused`（N007）和 `blank_cry` 由 `faces.py` 复制为灵梦、魔理沙、爱丽丝、橙、帕秋莉、螺壳魔理沙的运行贴图 `dazed.png`、`blank_cry.png`，只复制给运行图集与标准导出逐字节一致的种族；其他形态按回落链用惊讶和哭泣。

| 片段 | 时长 | 动作 | 表情编排 | 情景 |

| `boat_steady` 稳船 | 1.5 秒循环 | 缩紧身体，快速细小平衡 | 憋住 → 含泪 | 船进水、被拉拽、受惊 |
| `boat_call` 呼唤 | 2 秒循环 | 起身朝岸摇摆呼喊 | 哭喊与含泪交替 | 河边追随事件中 |
| `boat_brood` 帽船安胎 | 4 秒循环 | 低伏帽中，随水起伏 | 闭眼笑、满足 | 孕期在船上 |
| `boat_labor` 帽船分娩 | 2.4 秒循环 | 贴着帽底，用力幅度比陆上小；出生后转身把孩子揽进帽里 | 含泪 → 憋住 → 用力 → 闭眼笑 | 在船上分娩 |
| `hat_cradle` 帽中幼体 | 3 秒循环 | 坐在倒放的帽子里轻轻摇（帽船上白天在船主身前，夜里在她身下睡） | 开口笑 → 闭眼笑 → 犯困 | 帽船、地上或浮着的帽子里的幼体 |

- **依据**
  - 漂流：魔理沙蜷在帽船中漂流，同伴沿岸追赶呼唤（special-events）。
  - 稳船：漂流者缩紧身体稳船（events“湖上别乱动”）。
  - 小心不让身体落水、帽子进水（L25）。
  - 帽子运送幼体（L06）。
- **水上分娩的差别**（用户设计）：
  - 水生魔理沙夫妻都是水生魔理沙；水生魔理沙的帽子比陆生大（用户允许，原创 1.5 倍）。帽船上她坐在船尾的帽沿上，在船上分娩时孩子从出口直接落进身前帽内的干燥空间（用户：帽内是空的，没有进水，像小船一样装子油和食物）。
  - 临产时也可以临时靠岸，在岸边面朝河待产，像陆生一样用辫子摘帽接，只是把大帽翻过来浮在岸边水面上（`*_aq` 版本），父亲在岸上扶着帽檐，单亲则自己放好。用力过猛的孩子越过浮帽落进河里（用户：接生失误落水是水上接生的情形）。
  - 夜里子油睡在帽内的干燥空间，大亲油在上方，帽船仍漂在水上（用户纠正）；不再在岸上放帽过夜。

### 其他

- 已有片段的接入：
  - 玩具反应用 `hop`。
  - 螺壳魔理沙受惊时原地 `shell_retract`，不逃跑；缩壳期间受到的伤害减半（本项目原创）。下雨缩壳暂不做。

- 魔理沙问候举辫时，辫子略向前摆，辫根沿头侧下移 0.22 倍辫长；离线核算不穿帽檐、不进身体。

## 种族门控

`recipe.json` 的 `groups` 和每个片段的 `applies` 决定片段编入哪些模型；`scripts/validate_entity_assets.py` 按同一份规则校验。

| 分组 | 适用 |
| --- | --- |
| `all` | 全部 19 种形态 |
| `breeding` | 可繁殖形态：去掉家油（卵生）和不足形态 |
| `live_birth` | 可胎生形态：再去掉只茎生的捕食种 |
| `not_house` | 除家油外，供帽中幼体使用 |
| `aquatic_marisa` | 只有 `marisa` 模型；水生魔理沙沿用它 |
| `marisa_midwife` | `marisa`、`marisa_tsumuri`（螺壳无帽，只打气） |
| `marisa_hat` | `marisa`（用辫子摘帽、扶帽、戴帽；水生魔理沙沿用它，帽子按 1.5 倍绘制） |

游戏中，帽船类动作只在水生魔理沙船主和她船上的幼体身上触发。服务器选动作的优先级：

1. 命令动作
2. 移动时走路
3. 帽船
4. 群体互动
5. 行为
6. 短反应
7. 无饰品时低落

## 表情编排

- 每个片段带 `expression_spans`，在片段时间内依次换表情。
- 缺少的贴图按 `face_fallback` 依次替换，例如没有 `puff` 时用 `chewing_closed`；导出时逐个模型核对，只引用存在的贴图。
- 片段的 `expression_yield` 是 `["cry"]`：受伤时服务器给出的哭脸优先于编排。

## 做法

- **配方与求值**
  - `recipe.json` 写时长、循环、幅度、表情编排、门控与出处。
  - `author.py` 的 `state()` 给出每个时刻的整体变换，只驱动 `root`，包括缩放、旋转（Rz·Ry·Rx）、抬升和水平位移。
  - 手部骨骼的小幅动作另加：魔理沙挥辫、鬓发ぴこぴこ、分娩时侧发颤抖。
  - 带 `hat` 块的片段由 `hat.py` 求解，额外驱动 `hat_follow`（帽子与蝴蝶结整体，放下时沿帽子轴向把帽冠压扁到陆地或水上的比例）、`hand_right`（辫子，旋转加沿辫长缩放）和辫梢 `hand_right_tip`、`hand_right_ribbon`（卷住帽檐并抵消辫长缩放）。帽子的终点就是游戏放下帽子实体的位置，取自[帽子容器](../../../interactions/marisa-hat-vessel/README.md)的 `hat_vessel.json`；`reverse` 的片段按时间倒放。水生版本让未缩放的帽子落在大帽的锚点上，游戏再按 1.5 倍缩放帽子骨骼。
- **编译**
  - 由 [contact-safe](../contact-safe/README.md) 第 9 版的 `compile_revision` 逐形态编译。
  - 每 0.04 秒采样一次，按可见网格最低点落地，所以前倾时绕着地面接触点倾斜。
  - 产物写入 `yukkuri_presentation/motion_corrections.json`；基础模型、指纹、伤口和徽章数据不变。
- **跟随身体的挂件**
  - 客户端让嘴里叼的食物、额头的茎和胎生出口跟随本帧的 root 变换，身体前倾、起伏时不会脱开。
  - 孕体按 `LiveBirthGeometry.deform` 变形；饰物和魔理沙的辫子不参与变形，而是整体抬到变大的头上（帽子按头顶的抬高量，辫子按辫根的位移）。帽子或辫子被动作带离原位时，这个抬高量逐渐减到零，好让它们落在动作给出的位置。
  - 胎生出口的切洞在静止空间里计算，再放回当前姿势。
- **服务器端**
  - `social/EcologyPresentation` 的 `action`、`group`、`reaction`、`boat` 四张映射表，由 `entity/YukkuriEntity` 选用。
  - 分娩与接生片段（含 `hat_hold`）的起点对齐收缩时钟。
  - 辫子摘帽、戴帽由 `family/FamilyLife` 的帽子状态驱动：接生者先走到动作要求的站位并对正朝向，播放 1.6 秒（单亲 1.8 秒）的片段，片段结束时帽子变成地上或浮着的帽子实体；取回时先回到同一站位，帽子实体变回头上的帽子，再倒放片段。

重新导出：

```powershell

python scripts/export_motion_corrections.py
python standards/yukkuri-library/motions/variants/lore/births.py

```

## 限制

- 动作是整体刚体变换加手部骨骼小幅摆动，没有分段扭动。魔理沙的辫子在游戏里是一节刚性骨骼，摆弄帽子时靠绕辫根转动和沿辫长伸缩去够帽檐，伸缩在 0.65–1.32 倍；在岸边扶浮帽时要伸到水面，达 1.35–1.45 倍，看上去会明显变长。
- 服务器端判定伤口落点时，仍按伤口数据里的基础片段摆姿势，新片段在这里视为待机。客户端绘制伤口时跟随新片段。
