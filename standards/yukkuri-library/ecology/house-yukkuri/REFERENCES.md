# 家油参考核读

## 当前采用规则

当前采用较高、下腹饱满、上部收窄的卵形体态。v4 使用 71 个身体方块，以八边截面填充和连续斜面形成轮廓，造型待确认。头发、辫子、帽子、蝴蝶结和五官沿用标准组件，表情使用统一图集。下述大圆眼和短侧发观察属于历史参考，不作为当前外观的实现说明。

## 体态参考：用户所给形象

2026-09-11 用户提供四格灵梦图（文件名 `codex-clipboard-e838d23d-5b30-4896-9dc6-5384cd85adbd.png`），本轮已看图。作者和原始发布处未知，不根据图像猜测署名。图中可见上部略窄、下腹圆润的竖向卵形；大圆黑眼带白色双高光、小 ω 嘴、椭圆腮红；棕黑色尖刘海、扎红白发饰的短侧发及头顶红白蝴蝶结。四格分别表现普通、惊讶张嘴、斜侧面和鼓嘴带食屑。

前一版曾将这些特征适配为细分方块几何和自绘表情；该方案已按用户最新要求替换为低面数身体与统一组件。参考原图另存 Git 忽略的 `reference/house-yukkuri/user-reference.png`，不打入资产包。Wiki、漫画和小说继续提供下述生态依据。

## 本次设计

- 当前身体尺寸为宽 3.28、高 3.95、深 2.36 单位，饰物另计。身体最宽处位于离地 1.45 单位，底缘圆收，肩部逐段向顶部收窄。脸部保留浅平面，以承托标准五官；其他部件按统一 0.24 比例缩放后挂接。Wiki 的“赤油大小”和小说的大小描述不完全一致，模型具体尺寸仍是美术适配参数，不是测得的原作尺度。
- 子油为家油成体的 32%；三枚卵与 18 秒片段便于观察。未定义真实产卵量、孵化时长或世代遗传概率。
- 棉絮与灰尘使用灰米色短方块、散纤维；卵用奶白阶梯圆形糖壳。颜色和方块化几何均为原创适配。糖壳材质的文字出处仍按[既有记录](../../../../wiki/hakkei-reference/lore/house-nest-sources.md)标记为二手资料，不因本次建模提升为原作确证。
- 休息区与卵区相邻，画面留出通道。搬棉絮、觅食路线、晃卵和幼体离壳的关键时序是本次演示设计；普通走动、受惊动作复用当前素材库。
- 不将徽章、项圈或宠物服饰加给家油；不采用伤害画面作为正常外观。具体表现只服从当前项目已采纳规则。
