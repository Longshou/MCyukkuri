# 天然住所的叶床、结界与纸箱

原创制作源为 `build.py`，叶床、个人小叶巢和叶束由 `drafts/care-props/wild.py` 生成；叶床按成体真实尺寸铺设，后高前低的叶团围沿连接相邻睡位。部件引用原版贴图而不复制纹理文件。渲染单位为：1 铺垫、2–5 边中段、6–9 外角、10–17 边延续段。细枝结界、纸箱和便所由本包制作源维护。天然住所只添加叶床与细枝，洞顶、洞壁和坑底由现有地形提供；来源指纹见 `manifest.json`。

从仓库根目录运行 `python standards/yukkuri-library/ecology/wild-shelters/build.py`，同步可编辑 `.bbmodel`、静态网格、图集、选用快照及游戏资源。

每格十六单位，+Z 为入口。`forest_burrow` 由两层错叠、压实的折叶底垫、干草和细枝组成：相邻共巢睡位只连续平铺基础叶垫，连通组外缘才显示朝外斜起的蓬松围沿，因此形成一张没有内部接缝的亲子大巢。`personal_leaf_nest` 是后期子体在原睡位完成的较小椭圆叶碗，中心较低、四周草叶团与叶片较高；两者都不产生土墙或屋顶，也不增加物理睡位。角色脚部的局部 `Y=0` 是睡眠站立面基准：压实底垫嵌入其下，外沿最高约为 `Y=1.4`，不会覆盖新生体面部。入口细枝移至现有侧壁，浅坑沿上的细枝横放贴地，没有拱框或绑绳，森林模型碰撞为空。纸箱保留 3×3×2 格的外壳、一人睡位与原创纸板纹理。均为静态网格，无角色骨架或独立动画。

天然住所的能力与尺度以项目采用的生态规则为依据。纸箱参考为ゲスあき《街でゆっくり・ダンボールハウスでゆっくり》（2013-09-05，[原页面](http://blog.livedoor.jp/yukkuri_anko/archives/29803869.html)）。参考图不进入运行纹理。

`manifest.json` 保存来源及当前导出指纹。[生活环境说明](../../../../docs/WILD_SHELTERS.md)记录地形勘测、搬运和天气行为。
