# 天然住所的叶床、结界与纸箱

原创制作源为 `build.py`。当前选用已接入 Minecraft。用户于 2026-09-13 确认此前展示的天然洞穴叶床、细枝结界及浅坑布置，指纹登记在 `manifest.json` 的 `approvals`；本轮连续共巢叶垫与个人小叶巢待用户确认，纸箱和便所造型也仍待确认。用户已否定此前的整座覆土工事；森林资产只添加叶床和细枝，洞顶、洞壁与坑底由现有地形提供。

运行 `python standards/yukkuri-library/ecology/wild-shelters/build.py` 同步可编辑 `.bbmodel`、静态网格、图集、选用快照及游戏资源，并在本机生成多角度预览（不入库）。需要现有 Python、Pillow 与 Node.js。`verify.py` 核对源、选用与运行文件，将报告写入 `.local/reports/wild-shelters/`。

每格十六单位，+Z 为入口。`forest_burrow` 的叶面层按实际相邻共巢睡位连续平铺，边缘仅在整个连通组的外侧显示叶和细枝；`personal_leaf_nest` 是后期子体原睡位上的较小叶巢。两者厚度不足一单位，不建土墙或屋顶。入口细枝移至现有侧壁，浅坑沿上的细枝横放贴地，没有拱框或绑绳，森林模型碰撞为空。纸箱保留 3×3×2 格的外壳、一人睡位与原创纸板纹理。均为静态网格，无角色骨架或独立动画。

天然住所的能力与尺度以用户 2026-09-13 的生态纠正为依据；此前覆土图像的转译不再作为普通野外油库里的建造能力。纸箱参考为ゲスあき《街でゆっくり・ダンボールハウスでゆっくり》（2013-09-05，[原页面](http://blog.livedoor.jp/yukkuri_anko/archives/29803869.html)）。参考图不进入运行纹理。

`manifest.json` 保存来源及当前导出指纹。[生活环境说明](../../../../docs/WILD_SHELTERS.md)记录地形勘测、搬运和天气行为。
