# 天然住所的叶床、结界与纸箱

原创制作源为 `build.py`，叶床、个人小叶巢和叶束由 `drafts/care-props/wild.py` 生成；叶床按成体真实尺寸铺设，后高前低、由叼来的散干草堆压成的围沿连接相邻睡位。贴图为 `drafts/care-props/wild_kit.py` 的手绘图集，不引用也不复制原版纹理。渲染单位为：1 铺垫、2–5 边中段、6–9 外角、10–17 边延续段。细枝结界和纸箱由本包制作源维护。天然住所只添加叶床与细枝，洞顶、洞壁和坑底由现有地形提供；来源指纹见 `manifest.json`。

从仓库根目录运行 `python standards/yukkuri-library/ecology/wild-shelters/build.py`，同步可编辑 `.bbmodel`、静态网格、图集、选用快照及游戏资源。

每格十六单位，+Z 为入口。`forest_burrow` 由铺满整格的落叶垫、几片大叶与苔藓，以及外露边上一层层压实的散草、细枝和外露草茎组成：相邻共巢睡位只连续平铺落叶垫，连通组外缘的散草层略伸过段端、互相叠成一圈，因此形成一张没有内部接缝的亲子大巢。`personal_leaf_nest` 是后期子体在原睡位完成的较小椭圆草窝：先散几片叶，再推出一圈带缺口的低散草，最后一层层堆压成后高前低的草碗；两者都不产生土墙或屋顶，也不增加物理睡位。角色脚部的局部 `Y=0` 是睡眠站立面基准：落叶垫顶面约 `Y=0.2`；围沿在睡坑之外（内脚约距中心 6），入口侧最低，正面不挡新生体面部。入口细枝移至现有侧壁，浅坑沿上的细枝横放贴地，没有拱框或绑绳，森林模型碰撞为空。纸箱保留 3×3×2 格的外壳、一人睡位与原创纸板纹理。均为静态网格，无角色骨架或独立动画。

洞口结界屏障（方块 `den_barrier`，项目设计）由 `den_barrier.py` 生成原生方块模型、64×64 手绘贴图（沿用 `drafts/care-props/wild_kit.py` 的树皮、切口、落叶垫与叶片画法）、blockstate 和快照 `art/source/den-barrier/`，`--check` 只核对；`preview_den_barrier.py` 出离线预览。细枝插进土里，或沿洞口斜靠、或向格心倾倒搭在对面枝上，少数 45° 歪倒、两根带分叉；格心推进一团松散落叶，枝缝里塞一两片叶，脚下散落叶和两截短枝。不绑不编，顶部参差、留缝；方块无朝向，四面各有一层，碰撞为 14×16×14。

天然住所的能力与尺度以项目采用的生态规则为依据。纸箱参考为ゲスあき《街でゆっくり・ダンボールハウスでゆっくり》（2013-09-05，[原页面](http://blog.livedoor.jp/yukkuri_anko/archives/29803869.html)）。参考图不进入运行纹理。

`manifest.json` 保存来源及当前导出指纹。[生活环境说明](../../../../docs/WILD_SHELTERS.md)记录地形勘测、搬运和天气行为。
