# 魔理沙的帽子容器（帽船、侧放接生、岸边浮帽）

2026-10-14 起，接生用的帽子和水生魔理沙的帽船都改用魔理沙本人戴着的那顶帽子，状态为**待用户确认**。原因是用户指出分娩中的物件大小不匹配：原先的帽船道具 `hat_boat` 是旧方块时代的扁平碟形原型，帽檐比身体宽很多，帽冠只有 4 格深，和头上的帽子不是同一个东西。

## 造型

`build.py` 读取当前选用的运行模型 `yukkuri/marisa.json` 中的帽子部件（`brim_*`、`hat_*`、`bow_*`，全部是轴对齐的方块），逐块复制。

- **掏空**：帽檐和上两层帽冠（帽底一层、第一层收窄）掏成干燥的帽内空间，两层之间留一道台阶，第一层收窄的顶部是底板。下面几层、弯尖和蝴蝶结保持实心。壁厚 0.55 格。
- **贴图**：外表面沿用帽子在魔理沙图集里的原格子，按原面的映射取子区域，所以和戴着时一模一样。朝向帽内的面用帽檐边的深色格子。游戏和预览都直接用魔理沙的图集绘制，没有另做贴图。
- **坐标**：帽子翻过来，开口在原点、朝上，长的帽檐轴沿 Z，帽冠在下方。

| 用法 | 状态 | 姿态 |
| --- | --- | --- |
| 水生魔理沙的帽船 | `AFLOAT` | 开口朝上，帽檐高出水面 1.6 格（按帽子大小缩放），水面在开口处被遮住；船主坐在船尾帽沿上，幼体坐在帽内底板上：白天在她身前，夜里在她身下 |
| 陆生魔理沙接生 | `CRADLE` | 翻过来侧放在出口前，开口朝向母体，倾角取帽子实际几何的自然静止角：帽冠背面着地时 67.9°，蝴蝶结一侧着地时 75.3° |
| 水生魔理沙在岸边接生 | `MOORED` | 翻过来浮在岸边水面，近侧帽檐塞到岸下，开口在出口前，保持原位 |

水生魔理沙的帽子按用户允许做得比陆生大（原创 1.5 倍），戴在头上时也按这个大小绘制（游戏中按帽子在头上的落点缩放帽子骨骼）。

## 接生时帽子放在哪里

`hat_vessel.json` 的 `placements` 给出动作编排用的位置，游戏和动作编排读同一份数据。

- **帮手**（父亲）：用 `grip_worn` 记录的帽檐点钩住帽子。脚本在母体周围搜索帮手的位置和朝向，条件如下：
  - 辫子能够到抓握点，伸缩控制在 0.75–1.2 倍以内；在岸边时放宽到 1.45 倍，因为河岸比水面高。
  - 帽子不进入帮手身体，帮手不与母体重叠。
  - 帮手站在帽檐一端，不站在帽冠后面；在岸边时必须站在岸上。
  - 尽量面向母体的出口。
- **单亲母亲**：
  - 陆生：把帽子放在自己出口前，让它侧卧在蝴蝶结一侧。这样她辫子一侧的帽檐靠近自己，俯身 20° 就能放下、拿回。
  - 水生：把帽子浮在岸边。

游戏按母体的实际出口算出帽子位置，再反推接生者的站位和朝向，所以动作结束时头上的帽子正好落在帽子实体所在的位置。

## 文件

| 文件 | 用途 |
| --- | --- |
| `recipe.json` | 壁厚、水生帽子大小、抓握点、站位搜索的权重、帽船坐位、孕体参数（用于算出口） |
| `build.py` | 生成道具和数据，`--check` 只读核对 |
| `manifest.json` | 配方、脚本与输出的 SHA-256 |

运行资源：

- `src/main/resources/assets/mcyukkuri/yukkuri_props/marisa_hat_vessel.json`：道具网格，登记在 `subspecies-index.json`。
- `src/main/resources/assets/mcyukkuri/yukkuri_presentation/hat_vessel.json`：帽子尺寸、开口、底板、侧放姿态、坐位和接生站位。由 `HatVessel` 读取，[帽子动作](../../motions/variants/lore/hat.py)也读这一份。

重建顺序：魔理沙帽子造型改动后，依次运行：

1. `build.py`
2. `scripts/export_motion_corrections.py`（重新生成辫子动作）
3. `motions/variants/lore` 下的 `births.py`、`page.py` 与 `preview.py`

```
python standards/yukkuri-library/interactions/marisa-hat-vessel/build.py
```

需要 numpy，不启动游戏或浏览器。
