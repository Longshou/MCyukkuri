# 魔理沙的帽子翻过来：帽冠压扁

接生帽与水生魔理沙帽船都由魔理沙本人帽子倒置、压扁帽冠构成；不是另造巢或船体。

参考图见 [Wiki 美术参考](../../../../wiki/art-references/README.md)：

- EH22-001：水上魔理沙坐在帽里。
- EH22-006：把东西收进帽里。
- EH22-007：空帽浮在水面上。

实体 ID 保留 `hat_boat` 以兼容旧存档；当前唯一帽子道具为 `marisa_hat_turned`。

## 造型

`build.py` 从当前运行模型 `yukkuri/marisa.json` 逐块复制帽子（帽檐、帽冠各层、帽带、蝴蝶结），外表面沿用魔理沙图集里原来的格子，游戏和预览都直接用魔理沙的图集绘制。

1. 帽檐和帽冠前三层掏空成逐层收窄的内腔，壁厚 0.55 模型单位：开口是 8.7 × 12.0，中央深度为 7.0291（水上压扁后 3.866）。前部在原帽冠基座内保留浅台阶，与侧壁和下层布料相连；没有悬空托盘。内腔朝里的面用帽檐边缘的深色格子。
2. 整顶帽子倒过来，开口朝上，帽檐长轴沿 Z，原来戴着时的正面（蝴蝶结一侧）在 +X。
3. 帽冠沿帽子的轴向压扁，帽子形状不变：

| 放在哪里 | 实体状态 | 压扁 | 结果 |
| --- | --- | --- | --- |
| 陆地 | 接生的帽子（`CRADLE`） | 0.29 倍 | 帽冠压到贴地，帽檐离地 3.2 格 |
| 水上 | 水生魔理沙的帽船（`AFLOAT`），以及靠岸接生时浮在岸边的帽子（`MOORED`） | 0.55 倍（项目设计：原 0.75，压平水下帽冠让帽腔底抬高，岸上看得见帽里的孩子；帽檐、帽带与外观不变） | 帽冠沉在水下，帽檐高出水面 1.2 格（按帽子大小缩放）；开口处遮住水面，帽里是干的 |

只有一件道具 `marisa_hat_turned`，压扁比例由游戏按陆地或水上绘制时施加。

水生魔理沙的帽子及其佩戴尺寸为陆生帽子的 1.4 倍（项目设计：1.5 倍时成体船长几乎塞满帽口；1.4 倍取自预览，[R6](../../../../docs/REFACTOR_DESIGN.md)）。

陆地上帽檐离地 3.2 格，幼体从出口沿短弧越过近侧帽檐。

前部浅台阶低于帽檐 0.6 单位（水上高 0.87），范围 Z=-6.01…-4.00（深 2.01）；内腔分段由浅至深记录在 `hat_vessel.json` 的 `cavity_sections`。

**坐位**：

- 每只幼体有自己的位置，按身体大小（碰撞宽度的 0.42 倍作半径）排开，彼此留出约一成空隙；内腔底坐不下时才坐到台阶上。
- 位置由服务端给出并同步：茎生实子落在帽里空着的地方就坐在原处，胎生的孩子从帽子正中往外依次排；选位置时避开要从别的幼体身上越过去的地方。

当前帽面几何与坐位由 `recipe.json`、`delivery.py` 与 `hat_vessel.json` 共用。

## 摘帽与戴回

[辫子动作](../../motions/variants/lore/hat.py)搬动的是头上那顶帽子：

1. 辫子勾住帽檐上的一点，把帽子抬离头顶。
2. 绕辫根向辫子一侧摆出，在放帽的地方上方翻过来。
3. 从放帽地方的上方、远离接生者一侧落下按住，帽冠随之压扁到陆地或水上的比例，同时辫子从帽檐滑到开口外的帽檐上。
4. 动作结束时，游戏在同一位置换成帽子实体，姿态与动作末帧一致。戴回帽子时整个过程倒放。

## 孩子怎么进帽子

`delivery.py` 给出出生推出的路线，游戏（`HatGeometry`、`FamilyLife` 的飞行）与出生场景预览用同一套规则。出生外力路线是重力下的抛物线（重力取 Minecraft 的每刻 0.08 格）；主动跳跃由 `YukkuriLocomotion` 按身体能力另行求解，规则见[乘员转移](../../../../docs/AQUATIC_MARISA_IMPLEMENTATION.md#乘员转移)。

- **胎生**：孩子从出口挤出后被推出去，划一道弧线越过近侧帽檐，落进自己的位置。弧线取最短且不碰帽子的时长：飞过帽檐、台阶时整个身体离帽面至少 0.35 格；落向内腔时只要求身体正下方不穿帽面。帮手接生时约 5 刻（0.25 秒），最高约 5 格；单亲母亲自己放的帽子更近，个别弧线高一些（5–6 刻，最高约 7 格）。新生大小按[体型规范](../../../../docs/BEHAVIOR.md#体型规范)：胎生 0.14、茎生 0.20。
- **用力过猛**（原创 12%）：同一方向飞过整顶帽子，落到远侧帽檐外的地上或河里。
- **茎生**：实子从茎上直直落下。落在帽内空地就地坐好；碰到帽檐弹一下跳进去；落在帽子旁边的地上或水里，再跳进帽里。
- **帽船上分娩**：孩子出来就在她身前，轻轻落进帽内。
- **拿回帽子前**：幼体先跳出帽子，并排落在帽子没有大人的那一侧（岸边浮帽则跳上岸）。每只配给路线不交叉的落点，离落点最近的先跳，间隔 4 刻，不从还坐着的兄弟姐妹身上越过；全部跳出后约 0.7 秒再拿帽子。

## 放在哪里

`hat_vessel.json` 的 `placements` 给出位置，游戏和动作编排读同一份数据。

- **胎生时帽子的位置**：在出口正前方，长轴横在母体前，近侧帽檐在孩子身体前方 3 格；单亲母亲自己放时取辫子够得到的最远处（记在 `placements.land.self.gap`）。帽子不伸到孕肚下面。
- **茎生时帽子的位置**：帮手把帽子放在实子正下方，长轴顺着茎的方向，近侧帽檐离开母体；帮手站在帽子另一头，面朝母体。
- **帮手（父亲）**：脚本搜索他的站位和朝向，条件是：
  - 身体与满孕母体的间隙不少于 2.5 格。
  - 不压到帽檐。
  - 辫子能够到开口外的帽檐，且扶的那一点不在孩子飞过的路线上。
  - 摘帽时抓的那个帽檐点在帽子放下时仍够得到。
  - 尽量面向出口。

  帽子朝哪边转、辫子抓帽檐的哪一点，也在搜索中一起选出。
- **单亲母亲**：把帽子按在自己出口前，俯身 14°，放好后在原处松开辫子（辫长最多伸到 1.5 倍）。
- **水生**：靠岸时帽子浮在岸边水面，近侧帽檐塞到岸下；父亲站在岸上，与母体保持同样的间隙。

## 文件

| 文件 | 用途 |
| --- | --- |
| `recipe.json` | 内腔壁厚、陆地的帽檐高度、水上的压扁比例与干舷、水生帽子大小、站位搜索的条件与权重、孕体参数（用于算出口）、孩子进帽的路线与坐位（`delivery`） |
| `build.py` | 生成道具和数据，并打印典型弧线；`--check` 只读核对 |
| `delivery.py` | 帽面高度、坐位、抛物线、跳出位置；`build.py` 与出生场景预览共用，游戏中有对应实现 |
| `manifest.json` | 配方、脚本与输出的 SHA-256 |
| `preview_cabin.py` | 兼容的离线预览入口，转到 `motions/variants/lore/aquatic_home_preview.py` |
| `check_cabin.py` | 检查帽面三角网格的支撑与内腔分段连续性 |

**运行资源**：

- `yukkuri_props/marisa_hat_turned.json`，登记在 `subspecies-index.json`。
- `yukkuri_presentation/hat_vessel.json`：开口、内腔、帽檐各块、压扁比例、帽檐高度、水面遮罩、站位和 `delivery` 参数，由 `HatGeometry` 读取。

`cavity_sections` 由浅至深记录四段矩形/未压扁深度；包含前部浅台阶与三层帽冠。`surface` 取覆盖该 XZ 的最深段；`cabinClear` 按物体所在高度检查内腔。旧字段 `opening`、`well`、`ledge`、`floor` 仍可读取，`floor` 现在表示最深底，`well` 前界为 -4.00。旧资源没有新数组时使用原两层读取逻辑。外轮廓、船主高度、干舷、压扁、放帽站位均未变。

**重建顺序**：魔理沙帽子造型改动后依次运行下列脚本：

1. 本目录的 `build.py`
2. `scripts/export_motion_corrections.py`（重新生成辫子动作）
3. `motions/variants/lore/births.py`（在本机生成出生场景预览，输出到 `.local/previews/lore/`，不入库）
