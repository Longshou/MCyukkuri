# 魔理沙的帽子翻过来：软巢与软碗

接生用的帽子和水生魔理沙的帽船，都是魔理沙本人那顶帽子翻过来的样子，状态为**待用户确认**。

2026-10-15 按用户要求改为软布做法：帽子翻过来时，帽顶应该是软的，变成一个类似巢的结构；刚体帽子不符合接生要求。参考图见 [Wiki 美术参考](../../../../wiki/art-references/README.md)：

- EH22-001：水上魔理沙坐在帽里。
- EH22-006：把东西收进帽里。
- EH22-007：空帽浮在水面上，是一只带褶的软碗，帽檐呈波浪状。

此前的版本是逐块复制帽子再掏空的刚体帽，在地上侧放；再早是扁平碟形的 `hat_boat` 道具，已不使用。

## 造型

`build.py` 从当前运行模型 `yukkuri/marisa.json` 的帽子部件量出尺寸：帽底一层给出开口，帽檐给出外沿。每顶帽子是一层布：

1. 按角度给出一条中线，从碗底中心沿帽壁上到卷起的帽沿，再向外到帽檐边。
2. 中线向两侧加厚 0.45 格成为布层。
3. 碗壁上有 12 道褶，帽檐边是 14 个波浪。
4. 帽带在帽沿下方的外侧，蝴蝶结在原来帽子正面的一侧。

颜色取帽子在魔理沙图集里的格子，游戏和预览都直接用魔理沙的图集绘制。

| 道具 | 用在哪里 | 形状 |
| --- | --- | --- |
| `marisa_hat_nest` | 陆生魔理沙接生（`CRADLE`） | 开口朝上，软帽顶塌成低矮的圆巢，巢沿高 4.4 格，帽檐垂到地面 |
| `marisa_hat_vessel` | 水生魔理沙的帽船（`AFLOAT`），以及靠岸接生时浮在岸边的帽子（`MOORED`） | 深 7 格的软碗沉在水下，帽檐平铺在水面上，帽沿高出水面 0.5 格（按帽子大小缩放）；水面在开口处被遮住，碗里是干的 |

水生魔理沙的帽子做得比陆生大（用户允许；本项目取 1.5 倍），戴在头上时也按这个大小绘制。

**坐位**：

- 软巢里，幼体坐在巢底。
- 帽船上，船主低坐在碗里的船尾。幼体白天坐在她身前的碗里，夜里挪到她身下。

## 摘帽与戴回

[辫子动作](../../motions/variants/lore/hat.py)搬动的是头上那顶帽子：

1. 辫子勾住帽檐上的一点，把帽子抬离头顶。
2. 绕辫根向辫子一侧摆出，在放帽的地方上方翻过来。
3. 从放帽地方的上方、远离接生者一侧落下按住，软帽顶随之压扁到巢或碗的深度，同时辫子从帽檐滑到巢沿。
4. 动作结束时，游戏在同一位置换成软巢或软碗实体。戴回帽子时整个过程倒放。

## 放在哪里

`hat_vessel.json` 的 `placements` 给出位置，游戏和动作编排读同一份数据。

- **软巢的位置**：在出口正前方，开口靠母体一侧比出口近 1.6 格，孩子出来就落在巢里；长轴横在母体前，近侧帽檐塞在孕肚下方。
- **帮手（父亲）**：脚本搜索他的站位和朝向，条件是：
  - 身体与满孕母体的间隙不少于 2.5 格（用户反馈父亲靠太近穿模，此前只按未怀孕的身体检查）。
  - 不压到软巢的帽檐。
  - 辫子能够到巢沿。
  - 摘帽时抓的那个帽檐点在帽子放下时仍够得到，伸缩在 0.6–1.3 倍之间；在河岸上扶浮帽时放宽到 1.45 倍。
  - 尽量面向出口。

  帽子朝哪边转、辫子抓帽檐的哪一点，也在搜索中一起选出。
- **单亲母亲**：把帽子按在自己出口前，俯身 14°，放好后松开辫子。
- **水生**：靠岸时帽子浮在岸边水面，近侧帽檐塞到岸下；父亲站在岸上，与母体保持同样的间隙。

## 文件

| 文件 | 用途 |
| --- | --- |
| `recipe.json` | 布层厚度、褶与波浪、巢与碗的形状、水生帽子大小、坐位、站位搜索的条件与权重、孕体参数（用于算出口） |
| `build.py` | 生成两件道具和数据；`--check` 只读核对 |
| `manifest.json` | 配方、脚本与输出的 SHA-256 |

**运行资源**：

- `yukkuri_props/marisa_hat_nest.json` 与 `marisa_hat_vessel.json`，登记在 `subspecies-index.json`。
- `yukkuri_presentation/hat_vessel.json`：开口、深度、水面遮罩、坐位、压扁比例和站位，由 `HatVessel` 读取。

**重建顺序**：魔理沙帽子造型改动后依次运行下列脚本，需要 numpy，不启动游戏或浏览器：

1. 本目录的 `build.py`
2. `scripts/export_motion_corrections.py`（重新生成辫子动作）
3. `motions/variants/lore` 下的 `births.py`、`page.py` 与 `preview.py`
