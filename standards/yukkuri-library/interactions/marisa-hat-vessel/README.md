# 魔理沙的帽子翻过来：帽冠压扁

接生用的帽子和水生魔理沙的帽船，都是魔理沙本人那顶帽子倒过来放、帽冠压扁的样子，状态为**待用户确认**。

2026-10-15 用户说明：“巢”只是比喻，不要把帽子变成巢；帽子倒过来，底部压扁就行了。参考图见 [Wiki 美术参考](../../../../wiki/art-references/README.md)：

- EH22-001：水上魔理沙坐在帽里。
- EH22-006：把东西收进帽里。
- EH22-007：空帽浮在水面上。

此前的版本依次是：扁平碟形的 `hat_boat` 道具（已不使用）；逐块复制、侧放在地上的刚体帽；带褶软布做的软巢 `marisa_hat_nest` 与软碗 `marisa_hat_vessel`（用户认为变化太突兀，已删除）。

## 造型

`build.py` 从当前运行模型 `yukkuri/marisa.json` 逐块复制帽子（帽檐、帽冠各层、帽带、蝴蝶结），外表面沿用魔理沙图集里原来的格子，游戏和预览都直接用魔理沙的图集绘制。

1. 帽檐和帽冠下面两层掏空成内腔，壁厚 0.55 格：最下层的开口是 8.7 × 12.0 格，往里一层收窄，形成一圈台阶；内腔朝里的面用帽檐边缘的深色格子。
2. 整顶帽子倒过来，开口朝上，帽檐长轴沿 Z，原来戴着时的正面（蝴蝶结一侧）在 +X。
3. 帽冠沿帽子的轴向压扁，帽子形状不变：

| 放在哪里 | 实体状态 | 压扁 | 结果 |
| --- | --- | --- | --- |
| 陆地 | 接生的帽子（`CRADLE`） | 0.40 倍 | 帽冠压到贴地，帽檐离地 4.4 格 |
| 水上 | 水生魔理沙的帽船（`AFLOAT`），以及靠岸接生时浮在岸边的帽子（`MOORED`） | 0.75 倍 | 帽冠沉在水下，帽檐高出水面 1.2 格（按帽子大小缩放）；开口处遮住水面，帽里是干的 |

只有一件道具 `marisa_hat_turned`，压扁比例由游戏按陆地或水上绘制时施加。

水生魔理沙的帽子做得比陆生大（用户允许；本项目取 1.5 倍），戴在头上时也按这个大小绘制。

**坐位**：

- 陆地上，幼体坐在内腔底。
- 帽船上，船主坐在船尾那圈台阶上。幼体坐在内腔底，白天在她身前，夜里挪到她身下。

## 摘帽与戴回

[辫子动作](../../motions/variants/lore/hat.py)搬动的是头上那顶帽子：

1. 辫子勾住帽檐上的一点，把帽子抬离头顶。
2. 绕辫根向辫子一侧摆出，在放帽的地方上方翻过来。
3. 从放帽地方的上方、远离接生者一侧落下按住，帽冠随之压扁到陆地或水上的比例，同时辫子从帽檐滑到开口外的帽檐上。
4. 动作结束时，游戏在同一位置换成帽子实体，姿态与动作末帧一致。戴回帽子时整个过程倒放。

## 放在哪里

`hat_vessel.json` 的 `placements` 给出位置，游戏和动作编排读同一份数据。

- **陆地上的帽子**：在出口正前方，开口靠母体一侧比出口近 1.6 格，孩子出来就落进帽里；长轴横在母体前。
- **帮手（父亲）**：脚本搜索他的站位和朝向，条件是：
  - 身体与满孕母体的间隙不少于 2.5 格（用户反馈父亲靠太近穿模）。
  - 不压到帽檐。
  - 辫子能够到开口外的帽檐。
  - 摘帽时抓的那个帽檐点在帽子放下时仍够得到；陆上辫长伸缩在 0.92–1.33 倍，河岸上扶浮帽在 1.0–1.44 倍。
  - 尽量面向出口。

  帽子朝哪边转、辫子抓帽檐的哪一点，也在搜索中一起选出。
- **单亲母亲**：把帽子按在自己出口前，俯身 14°，放好后松开辫子。
- **水生**：靠岸时帽子浮在岸边水面，近侧帽檐塞到岸下；父亲站在岸上，与母体保持同样的间隙。

## 文件

| 文件 | 用途 |
| --- | --- |
| `recipe.json` | 内腔壁厚、陆地的帽檐高度、水上的压扁比例与干舷、水生帽子大小、坐位、站位搜索的条件与权重、孕体参数（用于算出口） |
| `build.py` | 生成道具和数据；`--check` 只读核对 |
| `manifest.json` | 配方、脚本与输出的 SHA-256 |

**运行资源**：

- `yukkuri_props/marisa_hat_turned.json`，登记在 `subspecies-index.json`。
- `yukkuri_presentation/hat_vessel.json`：开口、内腔、压扁比例、帽檐高度、水面遮罩、坐位和站位，由 `HatVessel` 读取。

**重建顺序**：魔理沙帽子造型改动后依次运行下列脚本，需要 numpy，不启动游戏或浏览器：

1. 本目录的 `build.py`
2. `scripts/export_motion_corrections.py`（重新生成辫子动作）
3. `motions/variants/lore` 下的 `births.py`、`page.py` 与 `preview.py`
