# 普通魔理沙单辫互动

已采用的动作源、模型和导出指纹见 [saved-action-v2.json](saved-action-v2.json)。七项互动由魔理沙自身左侧的单辫完成，另一侧短侧发不参与抓握；动作依据见[参考资料](REFERENCES.md)，游戏水面救援几何见[单辫水面救援](../braid-water-rescue/README.md)。当前模型使用圆润普通魔理沙。

| 动作 | 当前编排 |
| --- | --- |
| 捡拾石头、挥舞宝剑、拔草 | 辫梢卷握道具，动作节拍与轨迹按圆润体型适配 |
| 取下帽子 | 辫梢扣住帽檐右前沿，将帽子抬起并在头前翻转 |
| 护理帽子 | 取帽、翻转放置、擦拭帽带并整理蝴蝶结，再取起戴回 |
| 挥手道别 | 辫子绕辫根扬起、来回摆动后垂下，并配合点头 |
| 托子油上帽子 | 辫梢卷住子油，抬高越过帽檐并放到向前展开的帽檐上 |

辫身以轴向伸缩和浅弧到达接触点，卷握只在辫梢；探出、收回和越过头顶时围绕辫根转动。帽子只有一个抓握点，旋转绕该点进行，帽檐保持避开头部。辫根、辫长、分节、发结、发尾和帽檐抓握点从当前 `assembled/marisa` 网格读取。

帽子与子油松开后由独立物品或实体承接状态；托举结束时子油留在帽檐，重播回到起始状态。护理后的帽子保持整理状态，拔出的草留在附近；其余动作以收辫作为结束姿态。动作接入游戏时，角色与独立物品应拆为实体：抓握期间使用 `grip` 挂点，交接后切换地面或帽檐挂点，由服务端控制拾取、拔草和乘坐状态。

`recipes.json` 保存七项动作的时长、阶段和道具，`build.py` 求解辫子伸展、帽子单点抓握和道具轨迹，并生成可编辑模型、几何、动画及 `index.html` 预览。从仓库根目录运行 `python standards/yukkuri-library/interactions/marisa-braids/build.py` 重建；预览场景不包含游戏碰撞、存档或联机实现。
