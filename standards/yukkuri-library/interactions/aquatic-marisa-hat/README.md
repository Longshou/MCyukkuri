# 水生魔理沙的帽子

水生魔理沙帽的第二形态（外观尖锥圆台阶，帽腔圆冠盆）的制作源：戴在头上，放下时帽檐朝上浮在水面当帽船。现行水生帽（陆生帽翻过来，[marisa-hat-vessel](../marisa-hat-vessel/README.md)）保持不变；两种形态并存，由一个新测试物种使用新形态，在试玩场直接对比（用户决定）。陆生魔理沙的帽子与接生帽不受影响，两种魔理沙不共用帽子模型、物品外观或几何。`export.py` 导出运行资源；尚未接入游戏，接入见[待办](../../../../docs/TODO.md#进行中)。

| 文件 | 用途 |
| --- | --- |
| `recipe.json` | 尺寸（1.4 倍）、帽檐、外侧圆台阶、内侧圆盆、储粮每份体积 |
| `build.py` | 生成戴着与放下的网格，检查圆盆是否在外壳之内，写 `geometry.json`、`food_layer.png` |
| `export.py` | 导出运行网格、储粮贴图与两种形态的帽船剖面，写 `art/source/aquatic-basin-hat/` 快照与指纹 |
| `geometry.json` | 帽口、平底、深度、龙骨、翘边、圆盆剖面，以及三档储粮的层面高度 |
| `food_layer.png` | 储粮层 16×16 贴图（谷粒、干草、浆果、草籽） |
| `scene.py` | 身体、脚圆、支撑、储粮层、外壳静水力、辫子托兜范围 |
| `layout.py` | 按载重规则逐一摆放乘员，写 `<MCY_LOCAL 或 .local>/previews/aquatic-hat-round/layouts.json` |
| `preview.py` | 预览图 `sheet.png`（两种形态对照与新形态布局）与带布局表的 `index.html`（同一预览目录） |

```sh
python standards/yukkuri-library/interactions/aquatic-marisa-hat/build.py [--check]

MCY_LOCAL=<主检出>/.local python standards/yukkuri-library/interactions/aquatic-marisa-hat/preview.py
```

依赖 NumPy 和 Pillow。身体取当前运行的魔理沙模型（按 placement_fit 拟合），姿态取导出动作：

- 白天：`boat_drift`
- 夜里帽主俯身：`boat_cover_young`
- 夜里幼体：`boat_nest_curl`
- 早上辫托：`braid_cradle_lift`

帽子用魔理沙图集里陆生帽的同一批格子。脚本只读运行资源，不启动游戏。

## 造型

外侧和内侧是两个各自设计的形状，中间的布料厚度由两者之间的空间决定（项目设计）。

**戴着**

- 帽冠是四层圆台阶，沿用陆生帽逐层收窄的样子。
- 顶上直接用陆生帽自己的弯尖（`hat_tip_bend`、`hat_tip`、`hat_tip_end`），放在顶层台阶上的位置与陆生帽放在 `hat_taper_3` 上相同。
- 底层台阶有白带，蝴蝶结是陆生帽的那只，移到白带正前方。
- 帽檐是圆形，直径与陆生帽左右宽相同；外缘戴着时向下垂。

**放下**

- 帽檐外缘翘起，围在帽主四周（EH22-001）。
- 底层台阶保持直立；下面三层压成水下的台阶龙骨，弯尖压进龙骨，不单独画。
- 帽檐圈可以比戴着时窄。

**帽腔**

- 帽口先沿帽檐厚度直下，再以四分之一椭圆弧弯进平底。
- 中央压扁的帽尖留下浅窝。
- 圆盆必须在直立的底层台阶以内，至少留 `min_wall` 的布料；`build.py` 会检查。

尺寸（成体模型单位，16 = 1 格；以 `geometry.json` 为准）：

| 部位 | 数值 |
| --- | --- |
| 帽檐半径 | 14.2 |
| 帽冠底半径 | 10.6 |
| 帽口半径 | 10.15 |
| 平底半径 | 8.26 |
| 平底深度 | 4.0（从帽檐面往下量） |
| 龙骨底深度 | 6.55 |
| 翘边高度 | 1.26 |

## 支撑、占位与储粮（建议规则）

**支撑**

- 现行 `HatGeometry.travelSupport` 在身体半宽加 0.025 格处取 3×3 方格。方格四角离中心约 9.6，比帽口还宽，成体会被托到帽檐高度。
- 建议改成“身体底面贴帽面”：支撑高度取身体下各格的帽面高度减去该格身体底面高度后的最大值。
- 成体底面在半径 5.3 以内是平的，6.5 处抬起 0.7，7.2 处抬起 2.0，按体型缩放。

**占位**

- 现行 `room()` 用脚圆：半径为身宽一半加 0.02 格，两只身体高度重叠时脚圆不得相交。
- 成体的脚圆半径是 6.72，但身体前方只伸出约 5.4。按脚圆算，0.45 的子油在这顶帽里没有任何位置。
- 建议只按身体本身的轮廓判断是否相撞：只算身体，不算帽子、头发和辫子，因为它们是软的，可以交叠。

**储粮**

- 每份沿用现在画法所占的空间：帽底一个半径 0.09 格、高 0.06 格的圆柱，约 6.25 单位³。
- 全部份数在帽腔里铺成一个水平层，用 `food_layer.png` 画层面。份数越多，层面越高，乘员坐在层面上。
- 层面深度：6 份 3.86，12 份 3.71，24 份 3.43。

## 乘员布局（layout.py）

**规则**

- 载重规则见[水上生活·帽内空间与载重](../../../../docs/AQUATIC_MARISA_IMPLEMENTATION.md)。
- 白天：帽主坐在中间；只有为了让幼体放得下，才最少地往船尾挪。幼体在她身前，尽量低。
- 夜里：帽主俯身，幼体在她身前或俯身的身体下。
- 每种情况都按储粮 0、12、24 份各算一次。

**辫托与稳定**

- 辫托：按 `braid_cradle_lift` 的实际托兜范围（离辫根最远约 9.9，最低到身底以上约 0.75），帽主原地转身去够。
- 稳定：用外壳的排水体积、浮心与各乘员和储粮的真实重心求静横倾，再与翘边碰到水面的倾角比较。不超过该倾角的 0.6（`HullAfloat.STEADY`）算稳。

**结果（建议规则，平底半径 8.26）**

| 情况 | 放得下 | 位置与读数 |
| --- | --- | --- |
| 帽主 + 1～6 新生，或 + 6 只 0.20 赤油（载重 12） | 白天、夜里、三档储粮都能 | 帽主身底深约 4.0，幼体并排在她身前的平底和弧壁上；横倾 ≤ 5°，进水角约 21–24° |
| 帽主 + 0.30 小子油 | 能 | — |
| 帽主 + 0.45 子油；+ 2 新生；+ 0.30 + 2 新生（载重 11） | 能 | 帽主往船尾挪 1.5（夜里 3.0），子油在她正前方，身底深约 2.6；最大横倾约 12°/23° |
| 临产帽主（孕程 0.8）坐高座 | 能 | 她比帽口宽，坐在帽口上方，身底深约 1.3；两只新生在她身前下方的帽腔里（身底深约 3.2）；横倾约 9° |
| 1.2 倍帽主 + 6 新生 | 能 | 白天横倾约 11°，进水角约 16°，超过 0.6（仍浮着） |
| 1.2 倍帽主 + 0.45 子油 | 放不下 | — |

- 所有放得下的情况，早上辫子都够得着每只幼体。
- 按现行脚圆规则：新生、赤油、0.30 小子油和 1.2 倍帽主带 6 新生都能放下；只要有 0.45 子油，任何组合都放不下。

**攀上帽檐**

- 从水里攀上空帽时，成体只要四分之一体重挂在帽檐上就会进水。0.45 子油挂一半体重时横倾约 23°，不进水；挂四分之三就进水。
- 要让成体能攀上来，需要在实现时按她出水的程度计入体重，并考虑帽子倾斜跟上的时间。

## 帽船剖面（hull_profiles）

两种形态用同一格式，各自从游戏实际绘制的三角面量出：新形态取本目录的放下网格乘 `scale`；现行形态取 `marisa_hat_turned` 乘 `hat_vessel.json` 的水生倍率，竖向再乘制作源 `marisa-hat-vessel/geometry.json` 的 `squash.nest`；渲染读取剖面 `squash`。

坐标与单位：格；帽船坐标，原点在帽檐面中心（戴着时贴头的那面），+Y 出帽腔，+X 为戴着时的前方，船首朝 -Z。高度都是带符号的 `y`（帽檐面为 0，向下为负）。换用别的帽船倍率时，半径和高度按倍率之比缩放。

| 字段 | 含义 |
| --- | --- |
| `form`、`hull`、`scale`、`squash` | 形态（`cone_basin` / `turned_land_hat`）、帽船网格 ID、量取时的倍率与竖向压扁 |
| `azimuths` | 量取方向（度，从 +X 转向 +Z，含每 45° 与所有网格顶点投影的方向，保留台阶与矩形转角）；下列按方位的数组与之一一对应 |
| `sample_step`、`level_tolerance` | 径向采样间距；判定平底与龙骨底的高度容差（都是 1/64 格） |
| `rim.y` | 帽口外一圈最低的檐顶：水面高过它就灌进帽腔（新形态是翘边顶，现行形态是平帽檐面） |
| `brim.radius`、`opening.radius` | 各方位帽檐外缘、帽口边缘的半径 |
| `floor.radius`、`floor.y` | 帽腔内面不高出最深点 `level_tolerance` 的范围（从中心连续量起）；`floor.y` 为该范围内按面积平均的内面高度 |
| `hollow.y` | 帽腔最深点 |
| `keel.y`、`keel.radius` | 外壳最低点；各方位外壳底不高出最低点 `level_tolerance` 的最远半径 |
| `surface_triangles` | 朝上的实际帽面三角形，每面三个 `[x,y,z]`；Java 在加载时建立空间索引，精确查询台阶与弧壁支撑 |
| `inner` | 各方位帽腔内面 `[半径, y]`，从中心到帽口，末点为帽口边缘的帽檐面 |
| `outer` | 各方位外壳 `[半径, 底面 y, 干舷顶 y]`，从中心到帽檐外缘；帽口以内的干舷顶取 `rim.y`（灌水前帽腔是干的），以外取布面顶。排水柱高 = min(水面, 干舷顶) − 底面 |
| `volume` | `hollow` 帽檐面以下的帽腔容积、`to_rim` 水面齐 `rim.y` 时的排水量（立方格，网格积分）；`hull_mass` 空帽重量（`hat_vessel.json` `afloat.hull_mass` × 倍率²）；`empty_waterline_y` 空帽直立时的水线 |
| `anchors.owner_y` | 成体帽主（生长 1，`boat_drift`）坐在空帽正中时身底的高度，按“身体底面贴帽面”的建议规则 |
| `anchors.stores` | 每份储粮体积（立方格）与 1～24 份铺成水平层时的层面高度 `level_y`；乘员坐在层面上 |
| `sources` | 量取所用文件的 SHA-256 |
