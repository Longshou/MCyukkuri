2026-09-13：完整家油卵与裂壳卵 R2.4 已由用户确认，制作源、模型、贴图与预览已冻结保存，见[家油卵标准造型](../../ecology/house-egg/README.md)。其他周边素材保持待确认；游戏接入状态不因造型确认而改变。

R3 新增六类伤情、油霉和漏馅四阶段，使用两种选定角色生成 64 份场景；详见 [身体效果说明](BODY-EFFECTS.md)。新增效果未接入游戏。R3.1 已补充全身定位、最多八处独立伤口及四种动作的皮面挂接；见 [全身伤口交接](WOUND-PLACEMENT.md)。程度、位置和份量目前为预览输入，后续需建立与真实伤情及骨架动作的数据映射；不能将预览绑定名直接当作现有存档字段。

2026-09-12 原有周边代码盘点。本文用于接入交接，不表示以下工作已经完成。当前请求是周边造型和统一预览修订；R2.1 已新增运行食物标签适配；R2.3 修订食盆堆积效果；R2.4 重新制作卵壳连续曲线及贴面裂纹，两者仍属于候选预览，未修改 Java 或游戏存档。`yukkuri_forage` 包含原版短草、高草、小麦，并被 `yukkuri_food` 引用，沿用现有手喂、地面食物、取餐和食盆库存渲染路径；未注册另一种草。未单独调整营养平衡，也未实机验收该标签。
