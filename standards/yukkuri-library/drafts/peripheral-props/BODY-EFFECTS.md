# 身体伤情、油霉与漏馅候选

2026-09-13，R3.1。八个伤情示例之外新增全身伤口编辑入口，共九个身体效果条目，使用当前选定的灵梦、魔理沙模型；全部为待用户确认的美术候选，尚未接入 Minecraft。

[统一预览](previews/current/index.html)中选择“伤情与效果”，点击“全身伤口 · 多处挂接”可编辑不同部位与多处伤口；原有卡片也有“调整伤口位置／多处共存”入口。位置、动作、下载与配方说明见 [全身伤口说明](WOUND-PLACEMENT.md)。[总览图](previews/current/body-sheet.png)用于比较八类效果，细节与多角度截图位于 `previews/current/body-effects/`。

## 已制作内容

| 类别 | 形态与控制 |
| --- | --- |
| 擦伤 | 表皮细痕增加，重度有较宽磨损面 |
| 裂口 | 皮面局部内凹，不规则边缘与深紫馅料；五官贴面随皮面变形 |
| 凹陷 | 细分身体前面后形成真实凹面，深度和范围逐级增加 |
| 受压 | 身体降低、加宽，头饰保留自身形状并跟随根部 |
| 焦痕 | 从身体前侧下缘出现褐色、焦黑斑块 |
| 干瘪 | 身体收缩并增加褶痕，头饰根部同时随高度和前后位置调整 |
| 油霉 | 自绘细碎绿斑逐渐连片扩散，前、侧、背面均有贴面表现 |
| 漏馅 | 渗出、拉丝、飞散、落地四阶段；0–12 份独立分组；飞散可拖动时间或播放一次 |

六种伤情与油霉均为 0–3 级，0 级去除新增效果并恢复普通表情。预览体型范围为 0.3–1.2 倍，身体、五官、饰物和新增效果共同缩放；这项检查不等于另行制作幼体专属解剖结构。漏馅量为 0 时去掉释放的馅料，仍保留伤口出口。

## 制作源与交付文件

[body_effects.py](body_effects.py)是制作源，[body-effects-recipe.json](body-effects-recipe.json)登记选定角色文件及指纹、变形参数、头饰挂点和效果语义。[原始参考说明](REFERENCES-BODY.md)区分实际查看的八景 U 图层与本次三维适配选择。

`body-variants/<效果>_<角色>_<状态>/` 导出 8 类 × 2 角色 × 4 状态，共 64 份场景，每份包含 `.bbmodel`、`.mesh.json`、`.obj`、`.mtl` 和贴图。详情页下载随角色和状态切换。`assembled/body_*/` 保留对应卡片的默认场景。

身体变形直接写入场景顶点；伤痕、油霉和馅料有命名分组。飞散交换模型的分组附带起点、速度、重力及落地时间，浏览器据此播放。Blockbench 文件交付静态中间帧和可隐藏分组，没有导出原生 Blockbench 动画时间轴；OBJ 也不承载这些动态字段。

在项目根目录重建：

```powershell
python standards/yukkuri-library/drafts/peripheral-props/build.py
node standards/yukkuri-library/drafts/peripheral-props/render-body-review.cjs
```

## 检查与接入边界

[浏览器记录](reports/current/body-browser.json)覆盖两角色四视角、0–3 级、恢复状态、0.3／1.2 体型、漏馅四阶段与 0／1／4／12 份、飞散起中末帧和播放、搜索、关闭及移动布局。[视觉记录](reports/current/body-visual-review.md)记录实看范围和返工结果，[导出记录](reports/current/exports.json)保存源与产物指纹。

原有八个示例保留固定部位用于伤情对比。R3.1 的全身伤口编辑器支持六个方向的皮面定位、部位内连续偏移和点击实际皮面，也支持最多八处独立伤口。已适配侧弯、伸展、走动、按压四个预览动作；尚未核对角色全部动作及游戏受击接入。接入时需把真实伤情类型、程度、油霉状态、出馅单位、位置和角色体型传入适配层，并核对骨架动作、受压后的接触关系和恢复行为。预览的 0–3 级不是当前游戏数值的直接分档；`body.*` 绑定名是交接语义，不表示已有同名存档字段。

本轮没有修改 Java 或游戏资源，没有执行 Blockbench 应用导入及 Minecraft 运行验收。按死因区分的遗体、互动器具与拘束场景继续待做；已有卵标准的确认指纹保持有效。
