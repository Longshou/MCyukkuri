记录与边界

证据与制作选择

L36 记述爱丽丝的失控变体、失去理智时的身体能力变化，以及作品中的群落风险和歧视。它没有规定白眼、怒眉配笑脸，也没有固定的动作节奏或恢复秒数。

本页用已有的标准五官表达不同状态，移除了默认白眼笑脸、循环摇摆与前扑。中断、退让、疲惫恢复是本项目便于辨认状态的编排。

两个独立分支

素鸡立：以短时缓解为主题，正常 → 躁动 → 放松 → 疲惫 → 正常。不能把这个词直接等同于整段发情期。

雷普魔：爱丽丝的异常分支，警觉 → 定向接近 → 中断 → 疲惫恢复。普通爱丽丝不必进入这个分支，两个演出之间没有自动跳转。

仅使用成体模型；没有目标接触、交配过程或生殖器展示。原先的制作输入仍保留。

与当前游戏的关系

本页是待确认制作候选，没有把新动作或旧重绘表情自动选为游戏素材。游戏当前复用标准表情：躁动 confused、缓解 closed_smile、失控 angry、恢复 sleepy。

这里的 10 秒顺序、转向幅度、退让和光环是预览编排；游戏状态持续时间、行动中断及社会后果由服务器规则决定。素材图不能代替游戏验收。
