生命周期位置

赤油 → 子油 → 亚成 → 成油 · 发情期 →（异常分支）雷普魔

本页只展示成体发情期；赤油、子油与亚成不进入该演出。雷普魔是失控分支，不是必经阶段。

两种表现必须分开

素鸡立（すっきり）：程序使用 eye 68/70、brow 8、mouth 256/280、blush 30/34，表情从潮红闭眼笑过渡到伸舌。本页用 flushed_smile → 重绘 sukkiri_tongue（闭眼、开口、短舌；去掉原长舌的重叠层），身体保持站立，只做呼吸、重心摆动和轻度用力。

雷普魔爱丽丝（れいぽう）：程序在 *label_0643 选取 eye 0、brow 8、mouth 30、blush 0，并叠加锁定目标后的接近/前冲。原帧过于中性，本页重绘为 白眼 + 怒眉 + 开口笑 + 无腮红；动作包含抽头、下蹲、快速接近和跳跃前冲。它不是素鸡立的加强版。

动作如何通用

发情片段由各模型已有的 startle / brace / waddle 运行时片段分层组合；失控片段再加入 turn / hop。缺失骨骼自动跳过，因此同一套素鸡立可套到爱丽丝、魔理沙等运行模型。
