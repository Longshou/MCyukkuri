生命周期位置

赤油 → 子油 → 亚成 → 成油 · 发情期 →（异常分支）雷普魔

本页只展示成体发情期；赤油、子油与亚成不进入该演出。雷普魔是失控分支，不是必经阶段。

两种表现必须分开

素鸡立：八景 U「基本発情顔１→２」→ flushed_smile → flushed_tongue。闭眼、潮红、笑/伸舌；身体保持站立，只做呼吸、重心摆动和轻度用力，不离开原地。通用动作。

雷普魔爱丽丝：八景 U「基本エロ笑顔１→２」→ teary_tongue / teary_tongue_b。睁眼、含泪、伸舌；startle / turn / brace / waddle / hop 分层组合，加入突然抽头、下蹲、快速踱步和跳跃前冲。爱丽丝的失控异常状态，不是素鸡立的加强版。

标准表情来源

  • N034 flushed_smile · 「基本発情顔１グラベース」
  • N035 flushed_tongue · 「基本発情顔２グラベース」
  • N036 teary_tongue · 「基本エロ笑顔１グラベース」
  • N037 teary_tongue_b · 「基本エロ笑顔２グラベース」

表情读取标准素材库的 assembled 图集，不再使用自拼 heat 贴图。

动作如何通用

发情片段由各模型已有的 startle / brace / waddle 运行时片段分层组合；失控片段再加入 turn / hop。缺失骨骼自动跳过，因此同一套素鸡立可套到爱丽丝、魔理沙等运行模型。
