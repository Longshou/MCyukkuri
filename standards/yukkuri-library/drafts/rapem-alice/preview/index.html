不要把变体当成种族

Wiki 明确要求区分普通种特征与少数失控变体：不能把“雷普魔”推广为每只爱丽丝的潜在本性、行为必然性或固定敌意。

生命周期位置

赤油 → 子油 → 亚成 → 成油 · 发情期 →（异常分支）雷普魔

本页只展示成体发情期；赤油、子油与亚成不进入该演出。雷普魔是失控分支，不是必经阶段。

这个演出在表现什么

  • 失去理智：失神白眼、流涎、视线游移与突然的头部抽动。
  • 只想交配：持续扫视、向目标方向倾身、来回踱步与冲动冲刺；不演出交配过程。
  • 身体能力变强：更快的起跳/前冲、更大幅度的颤抖与恢复。

具体幅度、镜头与光环为展示设计，不是 wiki 的固定动作记录。

动作如何通用

发情片段只读取各模型共有的 body_motion / head / hand / rump / hair 等骨骼，缺失的骨骼会自动跳过，因此同一套“素鸡立”可套到爱丽丝、魔理沙等运行模型。
