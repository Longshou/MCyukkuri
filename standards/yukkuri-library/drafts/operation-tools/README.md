# 接触操作器具候选

制作源为 [build.py](build.py)，参数表同时导出为 `recipe.json`。十六件基础模型包含十四种工具、剪下的发束与培养瓶，另有角色适配的固定带、吊带和铁箱，配套可编辑网格位于 `assembled/<物品>/`。尺寸以每格 16 单位计，全部网格与色板为本项目制作。

形态参考本机八景 U v9.8 的大头针、锤、锥子、加热锥子、裁剪刀及鱼钩。粉色圆头针、黑色圆柱锤头、木柄金属锥和红柄裁剪刀来自已核读的原始图像；固定台、吊带背面及三维厚度属于 MC 适配设计。原图只存于项目临时参考目录，不进入导出。

当前造型待用户确认。游戏选定副本与来源记录见 [接入包](../../../../art/props/operation-tools/README.md)，不覆盖既有周边 R2.3、R2.4 或角色标准的批准指纹。

振动器的粉色椭圆轮廓、透明广口瓶与铁箱也已核读原始图像。铁箱正面观察栏为 MC 适配；培养瓶承托剪下的茎根，实子仍挂在原有分枝上。瓶身透明材质与金属边缘分别渲染。

执行 `python standards/yukkuri-library/drafts/operation-tools/build.py` 同步源参数、可编辑模型、接入快照和运行资源；`--check` 只核对。手工编辑模型后须先同步制作参数，避免下次构建丢失修改。

检查会重新按当前运行角色网格推导器具，核对几何、挂点、索引及来源指纹；PNG（包括 `.bbmodel` 内嵌贴图）比较尺寸和 RGBA 像素，JSON 比较结构与数值，避免压缩版本或换行造成误报。只有 `.bbmodel` 的未取整顶点允许 Windows／Linux 三角函数末位差异，限于以一个模型单位为最小尺度的一 ULP；运行顶点、UV、面拓扑和边界仍精确核对。构建保留经核对等价的现有字节，来源指纹只兼容同一内容的 LF／CRLF 表示。

`python scripts/test_operation_exports.py` 覆盖只读检查、编码差异、顶点／贴图／指纹损坏与文件缺失；不启动游戏。当前四种圆润不足形态的器具使用对应角色的现行网格重新适配，仍为待确认游戏适配版，不改变角色标准造型。
