# 发面伤口制作源

本包为项目原创美术。2026-10-22 用户明确授权本次由 Codex 制作；制作配方、生成器、导出网格和透明贴图保存在这里。当前是待视觉确认的制作源，未替换游戏运行资源，也不表示游戏已有发面裁切。

## 伤型表现

活动伤口严格对应 `WoundKind` 的 `SCRATCH`、`TEAR`、`DENT`、`SCORCH` 和 `BodyWound` 的 1–3 级。开放程度按 `BodySigns.open/deep`：二级裂伤开放，三级裂伤／凹伤／灼伤为深伤；三级擦伤不挖深腔。

| 类型 | 1 级 | 2 级 | 3 级 |
| --- | --- | --- | --- |
| 擦伤 | 少量短浅擦痕，头发保留 | 增加擦痕、毛束磨损 | 密集擦损、碎屑状浅破皮；不露核 |
| 裂伤 | 细窄闭合切痕，不露馅 | 裂口张开，参差断端，露普通馅 | 扩大的不规则深撕裂，断端及附着毛束继续遮住部分破口 |
| 凹伤 | 轻度共同凹陷 | 加深压陷和压折纹，头发保留 | 在压陷内形成压碎裂口；折发仍连接外围，非整片凹区缺失 |
| 灼伤 | 褐变与轻度焦痕 | 焦黑、卷曲和干裂，保持闭合 | 焦壳崩裂，开口边缘留下烧卷、脆断的短焦茬 |

中枢外露是深伤的派生状态，不能独立做成统一圆洞。三级裂伤、凹伤、灼伤分别保留撕裂、压碎、烧损外形，各导出中枢完好、受损、取出后空腔三种状态。中枢始终位于身体中央；腔壁和残余头发可以遮住它，不能为了完整展示核心而删除周围头发。

发面破口位于组织缺损轮廓以内，外侧原头发全部保留，部分原发面悬在皮面开口上方。裂伤断端按上下毛束方向参差排列；凹伤保留压折毛束；灼伤保留短焦茬与焦黑过渡。附着毛束与外侧头发相连，只有真正断离的部分直接消失，不制作散落头发，也不剃空环形区域。

`DIRT`、`MOLD`、`CHAR`、`SCAR`、`PASTE`、`CORE` 属于印记或派生显示，不增设虚构的三档活动伤：脏污三档、油霉四档、整周足缘焦化继续复用上级导出；旧疤用细窄闭合淡痕；普通馅只在开放创腔内；核心使用上述三种伤因的深腔。对应关系记录在素材 manifest 的 `derived_marks`。

灵梦黑发和魔理沙金发使用同一形状与挂接规则，断发边缘按发色适配。头发接收部件在 `recipe.json` 明确列出，帽子、蝴蝶结、发束袖口及独立垂辫不参与裁切或压陷。形状、配色和凹陷深度均为项目设计，没有新增玩法伤害数值。

## 文件和接口

| 文件 | 用途 |
| --- | --- |
| `recipe.json` | 四类三级参数、露核伤因、发面组件、颜色及保留／断发规则 |
| `author.cjs` | 在同侧真实皮面／发面采样，生成断发边、面皮边、馅壁和中央核心；生成压伤顶点及法线修改 |
| `materials.py`、`build.py` | 生成十二档伤口贴图和一张旧疤，调用网格导出、生成覆盖清单／指纹和离线预览 |
| `export.cjs` | 导出及只读核对当前模型上的制作样例 |
| `assembled/*.png` | `类型-等级.png` 共十二张 512×512 透明贴图，另有 `scar.png`；UV 映射见配方 |
| `assembled/*.json.gz` | 黑发、金发、裸露皮面各十二档活动伤及九种露核状态，共 63 份拟合样例 |
| `assembled/manifest.json` | 制作源／角色输入指纹、输出指纹及未选入运行资源的状态 |

网格沿用现有 `xyz/u/v/normal` 顶点布局，负 `u` 对应逐三角颜色与材料索引。`profile` 给出局部 U/V/N 基、伤因／等级、皮面 `outline` 与发面 `hairOutline` 两个轮廓、实际裁切半径 `cutRadius` 及固定核心位置。不能把皮面轮廓直接套到头发上。`surfaceEdits` 的每行为 `[vertexIndex,x,y,z,nx,ny,nz]`，用于皮面与头发共同压陷，以及焦发局部卷曲；不减少原模型顶点数。导出样例基于各自角色 `idle:0` 的实际拟合，不能作为无骨骼的固定贴片直接盖到未裁切模型上。

中枢形状复用上级 `cavity.cjs`，破裂材质朝实际创腔方向表现。`surface.cjs` 的可选发面分支读取导出的网格／压陷数据和贴图作离线光栅化；开口按片元裁切，正常头饰仍写入深度。正式接入须按 `profile` 裁切皮面和对应发面、补骨骼绑定，并从真实伤势选择压陷或断发，不能对所有受伤统一删发。压伤顶点样例不能直接复用于不同拓扑、表情或成长体型。

## 生成与预览

在仓库根目录运行：

```text
python standards/yukkuri-library/drafts/body-marks/hair-wounds/build.py --node node
python standards/yukkuri-library/drafts/body-marks/hair-wounds/build.py --node node --check
python standards/yukkuri-library/drafts/body-marks/hair-wounds/build.py --node node --preview
python scripts/build_preview_hub.py --node node
```

依赖 numpy、Pillow、Node.js 和中文字体；不使用浏览器、桌面自动化或 Java 编译。`--preview-root <仓库目录>` 可将独立工作树的预览输出到主仓库 `.local/previews/hair-wounds/`。该主题包含三种表面的四类三级矩阵、三伤因×三中枢状态矩阵及侧视；中间缓冲在 `.local/hair-wounds-work/`。生成器仅按自身 manifest 清理被替代的导出，不删除制作输入或参考图。

预览不代表游戏接入或试玩通过。运行时三角裁切、动作蒙皮、伤口状态同步、治疗和遗体变化仍按[通用设计](../WOUND_GENERATION.md)与[待办](../../../../../docs/TODO.md#美术opus)处理。
