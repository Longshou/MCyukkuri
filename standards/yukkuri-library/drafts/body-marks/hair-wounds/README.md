# 发面伤口制作源

本包为项目原创美术。2026-10-22 用户明确授权本次由 Codex 制作；制作配方、生成器、导出网格和透明贴图保存在这里。当前是待视觉确认的制作源，未替换游戏运行资源，也不表示游戏已有发面裁切。

## 伤型表现

- 擦伤：短划痕和毛束磨损，头发保留。
- 砸击／闭合压伤：面皮与覆盖毛束使用同一局部位移场一起凹陷，保留原三角形与 UV，不裁发、不露馅。压痕贴图只作辅助，凹陷由真实顶点位移产生。
- 裂伤：仅伤口通道内的毛束截断；断掉部分直接消失，不制作散落头发。周围发型保留，断发边缘向下接面皮断面与普通馅浅腔。
- 焦伤：闭合处保留头发，使用局部焦黑和细裂纹；不能仅因焦色就删除整片头发。
- 露核重伤：实际缺损通道内截断头发，浅色面皮断面接深部普通馅腔壁，唯一中枢仍在身体中央。完好、破裂、取出后空腔分别导出；普通裂口不含核心。
- 旧疤：细窄淡痕，收口而不保留活动创腔。

灵梦黑发和魔理沙金发使用同一形状与挂接规则，断发边缘按发色适配。头发接收部件在 `recipe.json` 明确列出，帽子、蝴蝶结、发束袖口及独立垂辫不参与裁切或压陷。形状、配色和凹陷深度均为项目设计，没有新增玩法伤害数值。

## 文件和接口

| 文件 | 用途 |
| --- | --- |
| `recipe.json` | 发面组件登记、颜色、开口尺寸、凹陷深度及保留／断发规则 |
| `author.cjs` | 在同侧真实皮面／发面采样，生成断发边、面皮边、馅壁和中央核心；生成压伤顶点及法线修改 |
| `build.py` | 生成四张 512×512 透明贴图、调用网格导出、生成素材指纹和离线预览 |
| `export.cjs` | 导出及只读核对当前模型上的制作样例 |
| `assembled/*.png` | 擦伤、压痕、局部焦伤、旧疤贴图；UV 映射见配方 |
| `assembled/*.json.gz` | 两种角色各五种样例：共同凹陷、普通裂口、完好中枢、破裂中枢、空腔 |
| `assembled/manifest.json` | 制作源／角色输入指纹、输出指纹及未选入运行资源的状态 |

网格沿用现有 `xyz/u/v/normal` 顶点布局，负 `u` 对应逐三角颜色与材料索引。`profile` 给出局部 U/V/N 基、同一伤口轮廓、身体中央核心和头发裁口比例。`surfaceEdits` 的每行为 `[vertexIndex,x,y,z,nx,ny,nz]`，只改变压伤区域的皮面、覆盖发面及相交五官；不减少原模型顶点数。导出样例基于各自角色 `idle:0` 的实际拟合，不能作为无骨骼的固定贴片直接盖到未裁切模型上。

中枢形状复用上级 `cavity.cjs`，破裂材质朝实际创腔方向表现。`surface.cjs` 的可选发面分支读取导出的网格／压陷数据和贴图作离线光栅化；开口按片元裁切，正常头饰仍写入深度。正式接入须按 `profile` 裁切皮面和对应发面、补骨骼绑定，并从真实伤势选择压陷或断发，不能对所有受伤统一删发。压伤顶点样例不能直接复用于不同拓扑、表情或成长体型。

## 生成与预览

在仓库根目录运行：

```text
python standards/yukkuri-library/drafts/body-marks/hair-wounds/build.py --node node
python standards/yukkuri-library/drafts/body-marks/hair-wounds/build.py --node node --check
python standards/yukkuri-library/drafts/body-marks/hair-wounds/build.py --node node --preview
python scripts/build_preview_hub.py --node node
```

依赖 numpy、Pillow、Node.js 和中文字体；不使用浏览器、桌面自动化或 Java 编译。`--preview-root <仓库目录>` 可将独立工作树的预览输出到主仓库 `.local/previews/hair-wounds/`。该主题包含总览、砸击前后对照、黑／金发八种状态与创腔近看；中间缓冲在 `.local/hair-wounds-work/`。

预览不代表游戏接入或试玩通过。运行时三角裁切、动作蒙皮、伤口状态同步、治疗和遗体变化仍按[通用设计](../WOUND_GENERATION.md)与[待办](../../../../../docs/TODO.md#美术opus)处理。
