# 水生魔理沙帽子候选

水生魔理沙专用帽子的造型候选：戴在头上，放下时帽檐朝上浮在水面当帽船；陆生魔理沙的接生帽保持现形，不共用。三个候选都是草稿，未导出到运行资源，也不改现行 `marisa_hat_turned`、`hat_vessel.json`。

| 文件 | 用途 |
| --- | --- |
| `recipe.json` | 共用参数：1.4 倍、圆帽檐、帽冠底、壁厚、干舷、新生大小、储粮每份体积与三档份数 |
| `<候选>/recipe.json` | 各自的帽冠与放下后帽腔 |
| `build.py` | 生成戴着与放下两种网格（同环数、同顺序，可逐顶点插值过渡），读回帽面高度场，写 `<候选>/geometry.json`、`food_layer.png` |
| `<候选>/geometry.json` | 帽口半径、帽腔最深、水下最深、沿船首尾线的高度剖面、三档粮层高度 |
| `food_layer.png` | 储粮层 16×16 贴图（谷粒、干草、浆果、草籽） |
| `preview_sheet.py` | 现版与候选对照的离线渲染：`<MCY_LOCAL 或 .local>/previews/aquatic-hat/` 的 `sheet.png`、`index.html`、`report.json` |

```sh
python standards/yukkuri-library/drafts/aquatic-hat/build.py [--check]
MCY_LOCAL=<主检出>/.local python standards/yukkuri-library/drafts/aquatic-hat/preview_sheet.py
```

需要 NumPy、Pillow；身体取当前运行的魔理沙模型与导出动作（`boat_drift`、`boat_cover_young`、`boat_nest_curl`），帽子用魔理沙图集里陆生帽同一批格子。只读运行资源，不启动游戏。

## 共同约定

- **尺寸**：帽檐圆形，半径 10.13 帽单位（直径等于陆生帽左右宽），外缘自半径 8.2 起戴着时下垂 0.9，放下后同一圈翘起成围着帽主的高边（EH22-001）；帽冠底半径 7.0、壁厚 0.55，统一乘 1.4（成体单位，16 = 1 格）：帽檐直径 28.4（1.77 格），帽口内径 18.1（1.13 格）。现版帽口 12.2 × 16.8，成体宽 12.8，所以只能站在帽檐高度。干舷与现版相同（帽檐面高出水面 1.68）。
- **支撑规则（三个候选都需要）**：现行 `HatGeometry.travelSupport` 在身体半宽 +0.025 格处取 3×3 方格，四角离中心约 9.6，比任何不超过帽子尺寸的圆帽口都宽，成体仍会被托到帽檐高度。建议改为“身体底面贴帽面”：支撑高度取脚圆内各点的帽面高度减去该点身体底面抬起量的最大值。成体底面抬起量约为：半径 5.3 以内为 0，6.5 处 0.7，7.2 处 2.0（按体型缩放）。圆帽的帽面高度只随离轴距离变化，可用一条径向剖面表示。预览按真实身体网格底面在 0.125 网格上计算；现版列仍按现行规则摆放。
- **储粮层**：每份沿用现在画法占的空间（半径 0.09 格、高 0.06 格的帽底圆柱，6.25 单位³），全部份数在帽腔里铺成一个水平层，用一张贴图画层面；份数越多，层面越高。乘员坐在层面上。三档为 6、12、24 份；24 份即载重上限 12（每份 0.5）且船上没有幼体。
- **辫子够得着**：`braid_cradle_lift` 中辫梢托兜最低只到身底以上约 0.75，离辫根最远 9.9。新生要在早上被辫子托出，夜里的位置就不能比帽主早上的座位低太多。

## A 尖锥帽 `cone`

- **造型**：陆生帽的阶梯帽冠改成四层圆台，顶端是钩向 +X 的弯尖（管状）。放下后和现版一样把帽冠压到 0.55，弯尖折平在最底下。
- **帽腔与高度场**：四圈同心平台，按半径分段取常数深度：半径 9.03 到 7.28 深 2.2，7.28 到 5.46 深 4.1，5.46 到 3.64 深 5.9，3.64 以内深 7.4。可以和现在的 `cavity_sections` 一样按段导出，只是矩形换成圆环。
- **乘员**：帽主的身体正好卡进第二层（身底 2.7，约身高的 28%），四周只剩一圈上层环台，白天两只新生坐在那上面（2.2，比帽主身底高，辫子够得着）。
- **储粮**：粮从尖底往上填，24 份时层面仍在帽主身下（4.9），不会把她抬起。但有人坐着时，从岸上几乎看不到粮层。
- **夜里**：帽底就是她身下的尖底，新生只能睡在那里（5.9），与她身下只有 0.1 的间隙；比她的座位低 3.2，辫子托不出来，要她先离开座位。
- **转身**：座位井只比她略宽，转身抬起 0.24。
- **还原度**：最接近陆生帽轮廓、“帽冠略压扁”和 EH22-001 水下垂着的锥形帽冠。帽体伸到水下 6.1（0.38 格），浅水里容易搁浅。
- **美术成本**：最低。圆台沿用同一批图集格子，放下仍是逐层压扁，高度场是分段常数。

## B 圆冠盆 `basin`

- **造型**：软帽冠，高 10.4 帽单位，从帽冠底平滑收成尖，尖端向 +X 垂下，是常见的圆檐巫师帽。放下后软帽冠塌成圆盆：帽口先直下一个帽檐厚度，再以四分之一椭圆弧弯到盆底。半径 6.4 以内是平底，深 3.85，中央压扁的帽尖留下 0.3 的浅窝。帽冠上段平铺在盆底，变成同心环。
- **帽腔与高度场**：径向剖面 `h(r)`。`r ≤ 6.44` 为平底加浅窝；6.44 到 9.03 是椭圆弧，从 3.85 升到帽檐厚度 1.12，再直上到帽檐面。没有台阶和角。
- **乘员**：帽主坐在盆底（3.9，约身高 41%，与 EH22-001 帽口在嘴边的高度相当），帽檐在她下半身。新生白天并排坐在她身前的同一盆底（3.6）。所有人都在同一层，辫子够得着。
- **储粮**：粮铺满整个盆底，成为一个大圆面，份数越多层面越高；从岸上看最像一层，但层薄、升得慢（6→24 份只升 0.5）。大家都坐在粮层上，24 份时帽主升到 3.1，仍坐在帽里。
- **夜里**：新生睡在她身前的盆底（3.7 / 3.5），她用 `boat_cover_young` 俯身盖住，与身体、头发和辫子仍有 1.2 的间隙。早上她不用挪位，辫子就在同一高度把新生托出。
- **转身**：全圆，中央原地转身不抬升，在座位处抬起 0.17。
- **还原度**：戴着时最像巫师帽。放下后的“柔软帽冠形成巢状空间”最直观，但帽冠压得比“略压扁”多，水下也不像 EH22-001 那样垂着锥尖。帽体只伸到水下 3.2（0.2 格），浅水也能浮。
- **美术成本**：中等。平滑旋转体共 31 环、约 1400 个三角形。放下不再是简单压扁，而是同拓扑的第二组环，`hat_off_self_aq` 等摘帽、放帽动作要改成逐顶点插值。高度场在三者中最简单。

## C 筒帽兜 `pocket`

- **造型**：硬帽带筒（带白带与蝴蝶结）上接软锥帽冠，再接弯尖。放下后帽带筒保持直立，筒顶就是平底，深 3.6；软锥下段平铺在底上，上段连同弯尖在船首一侧折成圆兜，兜心离轴 3.8、半径 4.5、比平底再深 3.2，弯尖压平在兜底。
- **帽腔与高度场**：平底加一个偏心圆兜，需要两个圆来描述，不再是径向对称。兜的位置决定了船首方向。
- **乘员**：帽主坐在兜对面的平底上（3.6）。新生并排坐在她身前的平底上（3.8 / 3.6）。兜口离她身下很近，兜是新生的落坑，辫子从兜里托不出来。预览按“幼体不进兜”摆放，这是一条要另加的规则。
- **储粮**：粮先灌进兜里，从岸上看是兜里一汪逐渐升高的粮面；约 24 份才漫到平底，之前不抬乘员。
- **夜里**：和 B 一样，新生在她身前平底（3.8 / 3.6），她俯身盖住，间隙 1.3，辫子够得着。
- **转身**：中央不抬升，靠近兜边的座位抬起 0.40。
- **还原度**：戴着时是带帽带筒的巫师帽。“弯尖折成粮兜”是项目设计，作品资料中没有。
- **美术成本**：最高。三段帽冠、偏心环和压平的弯尖都要单独处理；高度场、座位和幼体规则都要知道兜在哪里。

## 推荐

推荐 B 圆冠盆。它让帽主真正坐进帽里（身高的约 41%，帽檐和翘起的外缘在她下半身），全圆便于转身，粮层是一整面随份数升高的圆面；新生和帽主睡在同一层，夜里俯身能盖住，早上辫子在原高度就能托出。它也是戴着时最像巫师帽、吃水最浅、高度场最简单的一个。代价是储粮会把乘员整体抬高，24 份时抬 0.8，且薄层升得慢；放下需要做成同拓扑插值，不能再只靠压扁。A 最像陆生帽和 EH22 的水下锥尖，但夜里幼体被压在帽主身下，辫子托不出来，而且吃水深。C 的粮兜能让粮不抬人，但兜同时是幼体落坑，还要增加规则。

## 采用时

只是造型与读数候选，未接入。采用某一候选时：

- 把配方转为正式制作源并导出水生帽的戴着与放下网格。陆生帽和接生帽不变。
- `HatGeometry` 改为圆帽径向高度场，并实施上文的支撑规则。
- 摘帽、放帽、扶正等动作改用插值过渡。
- 浮力水线面、储粮从逐份小件改为粮层，以及 Wiki“水生魔理沙·项目采用”和[水上生活](../../../../docs/AQUATIC_MARISA_IMPLEMENTATION.md)中“与陆生种同形、1.75 倍”的旧描述，都按所选方案更新。

试玩前这些都是项目设计，不算行为验收。
