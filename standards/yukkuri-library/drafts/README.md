# 待确认素材

`expression-review/` 保存表情比较页、哈欠试用页及配套图，属于设计核对材料。页面组合可能读取当前角色导出，但嵌入的候选像素和文案保留其制作时状态，不能据此推断全部候选已确认。

| 入口 | 用途 |
| --- | --- |
| [待确认表情](expression-review/pending-expressions.html) | 比较当前版本与候选部件组合 |
| [部件比较](expression-review/component-review.html) | 查看表情部件试用差异 |
| [批次比较](expression-review/batch-16-40.html) | 保留一批表情的比较材料 |
| [哈欠动画候选](expression-review/yawn-animation.html) | 查看候选帧的组合 |

正式表情状态仍以 `expressions/index.json` 及其引用配方为准。新草稿按主题建目录，确认后更新正式源及导出，保留必要的历史比较记录。
