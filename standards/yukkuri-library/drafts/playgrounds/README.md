# 大型游具制作源

陶管、滑梯、蹦床和橙汁澡盆按 Minecraft 风格制作：简单折面与方盒结构（平法线，无平滑球面塑料感），表面贴每单位 1 像素的手绘像素贴图（1 像素图集留边），配色取自物品栏图标色阶（[图标绘制](../item-icons/draw.py)），不用噪点贴图或平滑渐变。`build.py` 定义各设施的形体、像素贴图与碰撞；`recipe.json` 是展开记录（部件、三角形数与碰撞盒），`assembled/<ID>/` 保存可编辑 Blockbench 网格及贴图图集。不要只修改导出。

在项目根目录运行 `python standards/yukkuri-library/drafts/playgrounds/build.py` 同步本包、[游戏选用快照](../../../../art/props/playgrounds/README.md)与运行资源；加 `--check` 只核对导出。`python standards/yukkuri-library/drafts/playgrounds/preview.py <输出目录>` 出使用中对照图（成体、幼体在玩耍位置上；蹦床另出床面压下 1、2 单位；澡盆另出橙汁 0–4 档与两只成体并坐）；图标、1×／4× 与两视角对照用 [block-props/preview.py](../block-props/preview.py)。

- 碰撞按与表面相同的尺寸计算，看到的表面就是站立的表面；滑梯斜板按一个单位沿坡采样。路线高度：陶管底面 3（路线点 2，在 0.6 格容差内）、滑梯台阶 4／8／12／16 与平台 16、蹦床床面 8 与边垫 9（碰撞里只有床面顶在 8）。
- 陶管：前后完全对称的 16 边折面釉面陶管，落在平底座上，两端都有相同的阶梯状凸起承口与管身阴刻窑纹；管内折面圆拱加平底（底面宽 14、净高 24.5），宽帽和长发可通过；管内随深度按清晰像素色阶变暗。
- 滑梯：钢架青绿滑梯。四级带防滑纹与亮边踏鼻的钢踏步，两侧方柱、铆钉钢侧板与方管斜扶手，青绿平台与折面 U 型滑槽（斜切护边、平出口与出口撑脚）。
- 蹦床：16 边折面圆形小蹦床。编织深色床面带中心弹跳靶圈与金色缝线边，16 根可见径向螺旋钢弹簧拉在床面与外钢圈之间，上方覆盖分瓣缝线金色护垫并留出弹簧可见空隙，下方六条方铁腿配橡胶脚垫。床面是独立部件 `bed`（unit 2，支点 y 8），渲染时整体下压至多 2 单位；床面下的静止折面凹井 `well` 在压下时露出带径向折痕的深色斜面，不露缝。
- 橙汁澡盆（物品 ID 仍为 `yukkuri_pool`）：低矮的 16 边折面圆角矩形白搪瓷澡盆，藏青卷边、外立面竖棱与蓝细线、盆底排水口与两端方管提耳，盆内前壁一级防滑座阶给小体型坐，盆外前方一块带腿与横撑的双板木踏凳。液面是独立网格 `yukkuri_pool_juice`：`juice_u1`–`juice_u4`（unit 1–4）各为一档不透明像素橙汁液面，画 unit 1..k 即 k 档满。澡盆的高度、液面与座位导出在 `data/mcyukkuri/playgrounds/yukkuri_pool.json` 的 `tub`。

静态道具没有角色骨架或预烘焙动作；使用过程由游戏内实体、碰撞与重力驱动。游戏资源快照与制作源分别维护；造型登记以接入包的来源记录为准。
