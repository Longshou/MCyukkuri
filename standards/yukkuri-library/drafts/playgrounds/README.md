# 大型游具制作源

陶管、滑梯、蹦床和橙汁澡盆按真实形体制作（[平滑网格套件](smooth.py)）：圆截面、倒角与圆角由扫掠、旋转和挤出生成，法线按折角平滑；配色取物品栏图标的色阶（[图标绘制](../item-icons/draw.py)），每段表面一个色块，深处用渐变条，木纹接缝这类细节用小贴花，不用噪点贴图。`build.py` 定义各设施的形体、上色与碰撞；`recipe.json` 是展开记录（部件、三角形数与碰撞盒），`assembled/<ID>/` 保存可编辑 Blockbench 网格及贴图图集。不要只修改导出。

在项目根目录运行 `python standards/yukkuri-library/drafts/playgrounds/build.py` 同步本包、[游戏选用快照](../../../../art/props/playgrounds/README.md)与运行资源；加 `--check` 只核对导出。`python standards/yukkuri-library/drafts/playgrounds/preview.py <输出目录>` 出使用中对照图（成体、幼体在玩耍位置上；蹦床另出床面压下 1、2 单位；澡盆另出橙汁 0–4 档与两只成体并坐）；图标、1×／4× 与两视角对照用 [block-props/preview.py](../block-props/preview.py)。

- 碰撞按与表面相同的尺寸计算，看到的表面就是站立的表面；滑梯斜板按一个单位沿坡采样。路线高度：陶管底面 3（路线点 2，在 0.6 格容差内）、滑梯台阶 4／8／12／16 与平台 16、蹦床床面 8 与边垫 9（碰撞里只有床面顶在 8）。
- 陶管：躺倒的釉面陶管，外圆下有平脚，+Z 端一节承口，两端口沿倒圆；管内圆拱加平底（底面宽 14、净高 24.5），宽帽和长发可通过；管内随深度变暗。
- 滑梯：幼儿滑梯。四级圆角踏步夹在两片侧板间，侧板顶是扶手；青绿滑槽的平直起段就是平台，平台四周护栏高 6，沿槽降到 4；滑槽末端弯成平出口。
- 蹦床：圆形小蹦床。金色边垫盖住弹簧并垂下裙边，钢圈与六条腿、橡胶脚垫；深色床面带缝线包边和中心圈。床面是独立部件 `bed`（unit 2，支点 y 8），渲染时整体下压至多 2 单位；床面下的静止锥面 `well` 从垫边斜到 r 5 处床面以下 2.3，压下时露出一圈稍暗的斜面，看上去是从垫边凹到平底的弹性凹陷，不露缝。
- 橙汁澡盆（物品 ID 仍为 `yukkuri_pool`）：低矮的白搪瓷椭圆澡盆，藏青卷边和两端提耳，盆内前壁一级座阶给小体型坐，盆外前方一块木踏凳。液面是独立网格 `yukkuri_pool_juice`：`juice_u1`–`juice_u4`（unit 1–4）各为一档不透明液面，画 unit 1..k 即 k 档满。澡盆的高度、液面与座位导出在 `data/mcyukkuri/playgrounds/yukkuri_pool.json` 的 `tub`。

静态道具没有角色骨架或预烘焙动作；使用过程由游戏内实体、碰撞与重力驱动。游戏资源快照与制作源分别维护；造型登记以接入包的来源记录为准。
