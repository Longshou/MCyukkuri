# 大型游具制作源

陶管、滑梯、蹦床和水池采用方块风格（[共享套件](../block-props/kit.py)）：1/16 格立方单元，每单位一个贴图像素，配色取物品栏图标的色阶（[图标绘制](../item-icons/draw.py)）。`build.py` 定义各设施的单元、上色规则与碰撞；`recipe.json` 是展开记录（部件、单元数与碰撞盒），`assembled/<ID>/` 保存可编辑 Blockbench 网格及贴图图集。不要只修改导出。

在项目根目录运行 `python standards/yukkuri-library/drafts/playgrounds/build.py` 同步本包、[游戏选用快照](../../../../art/props/playgrounds/README.md)与运行资源；加 `--check` 只核对导出。`python standards/yukkuri-library/drafts/playgrounds/preview.py <输出目录>` 出使用中对照图（成体、幼体站在路线点上，蹦床另出床面压下 2 单位）；图标、1×／4× 与两视角对照用 [block-props/preview.py](../block-props/preview.py)。

- 碰撞由同一组单元合并成盒子导出，看到的表面就是站立的表面；滑梯斜板单独按一个单位沿坡采样。路线高度：陶管底面 2、滑梯台阶 4／8／12／16 与平台 16、蹦床床面 8、水池侧踏台 6。
- 陶管：躺倒的阶梯圆截面，两端口沿凸起一圈，管内平底并放宽到 24 单位，宽帽和长发可通过；管内随深度变暗。
- 滑梯：钢台阶与塔身、青绿平台和带侧沿的滑板、平台护栏与扶手。滑板和扶手先平放制作，再沿坡剪切到位（如原版讲台斜板）。
- 蹦床：圆角金色框架、四条铁腿，围裙遮住弹簧；床面是独立部件（unit 2，支点在床面 y 8），渲染时可整体下压；框架内壁从围裙底起，床面压下 2 单位内只露出暗色内壁，不露缝也不露弹簧。
- 水池：白色池沿、蓝色池底与内壁（池沿下一道线），两侧瓷砖踏台各带一级外台阶；游戏内由原版水流体填充池内。

静态道具没有角色骨架或预烘焙动作；使用过程由游戏内实体、碰撞与重力驱动。游戏资源快照与制作源分别维护；造型登记以接入包的来源记录为准。
