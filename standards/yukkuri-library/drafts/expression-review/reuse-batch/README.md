`before.json` 是复用前配方快照，`before-overview.png` 是上次总览。`presets/` 保存本轮完整候选配方；`reuse-manifest.json` 逐槽记录供体编号、路径、文件指纹、实际改动及未覆盖的特殊部件。

组件 PNG 原样引用正式库，不重新绘制。N019 睁眼使用目标位置 `[0, 1.219, 0]`、比例 `[0.8, 0.7, 1]`，使眼睛位于刘海与鼓脸之间；嘴型沿用供体变换。泪花保持原像素，按目标眼睛的可见下缘平移，使泪花上缘覆盖下眼缘 0.1 个模型单位。N024/N025 的蓄泪、流泪差分分别保留，不合并为同一泪帧。

`textures/<角色>/` 是六个标准角色按各自 UV 绑定生成的配套候选图集。对照页在各角色现有模型上应用相同配方像素和相对几何变换，支持正面及斜侧面比较。本批次十二项已同步到 `assembled/`；本目录保留制作与对照记录，Minecraft 接入资源未修改。
