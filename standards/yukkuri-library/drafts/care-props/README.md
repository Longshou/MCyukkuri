# 照料道具统一造型

食盆、油粮袋、窝、残渣与便便、携带用品等照料道具的共用制作源。放置后的宠物照料用品（食盆与填充、宠物软垫窝、2×2 编织大窝、沙厕、陶厕、带盖厕与便堆）是圆润低多边形加手绘像素材质（`shapes.py`、`placed.py`）：圆形或圆角矩形轮廓沿短剖面旋转成型，24–40 段、无阶梯，每个面取同一张贴图上的专属手绘区域，约 1 texel／单位，色相偏移色阶、左上受光、低对比颗粒，不复制原版文件；每件有数款配色／花纹，放置后用染料切换；占地、高度和入口沿用 `CareBlock` 碰撞。其余道具仍是低多边形软造型：形体贴 1/16 格网（圆截面 1/32），颜色只取自 [共用色板](../../../../art/props/palette.json)（每种材质 4 阶，暗到亮），贴图是 4×4 texel 色块加可选贴花区（1–2 texel／单位，无抗锯齿位图字）；不描黑边，接触处和凹缝用本材质最暗一阶；物品 ≤600 三角，满盆 ≤2500。

野生油库里就地收集、搭建的东西是另一族（`wild_kit.py`）：叶床、个人小叶巢、叶束、2×2 野生大窝与储粮堆（含帽船粮袋的叶托）共用一张手绘 128×128 图集。造型照原版营火、堆肥桶、干草块的做法，用少量较大的圆润低多边形件，不用 1/16 立方阶梯：窝沿是叼来的散干草一口口推到位、一层层压实交错成圈（宽而扁的底层、压在接缝上的中层与有空隙的顶层小团，草茎顺着窝沿走，团端露出茎头，约三分之一用灰褐旧草，分面受光让纤维可见，不扎不捆），配落叶垫、整片大叶、方截面细枝、外露草茎与苔藓团；储粮堆是叶托上的一座低圆草丘，丘顶压着几团同样的散草与横搭草茎，一侧是一簇红浆果；草团与毛虫放在前方叶托上，满档另有一朵小白花，颜色只用草黄、叶绿和红色点缀。贴图照 `supplies.py` 的画法：左上受光，各材质用自己的色相偏移色阶，以本材质最暗一阶作轮廓，无黑边、无抗锯齿，不复制原版文件；1 texel／单位，沿路径或按世界坐标连续，镂空精灵只用 0／255 透明度。占地、高度、入口和碰撞沿用原值。

来源与采用范围（Wiki 摘录与图片，均未作原文逐字核验）：干草围成的碗状窝、窝内垫绿叶、窝旁叶片上放毛虫、白花和草团见 EH19 第 5 页（[图](../../../../wiki/art-references/ehentai/images/EH19/005.jpg)）；成束干草围成的深碗状窝见 M04 第 1 页（[图](../../../../wiki/art-references/images/M04/001-9b35bd1c.png)），两只幼体睡在细草茎绕成的圆碗窝里见 EH37 第 6 页（[图](../../../../wiki/art-references/ehentai/images/EH37/006.webp)，[作品页](../../../../wiki/art-references/ehentai/works/EH37.md)）；寝处叠起宽于睡圈的干草床见 [N103](../../../../wiki/novel-reading/cards/N103.md)，秋季收集叶枝见 [N38](../../../../wiki/novel-reading/cards/N38.md)，树根、岩石与苔藓铺层见[栖息与季节生活](../../../../wiki/hakkei-reference/lore/habitat-seasonal-life.md)；储粮的虫团与干草见 [N71](../../../../wiki/novel-reading/cards/N71.md)，坚果与干草耐放留作越冬见[资源与生态](../../../../wiki/hakkei-reference/world/resources-ecology.md)（L06，作者私设），花、毛虫与落果见 N93、N38 与 EH35。Wiki 没有画出堆放的存粮；草束的数量与尺寸、细枝与苔藓的搭配、叶托、储粮堆四档堆形与食物组合、帽船粮袋的叶托与物品摆放以及全部配色和贴图都是项目设计。

## 放置用品制作说明

来源（Wiki 采用范围）：[宠物生活](../../../../wiki/pet-life.md)“吃饭与请求”“居住与作息”“排泄与清洁”与[资源与生态](../../../../wiki/hakkei-reference/world/resources-ecology.md)“餐具与食物递送”。采用的只有形制：EH32 第 5–9 页地上的小而浅的圆形食盆（盛颗粒粮）和开口软垫窝；EH23 第 2 页写着名字与爱心的圆形宠物食盆、圆形凸沿软垫；EH34 第 17 页的长方形厕所；L32 仿写饲养手册为小型种铺砂底。图证均为黑白线稿，没有颜色、材质或花纹。

项目设计：全部配色、花纹与款式名；食盆盘底小印花；软垫窝的滚边与绗缝；2×2 编织方篮；陶厕与带盖厕（含后半盖）；油粮颗粒、麦穗与割草堆的画法；入口下沉方式；便堆造型。Wiki 未写盆里放什么，油粮／小麦／短草沿用玩法设定。
