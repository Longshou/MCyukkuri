## 逐项核读

### 翼（R2 最清楚，R1 可佐证）

- **形态**：蝙蝠翼。翼膜上能看出**分叉的指骨**，后缘是**扇形／花瓣状**的连续凹口，不是一条直线
- **尺寸**：展开时单侧长度接近体宽，双翼总跨度明显大于身体宽度
- **颜色**：翼膜深紫黑（近黑），指骨为略浅的灰紫；R3 平静姿态下翼几乎贴身，读起来像体侧的深色块
- **根位**：从身体**上侧偏后**伸出，R1 里能看到翼从帽子后下方探出
- **姿态**：R2 是展开警戒姿态，R3 是收拢常态——说明该种有收／展两态

### 头部（R1、R2、R3）

- **软帽**：粉红色，帽身是扁圆盘，**帽檐有一圈荷叶边（波浪造型）**；R2 的帽檐偏红粉，R3 偏红
- **蝴蝶结**：帽子**后方**一个**红色荷叶边**大结，不是普通平结
- **头发**：淡蓝紫（高光偏白、暗部偏紫），长度到身体两侧，R2 里刘海盖住额头
- **脸**：眼睛很大；R2 张口时可见口腔内部与舌，脸侧有明显腮红

### 身体

- 奶白／米色，圆胖，与标准种体型同级
- R2 体侧可见**深色弧形色块**，是收拢的翼压在体侧形成的

## 据此确定的参数

| 项目 | 取值 | 依据 |
| --- | --- | --- |
| 翼形 | 蝙蝠翼：翼脊＋后缘扇形凹口，每侧 5 段链骨 | R2 |
| 翼色 | 膜面深紫黑 `68,52,80`，指骨灰紫 `150,132,168`，前缘提亮 | R2 |
| 翼尺寸 | 单侧展长约等于体宽，收拢姿态另存 | R2 展开态 |
| 翼根 | 体上侧偏后，z 取身体后部 | R1 |
| 软帽 | 帽身扁圆盘＋外扩荷叶边帽檐，粉红 | R1、R3 |
| 蝴蝶结 | 红色荷叶边大结，置于**帽后** | R1 |
| 发色 | 淡蓝紫：主色 `168,196,232`、高光 `216,232,248`、暗部 `128,156,208` | R1、R2、R3 |

## 仍未确认

- 獠牙：R1、R3 看不出尖牙，R2 张口时口内可见但要判定是否有突出獠牙需要更清楚的图。**在用户确认前不把獠牙当作必有特征**
- R2 的张口是痛苦表情还是捕食姿态，无从判断
- 幼体形态（R3 有小个体）本轮不做
