# 本轮捕食种美术参考

2026-09-13。本轮制作两种游戏模型，不将单篇作品设定当成所有作品共用规则。

蕾米莉亚的蓝紫发、粉软帽、后红结与上侧偏后的蝙蝠翼沿用本包[既有 R1–R3 核读记录](REFERENCES.md)。这些图片来自此前用户提供的参考，本轮没有重新获取或冒称重新核读原图。旧稿几何没有直接充作新实体。

弗兰本轮实际查看了《ふらんと一緒～きしょーしゅ～》的封面图片：[作品页面](http://blog.livedoor.jp/yukkuri_anko/archives/38655831.html)、[核读图片](https://livedoor.blogimg.jp/yukkuri_anko/imgs/6/0/609a946f.png)。封面为背身视角，可见金发、偏侧马尾、浅色软帽与红结、深色枝状翼架及每侧四枚彩色菱形饰片；图片未显示的面部细节没有写成原作事实。作者署名本轮未确认。

本轮原创部分包括身体截面、低多边形发束、帽冠与荷叶边、翼膜三角网格、晶体关节、振翅曲线、像素尖牙、巢穴编织几何及 Minecraft 行为。眼睛、眉毛、嘴部形状复用项目已选用的魔理沙表情部件，再按种族调整虹膜配色。参考图片不进入运行资源，配方与产物指纹见 `species-manifest.json`。

飞行时长、体力、猎物筛选、咬取份量、商店价格、徽章教育门槛及自动结巢是本项目游戏规则。家养控制遵循用户本轮要求：教育达标的金银章个体可听主人命令，无章或教育不足个体保留野外个性。
