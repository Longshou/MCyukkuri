# 捕食种运行形态参考

蕾米莉亚的蓝紫发、粉软帽、后置红结与上侧偏后的蝙蝠翼沿用[参考核读](REFERENCES.md)中的用户参考图。芙兰的外观依据是《ふらんと一緒～きしょーしゅ～》封面：[作品页面](http://blog.livedoor.jp/yukkuri_anko/archives/38655831.html)、[封面图片](https://livedoor.blogimg.jp/yukkuri_anko/imgs/6/0/609a946f.png)。背身画面可见金发、偏侧马尾、浅色软帽与红结、深色枝状翼架及每侧四枚彩色菱形饰片；未显示的面部细节不作为原作事实。

身体截面、低多边形发束、帽冠与荷叶边、翼膜网格、晶体关节、振翅曲线、像素尖牙、巢穴几何及 Minecraft 行为为项目原创。眼睛、眉毛和嘴部复用已选用的魔理沙表情部件，并按种族调整虹膜配色。参考图不进入运行资源；模型配方和指纹见 [species-manifest.json](species-manifest.json)。

飞行时长、体力、猎物筛选、咬取份量、商店价格、徽章教育门槛和自动结巢均为本项目游戏规则。家养控制为：金银章且教育达标的个体可听从主人命令；无章或教育不足时保留野外个性。
