# 稀毛与歪脸魔理沙体态修复

2026-09-13，按用户“稀毛、歪脸魔理沙的体态没有修改，还是老的，修复”更新。此前圆润推广排除了全部不足形态，这两种仍从旧方块快照生成；本次仅将 `marisa_sparse`、`marisa_face` 改为当前圆润身体。灵梦不足形态、豆油和其他角色未改形。

制作源由 [recipe.json](recipe.json)、`inputs/` 冻结的圆润魔理沙模型及骨架、上级 `recipes.json` 中的稀毛和歪脸参数组成。定向重建命令为 `python scripts/export_marisa_deficient_rounded.py`。该脚本同步两种可编辑源、运行快照、256×256 表情图集、伤口表面、旧伤口迁移输入、嘴部和帽饰挂点；不重新生成其余角色。后续运行旧后发适配器会明确拒绝覆盖这两种体态。

身体与后部标记的网格及连续权重逐项保留圆润基线；稀毛缩窄发束并保留三束刘海，歪脸保留大小眼和偏移嘴部，并重新按身体高度贴合表面。匹配贴图必须使用本包冻结的 256 像素图集，不能沿用旧不足包的 128 像素图集。配套骨架保留 19 段动作，水平移动由游戏控制。

2026-10-13 起辫子随标准改为单侧粗辫：稀毛按 `recipe.json` 的 `sparse_side_hair` 只保留一束辫、发结、发尾和一缕短侧发，歪脸沿用标准单辫。冻结的圆润 donor 三个文件已替换为新标准导出。稀毛帽子按 `sparse_hat_seat` 戴到头上：帽身、帽檐、蝴蝶结及骨骼下移到帽檐底面距眉顶 0.3，头顶收进帽身，徽章挂点同步；取代原固定下移 1.0 与游戏内再降 0.5。单辫与帽子佩戴 2026-10-14 随单辫造型保存。

源与运行路径、指纹见 [manifest.json](manifest.json)。造型标为待用户确认，不修改既有圆润基线的批准记录。该次修正优先于旧文档中“全部不足油保持旧体型”的范围说明。

稀毛的三束刘海、侧短束和后束已按圆润头皮重新生成并绑定到身体，移除了两种旧的浮动顶板。仅稀毛的帽身、帽檐、蝴蝶结与挂点下移一个模型单位；歪脸保留能覆盖其完整发顶的帽子高度。独立审查首轮打回，修订后通过。

当前运行模型用 `python scripts/build_preview_hub.py --render` 离线预览。`preview_marisa_deficient.py` 仍保留两种源与导出、图集尺寸、身体权重、伤口指纹和动作时点的专项检查，其旧路径边界见[脚本说明](../../../../../scripts/README.md)，通用预览不替代专项检查。预览与检查结果不入库；交互页面由用户手工查看。帽子脱戴与帽托交互的资源入口见[交互包](../../../../../art/source/hat-interactions/README.md)，实际效果以当前运行包的用户试玩为准。
