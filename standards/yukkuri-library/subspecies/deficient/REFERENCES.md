# 本轮参考与适配

核读日期：2026-09-13。采纳范围先对照本项目 `wiki/hakkei-reference/lore/species/forms.md` 与 `world/individuals.md`；旧八景 U 移植中的不足形态记录仅作来源核对，外部工程保持只读。

- 《もみあげぴこぴこだんす》，转载署名としあき(おっぱい)，[作品页](http://blog.livedoor.jp/yukkuri_anko/archives/36240555.html)。本轮实际看首张彩图：左侧小个体头发与鬓毛稀少，窄长身体、小嘴伸舌，旁侧完整幼体可对照。后续受伤页未作为先天依据。缓存中的 `dance-01.png` 实际为站点广告，明确排除；核读的画面是 `dance-actual.jpg`。
- 《足りない親れいむ》，转载标作者不明，[作品页](http://blog.livedoor.jp/yukkuriplace_anko/archives/48512064.html)。本轮实际看第一页三格，左侧灵梦保留头发、饰物，眼形及眼位不对称，嘴有偏斜。该页支持面部差异，不支持失去亲子感情或低智的推断。
- 《ほんとうのしあわせ》，转载署名キリライターあき，[作品页](http://blog.livedoor.jp/yukkuri_anko/archives/29582969.html)。本轮看第1页 `9b35bd1c.png`，下排幼体鬓毛向两侧蓬开；用于核对已存在的多毛制作源，不将普通成年灵梦一并归为多毛。

图片缓存为既有本机核读资料，未复制进制作源或运行资源。游戏几何、贴图沿用项目现有自绘素材。稀疏毛发保留短簇，不做全秃；面部变化保留表情图集；豆形身体把上段收窄、头脸抬到上方，下段保留接地与动作骨架。具体三维比例为本轮制作参数，不能当作跨作者的统一设定。
