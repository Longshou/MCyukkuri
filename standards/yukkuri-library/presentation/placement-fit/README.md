# 头饰与头发位置适配

本包调整当前游戏形态的帽子、头饰与头发位置，使其贴合圆润身体并适配现有动作。游戏快照和来源指纹见 [art/source/placement-fit](../../../../art/source/placement-fit/README.md)。

## 造型依据

圆润身体的头顶是穹形：中心高9.6，两侧 x=±6 处约6.9。原发型的发顶却是一块平板，四角一直伸到 x=±6.83、y=10.61，正面看成方盒，鬓角像两根柱子立在发顶两侧。魔理沙帽檐平放在这块平板上，看上去是盖在头上的盖子。八景U参考（`wiki/art-references/game/standard-species/hakkei-slot-0.png` 等）中，头发顺着头顶圆下来，魔理沙帽子戴在头上，帽檐压在发际，刘海从帽檐下露出。

## 做法

所有调整都在静止空间完成，身体、五官、腮红与生殖器部件不动。基础选用模型及其指纹不改写；运行资源只保存被改动部件的替换网格和骨骼枢轴。

- 发顶圆角（dome）：取发型包围盒，在顶面四周的圆角区内，按“方变圆”映射把点沿高度与水平距离同时收拢。侧面圆角半径5.5、高3.2，后方3.0，正面只用1.2～2.0，刘海不会被拉进脸里。圆角区内的长边按弯曲量自适应细分（中点偏离弦超过0.03即切分），相邻三角形按同一条边判定，不产生裂缝；平直区域保留原三角形。
- 侧发收拢（taper）：侧墙与鬓角在 y 6.5～9.4 之间横向收至0.9，顶端收进发顶圆角之下。灵梦、歪脸灵梦、魔理沙、歪脸魔理沙的鬓角不参与发顶圆角，改为只竖直下收（drape）：被发顶盖住的一段顶端落到发顶底面下0.03，外侧随后侧发轮廓下降，水平位置不变。若鬓角也按圆角向内收，鼓腮外摆的中间过程会擦过圆角发顶，或在超过10°后插进头皮。魔理沙两种的鬓角发梢与发结前移0.05，外摆时不擦后侧发。
- 头顶垫块：灵梦、歪脸灵梦、魔理沙、壳魔理沙、橙、爱丽丝发顶下的垫块原本挂在不随身体压扁的骨骼上，压扁、蓄力等动作中会从发顶顶出（灵梦为肤色平板，原模型即有）。现改用与发顶相同的高度切片权重，与头发一起变形。
- 骨骼与权重：随高度切片绑定的顶点按新高度重新插值，动作中头发与身体在同一高度一起变形。帽子、蝴蝶结与猫耳的骨骼枢轴随部件一起移动；鬓角的铰点保持原位，顶端收进圆角后仍绕原铰点外摆。若铰点随圆角内收约1.5，鼓腮的侧发外摆找不到无穿插的角度，灵梦侧发会改为压住脸颊，因此不移动。
- 刚性附件：魔理沙帽子整体下移（普通、歪脸1.5，稀毛0.5），帽子外形不变，掉落饰物和徽章挂点无须改动。灵梦、歪脸灵梦的整个蝴蝶结按结心处后发的位移整体平移；尾带逐点贴在后发外0.05，从结心下方垂下。多毛灵梦的尾带与后发使用同一圆角映射，环与结心随结心处的位移平移。两种灵胖的蝴蝶结以下端为轴前倾6°，再沿前下方移动，使结心与尾带贴住后脑（重叠0.08）。稀毛灵梦的尾带逐点贴在头皮和头顶发丝外0.05，并使用头皮的高度切片权重。橙的帽子沿帽檐外沿落到圆角发顶上；猫耳只随根部竖直位移下移，保持外张。
- 软附件：爱丽丝发箍与头发使用同一圆角映射，始终贴着发面；发箍不细分，徽章三角形编号不变。

| 形态 | 调整 |
| --- | --- |
| 灵梦、歪脸灵梦 | 侧发收拢、发顶圆角、鬓角竖直下收、蝴蝶结随结心处后发平移且尾带贴后发、头顶垫块随发顶 |
| 多毛灵梦、多毛灵胖 | 发顶与后发圆角（侧面炸毛不动）；多毛灵梦的蝴蝶结同灵梦，多毛灵胖的蝴蝶结前倾贴头 |
| 灵胖 | 发顶圆角、蝴蝶结前倾贴头 |
| 稀毛灵梦 | 蝴蝶结尾带贴到头皮与发丝外并随头皮变形，不再半埋 |
| 魔理沙、歪脸魔理沙 | 侧发收拢、发顶圆角（正面2.0）、鬓角竖直下收与发梢前移、帽子下移1.5；魔理沙的头顶垫块随发顶 |
| 稀毛魔理沙 | 帽子由亚种导出器按眉顶定位（见[稀毛与歪脸魔理沙](../../subspecies/deficient/rounded-marisa/README.md)），本配方步骤为空 |
| 壳魔理沙 | 发顶与侧发同魔理沙，头顶垫块随发顶；螺壳不动 |
| 橙 | 侧发收拢、发顶圆角、猫耳随发面下移、帽子落座，头顶垫块缩小留在帽内并随发顶 |
| 爱丽丝 | 侧发收拢、发顶圆角、发箍随发面、头顶垫块随发顶 |

## 运行数据

`recipe.json` 逐形态列出步骤、部件名称（正则，整名匹配）与参数，`author.cjs` 计算网格。`scripts/export_placement_fit.cjs` 读取当前运行模型，写出 `src/main/resources/assets/mcyukkuri/yukkuri_presentation/placement_fit.json` 与 [manifest.json](../../../../art/source/placement-fit/manifest.json)。

每个改动部件记录为索引网格（位置与UV、按顶点的骨骼权重、三角索引）。未细分的部件 `inplace` 为真，按原三角顺序覆盖原位置，徽章挂点和鼓腮侧发偏移的三角编号因而不变；细分部件追加到顶点表末尾，部件范围改指向新网格。法线由读取方按三角面重建。每个形态记录基础模型的 SHA-256；指纹不一致时游戏跳过该形态的适配并记录警告。

游戏 `YukkuriModel` 先拼接位置适配，再应用[动作修订](../../motions/variants/contact-safe/README.md)；素材检查室 `pose.js` 与 `scripts/placement_fit.py` 使用同一拼接规则。鼓腮形变、帽子脱戴与帽托、果实悬挂点均按拼接后的网格重新导出。

## 重新导出

修改本目录或替换基础模型后，从项目根目录依次执行：

```powershell
node scripts/export_placement_fit.cjs
python scripts/export_motion_corrections.py
python scripts/export_hat_interactions.py
python scripts/preview_hat_interactions.py
python scripts/export_family_assets.py
python scripts/build_review_catalog.py
node scripts/verify_placement_fit.cjs
```

`export_placement_fit.cjs --check` 只核对；`--only id,... --out 文件` 将单项输出写到指定文件。果实悬挂点在 `art/props/family-life/recipe.json` 中按魔理沙帽子与橙帽子的位移手工同步（魔理沙 −1.5、橙 −0.0839），改变帽子位移时须一并更新。
