# 本轮检查

最新修订是八种圆润模型的背发贴合与移动绑定、灵胖刘海发根连接，见[头发修复验收](HAIR-CONTACT.md)及[候选指纹](../../features/hair-contact/candidate.json)。当前 `sources.json` 为 3,110 项，`structure.json` 为 131 段动作／3,275 个姿态；本轮浏览器报告为 `hair-gallery-browser.json`。下方原身体、面容与蝴蝶结记录仅适用于各自当时的文件指纹，不能证明头发修订已确认或已在 Minecraft 验收。

此前修订为灵胖蝴蝶结恢复普通灵梦的实际尺寸，身体仍为1.5倍，成熟面容像素保持不变。当时通过 868 项饰物／未变部件检查、200 个实际动作姿态、3,653 项来源检查和 64 项浏览器检查，见[候选指纹](../../features/deibu-bow/candidate.json)及 `reimu_deibu-bow.json`。这些记录保留为头发修订前的基线。

下方保留前两次身体尺寸与面容迭代的检查说明。旧 `reimu_deibu-scale.json` 中“所有部件统一放大”的结论已被本次蝴蝶结独立尺寸修订取代，不能再用于证明当前头饰尺寸。早期面容候选中的模型指纹也属于本次修订之前；面容纹理指纹仍匹配。

当前灵胖面容已按“大妈、减少可爱感”修改，半睁眼、小虹膜、浅眼袋与脸颊纹替代幼态大眼和粉红腮红。面容待确认，原圆润体型及1.5倍尺寸不变。制作与检查指纹见[面容候选记录](../../features/deibu-mature/candidate.json)；较早的面容批准和验证记录仅作为基线。

本轮补充：灵胖按用户要求整体设为普通灵梦的 1.5 倍，身体 19.2 × 14.4 × 16.095 单位。已通过 [精确缩放与七种模型不变检查](reimu_deibu-scale.json)、[200 个动作姿态](reimu_deibu-structure.json)、[34 项伸缩检查](reimu_deibu-anatomy.json)、[263 项胎生检查](reimu_deibu-birth.json)，并再次通过本页浏览器 64 项检查与来源 3,653 项检查。查看[同镜头对照](../../previews/current/deibu-size-comparison.png)。

批准时的灵梦、魔理沙几何顶点与当前正式版本逐项相同；另外六种换体型的角色使用相同身体网格。捕食种只登记已存在的同形身体，不改其专属模型。标准确认来自用户本轮“设置为标准体型并保存”的明确指示；技术检查不另行扩大角色专属造型的既有批准范围。

未执行 Minecraft 编译、游戏启动或实机验收，本轮也未改游戏接入快照。当前准确变形依赖配套 `animation-rig.json` 的顶点权重或 `runtime.model.json`；导入其他编辑器或引擎时需要接入该权重，不能只根据 `.geo.json` 文件名判断动画兼容性。
