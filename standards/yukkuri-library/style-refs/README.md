# 生图画风参考包

用途：所有 Codex 生图（分镜、概念图、四视图、贴图草图）默认附带的画风参考，统一体素造型、色阶与脸部像素风，减少返工。

- 只管画风，不管比例和数值：长度、角度、尺寸和时间一律来自真实模型、片段与检查，不从参考图或生成图读取。
- 内容：标准灵梦与魔理沙当前运行模型的正面和四分之三视图（中性脸）、在用道具魔理沙帽子的渲染、已确认标准表情的脸部像素表（取 89 项中的 12 项）。
- 清单与指纹在 `refs.json`（文件、内容、来源路径、来源指纹、本文件指纹）。`.local/tools/storyboard.py` 的 `gen`、`edit`、`review` 自动把这些图放在 `--ref` 之前；`--no-style` 跳过。文件缺失或指纹不符时直接报错。
- 更新：换用的标准素材变更后，重渲这些图并重写 `refs.json`；单图不超过 512 px，整包不超过 1.5 MB。
