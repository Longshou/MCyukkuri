# 接触工具游戏适配

本包选用[器具制作源](../../../standards/yukkuri-library/drafts/operation-tools/README.md)。[manifest.json](manifest.json)记录对应文件指纹。

- 合并：剪东西用原版剪刀，不另设理发器、裁剪刀、去势剪和剪茎剪刀；加热锥子是锥子烧热后的状态（`care_awl_hot` 只是模型与图标，不是物品）。剩下八种工具：大头针、锤、锥子、仰卧固定台、包裹吊带、悬吊鱼钩、振动器、铁箱。
- 图标：八种工具、烧热的锥子和剪下的头发都是 16×16 原版风格图标，快照在 `icons/`。画法与[照料补给物品图标](../supply-icons/README.md)一致：光从左上来，每种材质用一条色相偏移的色阶，轮廓取该材质最暗的一阶，不描黑边，不做抗锯齿。长柄工具沿原版工具的对角线摆放，握把在左下、工作端在右上。图标用于物品栏、地面和展示框。
  - 大头针：粉色小圆头的短钢针，四根一份。
  - 锤：八景的深蓝黑色鼓形锤头，两端钢面，木柄。
  - 锥子：圆木长柄、铁箍和细钢锥；烧热时锥尖从铁箍处的暗红渐亮到尖端的黄色。
  - 固定台：浅色橡木板上拱着两条红褐皮带，皮带上有黄铜扣。
  - 吊带：偏冷的白布兜由两根细绳挂在铁环下。
  - 鱼钩：短绳下挂着带环钢钩，钩弯带倒刺，不像锚。
  - 振动器：粉色卵形体，细线连着小开关盒。
  - 铁箱：方形铁箱，正面是黑色内腔前的亮铁栏，没有盖沿和搭扣，不像箱子。
  - 剪下的头发：四根相连、带折弯的柔软发丝；不打结，不捆扎。
  - 酒精灯 `alcohol_lamp` 是草稿图标，不导出。
- 手持立体模型：同一组工具在双手（第一与第三人称）显示原版方块模型式的长方体模型（`held/<物品>.json`，`neoforge:separate_transforms`：手里用立体底模，物品栏、地面、展示框用图标），像原版三叉戟与望远镜。贴图 `held/<物品>_model.png` 为 32×32，四块 16×16 材质色块取自图标的同一色阶，一像素对一贴素，与图标同密度。长柄工具用原版手持工具的握法与对角线，鱼钩、吊带、振动器按普通物品竖握，固定台、铁箱按方块拿。锥子烧热时由物品属性 `mcyukkuri:hot` 切到 `care_awl_hot`。
- 身上的模型：大头针、鱼钩、振动器束缚时显示与手里相同的模型（`held/<物品>.contact.json`，运行在 `yukkuri_props/<物品>.json`），原点是皮肤接触点、+Y 朝外：针尖扎进 1.5 像素、针头朝外；钩尖与吊绳环位置与 `OperationAttachments` 相同；振动器横贴皮肤。固定台、吊带、铁箱按每种体型与有无饰物贴合（`selected/<名称>/`），几何来自角色运行网格，表面按平面投影采样同一工具的材质贴图。培养瓶仍用调色板网格。目录表为 `operations-index.json`。
- 身体适配：挂接模型引用选定的角色源网格，不改变角色形状，没有独立动画，跟随身体姿态与体型。固定台导出支撑高度，吊带导出吊环坐标，针、振动器和钩使用当前蒙皮挂点。身体姿态、滚动角、发束缺失和支撑位置由服务端同步。

八种工具都有生存合成路线；剪下的头发只从真实剪发产生。固定用器具在解除、中断或重载时归还；创造模式不产出免费归还物。

剪下的茎与实子复用家庭茎形及原孩子的模型，由服务器胎次记录驱动；出生后不再显示相应实子。不把剪茎容器登记为已确认的普通断茎素材。培养瓶的根部与瓶口连接坐标随网格导出，瓶内直根接到原弯茎；服务端和客户端共用 `DetachedStemGeometry`。非瓶装离身茎的地面根高已按成熟实子的完整包围范围修正，并补出接地直茎。

剪饰物按原生 `yu_base.cs` 的 `お飾り切り動作` 产生破损饰物，显示的两片几何仍属于同一真实物品。

蕾米莉亚与弗兰使用各自的器具适配；制作源通过 `predator_body_surface` 识别捕食种身体，遇到未知身体时报错。
