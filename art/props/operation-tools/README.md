# 接触工具游戏适配

本包选用[器具制作源](../../../standards/yukkuri-library/drafts/operation-tools/README.md)。[manifest.json](manifest.json)记录对应文件指纹。

- 物品外观：十四种工具和剪下的头发都是 16×16 原版风格物品图标（`item/generated`）。画法与[照料补给物品图标](../supply-icons/README.md)一致：光从左上来，每种材质用一条色相偏移的色阶，轮廓取该材质最暗的一阶，不描黑边，不做抗锯齿。长柄工具沿原版工具的对角线摆放，握把在左下、工作端在右上。快照在 `icons/`，`build.py` 把图标写到 `textures/item/<物品>.png` 和 `models/item/<物品>.json`；物品栏、手持挤出、掉落物、展示框、货架和 NPC 手持都用同一张图。
  - 大头针：粉色小圆头的短钢针，比锥子短而细，四根一份。
  - 锤：八景的深蓝黑色鼓形锤头，两端各有两像素深的钢面，木柄。
  - 锥子：圆木长柄、铁箍和细钢锥。
  - 加热锥子：锥尖从铁箍处的暗红渐亮到尖端的黄色，带两点火星。
  - 固定具：略带俯视的浅色橡木板上拱着两条红褐皮带，每条皮带都有两像素的黄铜扣，与身上的固定台对应。
  - 吊带：偏冷的白布兜由两根细绳挂在铁环下，和小麦粉糊的暖白区分开。
  - 钩：短绳下挂着带环钢钩，钩柄在右，钩弯只向左上弯到带倒刺的钩尖，钩柄右侧不伸出任何部分，以免看成锚。
  - 理发器：沿对角线的一整根推剪机身。左下是皮握柄，经黄铜箍接到只比握柄略宽的短钢头，端面伸出两根梳齿；没有横过轴线的部分，和锤子区分开。
  - 裁剪刀：合拢的裁缝剪，两片长刃之间有暗缝，配一大一小两个空心红环。
  - 去势剪：全钢小圆环外科剪。
  - 剪茎剪刀：木柄修枝剪。
  - 瓶装剪茎剪刀：粉柄修枝剪，旁边有一只装糖水、插着茎的小瓶。
  - 振动器：粉色卵形体沿对角线横放，中间有一道接缝，细线连着小开关盒。
  - 铁箱：斜视角的方形铁箱，正面大半是黑色内腔前的四根亮铁栏，和身上网格的观察栏一致。有实心边框和铆钉，没有盖沿和搭扣，避免看成箱子。
  - 剪下的头发：四根相连、带折弯的柔软发丝，切口在左下错落并拢，向右上分开，发梢颜色较浅；不打结，不捆扎。
  - 酒精灯 `alcohol_lamp` 是草稿图标，不导出；物品注册后再导出。
- 世界中的模型：`selected/` 只保存装在身体上或身旁显示的网格，包括大头针、钩、振动器、培养瓶，以及按身体适配的固定台、吊带和铁箱。运行网格写入 `yukkuri_props/<名称>.json`，材质写入 `textures/props/`，目录表为 `operations-index.json`。只当物品显示的锤、锥、剪、推子等网格不再导出，只作为制作源留在 `drafts/operation-tools/assembled/`。
- 身体适配：每种角色都有各自的固定具、吊带与铁箱，并区分有饰物与失饰状态。这些挂接模型引用选定的角色源网格，不改变角色形状。它们没有独立动画，跟随身体姿态与体型。固定具导出支撑高度，吊带导出吊环坐标，针和钩使用当前蒙皮挂点。身体姿态、滚动角、发束缺失和支撑位置由服务端同步。

八种冷态工具有生存合成路线；加热锥子由普通锥子对燃烧营火或火源使用取得，30 秒后变回普通锥子。剪下的头发只从真实剪发产生。固定用器具在解除、中断或重载时归还；创造模式不产出免费归还物。

新增五种专用器具有各自配方。铁箱另有九种身体适配版，正面观察栏和箱体厚度为 MC 设计；培养瓶采用半透明材质。剪下的茎与实子复用家庭茎形及原孩子的模型，由服务器胎次记录驱动；出生后不再显示相应实子。不把剪茎容器登记为已确认的普通断茎素材。

培养瓶的根部与瓶口连接坐标随网格导出，瓶内直根接到原弯茎；服务端和客户端共用 `DetachedStemGeometry`。

非瓶装离身茎的地面根高已按成熟实子的完整包围范围修正，并补出接地直茎。

裁剪刀按原生 `yu_base.cs` 的 `お飾り切り動作` 产生破损饰物，显示的两片几何仍属于同一真实物品。

蕾米莉亚与弗兰使用各自的器具适配；制作源通过 `predator_body_surface` 识别捕食种身体，遇到未知身体时报错。
