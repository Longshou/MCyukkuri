# 家庭生长与茎生接入

制作源是 [recipe.json](recipe.json)，由 [export_family_assets.py](../../../scripts/export_family_assets.py)读取旧版生命周期、成长和茎组件，导出 `assets/mcyukkuri/yukkuri_presentation/family.json`。来源和输出指纹见 [provenance.json](provenance.json)。

普通灵梦与魔理沙继续使用 `art/source/standard-runtime/` 选定的角色快照、骨架和表情图。茎由 `FamilyGeometry` 共用于服务器出生位置与客户端绘制；挂茎子代读取同一运行模型的 `idle` 姿势和 `sleep` 贴图，脱落后交给真实实体。角色制作源与已确认记录未改动。

数量为 1–5，茎长、粗细随数量与个体差异变化。茎长由 [fit_stem.py](fit_stem.py) 按子油数量拟合，取能挂下这些实子的最短弧：每只长足的实子都挂在母体前方，直着落下碰不到母体的脸、帽子或耳朵；相邻实子前后错开，先落的不会砸到还挂着的；也不会碰到地面。所有能长茎的母体与子代种类都检查，并按最短的个体差异计算。一至五只依次为参考弧的 0.70、0.86、1.33、1.80、2.28 倍（原为 0.95、0.95、1.70、2.50、3.40）。子代按[体型规范](../../../docs/BEHAVIOR_BALANCE_DESIGN.md#体型规范)在茎上从 0.10 长到 0.20，落地 0.20，因此小母体的茎弧有独立长度下限；高帽魔理沙的连接点轻微埋入帽顶。自然生产完成后空茎从根部脱落，不再永久显示枯茎。剪下后由持有原胎次的离身茎方块接管，培养瓶与非瓶装根部的接入见[器具素材](../operation-tools/README.md)；其接地净空修正不改变母体上的茎形。

当前属于游戏适配造型，技术视觉检查通过不等于用户确认标准。茎长对照见世界观动作预览的“茎长”场景（`standards/yukkuri-library/motions/variants/lore/births.py` 在本机生成到 `.local/previews/lore/`，不入库），检查范围和实机结果见 [核心玩法记录](../../../docs/CORE_GAMEPLAY.md)。

## 自然脱茎物品（2026-10-16）

已亲读[《ゆっくりについて4 ゆっくり解体新書》](https://w.atwiki.jp/yukkuri_gyakutai/pages/3102.html)开头免责声明及4.3(1)植物型段：作者明确说明是个人设定，数值随意；本次仅取自然产后根部脱落、幼体可食用茎的母题。不采用其胎数、孕期天数、免疫推测或多根茎；项目的单根向前弯主茎、细短连接与1–5胎保持原样。

最后一次真实子油生成成功后，胎次先登记进 `ShedStemDrops` 世界等待记录，此时母体保留空茎；实体插入完成不等于出生落定。`FamilyData.Child.landed` 只在活的子油结束落体／落帽飞行，实际接地、接触水面或坐进帽中后记录并保存。所有已生成实子都落定，或已有死亡、明确移除、收容等终止记录后，母体才移除茎，世界记录才允许投放一件 `yukkuri_stem`。落水死亡／途中消失是终止结果，不记作活体成功落地；最后一只未生成或生成被取消不能满足完成条件。

普通卸载保持等待，不依据查不到实体或母体关闭AI推定子油落定。子油若在下落途中被设为NoAI，仍仅在实际接触地面／水体／帽且没有进行帽内飞行时确认落定；该纯接触检查不推进AI成长、帽内飞行或自动照料。等待记录在最后一次真实生成时已由世界持有，因此母体在幼体落地前死亡、卸载或装箱不会丢失后续处理；幼体重载后继续由真实落定事件或终止状态完成等待，不强加载远处区块。可投放时若母体仍已加载，更新为其当下根部位置；否则保留最后生成时记录的根部位置。服务器每20 tick只在投放位置区块已加载时投递，物品生成被事件取消则保留待投递记录。胎生、家油卵、取消胎次和剪下后培养的茎不会额外送茎。旧存档的永久枯茎直接清除，不追补旧物品；旧版已脱离母体的投递记录继续投递。

投递使用按胎次确定的物品UUID，已有同一实体时只完成登记；已成功投递的记录重载后不补发，即使物品已经被捡走或吃掉。这里保证正常保存／读档和失败重试中的身份守恒，不提供跨区块实体文件与世界存档在磁盘崩溃时的原子事务。

物品加入既有普通食物标签，可直接喂食、放入食盆或被饥饿个体拾食；沿用普通无专属营养组件食物的20营养值及普通进食恢复（当前恢复2点生命），无额外免疫或专属治疗效果。原创材料用途为“茎＋干草块＋白羊毛”制作一个油库里窝，替代旧配方中的线，旧配方保留。产后物品采用同一参考主茎弧的空茎代表造型，可堆叠，不含未出生子油或可培养胎次。

制作源为 [shed-stem.json](shed-stem.json)，读取现有标准茎中心线，由 `python art/props/family-life/export_shed_stem.py` 导出专用8边管网格、根部截面色、物品模型与素材索引，来源登记见 `shed-stem-provenance.json`。追加 `--check` 核对导出，追加 `--preview --node <Node路径>` 用现有软件光栅器输出 `.local/previews/shed-stem/yukkuri-stem.png`。造型状态仍为待用户确认。

真实受孕生成五只实子后，普通落地、落帽飞行、落水死亡、明确移除和普通卸载／重载各自走不同路径；母体在最后一只落定前死亡后仍保留世界任务。自然出生到脱茎的连续表现、食用、配方及多人／专服仍待游戏内确认。
