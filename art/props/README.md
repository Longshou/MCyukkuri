# 道具与设施素材

本目录按游戏选用快照组织。各子目录保存当前模型、配方和导出入口；对应制作源在 `standards/yukkuri-library/`，具体认可状态与指纹以包内 `manifest.json`、`provenance.json` 或 `selection.json` 为准。

| 主题 | 制作与选用入口 |
| --- | --- |
| 食物、容器与照料用品 | [运行道具](runtime-peripheral/README.md)、[消耗品](consumables/README.md)、[食盆](food-bowl/README.md)、[生活设施](care-facilities/README.md)、[照料扩展](care-expansion/README.md)、[宠物用品图标](pet-goods/README.md)、[照料补给图标](supply-icons/README.md) |
| 家庭、生长与住所 | [家庭与茎生](family-life/README.md)、[家油照料](house-care/README.md)、[野外住所](wild-shelters/README.md)、[冷冻收容](cold-storage/README.md) |
| 身体、头饰与交互 | [伤口表面](body-wounds/README.md)、[头饰损坏](hat-damage/README.md)、[接触工具](operation-tools/README.md)、[徽章挂接](badges/README.md) |
| 场景与展示 | [大型游具](playgrounds/README.md)、[商店界面](ui/README.md)、[捕食种枝巢与软帽](predators/README.md) |

共用色板在 [`palette.json`](palette.json)。模型与运行资源由各包的制作源导出；快照不会随标准库源自动更新。目录内的操作契约、碰撞和挂接数据以对应 README 与配方为准。
