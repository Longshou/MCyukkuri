# 人类商店与加工所

`build.py` 是原创方块布局和模板内实体的制作源；`language.json` 保存本模块当前中英文界面文案。`manifest.json` 记录尺寸与数量，`exports.json` 记录本模块源与运行导出的 SHA-256。统一入口为 `<py> scripts/export.py --family human-world`，检查加 `--check`。

宠物店随普通村庄生成。劳力工场、馒头工厂和活体袋装厂的建筑模板仍随制作源导出，玩法状态见[人类世界](../../../docs/FEATURES.md#人类世界)。

`author_products.py` 是四类专用机台、馒头、活体包装袋与金银章的制作源；`products/` 保存原创像素贴图及登记。机台使用原生方块元素，分别构成滚轴台、蒸箱、封装支架与育成护理台，物品陈列使用固定 `item_display`。运行几何、贴图、物品模型、战利品表与结构模板由统一导出同步，外部漫画不进入游戏资源。

运行 NBT 位于 `src/main/resources/data/mcyukkuri/structure/`，同目录树的 `worldgen/` 保存结构、池和放置规则，群系标签及人类生成规则也由脚本同步。模板使用 NeoForge 实体持久数据，按岗位绑定现场库存；不包含外部漫画图片或八景 U 提取物。

房间功能参考 [作品核读](../../../wiki/shops-factory-npcs.md)，建筑外形、台阶、柜台和机台为项目原创设计；玩法见[玩法说明](../../../docs/FEATURES.md#人类世界)。

`author_pipeline.py` 制作接收检查台、分选台、清洁台、观察台和周转托盘；`pipeline_language.py` 保存对应中英文本。五种设备使用原生方块几何，托盘实体复用 `factory_transfer_tray` 方块模型，由 `FactoryTrayRenderer` 渲染，载物面高度为 4/16 格。布局将两组亲代、两栏育成、异常观察与四道出货工序分开，保留工人和托盘通道。

## 村庄街面

`village_shop()` 在同一个店铺布局前延伸 8 格街面，实体及岗位随布局一起平移：y0 铺路，y1 行走，z3..5 是砾石车道，两侧人行道。村庄中心在原版打乱的道路接口中选择一个，先尝试 `mcyukkuri:village/<村庄类型>/frontage`，由原版 jigsaw 检查相接方向和占地。地块一旦选定，保留整个地基的水平范围，避免其他道路贴地铺设时横穿地块。地块放不下时池回退到同类型的原版道路；其他出口继续使用原版道路。每座村庄至多尝试一个店铺地块。已生成区块保留原布局。

街面两端接街道地块，制作源为 `author_street.py`，检查在 `check_structure.py`：

- 地块沿车道接续。东端接口名 `mcyukkuri:street_west`，西端名 `mcyukkuri:street_east`，各自以对方名称为目标、以 `village/street_sites` 为池；拼图只能不转向地接上，建筑总在车道远离村路的一侧，空着的一端继续向外抽选，长度由原版距离与碰撞检查决定。接口在车道中线（z4、y1），下方一格铺路，`final_state` 为空气。
- 宠物店西端抽 `village/street_sites`（集市摊位、后巷、空），东端抽 `village/street_east`（鬼威惨商店优先，其次集市摊位、空），所以每座村庄至多一家鬼威惨商店。
- 集市摊位 `village/street_stall`：条纹遮阳篷、农产品柜台、摊后板架下的挡风缝、木箱位和集市垃圾桶。后巷 `village/street_alley`：两间原版风格小屋夹出的死胡同，两只垃圾桶（一开一合）、披檐下的挡风缝、尽头的纸箱位和墙头灯。宠物店前的两只垃圾桶也是垃圾点，人行道有路灯。
- 流浪物件按流浪系统的读取方式放置（玩法见[功能说明](../../../docs/FEATURES.md)的临时避风与翻垃圾）。垃圾点是带 `NeoForgeData.YukkuriGarbage` 的木桶，正面朝向取物格，取物格上方的橡木活板门是盖子，桶里是有限的真实物品。挡风缝是上方有碰撞、侧面有整方块的干燥地面格，地上放一张不消失的纸。纸箱／木箱位是 `mcy_street_shelter` 标记，`data.Kind` 为 `mcyukkuri:cardboard_shelter` 或 `mcyukkuri:crate_shelter`，标记朝向即开口方向，中心格与 3×3×2 占地随模板旋转；箱体由代码按现有放置规则生成，因为结构旋转不会改写多方块箱体的部件编号。
- 增加地块：写一个函数（`street_band` 铺街、`street_ends` 放两端接口），加入 `pieces()`，并在 `export()` 的池里加一项。

试玩时用种子 `42` 新建默认世界。在原点附近运行 `/locate structure minecraft:village_plains` 可定位到 `(656, -304)`；也可用 `/tp @s 651 80 -302` 直接到临街步道，再沿步道上正门台阶。

离线预览：`<py> preview_street.py --minecraft-resources <原版客户端 jar>` 输出街道与鬼威惨商店的平面图和透视图到 `.local/previews/street-oni-layout/`。

## 鬼威惨商店

`author_street.oni_shop()` 生成 25×14×26 的博物馆模板 `mcyukkuri:yukkuri_oni_shop`，`village_oni_shop()` 在其前加 8 格街面成为村庄地块 `village/oni_shop`。低矮破旧的单层店：卵石墙基、云杉墙、补丁屋顶、褪色招牌（灵梦与魔理沙头像）、破遮阳篷。地板 y2，行走 y3，天花板 y7，外墙 x1..23、z3..24。

- 临街橱窗笼（内部 x2..6、z4..6）：落地街窗，铁栏朝大厅，员工门在南侧。
- 西墙工具墙（x2、z9..15，两排固定展示框）陈列 14 件工具；两排木桶货架（x4..5、x8..9，z10..13）东侧陈列消耗品和粮食日用品；入口木箱堆、大厅中间的低展示台和东侧街窗下的顾客桌。
- 三间库存笼（内部 x16..19；z8..10、z12..14、z16..18）：顾客一侧整面铁栏，员工门在背面 x20，开向两格宽的员工通道（x21..22），通道直通后屋。
- 柜台在 z16（x5..14，收银台 x9），顾客站 z15，柜台后 z17..18 是员工区，西端留 3 格口。后屋 z20..23 有进出货桶、废物桶、饲料、处理台（酿造台、水炼药锅、砂轮和工具），从柜台透过铁栏窗能看到处理台。
- 员工门都是两格宽的双开铁门，通道不少于两格；`check_structure.py` 另查一格宽的通道格。

代码使用的标记（随模板旋转）：

| 标记 | 用途 |
| --- | --- |
| `mcy_oni_corner` ×2 | 店铺范围：保护、库存名册、员工归属 |
| `mcy_oni_counter` | 柜台交接格（店主站位） |
| `mcy_oni_dock` | 进出货桶 |
| `mcy_oni_trash` | 废物桶 |
| `mcy_shop_frame` | 展示框，与宠物店共用：所在店铺登记时变成固定展示框 |

店主 `oniisan`（岗位 1、CRUEL、`SiteRole=oni_shopkeeper`）在柜台后，店员 `caretaker_brother`（岗位 1、CRUEL、`oni_staff`）在后屋。在售个体 `PendingRole=oni_shopkeeper`、`Use=stock`，性格偏骄横或迟钝，营养和清洁偏低，子油写真实年龄。角点等标记不用宠物店前缀：两店相邻时宠物店会读取 32 格内全部 `mcy_shop_*` 角点，同名会让它登记失败。代码接入前，这两位店员不属于任何店铺，不营业也不施虐，库存由店主名下保护。

## 宠物店

`build.py` 的 `shop()` 生成 41×16×33 的单层坡屋顶宠物店，动作博物馆通过 `yukkuri human build shop` 使用 `mcyukkuri:yukkuri_shop` 模板。主材为白石英墙、桦木框架与地板、泥砖屋顶；点缀为红白遮阳篷与深色橡木／绿色招牌。正面有灵梦头像招牌（美术评审方案 G）、遮阳篷、旗帜和整面橱窗；屋顶四行、立面六行。后院露天，后排屋顶只盖后屋与考场。

- 销售半边（x2–22，玩法见[玩法说明](../../../docs/FEATURES.md#宠物店徽章与宠物培育)）：临街两间落地展舱，左为非捕食种展舱（内部 x2–8、z4–7，粉羊毛地面，三个窝沿街窗排开，食盆与厕所靠过道一侧），右为捕食种房（内部 x16–22、z4–7，紫羊毛地面，两个捕食种窝，玻璃到顶、上有天花板，与其他栏不通气）。街窗在两间展舱处从地面起就是玻璃，路人平视即可看见。所有栏墙都是整块玻璃从地面到天花板（y3–7），每栏一扇两格宽、两格高的双开铁门（门轴在外侧，两扇向两边开），两侧原木立柱、上方原木门楣，门板不贴玻璃板。入口 x10–14 前厅，过道 z9–11 横贯大厅，柜台在 z12（x7–17，收银台在中间），店员在 z13–16。用品用固定展示框陈列：柜台后墙两排、西墙玩具、东墙头饰与布偶（标记实体 `mcy_shop_frame`，店铺登记时变为固定的原版展示框，村庄旋转后按身后的墙定向）。店内不放告示牌。
- 后屋（x17–22、z18–29，店员区）：进出货桶（`mcy_shop_dock`）、便便桶（`mcy_shop_trash`）、饲料桶、工作台与堆肥桶；双开铁门通大厅（17–18,17）与后院（16,21–22）。
- 后院（x2–15、z18–29）：围墙内露天草地，z18–20 是橡木台阶板檐廊（三盏吊灯），檐下四个窝与两个食盆，两个厕所在远角，地上有花、开花杜鹃丛与玩具；隐藏光源让夜里也不生怪。西墙前厅一侧的窗（z17，x3–5）可看见檐廊。
- 员工：三位店员都是 Job 1；柜台店员 `SiteRole` 为 `shopkeeper`，持有库存（模板动物的 `PendingRole` 都指向他），另外两位为 `shop_staff`（前厅西角与后屋）。考官 Job 3（`shop_examiner`）。店铺足迹由两枚 `mcy_shop_corner` 标记给出（x1–23、z3–30，不含考场），柜台交接格为 `mcy_shop_counter`。
- 初始库存：展舱里金章爱丽丝（六项技能）、子油灵梦与子油橙；捕食种房里银章蕾米莉亚（六项技能）与子油芙兰；后院放养子油魔理沙、帕秋莉、灵梦。子油以真实年龄写入 `YukkuriFamily.Age`；资格与已学技能写入根 `YukkuriPet.Grade`／`KnownSkills`，五属性写入 `YukkuriLife.Personality.Innate`。首次绑定店员时，已有资格的库存补齐发证编号、发证者与有效期。
- 考场（x24–38）：口试区（答题台对考官桌、躲藏箱、两个约定席）、7×5 玻璃模拟房间（`exam_mark` room、窗外观察位 examiner）、陪考生栏（三个 trainee 标记，门通模拟房间）、金章间（3×3 两格由玻璃隔开：gold／actor）。

`author_exam_props.py` 绘制并导出三个考场功能方块（答题台、躲藏箱、考位标记，`kind` 含 room／promise／actor／gold／trainee／examiner）的贴图与模型，躲藏箱内部宽 14/16、高 15/16，容得下全部普通与捕食成体，不含胖大的 deibu。`check_structure.py` 在 `export_human_world.py` 导出与 `--check` 中运行：检查方块覆盖、实体占位与地板、栏内食盆窝位、地面光照 ≥8（按灯笼泛光计算）、门高、员工可达性、立面单一材质不超过 6×6、屋顶占比。

考官为 caretaker_brother。顶灯嵌入 y8 天花板，使用赭黄蛙明灯，约每 6 格地面一盏以保证地面光照 ≥8；柜台与过道上方保留少量吊灯。`check_structure.py` 另查：有员工门的栏（展舱、捕食种房、后院）四壁从地面到天花板不留空、员工门是框在墙线里的双开铁门且门内外各有可走格，捕食种房顶部封闭。
