MCyukkuri generated these Japanese speech files using pyopenjtalk-plus
0.4.1.post9 and mei_normal.htsvoice. Changes include authored dialogue,
pitch and speaking-rate adjustments, trimming, fades, peak normalization,
and conversion to mono PCM WAV / Ogg Vorbis. Reimu and Marisa are two
parameter profiles of the same model. No endorsement is implied.
Retain this attribution with redistribution of the voice assets.

SFX are procedurally authored for MCyukkuri without external recordings.
See art/audio/recipe.json, scripts/build_audio.py and art/audio/manifest.json
in the source project for production parameters and file fingerprints.
