# 油库里日记音频参考与发声制作

核读日期：2026-09-12。上一版 OpenJTalk / Mei 方案已被用户否决，停止采用。其 WAV 留作错误对照，52 个 OGG 从游戏资源撤回 `archive/mei-first-pass/`，不将数值检查通过等同于声音正确。

## 已证实的制作方式

经典ゆっくり声的基础应从 **AquesTalk1** 查起。AQUEST 官方明确将其合成声称为「ゆっくりボイス」，并说明它接收假名音声记号列、输出 8 kHz / 16-bit PCM。不同代的 AquesTalk 算法和声质不同，不能因为名称接近就直接换成 AquesTalk10；此前使用 Mei 的声源选择也不成立。[AquesTalk1 官方说明](https://www.a-quest.com/products/aquestalk_1.html)、[引擎比较](https://www.a-quest.com/products/aquestalk.html)。

常见角色映射是 F1 对应灵梦、F2 对应魔理沙。合成应用开发者的版本说明直接列出了这组名称；但这只证明社区常用命名，**不能据此认定 2023 年《日记》原声的具体引擎版本、声种和调节参数**。同一应用的开发者还记录了版本更新及重采样引起音质差异的问题，因此后续须保存版本、声种和重采样方式。[开发者版本说明](https://apps.apple.com/jp/app/%E8%AA%AD%E3%81%BF%E4%B8%8A%E3%81%92-%E3%82%86%E3%81%A3%E3%81%8F%E3%82%8A%E6%A3%92%E8%AA%AD%E3%81%BF%E3%83%88%E3%83%BC%E3%82%AF/id542600107?platform=ipad)。

发音需要单独编写或校正音声记号列。官方规则要求按实际发音写假名：助词「は」写作「わ」，长音使用「ー」；`'` 控制重音下降位置，`/` 划分重音短语但不插入停顿，`、` 等符号引入停顿。促音「っ」和拗音必须保留，不能把「むーしゃ」拆成普通汉字音译再让中文 TTS 读出。[音声记号列规范](https://www.a-quest.com/archive/manual/siyo_onseikigou.pdf)。

官方 AquesTalkPlayer 支持声种、棒读、话速、音程和 WAV 导出，也支持无窗口命令行批量处理。需要注意「音程」通过改变采样率产生类似磁带变速的效果，**同时影响音高和速度**；「高度、重音幅度、声质」三项则仅适用于 AquesTalk10。后续参数记录应区分合成话速与播放变速，不能混成一个 pitch 值。[官方操作手册](https://www.a-quest.com/products/aquestalkplayer_man.html)。

## 本地《日记》实际素材

只读核查本机 `E:/yukkuri/YukkuriDiary-zhCN/original/`，它来自现有的 2023.v2 原包提取目录。该汉化项目说明保留了原配音；本轮未修改它。UnityPy 1.25.3 读取到 **423 个 AudioClip** 和 **776 个 AudioSource**。

423 个片段中，348 个为 44.1 kHz 单声道、63 个为 44.1 kHz 双声道、12 个为 48 kHz 双声道。这里是游戏资源的存储采样率，**不能反推出最初合成时的采样率**。其中包括角色语音、动作声和其他音频，不把 423 全部计作角色对白。

素材结构支持把「短叫声、动作发声、简短对白、物理音效」分别制作。此前将动作主要处理成弹跳音、噪声，把角色主要处理成完整礼貌句，遗漏了「ゆっ」「ぷっくー」「むーしゃ」这类有辨识度的声音单位。文件名不能证明触发时机，具体行为仍要另查。

静态 AudioSource 中 775 个 pitch 为 1.0、1 个为 -0.5。它们不是运行轨迹；本轮没有还原 IL2CPP 函数体，不能据此声称幼体不变调、所有语音都按原速播放，或已查清每句的触发条件。未找到作者公开的合成参数或足以证明引擎版本的署名。

## 重做时采用的步骤

1. 先用同一句话比较 AquesTalk1 的声种和版本，以《日记》的欢迎语及明确标有角色的素材为目标；不先批量生产整包。
2. 单独制作「ゆっ」「ゆー」「ぷっくー」「むーしゃむーしゃ」等短样，记录假名、长音、促音、重音、停顿；情绪优先通过节奏、重复和尾音表达。
3. 再制作灵梦与魔理沙的简短对白，按已核实的口吻保留「ね」「のぜ」。种族声线、情绪参数和年龄参数分别记录。
4. 动作中区分角色主动发出的声音与水声、落地声等物理音效；两者可以配合，不能互相替代。
5. 将原声参考、新样和错误旧样放到同一试听入口，先验收音色与发音，再导出游戏 OGG，并单独设置行为触发与重复间隔。

这条制作路线已经用于[本项目候选声音](aquestalk/README.md)，仍不是《日记》参数复原结果。《日记》原声没有复制进模组资源。

工具直接下载曾返回 HTTP 403，之后用户通过官网取得并提供本机 AquesTalkPlayer。本轮在项目 `.local/` 工具副本中设置参数，生成 112 条原版选句。官方说明个人非营利使用可免费，其他用途适用其使用许可；不推定已有商业许可。[官方下载与使用说明](https://www.a-quest.com/products/aquestalkplayer.html)。
