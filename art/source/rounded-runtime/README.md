# 圆润体型的 Minecraft 接入

本包将标准库形态转换为游戏选用快照和运行模型。`manifest.json` 逐项记录源模型、骨架、快照、贴图、动作和运行目标及 SHA-256；`selected/` 保存选用源，旁边的运行模型与骨架是游戏适配结果。`baseline/` 是不可覆盖的原始输入，用于比较圆润导出前后的骨架。

`scripts/export_rounded_runtime.py` 保留连续身体与后发混合权重，补齐通用动作，并去掉游戏中不应由动画重复驱动的水平位移。灵胖制作源是普通体型的 1.5 倍，导出先归一化，再由游戏统一施加 1.5 倍比例；碰撞、成长、挂件和出生出口使用同一比例。圆润体型变更后，伤口表面由 `scripts/rounded_wound_surface.cjs` 生成，脱落饰物、徽章挂点和茎根由 `scripts/export_rounded_attachments.py` 派生；对应挂件源须一并更新。

身体基线与专属形态的制作源分开维护；改动源不会自动更新运行快照。重新选用模型时，更新对应的伤口、附件、束具与预览数据，再由清单核对指纹。旧模型导出入口不得覆盖当前登记的形态。
