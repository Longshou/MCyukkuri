# 七种实体的接入快照

[打开动作预览](preview.html) · [来源指纹](provenance.json) · [游戏验收步骤](../../../docs/ENTITY_IMPLEMENTATION.md)

家油面部随步态浮动的横条与斜纹已另行修订，使用连续皮肤光照并保留原硬转角，模型与动作数据不变。当前对照、动图及验证范围见[面部光照修订](face-motion/SURFACE_LIGHTING.md)。

家油行走时的表情遮挡已定向修订：五官按面片实际高度跟随身体分段，摆动峰值补充小幅表面余量；携物辫子抬至额前，避开眼睛，客户端排除五官的不透明背面。静态造型不变，最终模型 6,600 个普通／携物行走表情样本无意外遮挡；固定构建的普通行走、慢走和携物实机定向复核通过。制作源、局部重导与当前实机验证范围见[家油动态五官](face-motion/README.md)。

普通走动已修正家油身体未继承油菊动作的问题，并增强其余五种的左右摆幅；慢走按实际位移触发，家油搬运时保留步态。见[本轮实机动图](previews/current/walking.html)、[制作与接入说明](WALKING.md)及[验证范围](../../../docs/validation/walking/current/README.md)。

| 目录 | 选定来源 | 接入方式 |
| --- | --- | --- |
| `reimu/`、`marisa/` | 标准库 `assembled/<种族>/` | 保留标准造型、原骨架与动作曲线，导出三角面 |
| `chen/`、`alice/`、`patchouli/` | 标准库 `assembled/<种族>/` | 专属头发饰物及共用动作；帕秋莉增加三个长发接触骨骼与逐顶点混合绑定 |
| `house_reimu/`、`house_marisa/` | 家油包 `assembled/` 的 v9.1 导出 | 保留造型；按家油比例适配标准骨架，连续身体和新头发分段绑定 |

每个目录中的 `.bbmodel` 是选定源的原样快照，保留其原始编辑骨架。`animation-rig.json` 是适配后的数字骨架，包含逐顶点双骨骼权重；不能直接交给只识别元素单骨骼绑定的旧查看器。`runtime.model.json` 是与游戏资源逐字节一致的最终三角面、骨架、绑定和动作数据。两套骨架之间的转换配方位于 [`scripts/export_runtime_models.py`](../../../scripts/export_runtime_models.py)，不反向覆盖标准库。

导出脚本读取项目内的标准导出，写入本目录、运行资源和来源登记，并生成 `preview-data.js`。它只制作静态数据，不启动预览、游戏或验证脚本。帕秋莉的接地配方在 `scripts/runtime_animation.py`，按 0.02 秒烘焙六段触地动作，上方挂点不动；预览地面网格的间距为半格。

修改适配时先改配方，再重新导出；修改标准造型时先走素材库的制作流程。

预览以文件方式打开 `preview.html`，无需服务。页面支持七种角色、19 个动作、表情选择、转向和时间轴。预览的 JavaScript 采样与 Java 客户端使用同一数据格式，预览渲染器独立于 Minecraft；相同数据不能证明两个运行环境的显示已经一致。

家油的鼓腮使用身体宽度和深度膨胀，配合生气表情；其他形变动作使用标准节奏和按比例缩放的位移，身体相邻截面混合绑定。四段伸缩保留家油原有的专用行程。常态、受伤、中断和重载隐藏伸缩部件；页面选择收回动作时会展示该动作的完整曲线，游戏命令则从当前伸出进度衔接。

家油的贴面头发（包覆发层、发冠、太阳穴与刘海）统一按身体高度连续绑定，修正左右伸展时部分头发整块移动、部分头发随身体弯曲造成的错位。帽子、蝴蝶结与独立侧发保留原有挂点。该修正只改变运行绑定，静态顶点、贴图、骨架和动作曲线均不变。当前[实机左右伸展动图](previews/current/house-side-stretch.gif)及[检查记录](../../../docs/validation/house-motion/current/README.md)对应本轮导出；此前报告仍只适用于各自登记的文件指纹。

三种新增角色的本轮实机动作图见 [当前预览](previews/current/species-game-actions.jpg)，数据、动作与游戏检查分项记录在 [种族实装记录](../../../docs/SPECIES_IMPLEMENTATION.md)。

原四种快照初建时仅核对静态数据。后续构建、引擎检查、动作录制和部分实机审查见 [当前 P1–P2 记录](../../../docs/P1_P2_IMPLEMENTATION.md)；家油造型仍待确认。生活嘴部叠加和饰物显隐使用 [设施配方](../../props/care-facilities/README.md)，不修改本目录的冻结模型。旧 `art/source/reimu/`、`marisa/` 保留为历史基线。

家油已增加俯身夹取、短辫搬运、放下与按场景触发的蠕动，详见[交互适配与漫画参考](HOUSE_INTERACTIONS.md)。这四段保存在独立的行为动作表，不增加指令动作枚举。

近处蠕动现与服务器位移同步：腰部持续俯下 22°–32°，腹底轻伸和收拢时连续拖行，每 0.6 秒前进 0.12 格。实际前进画面见 [蠕动实机预览](previews/current/house-crawl-game.gif)，原地页面只展示相同周期的形变。

日常生态另选用 5 套已确认表情，接入快照与独立来源指纹见[生态表情](../ecology/README.md)。不重建本目录的身体和行走骨架。
