# 家油拾取、搬运与蠕动

制作源为 [`runtime_house_interactions.py`](../../../scripts/runtime_house_interactions.py)，局部动作由 [`export_house_carry_motion.py`](../../../scripts/export_house_carry_motion.py) 导出到家油快照与游戏 JSON。动作片段保存在 `behavior_clips`，与指令动作分开；旧七模型全量导出器已停用。

| 行为 | 动作与交接 |
| --- | --- |
| 夹取碎食、巢材 | 身体俯低，双短辫合拢；0.65 秒时从真实掉落物取一份，1.3 秒转入搬运 |
| 搬运 | 双短辫在额前上方夹持；显示位置取两个实际变换后辫梢的中点 |
| 放下 | 俯身；0.65 秒时复核入口距离并入库，随后抬身收辫；满仓时放回真实物品 |
| 贴地蠕动 | 接近掉落物或进出缝隙时播放；根部俯仰 4°–8°，腹底伸长、压低各不超过约 4%，收拢时最多蹦起 0.1 模型单位；0.6 秒周期前进 0.12 格 |

短辫只旋转，不增加长度；携带物在动作中断和读档时继续由实体状态持有。显示的碎食复用 `food_scrap`，原版纸等材料仍使用原版掉落物模型。嘴内食物与辫子携带物分别绘制。

游戏位移与 12 tick 动作周期同步；接近阶段按目标距离切换步行、慢蠕动、接触取物和搬运，实际碰撞与重力仍由原版移动处理。死亡、NoAI、受伤、指令动作、接触操作或涉水会取消蠕动；接触取物本身不由客户端动画触发。

动作风格参考キリライターあき《[家ゆ](http://blog.livedoor.jp/yukkuri_anko/archives/29583875.html)》的低位移动，以及《[もみあげぴこぴこだんす](http://blog.livedoor.jp/yukkuri_anko/archives/36240555.html)》的侧发摆动；具体三维拾取和周期为项目适配，不是逐帧复刻。
