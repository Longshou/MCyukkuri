# 家油俯身取物与蠕动

本轮沿用家灵梦、家魔理沙 v9.1 的选定造型，只增加游戏动作适配。制作源为 [`runtime_house_interactions.py`](../../../scripts/runtime_house_interactions.py)，由 [`export_runtime_models.py`](../../../scripts/export_runtime_models.py) 同步生成两份 `animation-rig.json`、`runtime.model.json`、游戏 JSON 和预览数据。标准造型的待确认状态不变。

2026-09-13 搬运修订：两根短辫把物品举至额前上方，避开普通走路时的眼睛；夹取、搬运和放下保持相同交接姿态，长度与地面接触点不变。当前配方见 [carry-motion/recipe.json](carry-motion/recipe.json)，局部重导入口为 [export_house_carry_motion.py](../../../scripts/export_house_carry_motion.py)，保留已发布的普通走动五官挂接曲线。Minecraft 同时剔除两种家油五官薄片的背面与侧面，避免无背面剔除材质下的薄片互相遮眼；伤口替换表面使用相同规则。本轮实机与指纹见[五官及携物验收](../../../docs/validation/house-face-carry/current/README.md)，下方旧动图仅代表各自历史版本。

随后修正了家油身体逐三角面光照形成的浮动横带：仅共点、同原始法线的身体顶点共享变形后法线，轮廓硬边保留。模型、贴图和动作均未改变。当前固定模组与14组实机对照见[脸部明暗修正](../../../docs/validation/house-surface/current/README.md)。

| 行为 | 动作与接触 |
| --- | --- |
| 夹取碎食、巢材 | 下腹弯曲、上部俯下，两侧短辫提前合拢；0.65 秒接触时从真实掉落物拆出一份，1.3 秒衔接搬运 |
| 搬运 | 两侧短辫在额前上方夹持；显示位置取两个实际变换后的辫梢中点 |
| 放下 | 俯身后在 0.65 秒复核入口距离并入库，随后抬身收辫；满仓时放回真实物品 |
| 蠕动 | 贴近掉落物及进入／探出缝隙时，腰部保持 22°–32° 俯身并随腹底伸缩拖行；循环 0.6 秒，成体每周期前进 0.12 格 |

四段行为动作保存在 `behavior_clips`，与原有 19 个指令动作分开。普通走动仍使用原动作；短辫只旋转，不增加长度。脸、饰物与辫根共用上部刚性变换，身体及贴面头发在下腹区域连续混合，保持挂接关系。中断和读档保留真实携带物；其他身体动作中，夹持关节继续保持持物姿态。嘴内食物与携带物分别绘制。

碎食采用已有 `food_scrap` 美术。`HouseScrapRenderer` 将这种专用掉落物显示为低处的小碎屑，关闭普通掉落物的悬浮旋转；夹持尺寸由同一常量计算。原版纸等材料仍保留原版掉落物显示，夹取后按家油比例显示，因此原版材料的悬浮与缩放切换仍属于 Minecraft 的物品表现约定。食盆取食和嘴部咀嚼保留既有流程，本轮未增加短辫喂食动作。

## 漫画参考与原创部分

- キリライターあき《[家ゆ](http://blog.livedoor.jp/yukkuri_anko/archives/29583875.html)》：核读已有来源图第 1–4 页；第 3 页中左侧小魔理沙贴地移动的「ずりずり」线条用于低位滑行与动作节奏参考。压扁、受虐画格不作为常态动作依据。来源图留在原参考目录，未进入游戏资源。
- としあき(おっぱい)《[もみあげぴこぴこだんす](http://blog.livedoor.jp/yukkuri_anko/archives/36240555.html)》：核读第一幅漫画，参考侧发从根部摆动、身体相对稳定的画法。该图描绘舞蹈，不是拾取物品。
- システム《ゆっくり虐待》第 8 话《[まりさ虐待 負け](https://ncode.syosetu.com/n5569bl/8/)》：受伤的魔理沙颤抖着拖动身体，缓慢爬行逃开；后段明确写到身体疼痛、不能跳跃。本轮补充参考取其低位拖行、费力且有停顿的运动印象。它描述的是受伤个体，不能据此推断所有健康油库里的逃跑方式。

俯身角度、短辫可达范围、夹取与放下的关键帧是针对当前模型制作的原创适配。漫画与小说没有提供完整的三维夹取或蠕动周期，不能把本轮动作称为逐帧复刻。

蠕动使用现有高度分段骨骼形成下腹形变，脸、帽子和辫根保持共同的刚性变换，短辫不伸长。用户指出初版遮脸后，已将混合形变的上界降至静态高度 0.85 模型单位，使脸下的支撑表面与五官同步。

用户先指出大幅前移和下压把底部拉成裙边，随后指出收小幅度的版本移动太慢、缺少弯腰。当前采用下腹支点旋转，上半身持续俯下 22°–32°，附加前移仅 0.05 模型单位、下压仅 0.035；腹底伸展保持约 12%。脸部承托表面与五官保持相同变换。弯腰来自旋转，实际前进距离由服务器单独控制。侧面对照见 [弯腰修订图](previews/current/house-crawl-compact-comparison.png)。

动作与真实位移共用 12 tick 周期：0–4 tick 弯腰下压、腹底轻伸，4–5 tick 保持，5–10 tick 收拢，10–12 tick 保持较浅的俯身。腹底伸展量仍为 0.20 模型单位；每周期实际行程改为 1.92 模型单位，即 0.12 格，随实体和成长缩放。60% 行程均匀分配，40% 在腹部收拢时推进，平均 0.20 格／秒，是上一版的 9.6 倍。接触皮肤随身体拖行，已不采用前后缘交替固定的假设。同步的独立蠕动时钟保持姿态连续；原地页面不累积位移，实际前进见下方实机图。

[`HouseCrawlMotion`](../../../src/main/java/io/github/longshou/mcyukkuri/house/HouseCrawlMotion.java) 定义位移时序，资源检查核对它与导出记录中的周期、阶段和行程。取物在距离来源 0.6 格以内使用慢蠕动；生活取食在距离掉落物 1 格以内使用，实际接触后切入吃食。远处接近保持走动，搬运保持夹持姿态。进出巢口的期限按缩放延长，避免慢速动作在到达前超时。碰撞和重力仍经原版移动处理；死亡、NoAI、受伤、指令动作、接触操作和涉水等状态取消蠕动。无伤害的水平推挤会受到贴地速度控制抑制，尚未单独适配外力叠加。受伤逃跑的触发规则仍未加入。
