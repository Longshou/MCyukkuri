# 家油生态选用快照

制作源：[家油棉絮巢](../../../standards/yukkuri-library/ecology/house-nest/README.md)。`manifest.json` 登记输入与运行输出指纹。

新增棉絮团、棉絮巢垫和空残壳为原创造型。残壳派生自完整卵下部；完整卵与裂壳卵保持不变。`house_egg` 新物品直接复用现有完整卵网格与贴图。

由制作包 `build.py` 同时生成本快照、运行静态 prop、专用 catalog、两个物品显示模型和 `house_egg_geometry.json` 共用尺寸规格。完整卵、裂卵与空残壳的世界显示统一放大 2.4 倍；成长规格的 0.32 倍新生体保持不变。不得只改本目录或运行资源。

`house_supplies` 和 `house_dust_nest` 只呈现实际存在的地面散料与自然絮窝，不生成独立家具或物品。近处最多显示四簇，随观察距离减少；材料量为零时不画垫料。绒絮与碎食痕迹来自走动、睡眠、剪羊毛、进食和做饭，住户放下第一份絮后才显示絮窝。
