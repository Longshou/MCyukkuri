# 头饰与头发位置适配（游戏接入）

2026-10-07，第一版，状态为待用户复查。用户要求调整模型与组件的位置（帽子、身体等）使之更自然，并适配现有动作；范围选择为19种形态逐一检查，允许小幅改帽子尺寸。本版实际没有改动任何帽子外形，只改位置。

在[素材检查室](../../../preview/README.md)中选择任一形态即可看到本版效果。

## 本版效果

- 头发顺着圆润头顶收成圆顶：原发顶是一块伸到四角的平板，正面看是方盒，鬓角在发顶两侧立成柱子；现在两侧和后方的顶边按圆角收下，侧发顶端收进圆角之下。刘海只做很小的圆角，不会被拉进脸里。
- 魔理沙帽子戴在头上：普通与歪脸下移1.5，帽檐压在发际，刘海从帽檐下露出；稀毛下移0.5，与普通形态同高。帽子外形、蝴蝶结与帽带不变，所以掉落的帽子物品和徽章挂点照旧。
- 灵梦系蝴蝶结贴头：头发收圆后，蝴蝶结跟着结心处的后发一起前移下移，结心仍贴在后脑，尾带从结心下方顺着后发垂下；两种灵胖的蝴蝶结前倾6°贴头；稀毛灵梦原先半埋在头皮里的尾带现在贴在头皮外完整露出，并随头皮一起动。
- 橙的帽子落到收圆的发顶上，猫耳随发面下移并保持外张；爱丽丝的发箍随发面弯下。
- 动作适配：灵梦、歪脸灵梦在压扁、蓄力时，发顶下的肤色垫块会从头顶顶出（原模型即有）；现在垫块与发顶一起变形，不再露出。魔理沙、壳魔理沙、橙、爱丽丝的同类垫块同样处理。鬓角只竖直下收，铰点不动：鼓腮时灵梦侧发仍外摆10.75°、歪脸灵梦14°，与上一版相同；魔理沙与歪脸魔理沙的侧发现在有空间外摆（11.5°、14°），脸颊不再被侧发压扁。
- 家灵梦、家魔理沙、豆形两种、帕秋莉、蕾米莉亚、弗兰检查后保持原样，理由见[制作源说明](../../../standards/yukkuri-library/presentation/placement-fit/README.md)。

身体、五官、腮红与身体尺寸均未改动。具体步骤、参数与适用形态见制作源说明和 [recipe.json](../../../standards/yukkuri-library/presentation/placement-fit/recipe.json)。

## 运行资源与配套重导

| 产物 | 位置 | 说明 |
| --- | --- | --- |
| 位置适配 | `src/main/resources/assets/mcyukkuri/yukkuri_presentation/placement_fit.json` | 12种形态的替换网格与骨骼枢轴；游戏与检查室在动作修订之前拼接 |
| 来源清单 | [manifest.json](manifest.json) | 配方、生成器、导出器、每个基础模型及运行资源的指纹 |
| 鼓腮修订 | `yukkuri_presentation/motion_corrections.json` | 按拼接后的网格重新导出：侧发外摆角度和脸颊让位以新头发为障碍 |
| 帽子交互 | `yukkuri_presentation/hat_interactions.json` | 帽托位置、障碍盒和幼油外形按新网格重导；抬起距离只取决于帽檐，未变 |
| 果实悬挂点 | `yukkuri_presentation/family.json` | 幼油魔理沙挂在帽尖、幼橙挂在帽顶，悬挂点随帽子下移（−1.5、−0.0839） |

基础模型文件没有改写，伤口与徽章使用的模型指纹因此不受本版影响。游戏端 `YukkuriModel.applyFit` 核对每种形态的基础指纹，不一致时跳过并记录警告。
