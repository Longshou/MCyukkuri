# 演出放映室

放映室按演出、模型、道具和声音列出当前资源。动作片段按片段名归组，打开后可切换拥有该片段的模型。道具页显示当前打包的物品图标或基础外观，声音页直接播放打包音频。

## 生成与查看

在仓库根目录执行：

```sh
python scripts/build_preview_hub.py
python scripts/serve_review.py --port 8766
```

生成目录为 `.local/previews/`。手动打开 `http://127.0.0.1:8766/`，条目地址为 `/.local/previews/player.html?entry=编号`。可拖动三维模型看任意角度，滚轮和滑条调整缩放，也可用正面、侧面和背面按钮。播放速度、暂停、进度拖动和演出字幕共用同一时间轴。带多种模型的演出可用 `model` 参数分享当前形态。

`python scripts/preview.py moment excited_leak --model marisa --paper-cover` 可直接生成魔理沙盖报纸的漏尿演出链接。首次使用时会生成播放器和目录。

动作从包内模型和兼容的姿态修订取用，播放时通过本机 `/pose` 逐帧采样。受惊漏尿有惊叹号、水流、汗滴和留在地上的水洼。拖到进度条后段可以看水流和水洼消退。湿透后缓过来、雨中蜷缩和雷声中畏缩使用演出数据里的头顶符号。受惊吐馅显示馅料落地并留下痕迹。台词字幕与包内语音随进度播放，勾选「静音」可关闭语音。勾选「报纸盖」可查看贴合当前姿态的报纸两面，链接可加 `paper=1`。游戏玩法在动作博物馆试玩。

打开「叼着棍剑走动」可从侧面观察棍剑随嘴移动。打开「戴着破帽摇头」可转到帽子两侧看布面缺口和内衬。打开「并排贴脸蹭」可拖动进度条观察 MD-28 同层的一对从贴脸到左右蹭动，转动镜头可查看贴合处的侧发和蝴蝶结。道具、帽子和破损纹理均来自游戏运行资源。

编排演出时，用 `held` 指定道具和握点，用 `hat` 指定帽子和破损等级，用 `partner` 指定同一时间轴上的第二个演员。并排蹭的间距与头发避让由游戏的姿态核心计算。字段取值见[脚本说明](../scripts/README.md#预览与导出)。

`--render` 同时重建专项软件渲染图，部分专项需要本机原版资源。留存的专项页面和素材可以通过原地址打开。道具取用[当前物品索引](../scripts/README.md#预览与导出)。

## 外观审阅

显示外观的条目可点“通过”或“不通过”，并附最多 500 字的备注。尚无预览图的道具须到试玩场查看。播放器和“待你查看”中指向同一条目的按钮共享该条目的最新结果。单独登记的外观对比页按待查看编号记录。重建时，符合原登记信息的自动表情查看器链接在页面中转向实时播放器，原登记保存在 `inbox/items.json`。审阅记录写入当前服务检出目录的 `.local/reports/verdicts.jsonl`。在同一检出运行 `python scripts/preview.py verdicts` 可读取每个编号的最新结果。

“待你查看”的登记命令见[脚本说明](../scripts/README.md#预览与导出)，验收和结项按[协作约定](../docs/roles/lead.md#待办维护)执行。
