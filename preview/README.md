# 演出放映室

首页从同一份实时播放器目录列出演出、模型、道具和声音。演出区直接列出受惊漏尿、雨中蜷缩等演出。展开「演出片段」可查看其余包内演出行，展开「动作片段」可查看单独的动作。同一片段可以切换支持它的模型。道具页显示当前打包的物品图标或基础外观，声音页直接播放打包音频。

## 生成与查看

在仓库根目录执行：

```sh
python scripts/build_preview_hub.py
python scripts/serve_review.py --port 8766
```

生成目录为 `.local/previews/`。手动打开 `http://127.0.0.1:8766/`，条目地址为 `/.local/previews/player.html?entry=编号`。可拖动三维模型看任意角度，滚轮和滑条调整缩放，也可用正面、侧面和背面按钮。播放速度、暂停、进度拖动和演出字幕共用同一时间轴。带多种模型的演出可用 `model` 参数分享当前形态。

`python scripts/preview.py moment behavior_sunbathe` 生成晒太阳的条目链接。`python scripts/preview.py moment excited_leak --model marisa --paper-cover` 生成魔理沙盖报纸的漏尿演出链接。首次使用时会生成播放器和目录。

动作从包内模型和兼容的姿态修订取用，播放时通过本机 `/pose` 逐帧采样。受惊漏尿有惊叹号、水流、汗滴、身体下沿的湿痕和地上的水洼。可暂停从低处转到侧面看湿痕，并拖动进度条查看湿痕和水洼各自消退。湿透后缓过来、雨中蜷缩和雷声中畏缩使用演出数据里的头顶符号。受惊吐馅显示馅料落地并留下痕迹。台词字幕与包内语音随进度播放，勾选「静音」可关闭语音。勾选「报纸盖」可查看贴合当前姿态的报纸两面，链接可加 `paper=1`。游戏玩法在动作博物馆试玩。

打开「受击后的擦伤」，在受击前后拖动时间轴，从正面看脸颊、从侧面看发梢。擦伤和漏尿湿痕取用游戏的受伤表面、投影和贴图。

打开「叼着棍剑走动」可从侧面观察棍剑随嘴移动。打开「戴着破帽摇头」可转到帽子两侧看布面缺口和内衬。打开「并排贴脸蹭」可拖动进度条观察 MD-28 同层的一对从贴脸到左右蹭动，转动镜头可查看贴合处的侧发和蝴蝶结。道具、帽子和破损纹理均来自游戏运行资源。

打开「林缘育幼：亲代递喂」「普通配对：回应、蹭脸和绕后」或「爱丽丝雷普魔：宣言、追击与压制」，可拖动时间轴查看双演员每个阶段。亲代递喂按游戏站位和前倾规则播放，两张嘴之间可见的间隔是游戏当前效果。并排蹭、绕后与压制取用游戏的接触计算。

演出字段与双人采样见[脚本说明](../scripts/README.md#预览与导出)。

专项页面和素材通过原地址或「待你查看」打开。专项图的重建命令和物品索引见[脚本说明](../scripts/README.md#预览与导出)。

## 外观审阅

显示外观的条目可点“通过”或“不通过”，并附最多 500 字的备注。尚无预览图的道具须到试玩场查看。播放器和“待你查看”中指向同一条目的按钮共享该条目的最新结果。单独登记的外观对比页按待查看编号记录。“待你查看”页的“试玩”区在每次加载页面时列出游戏内待看的场景（来自当前待办），结论按场景与已装运行包提交记录（`playtest.<场景ID>.<提交前 9 位>`），运行包更新后重新待审；各标签页的结论每几秒自动同步。重建时，符合原登记信息的自动表情查看器链接在页面中转向实时播放器，原登记保存在 `inbox/items.json`。审阅记录写入当前服务检出目录的 `.local/reports/verdicts.jsonl`。在同一检出运行 `python scripts/preview.py verdicts` 可读取每个编号的最新结果。

“待你查看”的登记命令见[脚本说明](../scripts/README.md#预览与导出)，验收和结项按[协作约定](../docs/roles/lead.md#待办维护)执行。
