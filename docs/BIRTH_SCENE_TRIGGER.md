# 真实分娩触发入口

`/yukkuri birth_scene deliver <mother> <father> <natural|caught|missed|overstrain>` 是管理权限 2 的展示调试入口。它提前真实胎次的临产时间，不搬运双亲或幼体、不创建备用幼体、不临时制造接生帽。

## 接入前置条件

- 双亲是同维度、八格内的活着成年油库里，分别带 `pm_actor` 或 `living_showcase` 标签。
- 先用 `/yukkuri action ... idle` 结束占用身体的动作命令。双亲可以起初为 `NoAI`；入口成功后会启用正常 AI 与重力。
- 陆地或岸边的母油应在真实可用窝位两格内；水上母油已经乘坐自己实际拥有且浮起的帽船。入口不会用坐标替代认窝、登船或下水。
- 新胎次走 `FamilyData.conceive(..., LIVE, ...)`，保留生育能力、年龄、体况、营养消耗、容量、亲缘和既有配偶约束。仅此次管理命令临时跳过相识／亲密度门槛。
- 可以接续 `showcase pair ... live` 或正常受孕产生的既有胎次，但必须是同一双亲、尚未开始分娩、没有已出生子代的 LIVE 胎次。不会修改孩子 UUID、遗传、种类或父母。
- `caught` 与 `overstrain` 要求当前存在可用于接生的双亲帽子，或母油已在自己的真实帽船中；`missed` 不需要帽子。父油接生仍须自行走近并摘下现有帽子。

## 四种分支

- `natural`：保留正常随机分支。
- `caught`：这胎选择正常投向帽中的路线，仍服从实际位置、空间、碰撞和席位。障碍或帽子被移走仍可导致失败。
- `missed`（2026-10-17 重定义）：父油来不及，这胎不放帽子：不预先提前到预产前、父油在第一只落地前不会进入接生职责，也不会摘帽。新生儿直接落到地面，弹一下（落地声、扬尘），受一处真实的磕伤（扣 2 点生命，满值 10；经 `BodyLife.injured` 记录为凹痕，不致命，之后按既有伤口／感染规则处理）并哭泣（泪滴、呜咽声）；父亲被惊动后赶来蹭脸、轻舔，母亲产后先惊慌再蹭脸、轻舔安抚。
- `overstrain`：原先的 `missed`：帽子已就位但被推过帽沿，落地或入水触发既有死亡后果；适合隔离的失败展台。

`caught` 在父油为接生者时，会把临产提前到预产前约 150 tick，使他有时间察觉、走到母油出口前、摘下帽子翻面放好（`HatBoatEntity.setDown`，帽子真实离开头顶，成为帽实体）并扶住帽沿；之后落帽、问候、放出幼体、戴回帽子沿用既有流程（`tickHat`）。父亲约 15 秒内到不了位、帽子无法放下或被阻挡时，该胎改为无垫落地，同样伴随磕伤与安抚（失败路径）。

接生职责由服务器每 tick 主动领取（`FamilyLife.claimMidwife／tickMidwife`），不再依赖目标选择器能否轮到家庭目标；走位使用带宽限的到位判定（约 5 秒仍不到精确点时放宽到 0.8 格）以避免原先父油停在差一点的位置永远不动手。

展馆的参观者会在聊天栏看到灰色“[接生]”进度行，只有带 `pm_actor` 或 `living_showcase` 标签的演员才会发出，内容为服务器实际到达的状态；命令被拒时原因也发给附近玩家，而不只是命令来源。

命令只调用 `FamilyLife.prepareBirthScene(brood, outcome)` 提前到 `duration - 2`；服务器按正常流程生成唯一真实幼体，并完成接生、产后恢复与辫子拾幼。重复播放应由展区自己的真实家庭追踪／重置流程管理；不要先预放赤油，或以逐帧命令更改坐标。

## H 展馆接入

优先沿用真实家庭展区的 `living_showcase` 和 `living_<zone>` 双亲标签，使用现有 `showcase pair` 准备真实窝与 LIVE 胎次，再调用 `birth_scene deliver`。水上展台先按既有真实下水入口登船。新生儿的身份来自家庭账本，清理需沿双亲亲缘追踪，不能只查旧静态演员标签。

旧 `birth_scene start <mother> <helper> <children> <mode>` 仍可解析，但明确失败并提示新语法；所选幼体不会被当作模板、复制、隐藏或删除。旧 `stop` 不再倒放身体位置或撤销真实家庭。`BirthScene.restore` 的一次性坐标恢复仅兼容旧存档的 `MuseumBirthRestore`，新入口不写入这份演出恢复数据。
