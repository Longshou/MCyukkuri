# 真实分娩触发入口

`/yukkuri birth_scene deliver <mother> <father> <natural|caught|missed>` 是管理权限 2 的展示调试入口。它提前真实胎次的临产时间，不搬运双亲或幼体、不创建备用幼体、不临时制造接生帽。

- 双亲是同维度、八格内的活着成年油库里，带 `pm_actor` 标签（展馆演员）。

- 双亲是同维度、八格内的活着成年油库里，分别带 `pm_actor` 或 `living_showcase` 标签。
- 先用 `/yukkuri action ... idle` 结束占用身体的动作命令。双亲可以起初为 `NoAI`；入口成功后会启用正常 AI 与重力。
- 陆地或岸边的母油应在真实可用窝位两格内；水上母油已经乘坐自己实际拥有且浮起的帽船。入口不会用坐标替代认窝、登船或下水。
- 新胎次走 `FamilyData.conceive(..., LIVE, ...)`，保留生育能力、年龄、体况、营养消耗、容量、亲缘和既有配偶约束。仅此次管理命令临时跳过相识／亲密度门槛。
- 可以接续正常受孕产生的既有胎次，但必须是同一双亲、尚未开始分娩、没有已出生子代的 LIVE 胎次。不会修改孩子 UUID、遗传、种类或父母。
- `caught` 与 `missed` 都要求当前存在可用于接生的双亲帽子，或母油已在自己的真实帽船中。父油接生仍须自行走近并摘下现有帽子。

## 三种分支

- `natural`：保留正常随机分支。
- `caught`：这胎选择正常投向帽中的路线，仍服从实际位置、空间、碰撞和席位。障碍或帽子被移走仍可导致失败。
- `missed`：这胎选择既有过度用力、越过帽沿的漏接路线，落地或入水会触发现有死亡后果；适合隔离的失败展台。

命令只调用 `FamilyLife.prepareBirthScene(brood, outcome)` 提前到 `duration - 2`；服务器按正常流程生成唯一真实幼体，并完成接生、产后恢复与辫子拾幼。重复播放应由展区自己的真实家庭追踪／重置流程管理；不要先预放赤油，或以逐帧命令更改坐标。

## H 展馆接入

展馆的两处真实家庭庭院由 `museum_birth.py` 配置，用 `yukkuri museum live/home/aquatic birth` 准备真实窝位或帽船，再调用 `birth_scene deliver`。新生儿的身份来自家庭账本，清理需沿双亲亲缘追踪。
