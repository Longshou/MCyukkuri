# 油库里动作完整清单

共有 56 个注册动作。资源适配由当前19套基础模型和动作修订联合读取；有片段不代表适合所有年龄或情境。水生魔理沙共用普通魔理沙模型，但按生态身份区分使用。

生活馆按真实情景选展：寻路进食、休息、靠近蹭蹭、自由活动、求偶、妊娠、接生、幼体出生及实际帽船。没有为每段动画单独设置播放按钮。

家油与不足形态不展示普通安胎或胎生；捕食种不展示胎生分娩；初醒与帽托休息只用于幼体；船上动作只用于实际乘船者。
