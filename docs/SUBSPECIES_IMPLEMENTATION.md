# 亚种、先天形态与帽船

形态边界、出生遗传和灵胖判定的规则见[行为数值与成长设计](BEHAVIOR.md)；本页记录亚种、模型与帽船的规则和实现入口。

亚种与先天形态是实体上的两个独立标记：亚种（`SubspeciesLife.Kind`）决定螺壳、多毛、水生等整套外观与习性，先天形态（`Congenital`）决定灵梦／魔理沙的不足油外观；二者共用资格检查、出生抽取与模型选用。

代码：`subspecies/SubspeciesLife`、`subspecies/SubspeciesAssets`、`subspecies/ShellRetraction`、`subspecies/HatBoatEntity`（及 `Hat*`、`Aquatic*` 系列）、`entity/YukkuriVariant`、`entity/YukkuriEntity`

## 形态与模型

`entity/YukkuriVariant` 是基础种（灵梦、魔理沙、橙、爱丽丝、帕秋莉、蕾米莉亚、芙兰朵露、妖梦，以及灵梦／魔理沙的家油形态）。`SubspeciesLife.Kind` 为：`NORMAL`、`SHELL_MARISA`（螺壳魔理沙）、`WASA_REIMU`（多毛灵梦）、`AQUATIC_MARISA`（水生魔理沙）、`KOTATSU_MARISA`（被炉魔理沙）、`LONGTAIL_CHEN`／`ROUNDTAIL_CHEN`（长尾／圆尾橙）、`REDEYE_MYON`（红眼妖梦）；每种只适用于对应基础种。`Congenital` 为 `NORMAL`、`SPARSE_HAIR`（稀疏毛发）、`FACE_ASYMMETRY`（面部不足）、`BEAN_BODY`（豆形细长身体），只适用于灵梦与魔理沙；亚种与先天不足不叠加（`set` 拒绝同时非 `NORMAL`）。

- 本页覆盖螺壳、多毛灵梦、水生魔理沙与灵梦／魔理沙各自的三种先天不足；被炉魔理沙、橙的长／圆尾、红眼妖梦见[妖梦与稀有变体](RARE_FORMS.md)。
- 灵胖（后天）是单独的成年结果，机制与数值见下文“灵胖成年判定”；灵梦与多毛灵梦各有一套灵胖模型。
- 模型：螺壳 `marisa_tsumuri`、多毛灵梦 `reimu_wasa`、六种先天不足（配方 [recipes.json](../standards/yukkuri-library/subspecies/deficient/recipes.json)）共八套；水生魔理沙外观与普通魔理沙相同，沿用 `marisa` 模型。灵胖另有两套（`reimu_deibu`、`reimu_wasa_deibu`），圆润体型的运行选用见[运行包](../art/source/rounded-runtime/README.md)。

## 取得与保存

`SubspeciesLife` 将 `Kind`、`Congenital`、灵胖成年结果和帽船经历分开保存；客户端同步前两项及灵胖标记（`subspeciesFlags`：低4位 `Kind`、高4位 `Congenital`、位8为灵胖）。先天形态决定五项先天属性的合法区间，但不从后天伤口、关系、压力或技能推导遗传。

自然生成和出生按实体 UUID 抽取一次，存读或再次调用出生接口不会重抽。参数（模组参数，非作品统计）：

- 螺壳魔理沙／多毛灵梦：通常 1/160；任一亲本为同亚种时 1/4。
- 水生魔理沙：附近 6 格内有开阔水面的自然生成中 1/4；亲本一方为水生时子代 1/2（先判定螺壳）。
- 先天不足：普通灵梦／魔理沙为 1/200，稀疏毛发、面部不足、豆形三种等概率。

出生链路用 `birthFlags(UUID, variant, parentA, parentB)` 提前选定并保存后代形态，以 `initializeBirth(flags)` 在碰撞判定前初始化；随后由 `YukkuriPersonality.inheritBirth` 生成一次五项先天属性。自然生成与各类出生共用同一形态边界。静态 `assetId(variant, flags)` 供未出生幼体选用相同模型。

### 灵胖成年判定

只有普通灵梦和多毛灵梦、且先天形态为 `NORMAL` 的个体参与。她在亚成期（216,000～335,999 tick）连续保持营养≥75、压力≥70达24,000个已加载 tick，才会在跨入成年（336,000 tick）的唯一回调锁定灵胖结果。任一条件中断立即清零；未在边界满足者以后不补判，也没有易感概率、逆转或遗传。

结果锁定后，若仍在短动作中或当前位置容不下1.5倍体型，`SubspeciesLife` 等待安全接缝，在当前位置或3格内干燥、可达的位置尝试扩体。最多3次、每次至少间隔5秒；用尽后只有本人位置或周围空间改变才再次唤醒检查，最多每秒一次。过程不瞬移、不挤墙，不影响成年资格或重新检查营养和压力。

### 生育资格

六种先天不足形态（`Congenital != NORMAL`，`canReproduce()` 为假）共用形态资格检查，拒绝作为任一亲本自然受孕、辅助繁育、促繁刺激和工厂配种；多毛保留正常生育资格。普通亲本仍可能生下不足形态的子代。灵胖不是独立的 DOS 运行类型，不改变原有的生育资格。

形态导致的不育从亚种数据计算，与手术绝育标记分别保存。不足油母体仍挂接的未完成孕育在下次家庭更新时停止，直接出生接口也阻止绕过检查；已出生的子代、身份与家谱保留，未出生预留沿用取消孕育的账本状态，已剪下的茎和离体卵不追溯撤销。

### 习性差异

- 螺壳移动速度降低 35%，两个日常进水增量变为约四分之一（`waterGain`），仍会进水；饮食、寒冷和治疗沿用基础物种。缩壳见下节。
- 多毛灵梦的等待训练有独立意愿判定，未学会前每 240 tick 可尝试一次，成功意愿概率 5%；不强制修改其认知值。
- 豆形身体的基础碰撞高度为普通形态的 1.55 倍、宽度为 0.82 倍，再叠加现有成长与生理变形。

## 螺壳魔理沙缩壳

服务器端 `subspecies/ShellRetraction` 管理受惊和雨天的缩壳时序；`YukkuriEntity` 只接入移动目标、动作采样和实际受击门控。复用 `marisa_tsumuri` 的 `shell_retract` 制作源与运行片段。

来源：《[赤ちゃんまりさとまりさつむり](https://w.atwiki.jp/yukkuri_gyakutai/pages/2013.html)》（L24）描述螺壳饰物的耐水作用，也写出本体长期浸水仍受损；没有雨天缩壳规则。M09 的两张本地图是同篇作品的形态参考，种族说明见 [tsumuri](../wiki/hakkei-reference/lore/species/marisa/tsumuri.md)。雨天主动缩壳、需求让步阈值及半伤规则均是本项目原创适配，不能推导为原作既定动作或水伤免疫。

触发、持留与恢复：

- 只有螺壳亚种且当前实际持有壳饰物时能缩壳。失壳后，受惊改走原有逃跑路径，雨天不缩壳；显式 `shell_retract` 命令被拒绝，已开始的壳命令终止。
- 雨触发同时检查实体当前位置 `isRainingAt` 与生物群系的 `RAIN` 降水类型；屋顶、无雨生物群系和降雪不触发，不以全局天气代替本地暴露。
- 沿现有动作的 0–1.8 秒收拢，在 1.8 秒停留；持续雨不会反复播放整段动作。离开雨、进入遮蔽或需要恢复活动时，映射到当前姿态相应的伸出位置，再沿 3.2–5.5 秒恢复；半途解除或重新暴露时按原关键帧对应区间接续。
- 受惊使用原有 112 tick 惊恐计时，并给伸出阶段留下时间；雨不产生或延长惊恐计时。姿态时钟只在实体加载时推进，不写 NBT，读档后按当下条件重新判断。

优先级：浸水、着火、乘坐、操作以及玩家动作命令优先于自动缩壳。自动缩壳只在可用时占用移动和视线，水与火的逃生目标仍可运行；直接指定壳动作同样不能让浸水或着火的个体留在壳姿态。雨天避让仅在生活任务空闲、没有活动中的繁殖任务且生理条件允许时开始或持留：营养至少 45、精力至少 35、便意低于 70、干燥度低于 40，不在睡眠、进食、过冷或过热，也没有紧急需求。解除时完成伸出后让出目标。生活、生长、湿度及温度计时始终继续，不赋予无限耐水。

半伤要求真实壳、有效缩壳控制或玩家壳命令，以及动作每轮 1.2–3.8 秒的内部姿态；仅残留动画名称不产生保护；处于水或火中、火焰与溺水伤害标签均不减半。保护范围是外伤白名单：玩家／生物近身攻击、弹射物、爆炸、跌落、飞行撞墙、落物、石笋、仙人掌／浆果丛刺伤，以及已有的表面擦伤。冻伤、饥饿、刺激物及未知／通用伤害（含口干与经 `BodyLife` 的器官内伤）均不减半，也没有新增耐寒、抗饥饿或抗口干效果。白名单与半伤数值是项目原创。

## 帽船（水生魔理沙）

帽船只属于水生魔理沙；陆生魔理沙不放帽乘船，落水不会凭空生成帽船。投放、出航、翻覆救援、水上居住与生育、亲子初航、储粮与桨、争位和靠岸回帽等玩法见[水边生活实现](AQUATIC_MARISA_IMPLEMENTATION.md)。本页只保留亚种层面的约定：

- 帽船就是她自己的帽子倒过来放：帽冠略压扁、沉在水下，帽檐高出水面（参考 EH22，见[帽子翻过来](../standards/yukkuri-library/interactions/marisa-hat-vessel/README.md)），帽里是干的；水生魔理沙的帽子比陆生大（原创 1.5 倍），戴着时也按这个大小绘制。船体 `HatBoatEntity` 记录 `AFLOAT`、`BEACHED`、`CAPSIZED`、`RESCUED` 状态；实际乘员数由总载荷和真实座位共同限制，临时避难席位不建立亲缘，规则见[水边生活](AQUATIC_MARISA_IMPLEMENTATION.md)。
- 同一实体还有两种接生用状态。**地上的帽子**（`CRADLE`）：陆生魔理沙用辫子把帽子倒过来按在出口前的地上，帽冠压扁贴地，不可碰撞，不挡出生通道，幼体坐在帽内底部。**浮在岸边**（`MOORED`）：水生魔理沙在靠岸分娩时把帽子翻过来按在岸边水面上浮着，保持原位不漂走，孩子落进帽里。孩子进帽、跳出帽子都按重力下的抛物线运动（`HatVessel`、`FamilyLife` 的飞行）；不再需要时，主人回到摘帽位置，幼体先跳出帽子，再用辫子取回戴上。
- 水生魔理沙只与水生魔理沙配对。帽船上的动作（漂流、稳船、向岸呼唤、帽船安胎、帽船分娩、夜里睡觉与帽中幼体）见[世界观动作](../standards/yukkuri-library/motions/variants/lore/README.md)。
- `HatBoatEntity.find`、`createFor`、`board`、`boardYoung`、`capsize`、`rescue` 供野外事件和家庭使用；调用方以实际返回值和乘员关系判断阶段。查不到卸载区块中的实体不等于死亡或获救，不能生成替身船。`REMOVED` 保留给外部状态对接，正常收束走 `RESCUED` 后移除。
- 美术：帽船为魔理沙本人的帽子倒过来、帽冠压扁（`marisa_hat_turned`，陆地与水上压扁程度不同）；实体名 `hat_boat` 沿用。

## 美术接入

[选用清单](../art/source/subspecies-runtime/manifest.json)逐项列出模型、几何标识、骨架、贴图和运行目标，[交互预览](../art/source/subspecies-runtime/preview.html)来自当前运行导出；后发／动作适配见[后发运行适配](../art/source/subspecies-runtime/motion-contact/README.md)。

- 螺壳选用标准库 `marisa_tsumuri`，多毛灵梦选用已有 `reimu_wasa` 并适配基础尺度，不足形态由配方生成。独立螺壳物品由同一螺壳几何导出，拆下时不再变成普通帽子。动作复用基础种骨架曲线并重映射；螺壳侧弯为整体小幅转动，避免壳与头撕裂。
- 身体受伤表面、持食口部和饰物显隐按形态资源标识选择。豆形使用连续身体表面与混合骨骼，保留背部标记；稀疏形态的根部和蝴蝶结按实际身体位置适配；伤口锚点、束具与出生尺寸按选用资源同步。豆形受伤表面采用长边自适应细分。
- 八套模型各有 16 张表情，含生态用的 `closed_smile`、`chewing`、`chewing_closed`、`satisfied`、`open_smile`，缺图不以平静表情静默替代。螺壳图集 256×256，其余七套 128×128。`python scripts/export_subspecies.py --check-textures` 检查源确认指纹、PNG 解码、尺寸和源／快照／运行一致性。
- 螺壳沿用标准库模型；缩壳的运行片段由 `ShellRetraction` 触发。
