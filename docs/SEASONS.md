# 群系季节与体感

状态：群系季节、体感温差与观察页已接入；实际路径和客户端页面仍待游戏确认。

## 事实来源

季节不再按世界时间轮转。`settlement/Seasons.at(level, pos)` 是唯一事实来源：先读取 `season_winter`、`season_autumn`、`season_summer`、`season_spring` 群系标签，未标记的群系才按基础温度回退判定。雪地是冬、森林是秋、炎热地区是夏、平原和草甸是春；位置不换，昼夜、睡觉和 `/time` 都不会改变它。

群落需要稳定判定时使用群落中心，普通住户使用自己的住所或当前位置。

`biomeSeasons=false` 会关闭所有由群系季节触发的行为和温差；此时 `Seasons.at` 仍可供诊断读取，但不会影响游戏。

## 体感

`TemperatureLife` 在每次实际采样位置读取同一份群系季节，并在有天光、非固定时间的维度叠加温差：

| 参数 | 默认 | 范围 |
|---|---:|---:|
| `springTemperature` | 0 | -2 至 +2 |
| `summerTemperature` | +0.45 | -2 至 +2 |
| `autumnTemperature` | -0.25 | -2 至 +2 |
| `winterTemperature` | -0.8 | -2 至 +2 |

随后保留已有的昼夜、屋顶遮蔽、降雨、湿度、铺垫和无遮挡火把／营火计算。暑热继续驱动躲阴和口干；寒冷继续驱动体力消耗、冻伤和寻找暖处。住所记录本身不能提供保温，实际所在位置必须有完好、干燥的遮蔽和铺垫。下界、末地及固定时间维度不加季节温差。

观察笔记按玩家或被观察个体所在位置显示群系季节和本地温差，明确不随时间轮转。

## 设定边界

- [E07《ゆっくり解体新書》](https://w.atwiki.jp/yukkuri_gyakutai/pages/3102.html) 的四季段提供出窝、风雨、准备食物和冬日留窝的情境；作者明确为个人设定，本项目不搬入其成功率、月份、成长时限或免食机制。
- [N02《ゆっくりの一年春編》](https://w.atwiki.jp/yukkuri_gyakutai/pages/2736.html) 显示同一季节的家庭仍会因余粮和住居而不同；季节不保证生存，也不自动触发繁殖。
- M14 寒夜幼体和 M03 雪地活动画面支持保温需要及“冬天仍可外出”的方向，不给出统一温度、死亡期限或安全食物结论。

阈值、温差、遮阴公式和各类时间均为 Minecraft 原创适配。季节不会补发饥饿、成长、睡眠、繁殖或冻伤结算。

## 验证边界

自然地形路径、多人同步、自定义群系标签和观察页排版仍待在游戏里确认。

## 被炉魔理沙（2026-10-18）

被炉魔理沙按所在位置的群系季节行动：冬季群系里，被炉自带的热量（体感 +0.6）让她不觉得冷，不回巢越冬，照常外出觅食；夏季群系里，她整天都算休息时间，热了先去阴凉处再睡。规则见[妖梦与稀有变体](RARE_FORMS.md)。
