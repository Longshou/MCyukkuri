# 螺壳魔理沙的缩壳

服务器端 `subspecies/ShellRetraction` 管理受惊和雨天的缩壳时序；`YukkuriEntity` 只接入移动目标、动作采样和实际受击门控。复用当前 `marisa_tsumuri` 的 `shell_retract` 制作源与运行片段，不修改模型、骨架或关键帧。

## 来源边界

亲读《[赤ちゃんまりさとまりさつむり](https://w.atwiki.jp/yukkuri_gyakutai/pages/2013.html)》（L24）：文中描述螺壳饰物的耐水作用，也写出本体长期浸水仍受损；文中没有雨天缩壳规则。M09 的两张本地图是同篇作品的形态参考，不是另一份独立行为证据。种族说明见 [tsumuri](../wiki/hakkei-reference/lore/species/marisa/tsumuri.md)。

雨天主动缩壳、需求让步阈值及缩壳时的半伤规则均是本项目原创适配，不能由上述耐水描写推导为原作既定动作或水伤免疫。

## 触发、持留与恢复

- 只有螺壳亚种且当前实际持有壳饰物时能缩壳。失壳后，受惊改走原有逃跑路径，雨天不会缩壳；显式 `shell_retract` 命令也被拒绝，已开始的壳命令会终止。
- 雨触发同时检查实体当前位置 `isRainingAt` 与生物群系的 `RAIN` 降水类型。屋顶、无雨生物群系和降雪不触发；不以全局天气代替本地暴露。
- 沿现有动作的 0–1.8 秒收拢，在 1.8 秒停留。持续雨不会反复播放整段动作。离开雨、进入遮蔽或需要恢复活动时，映射到当前姿态相应的伸出位置，再沿 3.2–5.5 秒恢复。半途解除或重新暴露时按原身体关键帧的对应区间接续，避免从完全展开姿态重新开始。
- 受惊仍使用原有 112 tick 惊恐计时，并给伸出阶段留下时间。雨不会产生或延长惊恐计时。该姿态时钟只在实体加载时推进，不保存到 NBT；读档后按当下真实条件重新判断。

## 生存与优先级

浸水、着火、乘坐、操作以及玩家动作命令优先于自动缩壳。自动缩壳的目标只在可用时占用移动和视线；水与火的逃生目标仍可运行。直接指定壳动作同样不能让浸水或着火的个体留在壳姿态。

雨天避让仅在生活任务空闲、没有活动中的繁殖任务且生理条件允许时开始或持留：营养至少 45、精力至少 35、便意低于 70、干燥度低于 40，不在睡眠、进食、过冷或过热，也没有原有紧急需求。解除时完成伸出后让出目标。生活、生长、湿度及温度计时始终继续，不把雨天停留写成永久惊恐，也不赋予无限耐水。

半伤要求真实壳、有效缩壳控制或玩家壳命令，以及现有动作每轮 1.2–3.8 秒的内部姿态。仅残留动画名称不产生保护；处于水或火中、火焰伤害标签及溺水伤害标签均不减半。

保护范围采用外伤白名单：玩家／生物近身攻击、弹射物、爆炸、跌落、飞行撞墙、落物、石笋、仙人掌／浆果丛刺伤，以及本项目已有的表面擦伤。冻伤、饥饿、刺激物及未知／通用伤害均不减半；当前口干和器官内伤通过 `BodyLife` 使用通用伤害，因此也不获得保护。没有新增耐寒、抗饥饿或抗口干效果。白名单及半伤数值都是项目原创，未列出的伤害保持原伤害，不声称原作给出了防护范围或数值。

## 验证范围

本地雨雪与遮蔽、持续持留与恢复、需求优先、实际壳饰与伤害范围已在服务端受控场景核对。本机仅做静态与现有关键帧的离线检查，不编译或运行游戏。受惊、持续降雨、遮蔽切换及失壳后的视觉与自然导航仍待用户游戏确认。
