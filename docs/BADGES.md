# 宠物油金银章系统

2026-10-16 起，2026-09-13 的旧金银章系统（3／8 绿宝石报名、五项 5 秒抽象评定、店员交易界面“金银章考核 / 补发”、`BadgeLife`）已整体替换。现行规则只写在 [PET_SHOP.md](PET_SHOP.md)，本页不再重复数值，以免与实现分叉。

## 现在是什么

- 铜／银／金三级，资格绑定个体 UUID，徽章物品只是凭证：[PET_SHOP.md §1](PET_SHOP.md#1-等级与有效期)。
- 由商店考官办理简易／判定／昇格／更新四种考试及补发，每题是实体实际行动：[§3 考试](PET_SHOP.md#3-考试)。
- 手帖（`badge_handbook`）查看档案、摘章与重戴、开始家庭课程、许可繁殖：[§4 家庭课程](PET_SHOP.md#4-家庭课程)、[§5 繁殖与餡統](PET_SHOP.md#5-繁殖与餡統)。
- 疏忽与弃养会让登记作废：[§5.5](PET_SHOP.md#55-疏忽与弃养)。
- 持章者与旁观者的羡慕、嫉妒、炫耀等反应：[§7 社会反应](PET_SHOP.md#7-社会反应徽章)。
- 商店结构、店员与交易：[§6 商店](PET_SHOP.md#6-商店)；实现进度与未验证项：[§10](PET_SHOP.md#10-实现进度与验证)。

与旧系统的主要差别：新增铜章；银章、金章有效期默认 20 个游戏日并可更新；考试结果受餡統、压力、自制力影响；训练改为手帖里的四种家庭课程加主人反应；金章实技要隔玻璃应对野良役。

## 佩戴、挂点与美术

徽章是饰物上的圆形金属牌，随饰物离身而不显示，资格保留。挂点制作源、色板与导出方式见 [art/props/badges/README.md](../art/props/badges/README.md)；`python scripts/export_badges.py` 导出挂点、手帖配方和本模块语言，`--check` 核对当前内容。作品参考与佩戴依据见 [漫画与小说核读](../wiki/badges.md)。挂点与贴图为待用户确认版本。

徽章的社会反应（目击、记忆、预算、弧线、传闻、管理员命令）见 [PET_SHOP.md §7](PET_SHOP.md#7-社会反应徽章)；配置段为 `badge_social`。
