# 体感温度、避寒与避暑

状态：冷暖状态与避险代码已接入，服务端受控场景已核对阈值、真实遮蔽、热源及睡眠结算；自然玩法与客户端显示仍待确认。原作没有统一温标或死亡时限，下面的数值和寻路规则均为 MC 原创适配，不是现实摄氏温度或原作定律。

## 服务器模型

`life/TemperatureLife` 由生活模块持有。每 20 个已加载且 AI 启用的游戏刻采样并推进暴露。不依赖客户端帧率，不追补离线时间，不把区块卸载当死亡。旧存档缺少温度标签时按零暴露起步，位置、环境和行动路径重新判断。

体感以当前位置生物群系基础温度为起点；3.1 在有天光、非固定时间维度先加入当前季节温差，默认春季为 0，完全保留本单元原行为。有天光维度的露天夜晚减 0.35、遮蔽夜晚减 0.15。基础温度至少 0.8 的白天，日晒加 0.35；阴影仅削去超过 0.8 的热量，春季最多减 0.65，夏季等正温差可提高削热上限，详见季节说明。削热本身不能把普通温和群系的树荫降成寒冷。冷地露天降水再减 0.2，体表湿度按 0–0.35 降温。地下和屋顶依据实际高度图或完好实体棚屋判断，不能只靠记住一个家坐标。

默认值的非编译边界核算（干燥、无热源）：0.8 群系白天日晒为 1.15、树荫为 0.8，两者均不冷；2.0 群系日晒为 2.35、树荫为 1.35，后者低于炎热阈值 1.5；0.0 群系露天夜晚为 -0.35，有实体屋顶且有足够铺垫的窝为 -0.15 + 1.0 = 0.85。这些算例只检查公式边界，不代替游戏中的群系读取、屋顶识别或寻路验证。

保温只作用于实际站在该住所睡位的住户：完整且可用、有足够干铺垫的自然洞/纸箱；已经用六份实物材料建好的干净家油窝及其有顶入口；已认领、有顶且可站立的普通窝邻位。破损、被水淹或未完成的住所不给保温。普通窝把制作出的窝本身视为铺垫，不能给远处的成员提供效果。保温加成仅在偏冷时添加，不把普通阴影变成恒温房。

普通火把/墙上火把提供 0.9 强度、点燃营火提供 1.4，半径四格，按距离衰减；采用最强单个来源，不堆叠刷温度。必须存在直接无遮挡的碰撞射线；熄灭营火、灵魂火与墙后的热源均不算。落脚点远离营火、火、熔岩、岩浆块和仙人掌，不进入火中取暖。热源搜索、住所读取和射线所跨区域均检查已加载区块。

## 原创参数与行动

公共配置 `temperature` 中可调：

| 配置 | 默认 | 作用 |
|---|---:|---|
| `coldBelow` | 0.2 | 低于此体感时增加能量消耗、寻找暖处 |
| `freezeAtOrBelow` | 0.0 | 低于或等于此体感时积累冷暴露；有效值不超过冷阈值 |
| `hotAtOrAbove` | 1.5 | 达到后增加口干、寻找阴凉；有效值至少比冷阈值高 0.5 |
| `nestInsulation` | 1.0 | 真实保温窝在冷环境中的体感增量 |
| `coldExposureTicks` | 2400 | 冻伤前累计暴露量 |
| `freezeDamageInterval` | 200 | 暴露已过阈值且继续受冻时，每隔这些刻损失 1 生命 |
| `heatDrynessInterval` | 100 | 炎热时增加 1 点口干的间隔 |

边界统一：有效冻伤阈值为 `min(coldBelow, freezeAtOrBelow)`；“偏冷”表示低于冷阈值，或已达到包含等号的冻伤条件。因而 `coldBelow = freezeAtOrBelow = 0` 且体感恰好为 0 时，会积累暴露并主动求暖，也会触发实际窝的保温，不能把该位置选作安全睡位。热阈值仍归一化为至少比冷阈值高 0.5。温度表现、求暖、睡眠安全与候选点共用这组边界。

成体每刻积累 1 暴露，子油 1.5、赤油 2；脱离冰冻环境每刻消退 2。使用现有成长阶段，不定义统一月龄。偏冷每 100 刻额外消耗成体 1、未成年 2 能量。食物充足不能抵消冷暴露；没有自动回血、补水或凭空取食。当前热机制是口干与避暑，没有另加热射病死亡公式。

寻冷暖处只在附近六格内选择可站立、可达的安全位置，每轮至多对排序靠前的十六个候选寻路；优先满足实际保温窝，但不传送、不认领他人的窝、不新建住所。他人认领的普通窝睡位和家油窝内部/入口也不作为临时休息点。暖处必须脱离偏冷及冻伤边界且不太热，阴凉处必须有真实遮蔽且温度适宜。避险、玩家指令、操作、乘坐、进食、急迫排泄、临产和正在进行的家庭照顾优先；口渴且有可达水源时先喝水，没有水源也仍可先避晒。睡着或回家途中发现实际环境过冷/过热且附近有合适避难处时，可以换去那里；助眠药效不被温度行动取消。暂停不会删除搬运物或亲缘关系。

普通取暖/乘凉暂停最多 200 刻，本身不计完整睡眠、不给成长奖励。若已经真实抵达、安全停留至少 20 刻，且原有睡眠冷却已结束、符合疲劳或夜晚入睡条件，则把当前位置作为临时睡位转入原来的 `SLEEP`：睡眠从 0 重新计时，走正常的入睡、至少 220 刻后开始清醒与 640 阶段结束流程，沿用原成长和作息结算。不会先返回仍然寒冷的永久窝，也不把此前取暖时间或未完成的睡眠算作奖励。热源消失、位置失效、被推离、实际降雨或高优先级需求会中断；正常完成或被打断后清除临时睡位。该睡位不写入存档、不改变亲缘或住户/认屋记录。露天暖处仅在干燥且体感适宜时可以临时睡眠，不能取代住所所有权。

观察笔记增加中英日三语温度页，列出体感、暴露累计、实际遮蔽、保温窝与能照到当前位置的热源；行为显示寻找暖处、取暖、寻找阴凉或阴凉休息。复用现有身体动作和表情，没有挪用社会对白里的“冷淡”作为受寒发言。
