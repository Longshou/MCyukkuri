# 家油生态与演出

2026-10-18 整体重做。家油是类似室内寄居小动物的生态类型，普通宠物进屋不会变成家油。设定依据是[家油、巢穴与卵](../wiki/hakkei-reference/lore/house-nest-sources.md)和[资源与生活生态](../wiki/hakkei-reference/world/resources-ecology.md)：微小、寄居家具缝隙、收集棉絮灰尘筑巢、夜间觅食、卵生。以下自然积尘的数值、人类活动来源、搬入条件、认生、巡视、迁卵和所有时长是 Minecraft 项目适配。

## 闭环

```
人类活动(走动、睡觉、剪羊毛、拆羊毛和床、进食、做饭、收获作物)
   └→ 屋顶下的墙角、家具边出现地面痕迹：絮尘、食屑          （世界状态，上限、会淡去，玩家拿不到）
        └→ 痕迹聚到足够多，旁边有无人注视的隐蔽墙角，附近没有家油  →  一只家油搬到那个墙角
             └→ 它自己叼絮到墙角：絮窝出现(第一次放下絮) → 垫料一点点变厚(六份铺满) → 伴侣随后搬来
                  └→ 夜里(或安静的白天)出巢：巡视墙边 → 嗅 → 叼取 → 搬回 → 放下 → 铺压/储食 → 吃储粮 → 回巢睡
                       └→ 垫料铺满、粮够：产卵(2–4枚) → 亲油照卵、侧耳 → 窝脏了把卵叼去别的窝 → 破壳 → 幼体住进窝
```

棉絮和食屑**不再是玩家物品**。它们只是人类生活留在地面上的痕迹：玩家无法合成、领取、丢弃、放置或拿起它们，创造模式物品栏里也没有。家油在这个闭环里是唯一收集它们的角色。

- 保留的两个注册物品 `mcyukkuri:nest_lint`、`mcyukkuri:food_scrap` 只是**内部载体**：地面堆的存储类型、家油嘴里和窝里的显示、渲染模型都借用它们。它们不能在创造栏里找到，没有合成配方；`HouseholdEcology.itemJoin` 取消这两种物品实体的生成，`purgeInventory` 每5秒清走玩家背包里的这两种物品并提示“只是生活痕迹，带不走”。旧存档里的物品实体、背包物品、掉落物就这样被清理；旧的地面堆、窝内库存、家油嘴里的携带物继续有效，不丢进度。
- 唯一保留的真实物品是**废物** `yukkuri_waste`（抹布扫起或窝里清出的垃圾，可堆肥）。

## 痕迹的来源

只有已加载的玩家、村民活动才产生痕迹，且必须在屋顶下（树叶不算屋顶）。落点优先选墙边、墙角、家具边，所以痕迹聚在“缝隙”里而不是房间中央。

| 人类活动 | 产生 | 说明 |
| --- | --- | --- |
| 在屋里走动、停留 | 絮尘 | 每16×16×8区域累计600个活动tick落一份，约30秒。睡在床上的人累计速度翻倍 |
| 一觉醒来(`PlayerWakeUpEvent`) | 絮尘 ×2 | 被褥抖出的纤维 |
| 破坏羊毛、地毯、床 | 絮尘 ×2 | |
| 给羊剪毛 | 絮尘 ×2 | 落在羊身边（屋里） |
| 玩家真实进食完成 | 食屑 ×1 | |
| 合成或烧制出食物 | 食屑 ×1 | 厨房处理 |
| 收获成熟作物（屋里） | 食屑 ×1 | |
| 村民 | 絮尘（在场即累计）、食屑 | 村民身上某种面包、胡萝卜、马铃薯或甜菜根至少16份时，每区域每1200个活动tick最多消耗1份；先成功落地才扣粮 |

**预算与衰减**：事件类痕迹（上表中除走动外）按“区域×种类”各有4份预算，每200tick回复1份，空了就不再落；每个16×16×8区域最多8格、24份地面痕迹，每个区块整列最多16格、64份。满额、被喷驱油剂、被扫过都不再产出。一格最多64份。絮尘无人动会被吹散，食屑会变坏：满1.5个MC日（36000tick，约30分钟）没有变化后，每次随机刻损失1份，直到清空；废物不衰减。家油自己的进食不再产生食屑。

一格痕迹没有实体和tick，客户端按距离只画几簇（近4、中2、远1，12格外不画）；事件落点有一小团粒子（絮尘白灰、食屑面包屑）让人看见“这里落了东西”。

## 家油怎么来

自然搬入由 `HouseholdEcology.arrive` 判定，在活动采样里每约1200个活动tick检查一次（区域冷却24000tick，约20分钟）：

1. 该区域最近有玩家或村民活动（没有人就不累计，离线时间不补算）。
2. 屋内可达地面上有至少2份絮尘、总共至少5份痕迹。
3. 存在一个**隐蔽墙角**：可走、有屋顶、四周至少两侧是墙或家具（`hiddenCorner`），且有可走的入口侧，附近16格内没有已有的窝。
4. 20格内没有活着的家油，附近人口未满。
5. 没有玩家在12格内且视线能看到这个墙角（人看着时不搬）。
6. 没有被扫过（抹布）或喷过驱油剂；`houseArrivals`、`mobGriefing`、`doMobSpawning` 开着。

满足时先搬来**一只**（灵梦或魔理沙随机），出现在墙角入口侧并带一次惊讶表情。此时**还没有窝**。它要先找到絮：叼着第一份絮回到墙角放下，絮窝方块才出现在墙角，里面是第一份垫料；这就是“筑巢”的第一步。窝建成后，窝里有垫料或粮、该区域近期有人活动时，另一种家油作为伴侣在默认每600个有效tick后搬来（单窝最多两位，仍受附近人口上限限制）。

直接 `summon` 的家油没有窝也没有墙角时，会在10格内自己挑一个隐蔽墙角（日志 `[house] ... chose the corner`），白天睡在那里，夜里去找絮建窝，所以试玩场放一对家油也能看到完整的筑巢，不必先放巢方块。

## 一天

| 时段 | 行为 |
| --- | --- |
| 白天 | 在窝里睡。休息够（精力≥70）且周围8格内没有任何人时，才会出来干活；有人走近，立刻回窝（认生） |
| 夜里 | 精力≥35、附近没有人时出来干活；没有活干就继续睡，不会无意义徘徊 |
| 饿了(营养<45) | 不分昼夜出来找食屑；窝里有储粮就直接到入口吃 |
| 有人靠近(<3.5格，蹲下按约1.9倍距离算，隔着墙或家具要远得多) | 在外面的家油受惊，快步回窝躲到人走远；没有窝的就在墙角原地僵住（`house_hide`） |
| 幼体 | 待在窝里；醒着时每约1分钟探头看一下再回去 |

人类在场时不会出巢，所以要看家油干活，需要离开或蹲下站远一点，或者等夜里。

## 出巢干活的每一步

每一步都有明确的阶段，可在无界面工具里读到（见“怎么观察”）。

1. **探头** `leave`/`peek`：走出窝口，在入口左右张望一下（`house_peek` 表情＋字幕）。
2. **找东西**：先看8格内可达的痕迹堆；没有就**巡视** `scout`：选墙边、家具边的一个点走过去，到了**嗅** `sniff`（环顾约2秒，`house_sniff`），环顾时再扫一次；找不到换一处，最多3处，随后休息约1.5分钟再来。巡视范围是窝或墙角14格内。
3. **叼取** `to_source`→`pickup`：走到痕迹堆边，嘴部真正碰到才取走一份，堆上少一份，粒子一小团。
4. **搬运** `carry`：嘴里是真实携带物，随存档；搬运超过2分钟还没送到就放下（放回地面堆，放不下就散掉）。
5. **放下** `deposit`／`found_nest`：走到窝口放下。没有窝的新住户这一下会让**絮窝方块在墙角出现**（日志 `[house] nest founded`）；垫料每份可见变厚，满六份时窝建成（日志 `the nest ... is lined`）。
6. **铺压** `shape`：放絮后在窝边用身体压一压垫料（`house_shape`，约1.8秒）。
7. **储食**：食屑放进窝里（`stashed`），储粮目标12份；饿了的家油到窝口吃储粮。
8. **回巢睡觉**：进窝走窝口→门槛→床位（`approach`/`enter`/`rest`），睡眠恢复精力。
9. 窝脏了(垃圾≥3)或有卵：**照卵** `tend`→**侧耳** `listen`（亲油在卵边接触，登记照护）；垃圾被清到地面成废物堆。

产卵与破壳沿用既有流程：健康熟悉的成年亲油都在窝边、垫料已满、窝里至少4份储粮、脏污<6，才会产生2–4枚卵（每枚保存原子代 UUID、双亲、种族和成长参数，四个卵位固定）。照卵温存240tick，孵化要求登记的照护者留在卵区、有粮、垫料干净；每600个有效孵化tick消耗1份储粮；卵在后段间歇晃动、出现裂纹；破壳后幼体用原 UUID 出生在卵位，相邻出生至少间隔48tick，空壳停留120tick再收进脏污。详细的几何与伦理边界见下文“卵与亲代”。

### 迁卵

窝里有卵，但窝已不适合孵化（脏污≥6、被扰动或在驱油剂范围内）时，健康的亲油会：走进窝→在卵边**叼起**一枚卵（`lift`，真实卵物品带着原身份凭据）→出窝→**搬到**16格内另一个有空位、干净、已铺好的窝口，放入（`place_egg`）→两位亲油改以新窝为家。需要附近确实有第二个窝；没有就不迁。搬运中被打断，卵放回原窝，放不下就留在地面作为真实物品，账本不丢。

## 卵与亲代

沿用重做前的规则：每枚卵保存原子代 UUID、双亲、种族与成长参数；右侧四个卵位固定，孵化或取走一枚不会把其他卵挤到新位置。完整卵、裂卵和残壳统一使用制作配方导出的2.4倍世界尺寸，地面、巢内和携带显示一致；携带时抵消持有者的成长缩放。出生幼体仍使用原有0.32成长比例，不靠出生瞬间缩放来塞入卵。`house/HouseEggGeometry` 读取随模组打包的几何规格；离线检查核对两种家油的全身网格（含饰品）落在扣除壳厚的卵内，以及四卵位和成体碰撞箱间距。该检查不代替实际破壳动画与碰撞演出确认。摇晃、听卵和残壳的具体演出是原创，不宣称漫画确证了完整自然孵化过程。

## 清扫与限时驱油喷雾

| 操作 | 结果 |
| --- | --- |
| 潜行持抹布右键地面或零碎 | 干布也可扫附近3×3可见地面痕迹，收为废物 |
| 扫过一个生活区域 | 暂时抑制积尘和新寄居2400tick，约两分钟 |
| 空手右键痕迹格 | 查询类型与准确数量；只有废物堆能潜行收回 |
| 持废物右键原版堆肥桶 | 按原版30%成功率推进堆肥，最终得到骨粉 |
| 对自然絮窝普通用抹布 | 清走污物、剩食与残壳，保留垫料和卵；居民惊缩离开 |
| 对自然絮窝潜行用抹布 | 拆除絮窝，回收废物并惊扰居民；只损失仍在该窝的未出生卵 |
| 持驱油喷雾右键方块 | 以命中方块为中心保护水平±8格、垂直±4格，持续72000游戏tick |
| 潜行持喷雾右键方块 | 免费查询该位置是否受保护及剩余时间 |

玻璃瓶、铁粒和任意树叶无序合成一瓶喷雾，可用16次。有效范围内停止自动积尘、自然搬入和新卵，已有居民、卵和痕迹保留；保护按维度保存锚点和到期时间，每维度最多256条。

## 玩家交互与后果

| 操作 | 结果 |
| --- | --- |
| 普通空手右键窝 | 查看巢材、藏食、脏污、卵数与进度 |
| 空手潜行右键窝 | 小心取出一枚真实卵，保留进度；携带或存箱时暂停 |
| 持卵右键完整遮蔽窝 | 有空位和人口余量时放入，继续原卵的进度 |
| 破坏窝方块 | 垫料与脏污转为废物，未出生卵损失；迁出卵及已出生幼体保留 |

家油没有人工“缝隙”家具：不绘制木制外壳，只有真实搬来的垫料、剩食和卵可见。卵物品保存可撤销的凭据，世界亲缘账本才是权威，复制旧物品不能产生第二只子代。

## 遗体

家油遗体与其他油库里的遗体规则一致：永久保留，不自动消失，只有玩家主动收取、掩埋，或试玩场的“清空本场地”会处理。

## 防止杂物堆满服务器

痕迹按区域和区块封顶（见上），一格一份方块实体、没有逐tick更新；活动来源每轮最多处理64个、轮换维度；写入后更新同一视图，不重复遍历区块。自动来源只写可达地面；不替换家具、不隔墙投放、不强制加载区块。

## 怎么观察（运维与自动检查）

- `/yukkuri household status`：在执行者所在位置，列出附近痕迹数量、活动记录(积尘、迁入计时、冷却)、每只居民的阶段与统计、每个窝的垫料/储粮/脏污/卵。
- `/yukkuri household activity <tick> [睡觉] [强制]`：模拟“人类在这里生活了一段时间”，走与真实生活相同的上限与来源，一次性落下絮尘和食屑，并在条件满足时让家油搬入。`强制`为真会清掉扫地抑制和迁入冷却。
- 居民 NBT：`YukkuriHouse.Stage`（`sleep idle leave peek scout sniff to_source pickup carry deposit found_nest shape feed hide hide_home to_nest enter rest tend listen lift to_clutch carry_egg place_egg`）、`YukkuriHouse.Stats`/`Counts`（picked delivered founded built stashed ate tended moved hidden scouted）、`YukkuriHouse.HumanDistanceTenths`、`YukkuriDebugGoals`（当前运行的 AI 目标和优先级）。
- 日志：`[house] a house reimu moved in`、`nest founded`、`the nest ... is lined`、`clutch moved`。

## 为什么旧版几乎看不到演出（根因，2026-10-18）

1. **没有自己的目的**：旧的家油日程只在“眼前有掉落的絮/屑”时才有事可做；没有玩家丢的东西时，夜里只会在窝口探头、白天在窝里睡觉，其余时间交给别的目标，看上去就是两只家油在晃。
2. **材料不是生活的产物**：絮和屑需要玩家合成或领取再丢，没有闭环；自动痕迹来源只有“屋里走动”和“玩家吃东西”，慢且看不见。
3. **白天看不到**：试玩场默认正午，家油按昼夜白天都躲在窝里睡，无窝的家油被通用休息逻辑原地睡觉(不会动)。
4. **一个会让服务器崩溃的缺陷**：旧的 `DropSettling` 在遍历登记表时丢弃物品实体，触发 `ConcurrentModificationException`，物品静止30秒转成地面堆的那一刻就会让整个服务器崩溃（已用旧版运行产物复现，整个机制已删除）。
5. **路线穿窝**：旧版窝口方块可被外部路径穿过，家油去拿墙角的东西会走进窝里又被“出巢必须过窝口”的规则拉回，来回徘徊。窝方块现在对外部寻路不可通行，进出窝只走窝口。

## 给试玩场的需求

- 一座有人类活动的屋子：玩家能在里面走动、吃东西、睡觉、剪羊毛、做饭，同时有隐蔽墙角（至少两侧是墙或家具）。
- 一个快速产生痕迹的按钮：执行 `/yukkuri household activity 6000 false true`（在屋子里的锚点位置执行；注意地图上一个“区域”是16×16×8，窝和活动点要在同一区域里，否则近期活动判定不同步）。再加一个“夜里”和“正午”按钮方便看作息，以及“睡一晚”变体 `/yukkuri household activity 6000 true true`。
- 不要再让玩家领取棉絮或食屑。场景里不要预放 `nest_lint`、`food_scrap` 物品实体（会被取消生成）。
- 看迁卵需要放第二个已铺好的窝：`setblock <x y z> mcyukkuri:house_dust_nest{Materials:6,Food:8,Arrivals:2,Entrance:"north"}`，再让原窝脏污≥6。
- 家油遗体由“清空本场地”统一处理。

## 检查边界

本机不编译、不启动游戏窗口。无界面服务器用 CI 运行产物实测了：人类活动模拟落下痕迹、家油搬入、叼絮建窝、放下、铺压、储食、进食、照护等阶段的状态推进，以及从旧版复现崩溃。视觉效果、字幕配音和真实玩家交互需要在游戏里的试玩场亲自看。
