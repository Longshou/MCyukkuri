# 家油生态与演出

2026-10-17。家油是类似室内寄居小动物的生态类型，普通宠物进屋不会变成家油。设定依据是[家油、巢穴与卵](../wiki/hakkei-reference/lore/house-nest-sources.md)和[资源与生活生态](../wiki/hakkei-reference/world/resources-ecology.md)。以下自然积尘、数量预算、清洁期、防护盒和时长是 Minecraft 项目适配。

## 生活空间先产生物资，再产生寄居者

主入口是玩家和村民的日常生活，不是合成棉絮和人工投喂。只有已加载的玩家、村民活动会积累室内活动时间；空建筑、只有其他动物的房子、区块卸载时间都不会累计。屋顶下可走的干燥地面即可，高大厅和洞穴住所也可成立，不检查指定家具、精确亮度或夜间。树叶形成的树冠不单独当作屋顶。

- **絮尘**：衣物、寝具与日常磨损的低量模拟。每个16×16×8区域累计600个活动tick产生一份，通常约30秒；不扣家具、羊毛方块或村民物品。靠墙、床边等处优先落地，但家具不是门槛。
- **玩家和油库里碎食**：真实进食完成后，尝试把一份剩屑加入附近地面。吃碎食不会再生碎食。自动来源不进入背包，不产生可自动拾取的 ItemEntity。
- **村民碎食**：村民低频处理真实余粮。每区域累计1200个活动tick最多一次，只有某食品槽至少16份面包、胡萝卜、马铃薯或甜菜根时才消费一份；必须先成功落地才扣粮。不会凭空造粮、取箱子或把少量口粮抽空。
- **自然寄居**：区域累计1200个活动tick且附近实际存在棉絮或碎食时，才会把其中一份转移成低矮絮窝的库存。附近已有巢就不再造窝；没有物资就等物资。每区域成功建立自然窝后至少24000tick不再建立第二处，扫除不会立刻补窝。

自然窝的材料、粮、卵均沿用真实库存。近期有玩家或村民活动，巢内有任意一份巢材或食物，就可等待家油入住；不再要求四份粮，不消耗招引税，不限昼夜。默认每600个有效加载tick最多出现一位，单巢最多两位，仍受附近总人口上限约束。后续繁殖从已有成年居民和真实食物产生，不能用方块无限制造人口。

默认 `houseArrivals`、`mobGriefing`、`doMobSpawning` 控制自动生活环境与自然寄居。已经存在的家油始终是实体；扫地或放置防护盒不会把它们凭空删除。已有配置文件中的 `houseArrivalTicks` 会保留原值。

## 防止杂物堆满服务器

每个16×16×8区域最多自动形成8个散料格、24份地面材料。达到任一生成预算就停止增加新格或新数量；手工整理的单堆容量为64，手工额外库存也会占用自动生成预算。多人、多个村民在同一区域不会加速累计，每维度每轮最多处理64个活动源并轮换。

一格散料是一份保存类型、数量和物品组件的方块实体，没有逐tick更新；客户端最多画8簇，无论里面是8份还是64份。家油寻找目标时才读取这些格，接触动作到点后真实取走一份。不存在每粒絮尘一个实体、每帧生成材料或离线补算。

自动来源只写可达地面散料；满额、无落点或有防护时不产出，不回退为掉落物。不替换家具、不隔墙投放、不强制加载区块。巢内清出的污物同样先找到地面存放位置，找不到就留在巢内。手动按Q丢材料、主动拆坏散料格、背包满时主动收回仍遵循普通物品规则，这些不是自然持续产出的通道。

极小模型对应整格薄选择框；玩家无需瞄准像素。散料没有实体碰撞，不挡家油或行走，建筑方块可替换它，活塞可破坏它；被替换或拆除只退还一次剩余材料。

## 清扫与一劳永逸的预防

| 操作 | 结果 |
| --- | --- |
| 潜行持抹布右键地面或零碎 | 干布也可扫附近3×3可见地面散料和普通零碎，收为废物；卵不在扫地范围 |
| 扫过一个生活区域 | 暂时抑制积尘和新寄居2400tick，约两分钟；真实玩家后来吃饭仍可能重新弄脏 |
| 空手右键散料格 | 查询类型与准确数量；走过去不会自动塞满背包 |
| 空手潜行右键散料格 | 整堆原样收回，适合保留干净材料 |
| 持废物右键原版堆肥桶 | 按原版30%成功率推进堆肥，最终得到骨粉；失败同样消耗该份 |
| 对自然絮窝普通用抹布 | 清走污物、剩食与残壳，保留垫料和卵 |
| 对自然絮窝潜行用抹布 | 拆除絮窝，回收废物并惊扰居民；只损失仍在该窝的未出生卵 |
| 放置家居防护盒 | 无燃料、无电、无损耗，持续保护水平±16格、垂直±8格的方形范围 |

家居防护盒由两锭铁、两张纸和一块任意羊毛合成；获得铁锭解锁。范围内停止自动积尘、自动碎屑、自然建窝和入住，同时暂停新卵形成及现有卵孵化。已有居民、卵和杂物保留；先清扫，再放盒子可长期保持。移走防护盒或迁卵到未受保护的巢后，原卵可继续。空手右键盒子查看范围，较大或多层建筑可放多个。

盒子是普通方块，没有方块实体或ticker。保护范围按维度保存，查询只查附近区块索引；邻区块卸载或服务器重启不会使盒子失效，不用加载保护盒所在区块才能拦截边界处产出。

## 物品的来源与归处

| 物品 | 来源与形态 | 去处 |
| --- | --- | --- |
| 筑巢棉絮 | 有人生活的地面低频积絮；一块羊毛合成六份仅作可选调控入口；线仍兼容巢材 | 家油实际夹取、搬回，每六份组成完整垫料；干净散料可回收，拆过的垫料转废物 |
| 食物碎屑 | 玩家/油库里真实进食残屑，村民余粮处理；一块面包合成四份是可选入口 | 地面散料→实际携带→巢藏食（24份上限）或饥饿家油直接进食；繁殖/孵化也消耗粮；清扫转废物 |
| 家油卵 | 已有成年亲油在真实巢内繁殖，带唯一身份 | 固定卵位→人工取出存箱暂停→放入有效巢续孵；孵化为真实幼体，空壳变脏污/废物，不进入散料堆 |
| 废弃物 | 排泄、清扫、巢内污物、拆除垫料、残壳 | 地面有限堆、玩家主动回收或堆肥；溢出的残壳留作巢内待清污物，不另造无限掉落实体 |

手工控制仍保留：持材料右键干燥地面放一份，潜行最多八份；每格一种类型及组件，不混堆。棉絮/碎食也可直接存入人工家油缝隙，方便定点观察。人工缝隙由两块橡木板和木棍合成，北侧入口需可走并有遮蔽，但它不是自然生态的必需品。

家油白天藏身休息，夜间探头搬运，饥饿时也可白天寻找地面碎食。六份巢材铺窝，亲油整理、照卵；真实携带和库存转移驱动夹起、衔行、放下的演出。口渴、排泄、受惊等生活需求可打断日程。

## 卵与亲代

健康熟悉的成年亲油实际回到巢边、材料与藏食充足时可产生2–4枚卵。每枚卵保存原子代 UUID、双亲、种族与成长参数；右侧四个卵位固定，孵化或取走一枚不会把其他卵挤到新位置。

亲油进入巢内，在照卵动作第26 tick 接触后登记照护，继而侧头倾听。照护温存240 tick，孵化仍要求登记的照护者健康且实际留在卵区附近，并有食物、干净垫料与遮蔽。每600个有效孵化 tick 消耗一份真实碎食。离开、缺粮、过脏、受扰、运输或卸载时暂停，不补算离线进度。

卵在后段间歇晃动、出现裂纹；实际出生使用原 UUID，在卵位进行碰撞检查，出口被占据就等待。相邻出生至少间隔48 tick，空壳在原位停留120 tick，随后收进脏污；脏污已满则尝试放入有限废物堆，没有落点就保留为待清污物。残壳不是可拾取的第二枚卵。摇晃、听卵和残壳的具体演出是原创，不宣称漫画确证了完整自然孵化过程。

## 玩家交互与后果

| 操作 | 结果 |
| --- | --- |
| 持棉絮、线或碎食右键巢 | 普通每次存入一份；棉絮和碎食潜行可存最多八份，分别进入巢材或藏食；达到上限后不再接收 |
| 普通空手右键巢 | 查看巢材、藏食、脏污、卵数与进度 |
| 空手潜行右键巢 | 小心取出一枚真实卵，保留进度；携带或存箱时暂停 |
| 持卵右键完整遮蔽巢 | 有空位和人口余量时放入，继续原卵的进度；允许混合来自不同原巢的卵 |
| 湿布普通清扫巢 | 移除脏污、藏食和残壳并收为废物，家油惊缩后离开受扰巢位；垫料与卵保留但暂停照护 |
| 湿布潜行清扫巢 | 脏污、藏食与垫料收为废物，只损失仍在这处巢内的未出生卵；已移走的卵及已出生幼体不被追溯删除 |
| 破坏巢方块 | 剩余碎食掉出，垫料和脏污转为废物，在巢未出生卵损失；迁出卵及已出生幼体保留 |
| 有效卵掉落后被毁或自然消失 | 核销该卵的未出生状态与人口预留；正常拾取、区块卸载和跨维移动不视为损失 |

卵物品保存可撤销的凭据，世界亲缘账本才是权威。成功放入会使旧凭据失效，复制旧物品不能产生第二只子代。家油记住巢的坐标与身份；原地新放的另一处巢不会自动继承旧家。失巢后实体寻找遮蔽和附近可达的新巢，亲缘继续存在。

## 检查边界

以上物品来源、库存转移、散料堆回收和卵的生死归属由游戏服务端执行。24秒离线演示读取当前模型、贴图与数字关键帧，依次展示日间入巢、夜间搬运、照卵倾听和裂壳出生；为看清动作采用剖面构图并压缩等待时长。它没有运行游戏 AI、招引计时或完整繁殖流程，不能据此判断游戏里六秒就能招引或孵化，也不代替从原料开始的实机验证。

本机只执行导出一致性、资源与差异检查，不编译也不启动游戏。远端 `Build` 编译模组；`Optional P0 GameTest` 的 `house_ecology` 组检查取放卵、旧票失效、存档迁移、清扫和已出生个体的归属边界，并让两只完整 AI 从巢外自行入巢睡眠、接触照卵，再于夜间实际拾取搬运碎食。自然环境场景另覆盖活动积絮与实际入住、村民扣粮与散料预算、防护持久化与清扫静默，以及饥饿家油白天取食时保留携带物。离线分镜与固定场地服务端检查不代替复杂地形、多人画面与连续多代平衡确认。
