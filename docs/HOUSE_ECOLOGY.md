# 家油生态与演出

2026-10-16。家油是微小的室内寄居类型，普通宠物进屋不会变成家油。设定依据是 [家油、巢穴与卵](../wiki/hakkei-reference/lore/house-nest-sources.md)和[资源与生活生态](../wiki/hakkei-reference/world/resources-ecology.md)。夜间碎食、棉絮灰尘巢和卵生沿用整理资料；以下具体容量、时长、合成和破壳分镜是项目适配。

## 一天如何运转

在遮蔽处放置朝北开口的家油缝隙，入口保持可走。碎食来自普通油库里的真实进食残屑，也可用面包合成。夜间有藏食的缝隙最多吸引两只初始家油，每只消耗四份；出生个体另走亲缘账本，不藏在方块内模拟人口。

家油白天钻入左侧棉絮睡位，夜间先探头，再寻找附近实际掉落的碎食或巢材。拾取、夹持、放下分阶段发生，每次只转移一个物品；目标已被同伴取走或粮仓已满时不复制资源。紧急口渴、排泄、温度和饥饿可打断作息。幼体沿用自己的成长和觅食能力，巢内真实休息恢复体力并在醒来结算成长。

一块羊毛可拆为六份筑巢棉絮；棉絮或线用于铺窝，食物碎屑进入独立粮区。纸和小麦不再作为家油巢材，旧存档已铺好的材料量保留。六份巢材铺成完整窝垫，藏食上限24份。亲油会拱絮整理，把一份脏污移成入口外的真实废弃物；食物和巢材仍需外界来源。

## 卵与亲代

健康熟悉的成年亲油实际回到巢边、材料与藏食充足时可产生2–4枚卵。每枚卵保存原子代 UUID、双亲、种族与成长参数；右侧四个卵位固定，孵化或取走一枚不会把其他卵挤到新位置。

亲油进入巢内，在照卵动作第26 tick 接触后登记照护，继而侧头倾听。照护温存240 tick，孵化仍要求登记的照护者健康且实际留在卵区附近，并有食物、干净垫料与遮蔽。每600个有效孵化 tick 消耗一份真实碎食。离开、缺粮、过脏、受扰、运输或卸载时暂停，不补算离线进度。

卵在后段间歇晃动、出现裂纹；实际出生使用原 UUID，在卵位进行碰撞检查，出口被占据就等待。相邻出生至少间隔48 tick，空壳在原位停留120 tick。摇晃、听卵和残壳的具体演出是原创，不宣称漫画确证了完整自然孵化过程。

## 玩家交互与后果

| 操作 | 结果 |
| --- | --- |
| 普通空手右键 | 查看巢材、藏食、脏污、卵数与进度 |
| 空手潜行右键 | 小心取出一枚真实卵，保留进度；携带或存箱时暂停 |
| 持卵右键完整遮蔽巢 | 有空位和人口余量时放入，继续原卵的进度；允许混合来自不同原巢的卵 |
| 湿布普通清扫 | 移除脏污和藏食，家油惊缩后离开受扰巢位；卵保留但暂停照护 |
| 湿布潜行清扫或拆巢 | 只损失仍在这处巢内的未出生卵和垫料；已移走的卵及已出生幼体不被追溯删除 |
| 有效卵掉落后被毁或自然消失 | 核销该卵的未出生状态与人口预留；正常拾取、区块卸载和跨维移动不视为损失 |

卵物品保存可撤销的凭据，世界亲缘账本才是权威。成功放入会使旧凭据失效，复制旧物品不能产生第二只子代。家油记住巢的坐标与身份；原地新放的另一处巢不会自动继承旧家。失巢后实体寻找遮蔽和附近可达的新巢，亲缘继续存在。

## 检查边界

本机只执行导出一致性、资源与差异检查，不编译也不启动游戏。远端 `Build` 编译模组；`Optional P0 GameTest` 的 `house_ecology` 组检查取放卵、旧票失效、存档迁移、清扫和已出生个体的归属边界。离线分镜与服务端检查不代替游戏内路径、多人画面与连续多代平衡确认。
