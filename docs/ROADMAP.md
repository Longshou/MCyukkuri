# 开发路线

本页记录已交付的里程碑。2026-10-08 起，后续开发按[完善计划](DEVELOPMENT_PLAN.md)分步骤推进。

2026-10-16 已重做宠物店、金银章与宠物培育（[PET_SHOP.md](PET_SHOP.md)）：41×16×33 的新商店与店主／考官／饲养员三种店员，铜银金三级徽章与有效期，考官在考场用实体实际行动办理的简易／判定／昇格／更新考试，手帖里的家庭课程与主人反应，餡統、压力、溺爱，繁殖许可与店内相亲，疏忽与弃养，以及徽章社会反应；工厂到商店的出货、走失委托的新店来源和九项进度随后接入。远端构建与 P0 套件通过，实机验收待做（范围见 [PET_SHOP.md §10](PET_SHOP.md#10-实现进度与验证)）。

商店、三类独立工厂与鬼威惨、爱派两种人类 NPC 见 [人类世界](HUMAN_WORLD.md)。已接入宠物油徽章、20 种用品、劳力制纸、馒头与活体袋生产，以及实际亲代／子油育成分流；鬼威惨采用莫西干头。两种[捕食种](PREDATOR_IMPLEMENTATION.md)的飞行捕猎、枝巢、徽章控制和实际商店库存已接入。有限交易、活体交付、走失委托和照顾行为保持可用；工厂到商店的物流已有首版，其他稀有种与村边纠纷仍需后续实现。

八景 U 内容移植计划的 P0–P7 对应下列 M1–M4。P0 专服与多人检查已补齐，P1–P4 核心生活、家庭及家油生态可运行。2026-09-13 已分批接入 P5 身体资源、工具、专用器具与游具；消耗品、普通胎生、日常生态、独立认知及亚种帽船已完成本轮专项和实机检查，P6 事件专项和实机检查也已完成；共同版本构建、36 项 GameTest、专服双客户端和磁盘恢复已通过；默认速度多代生存与长期平衡尚未完成。此前结果见[核心玩法记录](CORE_GAMEPLAY.md)，当前状态见[剩余移植实施记录](PORT_REMAINDER.md)。

资产分类与已有原型见 [项目导航](../PROJECT_MAP.md)。已制作的甩臀、体操、鼓腮、进食、排嗯嗯和互动较量均保留源数据；制作源、游戏接入和实际验收分别登记，具体范围见下文。

## M0：项目基础

- Java 21、NeoForge 1.21.1 固定依赖；实体采用项目内的网格与骨架渲染器。
- 模组入口、物品注册、创造模式分类、中英文本地化。
- 精选模型源文件与 Wiki 纳入版本管理。
- GitHub 自动构建、问题模板与 PR 模板。

## M1：标准种族与家油进入世界

Issue #1、#2 的实体、生成蛋、模型渲染与动画代码及资源已加入。早期单人验收后，本轮已补做专服、双客户端晚加入、区块卸载与正常磁盘重启，相关结果归档在核心玩法记录。详见 [P0 验收记录](P0_VALIDATION.md)和[实体与动画开发记录](ENTITY_IMPLEMENTATION.md)。

- 选定灵梦、魔理沙、橙、爱丽丝、帕秋莉与两种家油，接入方块及连续网格渲染；新种族与长发接地适配见 [种族实装记录](SPECIES_IMPLEMENTATION.md)。
- 七种生成蛋、身体碰撞箱、属性及标准库 19 个动作。
- 后续已增加蕾米莉亚、弗兰，共九种实体与生成蛋；两种捕食种的独立模型、动作与资源检查已通过，造型仍待确认。
- 最终共同版本已补做九种实体状态同步、两客户端晚加入、资源重载及专服磁盘恢复。八套亚种的全部 128 张表情另经实际解码与加载。
- 验收：存档重载保留种族与实体状态，多人看到一致动作。

## M2：最小生活循环

持续生活、分阶段进食、食盆、住所与躲雨、清洁和厕所、自然发现与单体运输已实现。P2 同时加入六种个性、分玩家记忆、有向关系、分食争抢、玩具、饰物和等待学习。

早期核心版本的 79 项生活／社交及 189 项基础实体断言见[核心记录](CORE_GAMEPLAY.md)，当时已验证生活状态、家址、玩家记忆与容器身份。后续日常生态、独立认知与新增资源也已进入共同回归；默认速度多代自然生存与长期平衡仍待验。

## M3：成长与家庭

- 已实现成长阶段、亲属记录、普通种茎生与胎生、家油巢卵、幼体跟随、亲代等待和分食；[普通胎生](CONSUMABLES_AND_BIRTH.md)保留固定胎次、亚种与真实双亲身份。
- 本地种群含未加载个体与未出生预留；已有引擎检查与 20／50／100 实体短时采样。
- 茎生最后一只子油真实生成后，等待实子实际落地／落帽或明确终止，茎才从根部自动脱落并生成物品“油库里的茎”。2026-10-16 已接入持久等待与投递记录、普通食物与原创制窝材料用途；剪茎培养不额外掉落，游戏内确认待完成。制作与来源见[家庭生长与茎生](../art/props/family-life/README.md#自然脱茎物品2026-10-16)。
- 设定与数值可配置，分别记录 Wiki 来源与游戏设计决定。
- 验收：控制种群上限，测试多个群体的寻路和服务器 tick 开销。

## M4：世界与图鉴

已增加流浪个体、小型家庭、森林聚落（有／无帕秋莉族长）的自然发现、持久群体登记、返家集合与有限野草采食。实现边界、来源和检查见[群落记录](SETTLEMENTS.md)；季节迁徙、公共粮仓与长时生态平衡仍未完成。

- 七类连续遭遇与 41 张情景卡、帽船、冷冻收容、观察图鉴与进度已接入；具体行为和实机证据见[本轮交付](PORT_REMAINDER.md)。
- Patchouli 图鉴、Jade 状态显示、农夫乐事食物适配仍是可选兼容计划，尚未接入。
- 可选季节和群系集成仍待评估；根据实机测试决定依赖版本。
- 生存玩法、生态观测、平衡与体验打磨。
