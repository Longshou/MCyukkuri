# 开发路线

资产分类与已有原型见 [项目导航](../PROJECT_MAP.md) 和 [动作资料库](../art/library/README.md)。已制作的甩臀、体操、鼓腮、进食、排嗯嗯和互动较量均保留源数据；以下实体接入与生态阶段尚不能视为已完成。

## M0：项目基础

- Java 21、NeoForge 1.21.1、GeckoLib 4 固定依赖。
- 模组入口、物品注册、创造模式分类、中英文本地化。
- 精选模型源文件与 Wiki 纳入版本管理。
- GitHub 自动构建、问题模板与 PR 模板。

## M1：两种油库里进入世界

Issue #1、#2 的实体、生成蛋、模型渲染与动画代码及资源已加入，编译和实机验收待完成。Issue #3 的存档重载、多人同步与移动场景验证仍未完成，见[实体与动画开发记录](ENTITY_IMPLEMENTATION.md)。

- 从当前选定的灵梦、魔理沙基础模型接入 GeckoLib 实体渲染。
- 生成蛋、碰撞箱、属性、基础移动与待机动作。
- 验收：两种实体可生成，客户端无缺失贴图，专用服务器可加载。
- 验收：存档重载保留种族与实体状态，多人看到一致动作。

## M2：最小生活循环

- 饥饿、觅食、进食、休息、巢穴记忆、躲雨。
- 食物分类使用数据包标签，先支持原版食物，再适配农夫乐事。
- 验收：服务器驱动状态；离开并重进世界后巢穴和饥饿值仍正确。

## M3：成长与家庭

- 成长阶段、亲属关系、种族差异、繁殖、家庭与群体行为。
- 茎生出生时，茎从根部自动脱落，在 Minecraft 中生成物品“油库里的茎”。当前仅记录设定，根部脱落与物品生成均暂不实现；见[茎生说明](../standards/yukkuri-v1/LIFECYCLE.md)。
- 设定与数值可配置，分别记录 Wiki 来源与游戏设计决定。
- 验收：控制种群上限，测试多个群体的寻路和服务器 tick 开销。

## M4：世界与图鉴

- Patchouli 图鉴、Jade 状态显示、农夫乐事食物适配。
- 可选季节和群系集成；根据实机测试决定依赖版本。
- 生存玩法、生态观测、平衡与体验打磨。

每个里程碑拆为 GitHub Issues，以具体验收条件推进；后续阶段不代表当前已实现。
