# 行为与成长

本页说明个体属性、关系、成长、遗传与技能规则。默认速度下，个体应在真实食物与住所条件下跨多代大致稳定；试玩进度见[待办](TODO.md)。

普通个体营养低于30时，即使未发现粮源也立即进入 `forage_seek`，实际走动并周期搜索；扫描预算只限制扫描，不延迟搜索状态，空粮搜索不按20秒强制退出。营养低于20时搜索移速为普通移动的1.12倍，停步寻找时表现焦急；手持食物吸引使用 `seek_food`，不再显示 idle。发现真实粮源后交接取食，搜不到仍会消耗并承受饥饿，不能只显示搜索状态。普通闲逛以 `roam` 显示；对撞停滞时尝试侧向路径，保留原目的地，无法通过则结束本次路径后重新选择，并记录阻塞。

## 属性与关系

`social/YukkuriPersonality` 拥有五项 0～100 的行为属性。有效值由先天值与后天经历组成，后天修正最多 ±20；真实完成的经历累计满 8 单位才增加 1 点。观察、动画和重复使用已学技能不增加经历。

| 属性 | 作用 |
| --- | --- |
| 智力 | 学习、食物与失饰辨识 |
| 友善 | 分享、照护、帮助、救援、保护；低值更可能升级冲突 |
| 胆量 | 探索范围、陌生接触和危险退避距离 |
| 依恋 | 寻伴、随亲与分离后的陪伴需求 |
| 自制 | 已学规则的遵守、等待、练习段数和冲突克制 |

友善主导喂养、照护与救援，依恋不增加这些意愿；依恋影响陪伴、随亲和关系维持。高亲近和高恐惧可以并存，善待只降低对应对象的恐惧。智力不决定亲近或善恶，胆量不使不可达路径可达，自制不打断已经开始的动作。五属性取代认知分、四科培养分、环境友善度、溺爱及独立的攻击、利己、好奇数值。

活动范围（项目设计）：`TravelRange` 管理普通远行的双倍距离及赤油边界；地面导航单次搜索预算为 64 格，不改攻击、接触、听觉或真实热源作用距离。陆地食物／照料设施搜索由 8→16 格，饮水 6→12 格，草料基础搜索 6→12 格，避雨 16→32 格；找现成住所 12→24 格、找新洞位 8→16 格，搬家与流浪搜索也扩大。家庭觅食父油基础／上限 48／192 格、母油 20／128 格，仍乘胆量系数，行程时限同步加倍；迁徙保留配置下限、选址上限为配置值的两倍。捕食、枝巢、寻宝、冷热避险、家油物资搜索，以及水生找岸／漂浮物与自主划船范围同步扩大，帽船局部路径范围 24 格；各自真实能力、亲子距离、资源、已加载区块与碰撞约束仍有效。

赤油的平静自主活动最多到有效巢附近 3 格；闲逛取点有 80% 优先留在可用天然巢内，人工巢以内侧有顶位置承接此偏好。真实危险、亲代搬运与家庭迁徙允许既有交接，不用巢边限制把赤油锁死。普通闲逛半径为 `20×胆量探索系数`（中性 20 格）；符合条件的[子油魔理沙探险](WILD_EVENTS_IMPLEMENTATION.md#补充群体事件)使用同一个基准的两倍。状态、逐项复测与演出缺口见[待办](TODO.md#玩法待办)。

`life/YukkuriWorldData` 保存有方向的对象关系：每个玩家、人类 NPC 或油库里分别记录亲近度（−100～100）、恐惧（0～100）和最近互动时间。每只个体最多保留 64 条关系，主人和活动对象受保护；满额时优先遗忘最久未互动的弱关系。未加载不等于死亡，关系遗忘不删家谱或所有权。

压力只有 `mind/MindLife.unease` 一个权威值。恐惧 0～29 为正常、30～59 为谨慎、60 以上为害怕，回退使用 5 点回差。喂食、温和交流、清洗、受击及饰物交接会按真实结果更新关系；具体变化由领域行为结算。等待、使用食盆、定点如厕、按时就寝、识字和基础算术技能保存在 `YukkuriPet.KnownSkills`。后天属性修正、技能、关系、压力与父母徽章不遗传；五项先天属性按下文规则遗传，馅统只记录父母徽章。

## 成长时钟、阶段与体型

每游戏日为 24,000 个模拟 tick。年龄仅在个体已加载、存活且正常更新时推进；暂停、收纳、冻结、未加载和改世界日期均不补算。

| 阶段 | 年龄 | 时长与资格 |
| --- | --- | --- |
| 赤油 | `0 ≤ age < 72,000` | 3 天，需要早期照护 |
| 子油 | `72,000 ≤ age < 216,000` | 6 天，逐步自主进食和行动 |
| 亚成油 | `216,000 ≤ age < 336,000` | 5 天，达到独立生活年龄，不能繁殖 |
| 成油 | `336,000 ≤ age < 1,056,000` | 30 天，取得繁殖资格 |
| 老年 | `948,000 ≤ age < 1,056,000` | 成油期最后 15%，停止新繁殖 |

总寿命为 44 游戏日。内部阶段只保存 `BABY`、`JUVENILE`、`ADULT`；亚成油由年龄区间导出。胎生和卵生从年龄 0 开始；茎生在茎上完成赤油阶段，落地从 72,000 tick 开始；自然家庭生成的孩子从 144,000 tick 开始。`mcyukkuri-family.toml` 的 `aging=false` 可关闭自然寿终。

`GrowthSize` 每 100 tick 按连续营养曲线尝试更新体型，营养至少 35 才尝试扩体；年龄阶段仍按时推进，营养、伤势和空间只影响体型及实际能力，不把阶段资格卡住。体型不倒退，条件恢复后继续成长。

### 体型规范

以下为项目美术与运行适配值，以普通成体为 1.00，不含饰物；这些比例不是八景原文的厘米换算。

| 类型 | 赤体／幼体 | 子体 | 成体 |
| --- | --- | --- | --- |
| 普通种 | `0.10～0.20` | `0.20～0.80` | `0.80～1.20`，标准值 `1.00` |
| 家油（相对家油成体） | `0.32～0.50` | `0.50～0.80` | `0.80～1.00` |

胎生新生为 `0.14`；茎上实子从 `0.10` 长至 `0.20`，孕程 0.15 起显现、0.95 长足；茎生落地为 `0.20` 子体，家油卵生为家油成体比例 `0.32`。普通大体型成体不会自动成为 DOS。移动速度按成长比例变化：赤体为成体的 `0.45～0.55`，子体从赤体上限线性升至 `1.00`；亚种、伤病和动作另有修正。

## 灵胖：成年时的一次判定

灵胖仅适用于普通灵梦和多毛灵梦：亚成期间营养 ≥75 且压力 ≥70 连续维持一个已加载游戏日，并在 336,000 tick 成年边界仍达标，才锁定灵胖；中途未达标即清零，成年后不补判。换体型只在短动作结束或安全接缝后尝试，附近无安全可达位置时最多重试三次；失败不瞬移或反复判定。

## 遗传、特殊形态与胎数

子代用固定 UUID 种子只生成一次五轴先天值。已知亲本分别映射到合法区间的归一化位置，取均值并加 −10%～+10% 扰动，再映射到子代区间；未知双亲使用区间中点。特殊形态边界为：

| 形态 | 属性边界 |
| --- | --- |
| 普通 | 五轴均为 0～100 |
| 不足油 | 智力 0～25、友善 75～100，其余正常 |
| 多毛灵梦 `WASA_REIMU` | 友善 0～25、依恋 75～100、自制 0～25，其余正常 |

后天变化不能越过形态边界；不足油可学习但智力不超过 25，多毛可改善自制但不超过 25。灵胖不使用不足油边界。特殊形态出生规则见[亚种与先天形态](SUBSPECIES_IMPLEMENTATION.md)。

`family.offspringSizeInfluence` 默认 `0.70`、范围 `0～4`。普通茎生、胎生和辅助繁育按成年目标体型计算四次独立抽取：

```text
p = clamp(0.15 + c × x + (0.70 − c) × 0.5, 0, 1)
胎数 = 1 + 四次成功数（1～5）
```

`x` 为母体成年目标体型 `0.8～1.2` 的归一化值，`c` 为配置；`c=0` 时不计体型差异。家油仍独立按 2～4 枚卵生成；胎次一经确定不重抽。

## 认知、技能与教学

`cognition/Cognition` 只读取五轴智力。未知技能只在真实完成时抽取一次：

```text
学习成功率 = clamp(0.15 + 0.0075 × 智力 − min(0.15, 0.003 × max(压力 − 30, 0)), 0.05, 0.95)
食物辨识率 = clamp(0.35 + 0.006 × 智力, 0.35, 0.95)
```

首次学会技能增加 8 单位智力经历；食盆、如厕、就寝在真实生活事件完成时结算，课程技能在课程结束时结算。拒绝、中断和失效不记为完成。互教要求同世界、双方可学、非紧急、未进食、四格内双向可见、非敌对且教师智力较高；教师是否主动发起受友善的帮助概率影响。野外 `teach` 卡须有真实课堂、成员顺序、来源和三次回应才确认示范，不额外生成通用认知分。失饰辨识由智力决定，普通观察者需达到 80；水生种例外。不足油能听、看、进食和学习动作，但不能口读、口算或面谈。

一次真实选择只在机会开始时抽取。资格、资源、路径和身体条件先判定；已开始的进食、排便、教学、亲昵、游具、上船、送食与家庭短动作按真实完成点推进，普通属性波动不会逐 tick 抢占。火灾、溺水、追击、濒死及营养或精力低于 15 等急迫情况可以中断，未完成不结算成功。

| 行为 | 规则 |
| --- | --- |
| 帮助、照料与救援 | `clamp(0.10 + 0.008×友善 + 关系加成[−0.10,+0.10] + 紧急0.10, 0.05, 0.95)`；依恋不加分 |
| 陪伴 | `clamp(0.10 + 0.008×依恋, 0.10, 0.90)`；只在有可接近且非恐惧同伴时参与选择 |
| 已学规则遵守 | 自制 0／20／50／70／80 对应 40%／65%／90%／98%／100%，区间线性插值 |
| 等待与练习 | 等待 `round((1 + 0.1×自制)×20)` tick；练习段数 `min(5, 1 + floor(自制/25))` |
| 探索与退避 | 探索倍率 `0.50 + 0.01×胆量`；退避距离 `max(0, 9 − 0.05×胆量 + 0.05×max(恐惧−30, 0))` |

普通油库里受同类实际攻击、推搡或抢夺时，以自己的胆量、对攻击者的恐惧、双方体型和种族力量、当前血量与精力选择反击或逃跑；欺负者被反击时用同一规则重新判断【项目设计】。生命不高于 40%、虚弱、中枢受损、营养或精力低于 15，或遇到火水危险时必须退避；低血量不能因高胆量继续反击。其余情况用 `胆量 − 0.5×对象恐惧 + 35×clamp(自身战力/对方战力 − 1, −1, 1)` 评分，至少 50 才反击，战力按身体宽度、种族力量、生命比例和精力比例相乘。实际反击仍需走近、视线和命中；不能以反击决定直接扣血或锁住对方。妖梦与捕食种沿用各自专属战斗流程。

`social/PeerDefense` 由群体交互组件管理，`behavior.group_session` 显示最近选择、分数和目标；显示中的 `self_defense` 只来自实际运行的反击 Goal。服务端 `[social]` 记录选择、交接、实际命中与结束，玩法验收见[头饰待办](TODO.md)。
