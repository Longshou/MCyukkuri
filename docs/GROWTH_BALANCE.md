# 成长与寿命调整

2026-09-13。用户要求显著延长寿命，成长节奏参考 Minecraft 小牛、小羊。当前代码将幼年成长与成年寿命分别配置，取代总寿命三分之一才成熟的旧比例。性格改版（四项倾向）和灵胖转变后来已在代码中实现（`social/YukkuriPersonality`、`subspecies/SubspeciesLife`），说明见 [性格设计](PERSONALITY_DESIGN.md) 与 [灵胖成长转变](../wiki/reimu-deibu-development.md)。

## 时间设定

本机 Minecraft Java 1.21.1 开发源码中，`AgeableMob.BABY_START_AGE = -24000`，幼体随实际 tick 将年龄加到零；`Animal` 的喂食分支可推进幼体年龄。牛和羊沿用这个基础年龄机制。24,000 tick 在 20 TPS 下为 20 分钟。这里仅参考原版成长节奏，没有照搬喂一次食物立刻加速成长的规则。

| 阶段或参数 | 默认时间 | 行为 |
| --- | --- | --- |
| 赤体阶段 | 从出生到约10分钟，12,000 tick | 营养积累合格后，睡醒检查进入子体 |
| 成熟门槛 `maturityTicks` | 从出生累计约40分钟，48,000 tick | 超过年龄门槛，营养积累达到36,000，当前营养至少35，睡醒且有空间时成为成体 |
| 成体体型继续长足 | 营养积累从48,000到72,000 | 由0.8倍长到各自成年目标尺寸；营养持续充足时约再20分钟，仍在睡醒时更新 |
| 成年时段 `adultLifespanTicks` | 30小时，2,160,000 tick | 从成熟年龄门槛到自然寿终；正常个体总寿命约30小时40分钟 |
| 老年 | 成年时段最后15%，约4.5小时 | 沿用原有老年限制，不再参与繁育 |

这些时间只累计实体已加载、存活且正常更新的 tick。暂停、卸载、运输收纳期间不补算，改变昼夜时间也不直接长大。30小时成年时段相当于约90个原版昼夜；这是为了让玩家经历多次照顾、训练和家庭互动而选用的项目初始平衡值，并非原作寿命。

自然生成成体的成长时间与成年时段使用同一组±5%个体差异，从自身成熟门槛后开始计龄。子代继承双亲这两个时钟的平均值再浮动±5%；无已知父方的辅助繁育沿用母方。茎生子代脱茎直接进入子体的既有规则保留，因此不另外补一个赤体阶段。

成熟依旧受营养、睡眠与碰撞空间影响。营养不良会延迟成熟，但寿命时钟仍然推进；“成年后30小时”是正常成长的目标时段，并不为晚熟个体重新赠送30小时。饥饿、感染与伤害仍可造成提前死亡。

## 体型规范

2026-10-15。用户看接生预览，觉得子油偏大，要求给出各成长阶段的大小规范，数值由项目决定，以动作自然为准。大小以标准成体为 1（宽 0.8 格）；唯一的现实尺度是用户设定的“普通成体篮球大小”（宽约 24 cm），下表厘米据此换算，均为原创参考，不是原作数值。

| 阶段 | 大小 | 约合 | 说明 |
| --- | --- | --- | --- |
| 茎上实子 | 0.10 → 0.20 | 2.4 → 4.8 cm | 在茎上完成赤体期，随孕程长大，0.15 起可见 |
| 胎生新生（赤体） | 出生 0.14 | 约 3.4 cm | 比乒乓球略小（原为 0.18） |
| 赤体 | 0.14 → 0.20 | 至约 4.8 cm | 胎生出生后的头约 10 分钟 |
| 茎生落地（子体） | 出生 0.20 | 约 4.8 cm | 落地即子体（八景设定），比胎生新生略大（原为 0.30） |
| 子体 | 0.20 → 0.80 | 至约 19 cm | 营养决定快慢 |
| 成体 | 0.80 → 个体目标 0.80–1.20 | 19–29 cm | 篮球大小；不变 |
| 灵胖 | 成体 × 1.5 | — | 不变 |
| 家油（相对家油成体） | 卵生 0.32 → 0.50 → 0.80 → 1 | — | 家油成体约等于普通赤体大小；数值不变 |

关系：

- 新生宽约为标准母体的 1/7，满孕母体的 1/10。
- 倒放的帽子内腔能并排坐下 5 只胎生新生，茎生 3 只也不挤；每只按身体大小各占一处，彼此留出约一成空隙。

**成长曲线**：大小只由营养积累决定，按成熟时间 M 分段线性；阶段只决定上限，体型只增不减。

| 营养积累 | 大小 |
| --- | --- |
| 0 → M/4 | 0.14 → 0.20 |
| M/4 → M | 0.20 → 0.80 |
| M → 1.5M | 0.80 → 个体目标 |

- 赤体最多 0.20，子体最多 0.80，成体至少 0.80。
- 茎生落地的 0.20 子体会停在原大小，等营养曲线追上再长，所以阶段切换时不再突然变大（此前赤体→子体会从 0.30 跳到约 0.43）。
- 聚落生成的子体按自身营养从曲线取值，不再固定为 0.40。
- 已存档个体保留现有大小，之后按新曲线继续长。

茎长随之按子油数量拟合，见[家庭生长与茎生](../art/props/family-life/README.md)。

单一来源是 `standards/yukkuri-v1/profiles/growth.json`，由 `scripts/export_family_assets.py` 导出到 `yukkuri_presentation/family.json` 的 `growth`。游戏由 `family/GrowthSize` 读取；出生场景预览和[帽子容器](../standards/yukkuri-library/interactions/marisa-hat-vessel/README.md)的站位计算也读同一份。对照见世界观动作预览（由 `standards/yukkuri-library/motions/variants/lore/births.py` 在本机生成，不入库）的“体型规范”场景。旧 v1 胎生原型（`standards/yukkuri-v1/behaviors/viviparous-birth.json`）仍按 0.18 绘制，未随本次更新。

## 配置与旧档

服务器配置文件名仍为 `mcyukkuri-family.toml`，由 NeoForge 的 SERVER 配置管理。新增 `maturityTicks` 与 `adultLifespanTicks`，旧键 `lifespanTicks` 不再用于计算；原世界加载时会生成新键默认值。后续更改新键影响新初始化个体，不反复改写已经保存的个体时钟。保留 `aging=false` 可关闭自然寿终。

个体家庭 NBT 与家庭世界记录升级到版本2，保存独立 `Maturity`。版本1首次读取时：

- 以旧寿命相对72,000的比例保留个体差异，换算新的成长时间和成年时段。旧自定义寿命的相同比例也参与迁移；希望改变节奏时可先配置新的两个键。
- 幼体保留已经走过的成长比例；成体保留已经消耗的成年时段比例。营养积累按成长时间比例换算。
- 保留 UUID、生命阶段、外观尺寸、亲缘、胎次与先天亚种。已到寿命终点的个体不会因换算而复活。
- 未出生子代同样迁移其预留时钟；脱离母体但仍由家庭记录保存的胎次走同一流程。
- 版本2重复读取不再次延寿。收纳中的旧个体在恢复读取时迁移。

工厂幼体转出门槛改为引用成熟年龄，避免延长成年寿命后把育幼阶段错误拖到数小时。孕期、繁殖恢复、人口上限本次未调整；较长寿命会使群落更容易触及已有数量上限，这部分需要长期游玩平衡。

## 母体大小与胎数配置（2026-10-16）

服务器配置 `mcyukkuri-family.toml` 的 `[family]` 新增 `offspringSizeInfluence`，默认0.70，允许0–4。母体大小影响胎数、胎数影响茎长和粗细的依据见 [Wiki 基本设定](../wiki/hakkei-reference/world/rules.md)；该页没有给出系数，本项概率、范围和默认值均是项目原创平衡值。

普通茎生、胎生及已有辅助繁育使用同一抽取方法：将母体的成年目标体型0.8–1.2归一化为 `x`（钳制0–1），以 `p = clamp(0.15 + c*x + (0.70-c)/2, 0, 1)` 进行四次独立抽取，胎数等于1加成功次数，始终为1–5只。默认 `c=0.70` 时严格保留旧概率运算和同一seed的四次抽数；家油卵另有2–4枚的既有逻辑，不受该项配置影响。

| 体型影响 `c` | 小母体0.8：平均胎数 | 标准母体1.0：平均胎数 | 大母体1.2：平均胎数 |
| --- | --- | --- | --- |
| 0 | 3 | 3 | 3 |
| 0.70（默认） | 约1.6 | 约3 | 约4.4 |
| 1.4 | 1 | 约3 | 5 |

配置0关闭体型差异；增大配置扩大标准体型两侧的差异，达到概率边界后不再增加。这里使用成年目标体型，不是渲染帧的当前缩放。配置在新受孕或辅助繁育抽数时读取，已保存胎次的子油数量不重抽；茎继续沿用已有按胎数和个体差异拟合的长度与粗细。

母体体型公式、默认 seed 兼容及数量边界已完成数学核对，并在服务端受控场景核对关闭差异、增强差异和极端配置。不同母体在自然游戏中的胎数分布、茎显示与服务器配置体验仍待确认；家庭整合状态另见[完善计划](DEVELOPMENT_PLAN.md)。

## 验证

运行 `scripts/growth_checks.init.gradle` 和 `scripts/run_growth_checks.py`，输出隔离在 `.local/deibu-life-design/`。包含新版成长／迁移、既有家庭行为、消耗品与胎生七项 GameTest。

没有连续挂机30小时，也没有执行新版客户端、多人或用户世界升级验收；边界时刻通过受控设置年龄后调用真实游戏逻辑检查，睡眠、成长和出生另由实际引擎 tick 验证。
