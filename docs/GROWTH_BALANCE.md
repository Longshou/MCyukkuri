# 成长与寿命

实现状态：**已接入待试玩**。固定时钟、阶段资格和体型发育的目标规则见[行为数值与成长设计](BEHAVIOR_BALANCE_DESIGN.md)；本页记录当前代码的单一口径。

## 固定加载时钟

年龄只在实体已加载、存活且正常更新的 tick 增加。暂停、未加载、收纳、冻结、睡眠跳夜和改世界日期都不补算。营养、伤势、睡眠和碰撞不会延后阶段资格。

| 阶段 | 年龄区间 | 时长 |
| --- | --- | ---: |
| 赤油 | `0 ≤ age < 72,000` | 3游戏天 |
| 子油 | `72,000 ≤ age < 216,000` | 6游戏天 |
| 亚成油 | `216,000 ≤ age < 336,000` | 5游戏天 |
| 成油 | `336,000 ≤ age < 1,056,000` | 30游戏天 |
| 老年 | `948,000 ≤ age < 1,056,000` | 成油期最后15% |

总寿命为44游戏天（20 TPS 下14小时40分），成年年龄固定为336,000 tick。老年停止新的繁殖资格，但可在身体允许时继续生活、照料、学习和社交。

内部保存的阶段枚举仍是 `BABY`、`JUVENILE`、`ADULT`；216,000～335,999 tick 通过 `FamilyLife.subadult()` 作为亚成资格，不另存一份平行阶段状态。`growth.stage` 会将该区间显示为 `subadult`。

胎生和卵生从年龄0开始；茎生在茎上完成赤油期，落地从72,000 tick 的子油起点继续。自然家庭生成的孩子初始化到子油期中段（144,000 tick）且已有相应营养成长；试玩和状态工具写入的是实际年龄，不是单独的阶段标签。

## 阶段、体型和能力

`FamilyLife` 每 tick 推进年龄，并按固定边界更新阶段；每100 tick 才尝试按营养更新体型。营养不足、伤势或扩体碰撞不阻止赤油、子油、亚成和成年资格按时到达，只会保留较小体型和对应移动能力，待条件允许后再继续长大。

体型沿 `GrowthSize` 的连续营养曲线增长且不倒退，阶段仅限制当前可达到的上限。当前营养至少35才尝试扩体；碰撞不足时不强行挤开方块或实体。`growth.growth_percent` 仍可反映营养发育进度，`growth.stage_left_ticks` 只显示到下一个固定年龄边界的已加载 tick。

独立进食、分床和离巢仍检查真实生活能力。亚成在年龄上已有独立资格；营养和已完成的进食、首便、爬行／起跳等能力决定她是否仍需要随亲照护。成年才取得繁殖资格。

## 保存与配置

家庭 NBT 保存 `Age`、营养、体型和其他家庭状态；加载时用固定时间边界重新导出阶段。`GrowthTiming` 是成长和寿命的唯一数值来源，不再提供 `maturityTicks` 或 `adultLifespanTicks` 配置项。`mcyukkuri-family.toml` 的 `aging=false` 仍可关闭自然寿终。

## 母体大小与胎数

`mcyukkuri-family.toml` 的 `family.offspringSizeInfluence` 默认0.70，范围0～4。普通茎生、胎生和辅助繁育以母体成年目标体型0.8～1.2归一化为 `x`，进行四次独立抽取：

`p = clamp(0.15 + c*x + (0.70-c)/2, 0, 1)`

胎数为1加成功次数，范围1～5。配置0关闭体型差异；家油卵生的2～4枚规则独立。胎数在受孕或辅助繁育时确定，已保存的胎次不会重抽。

## 试玩

在试玩场的 `growth` 场景清空后重开，查看 `growth.stage`、`growth.age_ticks`、`growth.stage_left_ticks`、`growth.growth_percent`、`growth.scale` 与 `growth.elder`。验证时分别观察年龄跨过72,000、216,000、336,000、948,000边界，以及低营养或狭窄空间下阶段仍按时切换、体型随后恢复生长。CI只编译；最终以用户在游戏内试玩为准。
