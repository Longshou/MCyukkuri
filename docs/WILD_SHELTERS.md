# 野外住所与生活环境

野外油库里只利用现成洞穴、岩土凹处和土坑，搬来零散叶子、草和细枝布置睡窝。洞口几根枝条被它们称为“结界”，没有承重、挡雨或防御能力。流浪油使用人类遗留的纸箱。此前的整座覆土工事方案已被用户否定，当前实现已撤掉其外壳、拱框、绑绳及建造配方。

## 认领现成地形

`NaturalShelter` 勘测已加载地形，不挖土、不堆土、不造洞顶。当前识别低洞顶及附近有岩土／原木岸壁的凹处，沿同一高度的可站立地面收集睡位，浅坑另记录高一格的坑沿出口；一次最多登记十六格，每格一个睡位。露天坑按周围岸壁判断，可有多个睡位。水、实心障碍、其他住所已登记睡位均不能作为新床位。此处判断的是现有方块材料与空间，无法区分自然生成与玩家以前放置的同材质地形。

正式认领只在洞口内侧放一个无碰撞的住所核心，保存床位、库存及状态；叶床按实际睡位绘制，细枝靠向入口旁的现有洞壁；封闭浅坑则在坑沿横放细枝。洞顶、洞壁与坑底始终是原来的 Minecraft 地形。拆掉睡窝只移除核心和有限物资，保留地形。旧版覆土多方块的外围部件在加载后的计划 tick 清理；缺少天然床位登记的旧核心释放库存后移除，不把旧工事当作天然洞穴。

初始家庭仍为 2～7 只，森林聚落仍为 6～12 户及可选帕秋莉族长。生成器在中心附近先为所有家庭找到容量足够且可达的现成住所，再加入成员；不再要求首户恰好位于种子脚下。没有足够洞穴就取消本次成组遭遇，保留原有独居种子，不缩减为固定三口之家，也不凭空施工。之后个体仍可寻找可用住所或认领附近现成凹处。

人类村庄附近的独居遭遇可带有人类遗留纸箱；其他野地不凭空出现纸箱。玩家放置的纸箱也可被认领。纸箱仍使用实体外壳和单人睡位，其制造与放置属于玩家行为。森林工事材料包已从合成与创造页撤下，旧物品 ID 仅保留存档兼容，使用时仍须通过天然地形检查。

## 搬运与维护

- 树叶物品、短草、纸和小麦可作为四层有限垫料；木棍只增加或整理至多三根结界枝。油库里不能用纸修复纸箱外壳。
- 住户拾取附近实际掉落的材料或食物，每次携带一份。可采一株低矮短草作补充垫料或存粮，不砍树、拆洞壁、搬整块泥土。现阶段没有落叶自然再生系统；叶类材料来自实际物品投入或掉落。
- 库存最多三十二份、九个槽；取食、咀嚼、分食和清理继续转移真实物品。脏垫料更换消耗新材料，排泄物搬到洞外，不直接删除或复制。
- 自然遭遇表示已在此生活的住户，初始化有限垫料、少量枝条和短草库存；自主新认领的空洞没有免费库存，需要自行收集。`mobGriefing` 关闭时不自主放置住所核心或收集、搬动环境物资。
- 住址、实际床位、亲缘、枝条、垫料、库存和携带物写入存档。不同家庭不能重复登记同一片床位，未出生幼体也占用预留名额。

## 天气、休息与繁殖

挡雨由上方实际方块高度判断，结界与叶床不提供遮蔽。晴天可以在已认领的露天土坑睡觉；降雨会打断露天睡眠，住户寻找可达的真实遮蔽。洞顶拆除后立即重新判断挡雨。积水、过湿或过脏的床位不可用。

每一百 tick 检查一次住所状态：露天叶床雨淋潮湿增加八，露天纸箱增加七，干燥时下降四。潮湿达到六十后加快食物腐坏，纸箱损坏、枝条变乱；达到七十五后逐渐损失垫料。三个以上干燥垫料可减轻寒冷，树枝结界完好度不影响天然洞穴的承重或叶床保温。寒冷且湿润时仍有冻伤风险。

繁殖同时检查实际床位、既有住户、未出生预留、垫料、湿度、卫生和总人口预算。纸箱另需箱体完好；天然洞穴不把枝条完好度当作洞壁强度。观察笔记和空手查看可见住所状态与露天／有顶区别。

## 验证与边界

模型制作与选用见[素材包](../standards/yukkuri-library/ecology/wild-shelters/README.md)，天然洞穴叶床、细枝结界及浅坑布置已于 2026-09-13 经用户确认；纸箱和便所造型仍待确认。

勘测暂限同层床位、近处岸壁和低洞顶入口，尚未覆盖大型高顶山洞、超过一格的入口高差及完整地下洞系。聚落不会整体迁址，未实现季节性落叶与材料再生。自然世界的合适地形密度、长期成群遭遇率和多人生态平衡仍需游玩验收；预置地形的引擎检查不代表这些项目已完成。
