# 基础生活与饲养操作

玩家与油库里最基本的交互：发现、观察、喂食、安置、运输、冷冻收容、清洁、交流和繁殖入口，以及生活数值的推进规则和服务端配置。家油、伤病、成长、宠物店等其余专题见[文档索引](README.md)。

代码：生活与设施 `life/`，人格与行为 `social/`，工具物品 `item/`，家庭与成长 `family/`，冷冻与观察手册 `freezer/`、`notebook/`。配方以 `src/main/resources/data/mcyukkuri/recipe/` 为准。

## 玩家操作

| 目标 | 操作与结果 |
| --- | --- |
| 发现个体 | 普通种在已配置的平原、森林、草甸等干燥草地自然生成，受光照、原版生成规则和局部上限约束。家油不自然生成，见[家油生态](HOUSE_ECOLOGY.md) |
| 观察 | 观察笔记（`field_notebook`）右键个体看状态页，对空气使用看指南 |
| 喂食 | 手持食物右键，或把食物丢在干燥可达的地面；一次取一件，含住、咀嚼、吞咽后才增加营养和生命 |
| 食盆 | 右键打开九格库存。实际库存决定盆内显示；耗尽后寻找其他食源，取食遵守 `mobGriefing` |
| 安置 | 放草窝，用笔记右键草窝选位置，再潜行右键个体登记；每窝一名住户。个体也会自己寻找可达遮蔽，野外住所见[野外住所](WILD_SHELTERS.md) |
| 运输 | 携带箱右键收纳单只，右键有安全空间的方块放出；身份和生活数据保留，放置失败时个体留在箱内 |
| 冷冻收容 | 运输篮对活体收纳，再将满篮交给冷冻柜存入个人收容库；空篮可取回最早存入的原个体，详情见[冷冻收容](#冷冻收容与观察手册) |
| 清洗与清扫 | 湿布对水源补水，右键个体清洗；对沙厕使用清出积存排泄物。满厕不再接收，没有可用厕所时会在地面排泄 |
| 说话 | 空手右键温柔说话；潜行空手右键打开照料菜单，在“说话”页选择温柔说话、冷淡说话等预设互动。信任、恐惧和冷却按玩家分别记录；普通聊天栏文字不作为语言互动输入 |
| 玩具 | 丢下毛线球，感兴趣且没有紧迫需求的个体会接近、探看并轻推 |
| 饰物 | 潜行持剪刀右键取下饰物，持取下的饰物右键原主人归还。失饰后果见[头饰](HEADWEAR.md) |
| 学习 | 信任足够、恐惧较低时持教学哨右键上课，学会短时等待；规则见[认知](BEHAVIOR_BALANCE_DESIGN.md#认知技能与教学) |
| 介绍配对 | 同伴绳把附近两只合格成体介绍认识，不直接加好感或立即产生子代。普通种在健康、饱食、互相认识且住所邻近时自行配对孕育，见[成体发情期](ADULT_AGITATION.md)与[消耗品与胎生](CONSUMABLES_AND_BIRTH.md) |
| 伤病与遗体 | 橙汁治伤、面粉糊去疤、草药治感染；死亡留下遗体，可搬运和安葬，见[受伤与遗体](INJURIES_AND_REMAINS.md) |

饰物、排泄物、絮尘等只来自实际生活过程，没有凭空产出的配方。

## 冷冻收容与观察手册

冷冻收容柜把油库里个体以原身份存入玩家个人收容库并停止其演进；观察手册提供指南、个体状态读取与七个生存进度。

### 冷冻操作

用四个铁锭、两个雪块、一个箱子、一份红石和一颗末影珍珠合成冷冻收容柜。合成格为 `铁／珍珠／铁`、`雪／箱子／雪`、`铁／红石／铁`。取得末影珍珠后解锁配方（仅解锁冷冻柜配方）。

1. 用运输篮对活体使用，保留原个体身份装入。
2. 满运输篮对柜使用，将一只存入个人收容库；成功后篮子才变为空篮。
3. 空运输篮对柜使用，取回最早存入的一只，再对有落脚点的干燥空地放出。
4. 空手对柜使用可查看数量、种类和操作提示。满库或失效凭据拒绝存入；取回或放出失败不消耗活体记录。

每位玩家在该世界共四格，所有柜共享这四格。增建柜只增加访问地点，不增加容量。其他玩家不能取用你的槽位。拆柜、爆炸、玩家死亡或跨维度旅行不会删除库内个体；重建任意柜可取回。该个人库是明确的 Minecraft 适配，末影珍珠是其合成材料。

库内停止年龄、生理、受伤演进及母体内孕期，不施加冻伤，也不按现实时间补算。运输篮本身沿用已有暂停规则。已离体的茎、世界中的巢卵与其他家庭成员继续服从各自规则；它们不会跟随母体一起进入库中。

### 存储实现与接口

柜是可生存取得的方块和真实物品；无需方块实体，活体权威记录放在原有 `YukkuriWorldData` 中，与身份记录同文件保存。

- `YukkuriWorldData.freezer`：维护个人槽位；`store(owner, token)` 和 `retrieve(owner)` 在服务端同步转移持有权。
- `rotateToken(token)`：轮换唯一凭据，原运输篮的旧副本立即失效。已在库中的令牌不能经普通 `release` 或外部 `rotateToken` 放出。
- `FreezerVaults`：与原有 `Captives` 同一份 SavedData 序列化；没有另外存一份可生成实体的 NBT。
- 原 `capture`、`release`、`captiveSnapshot`、`isCaptured` 签名保持，工厂与 LiveBag 不改。
- 放出继续检查跨维度重复 UUID、碰撞、液体及实际加入世界是否成功。失败保留记录，成功后才消耗令牌。

收容前沿用已有操作中断与物品归还逻辑；乘坐或载有乘客的实体仍不能直接捕入。柜体损坏不创建装有活体的普通掉落物，避免掉落物消失造成库内生命丢失。

`CarrierItem` 取当前交互手的实际物品并检查类型、数量后写入凭据（创造模式下原版会把物品副本传给 `Item.interactLivingEntity`，不能写在副本上）；`NotebookItem` 的观察登记同样写入实际手持笔记。

### 手册与进度

继续使用原 `field_notebook`，书与羽毛即可制作。空中使用打开指南，对个体使用读取当前状态；选择住所及潜行安排入住入口保持不变。

`NotebookGuide` 提供分步取得路线、饮食与清洁、药品、情感互动、住所、成长与家庭、茎生／胎生／巢卵、身体、工具、游乐、收容、交易和进度说明。种族页按现有 `YukkuriVariant` 生成；观察后在手册的 `ObservedSpecies` 标记。亚种与先天形态使用独立的 `ObservedForms`，不会修改种族；帽船状态与乘船经历也单独显示。

保留原情感、个性、关系、身体与消耗品页。胎次页显示方式、进度、未出生数量与父体；未知父体明确显示未知。种族注册、模型存在与行为验收分开陈述，捕食种及新形态仍标明分别验收，未完成候选没有虚构的生存取得路线。Patchouli、Jade 等可选兼容仍未接入。

七个生存进度为取得笔记、首次观察、备齐三种照料设施、成功安排住所、真实存入、取回原个体与真实家庭出生。取得物品使用原版 `inventory_changed`，其余由成功操作或出生事件完成。`SurvivalProgress.award` 复用原版进度账本，每条记录一次，无经验或物品奖励；反复观察不治疗、喂食或改变个性。配方解锁只授予冷冻柜配方。

家庭出生触发由胎生任务接入：实际幼体加入世界后，向真实父母的在线玩家所有者记进度；未知父体跳过。该接口不伪造父母或奖励未出生子体。

## 生活与资源规则

- 生活数据只在实体已加载并实际模拟时推进；收纳、离线、卸载、冷冻期间不补算。饥饿、精力、清洁、湿透、如厕需求、家址、进食进度与人格存在实体 NBT。
- 一餐 64 tick，45 tick 时吞咽结算。取食从原库存扣一件，吞咽前中断可落回，吞咽后不退；存档和运输保留嘴里的食物和阶段。分享转移的是这一件实际食物，争抢只有一个赢家。
- 家址含维度和方块坐标，寻找设施不强制加载区块。家址被拆、被占或不可达时重新选择；区块未加载不等于住所被拆。躲雨要实际到达遮蔽处。
- 水：短洗只带来少量湿透；雨淋与浸水积累速度不同，持续湿透达到阈值后受伤。身体在水或气泡柱内通常每 20 tick 扣 1 点生命，水生魔理沙为每 60 tick 扣 1 点（关闭 AI 也适用），浸水期间不叠加湿透伤害；干燥帽内乘员不算入水。普通种不主动跨水，落水后沿可达路径逃向干岸。
- 火和其他危险优先打断进食、休闲和教学。
- 携带箱用一次性凭证引用世界 `SavedData` 托管的完整个体；放出保留 UUID 并使凭证失效，复制箱子不能再次放出同一个体。
- 亲缘由真实出生记录决定，未知父母保持未知；已知亲子与同胞不得配对。子代身份、种族和遗传参数在受孕时固定，出生只结算一次。区块卸载与运输不算死亡。
- 同伴关系存在世界级有向表。失饰影响观察者的识别，不删除既有关系；能否认出由观察者智力决定。

## 服务端配置

2026-10-20 饥饿平衡：清醒时基础消耗提高为原来的两倍，睡眠保持原消耗；不改配置键或已有存档的周期进度，旧世界同样生效。默认周期下，普通成体从满营养到主动找食物约 2 分 36 秒，需喂糜幼体约 1 分 18 秒；孕育、劳动等额外消耗另计。这些是 20 TPS、持续清醒且没有进食的估算，实际家庭食物负担待试玩。

`mcyukkuri-server.toml`（`life/YukkuriConfig`）：

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `life.hungerInterval` | 240 | 一个代谢周期的加载 tick；清醒扣 2 点营养，睡眠扣 1 点；需喂糜幼体的周期减半，家油沿用 ×4 周期 |
| `life.energyInterval` | 160 | 精力消耗间隔 |
| `life.hygieneInterval` | 300 | 清洁消耗间隔 |
| `life.wetDamageThreshold` | 60 | 离水后持续湿透的伤害阈值；不影响直接入水伤害 |
| `discovery.naturalSpawns` | true | 是否允许普通种自然生成 |
| `discovery.localSpawnCap` | 8 | 附近自然生成上限 |

`mcyukkuri-family.toml`（`family/FamilyConfig`）：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `gestationTicks` | 6,000 | 条件满足时的孕育推进时间 |
| `reproductionRecoveryTicks` | 12,000 | 繁殖恢复时间 |
| `eggIncubationTicks` | 4,000 | 家油卵孵化推进时间 |
| `houseArrivalTicks` | 600 | 每只家油创始者入住前的加载时间 |
| `localPopulationCap` | 16 | 附近已知活体与未出生预留的上限，未加载个体仍计数 |
| `naturalPairing` | true | 是否自行配对 |

其余模块各有配置（如 `mcyukkuri-human-world.toml`），见对应专题。所有数值是 Minecraft 适配参数，不是八景原始数值；20 tick 约一秒。
