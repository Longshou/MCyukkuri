# 物种行为差异（世界观还原包 4）

依据 komicolle「饅饅來大講堂」11518905（物种档案）。差异全部走一张查表：`entity/SpeciesTraits`（按 `YukkuriVariant` 取系数），共享 AI 读系数，不按种族另写 AI。家油与捕食种取中性行，保留现有生态。每只个体的计数与说话钩子在 `life/SpeciesLife`，已登记到状态中枢（`species.*`）。系数是项目设计，按讲堂形容词定量。

## 吐馅（仅帕秋莉）
`SpeciesLife.vomit` 调用 `BodyLife.releaseFilling("vomited")`，冷却 3600 tick，馅份不足 4 时不吐（不会自行致死），吐后压力 +3 并流泪。触发：连吃（两餐间隔不足 600 tick，或饿得低于 15 就吞）40%；受惊起步 25%；压力 ≥60 时每 400 tick 20%。

## 颊囊（仅灵梦）
- 家务拾取：捡起食物后，在 2.5 格内继续捡同种食物，直到 2 份；放储粮点时逐份由嘴接触放入（`HabitatLife.depositCarried`）。
- 觅食出行：灵梦每趟的装载上限 +2。其余种族此处沿用既有的 4～6 份（`ForageTrip`，野外代理的设计，与“其余 1 份”口径有出入，未改）。

## 接入的台词事件
- 称呼（`SpeechAddress`）：对 6 格内可见的玩家和居民（按信任/恐惧/饲主/态度选“饲主先生/大哥哥/大姐姐/人类先生/臭老太婆/糞老頭”；人类的性别与年长由 UUID 稳定派生，因为游戏没有这个数据）、对家人（母/父/伴侣/孩子/兄姊弟妹/族长）、对看到的捕食种（蕾米莉亚/芙兰）。同一对象 2400 tick 内不重复。
- 数数（`speakCount`）：放储粮后（40%，数当前储量）；偶尔数身边孩子、同伴、地上的食物（饿时）。
- 自述（`narrate_*`）：见 [原版台词接入](DIALOGUE_IMPLEMENTATION.md)。

## 验证
状态键 `species.cheek_capacity / cheek_load / vomits / chores / false_alarms / songs / nuzzles / move_speed / speech_hooks`，用 `/data get entity <e> YukkuriStatusView.species` 读取。
