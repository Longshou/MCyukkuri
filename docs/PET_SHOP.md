# 宠物店、徽章考核与宠物培育

宠物店的循环是“买 → 照料／学习 → 考核 → 出售或繁殖 → 补货”。本页记录当前规则和仍需试玩的边界；数值及服务器判定以 `pet/`、`shop/`、`badge/` 和 `human/HumanCommerce` 代码为准。

## 相关入口

- NPC 饲主确认死亡后，宠物、库存和工厂个体转为无主，血缘、技能、徽章及历史保留；不写弃养记录或作废徽章。快照、旧档 `UNKNOWN` 和失败回滚见[人类世界](HUMAN_WORLD.md#店铺登记与饲主归属)。
- 工厂、居民、鬼威惨、建筑和放置入口见[人类世界](HUMAN_WORLD.md)。徽章美术与挂点见 [art/props/badges/README.md](../art/props/badges/README.md)，作品依据见[徽章核读](../wiki/badges.md)与[宠物生活](../wiki/pet-life.md)。
- 徽章社会反应由服务器配置段 `badge_social` 控制；资料来源扩充不等于场景已接入。

## 依据与取舍

M02 的四类考试、有效期、社会性实技与学力题提供了考试结构；R2 提供前场展示与后场库存的商店母题；N12／N19 提供饰物徽章与店内展示；EH25、L19 提供考试结果和高阶徽章的情绪依据；TM08、TM13 提供弃养与饲主威胁的母题。费用、阈值、时长、题目具体表现和商业规则均为项目设计，不将不同作者规则拼成统一原作设定。

## 1. 等级与有效期

- `BadgeGrade` 为无章、铜、银、金四级。资格绑定个体 UUID；徽章物品只是带发证编号的凭证，不能把别人的章变成自己的资格。
- 铜章不过期。银、金默认有效 20 个游戏日（`badgeValidityDays=0` 时永久）；过期仍可佩戴，社会反应和报价按低一级的 `effectiveGrade` 计算，更新或晋级后恢复。
- 有效徽章表示已登记主人。鬼威惨不施虐受保护个体；普通观察者是否认出失饰个体由智力决定，水生魔理沙保留其例外；捕食种服从要求至少有效银章。详见[头饰](HEADWEAR.md)。
- 新店展示个体、种油和后场库存的资格、五轴和六项技能独立保存。既有资格补发编号时不自动补技能或属性；新生儿不继承父母徽章或技能。
- 手册可摘下、重戴或补发徽章。补发花 1 绿宝石并使旧编号失效；摘下饰物只隐藏外观，不取消资格。

## 2. 技能与照料状态

宠物只使用[行为数值设计](BEHAVIOR.md)的五项主属性：智力、友善、胆量、依恋、自制。没有四科能力、馅统总分或溺爱值。

| 数据 | 当前规则 |
| --- | --- |
| `PetSkill` | 等待、食盆、如厕、就寝、读字、算术六项。完成对应真实行为后才按学习判定建立；已掌握后重复行为不累加培养分。 |
| 生活完成 | 食盆、厕所和完整睡眠会分别尝试建立技能，不是可增长的生活记录分数。 |
| 压力 | `PetLife.stress()` 读写 `MindLife.unease` 的单一值；饥饿、伤势、恐惧、失饰、课程与考试共用它。 |
| 考试档案 | 最多 16 条，保存考试类型、时间、等级、结果和考官；称号“万年银”“隠れ金”只作展示。 |
| 家谱 | `FamilyData` 记录父母曾取得的徽章，只供展示，不参与遗传、学习、考试或定价。 |

## 3. 考试

考官右键打开 `ExamMenu`。可选对象是 8 格内自己的油库里，以及信任达到条件的无主野生个体（只能报名简易考试）。考场由考官住处附近的答题台、躲藏箱、考位、模拟房间、食盆、厕所、垫子和金章挑战位实际扫描得到；数据包不携带动物 ID。

### 3.1 考试类型

| 考试 | 费用 | 条件与结果 |
| --- | --- | --- |
| 简易 | 0 | 无章且有饰物。合格得铜章；野生个体同时完成登记，未得铜章则恢复无主。体力低于 30%、营养低于 10 或着火时不合格。 |
| 判定 | 9；评到银或金退 3 | 任何等级可报。按金、银、铜顺序检查实际任务，可直接升、降或撤销。 |
| 晋级 | 4 | 铜或银可报。检查下一等级任务；可升级、维持或降级。 |
| 更新 | 2 | 银或金且非永久有效。通过当前等级任务才续期；新增未经许可生育会降级。 |
| 补发 | 1 | 有章即可；不考试，替换编号。 |

通用拒绝条件是非白天、距离或状态不合格、考场设施不齐、冷却未结束、饰物缺失、考官忙碌或绿宝石不足。简易考试还拒绝最近三游戏日弃养过、或附近有严重疏忽宠物的玩家；原因码为 `no_management`。

### 3.2 题目与结果

题目是实体实际完成的行动，不预先按旧能力分数掷骰；每题最多两分钟。照护区考给饵、如厕、就寝和不打架，答题台考算术、读字、躲藏、约定和面谈，挑战区考面对野良役和走失幼体时的应对。铜、银、金分别要求照护、答题和挑战任务的组合。

`ExamSession` 依次集合、移动、作答和展示结果。完成后写考试档案；结束会增加单一压力，失败或降级再增加压力。成功时别上徽章并播放结果演出，维持时续期；失败／降级会有僵住、哭泣和缩起演出。受惊、受伤、着火、泡水、被抱起、夜间、参与者离开或死亡等会中断，60 秒冷却且不退费。进行中的考试不存档，重启会终止它。

## 4. 家庭课程与日常照料

宠物手册（`badge_handbook`）打开档案并开始课程；课程不保存分数。主人超过 12 格或个体进入危险、被抱起、紧急需求等会中断。

| 技能 | 前提 | 完成方式 |
| --- | --- | --- |
| 等待 | 背包有甜食 | 在约定场景等待后尝试建立。 |
| 食盆／如厕／就寝 | 8 格内有对应可达设施 | 实际进食、排泄或完整睡眠后尝试建立。 |
| 读字／算术 | 无额外物品 | 完成短题卡场景后尝试建立。 |

课程结果后有 4 秒主人反应窗口：温柔夸奖在成功时压力 −3，甜食奖励 −5；冷淡训斥 +4，弹额 +10，失败不产生培养收益。每次课冷却 10 秒；生活习惯完成也会开同类夸奖窗口。惩罚不建立技能。

甜食是加餐和等待奖励，不替代主食；糖粒、曲奇、布丁分别为不同档位，主人亲手喂自己的宠物会降低压力和无聊，高级油粮及布丁要求银章。日常请求会在平静、主人可见时提出食物、取暖、亲昵、玩耍、零食或散步；满足会改善关系和疏忽度，忽略只产生轻微压力和冷落反应。`ASK` 会复述未决请求，否则按当前状态表达心情。

胴带只能由主人给能独立生活的宠物佩戴，允许主人用原版拴绳牵引；课程、交易、相亲、换主、弃养、死亡等会自动收绳。按实际水平位移累计散步，每 64 格一个单位、每日最多 4 个，降低无聊、亲昵需求和压力并消耗少量体力、营养。襁褓只给未独立幼体，降低寒冷暴露并加快压力恢复，不限制行动、成长或学习；独立、泡水、着火或换主时自动归还。

## 5. 繁殖与家谱展示

- 玩家宠物所生子代归同一主人；商店种油所生子代归饲养员的育幼用途。子代继承五轴先天值的受限扰动，不继承技能、压力、关系或徽章。
- 手册可给两只同主、可育成体一次双向繁殖许可（24000 刻）；两只都须有有效铜章以上。未许可繁殖仍按自制与生理规则判定，受孕时记录未经许可生育；晋级和更新考试会审查它。
- 店内相亲由饲养员安排。玩家带自己的有效银章成体，花 6 绿宝石与店方种油配对；通过预检才扣费，失败退款。相亲绕过距离、识别、好感和巢位搜索，但仍保留成体、物种、亲缘、营养、人口上限和出生位置的真实检查。试玩完成标准见[待办](TODO.md)。

### 5.5 疏忽与弃养

- 已加载宠物距有效关怀接触超过三游戏日后累积疏忽和压力；喂食、说话、非伤害照料及主人在 16 格内都可缓解。疏忽高时会寻找主人，首次重逢播放欢迎演出。
- 弃养清除主人和用途，记录前主人、时间、地点及徽章状态；资格作废后，社会反应和报价按无章。店主或考官看见会收回可见徽章。
- 依恋高或幼体会在弃养点附近等待一日后成为普通野生个体；低友善个体自行离开。新主人收养会清除弃养记录，原主人领回时恢复登记并演出重逢，但不自动恢复信任。

## 6. 商店

### 6.1 结构与店员

`mcyukkuri:yukkuri_shop` 是 41×16×33 的街边店，含四个展舱、四个后场栏、繁育室和考场。店主打开 `ShopMenu`，考官管理考试，饲养员负责相亲、补货和运送。走失委托由咨询角的爱派大姐姐和店后树篱中的魔理沙提供，仍只支付一次且没有超时重新分配。

### 6.2 店主界面、用品与报价

店主界面有五个顶层页签：活体、用品、收购、咨询、进货。用品为 25 项、五类，按每页四项自动分成 **8 页**；货架存量按店主保存、每日补货。每名玩家在同一店主处每天最多买 `supplyTradesPerDay` 件，默认 **24**。

| 类别 | 内容 | 徽章门槛 |
| --- | --- | --- |
| 食物与零食 | 三档油粮、橙汁、糖粒、曲奇、布丁 | 高级油粮、布丁：银章 |
| 照料 | 运输篮、洗布、食盆、巢、厕所、除霉剂 | 无 |
| 玩具与饰物 | 毛线球、蝴蝶结及各物种帽饰 | 无 |
| 训练与外出 | 教导哨、牵引胴带 | 胴带：铜章 |
| 繁殖与育幼 | 同伴绳、襁褓布 | 无 |

活体报价仅由物种基价和**有效**徽章等级组成；无章减半，无章工厂出货再乘 0.8。五轴、技能、父母徽章、家谱和旧“馅统”都不参与定价。收购按该报价乘有效等级的回收率（无章／铜 60%、银 70%、金 80%），再按压力折价；收购库存上限为 12，且要有空栏。咨询页只展示技能、性格、健康、营养、压力、父母徽章、有效期和未经许可生育。

### 6.3 相亲、库存与工厂出货

- 模板首次放置有 14 只展示、库存、种油、陪考生和野良役；不靠重载补货。饲养员在总体数量条件满足时让种油实际受孕，育幼个体独立后转为在售库存；不自动生成技能或徽章。
- 出售、收购、育幼转栏和工厂到货使用运输篮与预约令牌，保留同一实体身份。饲养员的相亲、交接与转栏为已有演出；种油交配和新生儿仍无公开演出。
- 工厂向店铺出货的条件、时序和未做项见[人类世界](HUMAN_WORLD.md#交易照顾与工厂)。
- `commodityHarshness` 控制商品化背景；为 0 时关闭滞销回收。开启后，滞销库存才可能送往工厂；工厂母体损耗、考试处分和中枢馅收购也受该配置控制。

## 7. 社会反应（徽章）

`pet/social/` 采用“观察 → 记忆 → 选择 → 场景 → 后果”。可见徽章的个体在 8 格、视线及朝向条件满足时写目击台账；多数目击无声。亲子和亲近关系优先，过期按低一级、作废按无章；睡眠、进食、会话、课程、考试、恐慌、受伤等状态不触发。

可见反应受每位玩家／世界的预算、观察者、对象和配对冷却限制；台账最多保留 12 个对象，五游戏日未再见则遗忘。弧线涵盖好奇、羡慕、炫耀、讨一口、挑衅、请求收养、报告、护窝、夺饰物等。涉及食物时实际转交一口，涉及收养时仍走既有收养、喂食、拒绝流程。传闻只写入当事者所属聚落，不会在集合时段自动传播。B8 夺饰物默认关闭，恢复路径须先经试玩确认。

## 8. 演出与限制

考试、相亲、出售、收购、运输、社交和课程使用实体实际动作、表情、原版粒子／音效及 `pet/stage/Staging` 的临时卡片。可用动作包括思考、紧张、得意、欢跳、沮丧、藏脸、乞求、鞠躬、害羞、昏睡、抗拒、进出篮子、无视、克制、夺饰物、站稳和递食；整体俯仰／侧倾不超过约 12°，表达依靠压扁、位移、转身、跳动和表情。

字幕均为项目原创，考试、商店、课程、相亲和徽章社交已覆盖对应事件；配音统一见[配音收尾](DIALOGUE_IMPLEMENTATION.md#台词与配音边界)。界面只展示五轴、六项技能、单一压力和父母徽章，不展示旧四科、馅统或溺爱。徽章、手册、用品和界面从制作源导出，借用原版图标须登记到[道具制作源](../art/props/README.md)。
