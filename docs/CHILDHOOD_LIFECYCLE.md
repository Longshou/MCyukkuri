# 胎体、赤油、子油与亚成油独立

本专题规定从胎体发育、出生、亲代照料、学习和分床，到亚成油独立生活的连续过程。普通陆生家庭沿用服务端成长时钟、亲缘账本、真实食物和天然住所；水生家庭保留帽船生活与初航，家油卵和捕食种保留各自出生、取食与住所规则。下述年龄比例、材料数量和距离均为本项目原创，不作为作品中的统一设定。

## 术语与能力

赤油、子油、亚成油、成油用于描述成长；亲油与子代表示亲缘。幼油只是未成年个体的泛称，不能用于判定进食、劳动、独立或繁殖资格。茎上实子仍未出生，胎体也不具有独立生活任务。

胎生出生为赤油；茎生在茎上完成赤体发育，出生为初生子油。两者都先进入新生受喂与护理过程，出生为子油不跳过喂糜和首便照料。亚成油是子油后期已经具备独立生活能力、尚未生殖成熟的阶段；内部保留原有 JUVENILE 存档类型，能力与显示另行区分，避免把独立资格误当成年资格。

自主咬食、主动跳跃、嗯嗯体操、学习、分床、独立生活和繁殖分别判断。食糜是咀嚼后的食物，馅是身体内容物，嗯嗯是排泄物；亲昵蹭脸、清洁擦洗与首便辅助也分别结算。

## 一条连续的成长过程

| 阶段 | 进入条件 | 吃与活动 | 睡在哪里 | 向下一阶段过渡 |
| --- | --- | --- | --- | --- |
| 出生前 | 已有胎次 | 亲代进食、回住所安胎；照护者在真实位置接生 | 为本胎保留可用的实际睡位，不能超额许诺 | 真实生成幼体；茎生等待落定，胎生完成分娩，卵生走原孵化流程 |
| 新生赤油／初生子油 | 胎体已真实产出；实子实际落定或进入接生帽 | 等待亲油嚼糜、对嘴递喂；先爬行、求助和休息，首次排便由亲油帮助；不能自行啃食、远行或做家务 | 优先继承母亲住所，母亲没有可用住所时尝试父亲；正常陆生幼体归入家庭大巢 | 落定、受喂、首便与运动能力分别保存；离帽按已有行动能力处理，不强制所有新生跳出 |
| 赤体与早期子体 | 未达到分床门槛 | 新生阶段等待近身喂糜；年龄达到成熟年龄的 1/4 且营养成长达到 3/16 后才能独立吃固体。安全时围着家庭巢活动 | 与父母和兄弟姐妹睡在同一片连续叶巢中，每只仍有互不重叠的睡位 | 年龄至少达到成熟年龄的一半，且营养成长累计至少达到成熟年龄的 3/8 |
| 后期子体 | 同时满足年龄和营养成长门槛 | 可以承担短程铺巢工作；仍受亲代照料，紧急需求优先 | 在原住所及周边三格内收集两份植物铺材，回自己的睡位完成 120 个实际施工 tick 后拥有个人小叶巢 | 分床不改变家庭、亲缘或库存归属；没有材料就继续共巢 |
| 亚成油、尚未离家 | 年龄至少达到成熟年龄的 3/4，营养成长至少达到 9/16，并具备自主进食、排泄和行动能力 | 自行取食、维护住所、认识环境；仍可与家人互动，不参与繁殖 | 可继续住家庭巢或已经铺好的个人小巢 | 健康、体力与食物需求稳定，没有配偶或照幼负担，才考虑独立筑居 |
| 离家筑居 | 已选中可达的新址 | 先告别，再逐件取材、搬运和施工；途中仍需吃、喝、休息和避险 | 新居成功认领前保留原住处 | 新居真实可用且认领成功后才转移床位、退出原群并建立新家 |
| 独立生活 | 已完成搬家 | 维护新居、寻食；晴日可短时探访家人 | 始终以自己的新居为归处 | 返访不拿回旧床、不复制旧粮、不取消独立身份 |

新生受喂期间的饥饿与精力消耗间隔为普通阶段的一半，精力降至 65 就可休息；完成休息后等待 200 tick 再检查，形成少量、多次的进食与休息节奏。这些是项目节奏参数。

成长继续使用现有 `FamilyLife` 的双条件：年龄会随已加载时间增加，营养足够且身体健康时才累计有效成长；营养不足的子体不会仅凭日历越过分床或成年门槛。默认成熟基准为 48000 tick，个体存在已有差异；不新增一套与体型脱节的年龄表。

照料接近按双方的实际站位协作：先确定有地面支撑、双方可达且高度相容的位置，孩子停下等待，亲代走到嘴部或后侧接触点。跨台阶、绕障碍仍走寻路；只有最后一小段平整地面使用精确挪步。受阻会换站位并退让重试，不能靠距离接近就停用寻路，也不能追着持续移动的孩子无限转圈。

帽内移动沿可站立的帽面路径，避开其他乘员，身体步态随真实行走播放。尚不能越过帽内高差的新生儿由亲代先实际靠近、衔起，沿可支撑双方身体的路线扶携到目的地，再放下；不让孩子自行平移越过帽壁。亲代首便照料后陪同到帽檐，站稳转向后才排泄，结束后各自返位。照料与扶携期间船体方向保持稳定，不随亲代转头打转；保存后从实际接近或持有阶段恢复。喂食交接后保留位置直到孩子吞咽结束；亲昵同样要求真实近身接触。紧急饥饿优先于首便和亲昵，失败动作有短暂退让时间。

## 新生喂糜、首便与运动学习

Wiki 收录的 [EH08 第 6 页](../wiki/art-references/ehentai/images/EH08/006.webp) 明确描写刚出生的赤油牙齿脆弱，野外第一餐通常是亲油嚼碎的糊糊。本项目据此采用新生受喂规则：先由亲油咀嚼加工，再递到幼油嘴边，幼油受喂、吞咽；不能把整块食物或整根空茎直接放进新生幼油嘴里并播放普通咀嚼。该页属于[具体作品的叙述](../wiki/art-references/ehentai/works/EH08.md)，没有规定跨作品通用的断奶年龄。

自主进食沿用现有赤体成长节点：年龄至少达到成熟年龄的 1/4，且营养成长累计至少达到成熟年龄的 3/16。两个条件同时满足才解除依赖；茎生虽然落地就是子体，年龄和营养成长仍从零开始，同样需要喂糜。数值属于项目适配。家油卵生和捕食种的特殊取食系统保留自身规则。

茎生的空茎在本胎所有实子实际落地、落帽或已有明确终止结果后才脱落。整根空茎只是一份真实食物，吞咽后提供 20 营养并恢复 2 点生命；它不携带活胎，不会继续长出孩子，也没有免疫增益。能独立进食的个体可以直接吃，新生幼油须由亲油先嚼碎。多胎家庭仍需要其他食物，不会因一根空茎自动给每只孩子发一份。

亲代从自己的真实存粮或附近实际掉落食物中取一份，优先照顾更饥饿的孩子。咀嚼加工只改变这份食物的形态，不增加亲代营养；糜状食物保留原食材的营养和来源。亲油持糜走近，在孩子正前方站稳、微微前倾，用表情和照料语音回应，双方达到真实近身接触条件后交接，只有孩子实际吞咽才获得营养。接触中断重新等待，不能隔墙、背对或隔空完成。食糜在交接前随亲油嘴部运动，接触后转到孩子嘴部，没有独立飞行轨迹。源动作与目标跟踪共用 10 度的总前倾上限，不能叠加成大幅度俯身；身体重心保持在支撑面上。帽船采用自身的席位移动：亲油在帽内靠近孩子并轻微前倾，临时照料位置结束后回到原有安全位置；口部接触条件相同。父母处于急迫饥饿、受伤避险或生产状态时先处理自身需要。

加工、搬运或受喂中断时，同一份食物仍保存于携带、嘴里、库存或地上；保存重载不能复制营养，也不能把已经嚼好的糜变回完整茎。新生幼油不能靠地面拾食、食盆、住所库存或帽船的紧急自取绕过照料。帽中亲油同样先加工再喂；长大后的嘴边分享和自主取食继续使用普通进食流程。

[EH08 第 8 页](../wiki/art-references/ehentai/images/EH08/008.webp)明确描述新生赤油首次排便需亲油舔舐刺激。本项目据此补充普通种新生首便照料：便意出现后孩子求助，亲油实际接近其后侧、停下帮助；有效接触完成后排出一份真实废物，之后才解除首便依赖。普通厕所、体操、洗澡和亲昵不能代替该过程。帮助中断不提前排出或解除依赖，重复帮助与重载不重复生成废物。缺少新生护理记录的旧存档不补演出生护理；已有进食年龄与营养门槛继续生效。

水生家庭的帽船是居所。亲油先在帽内靠近孩子后侧完成首便辅助，再陪护孩子走到帽沿；尚不能越过帽内高差时扶携过去。身体保持受支撑、后侧朝向水外，排泄物从真实位置落入水中，随后回到原睡位。此后亲油和子代的日常排泄也采用帽沿朝水的姿势；不污染帽内睡位，不因排泄返岸，也不把排泄物凭空挪到远处。下方没有实际水面或帽沿位置不可用时等待，不能提前结算。

初生移动先以爬行和短距离试探为主；能活动后在安全范围内练习起跳、落地，亲油可在附近示范。练习需要真实运动结果，不能只等待冷却就授予能力。没有亲油时保留渐进练习的路径，但不会因此绕过新生喂养。壳型不强制套用普通跳跃动作，保持爬行和亲代照料；水生幼体在帽内练习爬行和受支撑的短跳，进度按相对帽船的实际移动记录；船体漂移不计练习。随后完成初航往返，亚成期以自己的帽船独立。所有阶段保留水火逃生，不能用学习门禁锁死逃生。

## 大巢、小巢与洞穴是不同的东西

天然洞穴、树根间空隙或已有浅坑提供地形遮挡，油库里在里面铺树叶、草和其他植物材料。它们不会凭空修出土墙、石顶，也不会把“树叶能铺床”解释成“一层叶子可以防洪或挡住暴雨”。洞口细枝只作边界提示。

早期家庭大巢由相邻睡位连成连续的植物铺层，只在整片巢的外缘显示边沿。父母和孩子在同一片巢中各有站立、睡眠位置，避免把多个实体压在一个坐标。新生儿优先分配靠近父母的空位；场地不足继续阻止新一胎，已经出生的孩子不能因此被删除。旧存档中已有的亲子住户重新显示为共巢，不追缴材料，也不清除原住户。

普通野外双亲使用天然住所时，繁殖前同时检查本胎幼体与父亲加入所需的容量。受孕后父亲通过正常的可达性检查认领母方住所，成功才释放旧床位；道路暂时不通时保留原住所，在本胎待产期间重试。这个过程不传送、不驱逐其他住户，也不改变玩家已经指定的人工住处。

后期子体铺个人小巢时使用自己的原睡位，不占据另一个家庭的住处，也不建立新群。两份树叶、草或小麦必须来自真实材料，可混用；纸张和空茎不纳入自动铺材，空茎保留食物用途。取材优先寻找住处周边可接触的树叶、杜鹃灌木、短草或蕨类方块，走到侧边、转身衔取，持续接触 36 tick 后消耗该方块并得到一份材料。够不着的高树冠不会被隔空采走；已经存在的真实掉落铺材也可拾取。生物破坏关闭时不采植物，但仍能用已有掉落物铺床。

施工逐份进行：取回第一份先铺底，再取第二份铺面和压边。每份材料对应放下、摊开、压实三个 20 tick 阶段，床面按真实进度显现；携带时显示叶草束，不显示一整块树叶方块。已放下的材料和施工进度归住所保存，饥饿、避险、保存重载或成长为成体都不会抹掉已有劳动；迁居、死亡或住所拆毁时释放未完工材料。施工只在自己的睡位发生，赤体和早期子体不承担清扫和储粮劳动。材料不够、住所受潮、道路不通或身体状态不适合时，分床推迟；卸载不补施工进度。

分床后的家庭仍共享住所里的真实食物库存。分床不意味着父母立即停止照料，也不意味着孩子获得生殖资格。亚成油独立仍要求原住所中的亲代登记、有效成员身份和可达新址；失饰处分不能靠分床或搬家被清除。已独立但未成年的子代以新居为归处，不再被亲子跟随任务拉回原家。

## 生活与异常情况

| 情况 | 处理 |
| --- | --- |
| 父母外出、幼体留在可用住所 | 赤体和早期子体在巢附近等待；不会因跟随目标优先级而不断追着远行亲代跑 |
| 亲代在附近、孩子落在巢外 | 按已有识别和可达条件接近家人，回到实际可用住处；不传送 |
| 父母之一死亡或不可见 | 仍可由另一亲代照料；死亡与暂时卸载分开判断；新生幼油不会因为失去照护者就自动获得独立进食能力 |
| 双亲失去联系 | 保留血缘和最后可用住处，不凭空生成替代父母，不强制加载区块；无安全住所时寻找亲人、避险，新生饥饿风险真实保留；达到自主进食门槛后才自行取食 |
| 饥饿、口干、便意或受伤 | 生理与逃生优先于铺小巢、维护和告别；不会为完成成长演出锁住实体 |
| 夜晚、雨雪、冷与热 | 回真实住处；保温仍需干燥铺材，幼体的温度脆弱性沿用原规则，不因“家庭巢”标签获得无条件保护 |
| 巢内排泄物或潮湿 | 原清扫、换垫料、受潮、腐败继续作用；幼体不靠擦脸直接清洁住所 |
| 巢被拆毁、淹水或玩家重新指定住处 | 停止当前铺巢任务，携带实物不消失；没有有效住所就不把旧坐标当安全点 |
| 中途保存、收容、卸载 | 保存住户、个人巢归属和真实携带物；未完成当前施工不补算离线劳动，不重复发材料 |
| 水生魔理沙、家油、捕食种、玩家人工窝 | 各自已有生育、载具和住所仍有效；本轮的天然共巢与分床只应用于普通陆生家庭 |

## 实施顺序与核对点

1. **出生与喂养**：空茎与其他固体食物都按新生取食能力处理；亲油取一份实物、嚼成糜、近身递喂，幼油吞咽后结算。核对物品数量、营养只结算一次、两亲代选择、落定前限制与中断保存。
2. **共巢与分床**：复用 `ShelterBlockEntity` 住户与睡位，增加个人小巢归属；按亲缘就近安排孩子，增加后期子体的本地材料施工。核对年龄与营养门槛、早期幼体无家务、材料短缺、中断和保存重载。
3. **活动边界与离家衔接**：让安全住所中的早期幼体等待亲代，完善原住所与个人巢的生命周期；衔接亚成独立的真实选址、施工、失败回退和返访。核对分床不释放原家成员、独立搬家才释放旧床。
4. **叶巢表现**：从现有野外住所制作源导出连续家庭铺层和个人小巢，客户端按真实归属组合。生成有亲代、不同年龄子代及对应动作的本机预览，加入集中入口。
5. **验证与交付**：本机只做必要的语法与资源一致性检查；提交并推送 `main` 后由远端 CI 编译。针对送食、共巢、分床、保存和离家使用真实引擎专项；自然地形寻路、长期节奏和游戏内观感交由用户可运行环境观察，不能用静态预览代替。

远端 `childhood` 专项覆盖亲代真实送食、陆地与帽上首便、实际爬行和起落、共巢睡位和个人小巢；`aquatic_family` 核对帽内实物递食和水上初航、独立。`growth`、`shed_stem` 与 `independence` 专项核对成长、空茎脱落和陆上亚成离家。预览入口的家庭章节展示共巢睡眠、送食、铺小巢、另筑新居和返访动作。引擎受控场景与离线预览的结果分别解释，不代表自然世界的长期生态或游戏内观感已经确认。
