# 水生魔理沙的水边生活

2026-10-16 接入。设定入口为 [水生魔理沙](../wiki/hakkei-reference/lore/species/marisa/aquatic-marisa.md)。本机只做资源导出、静态检查与离线预览；运行效果需要在可运行环境中确认。

## 采用的设定

- N09／L25：帽船提供浮力，身体仍怕水，木棒用于操船。
- EH22 第 5、6 页：辫端持枝条、帽内收物。当前采用辫子握棒划水，木棒用原版真实木棍表现。
- N13：先稳住帽子再登乘；照料幼体和操船是不同任务。登船等待期间稳船，幼体逐个跳进帽内；玩家仍可从岸上拉近帽船。
- 用户已采纳：大帽为普通帽的 1.5 倍，帽内保持干燥，能载食物与自家幼体，夜里幼体在亲油下方睡，保持既有水上／岸边生育规则。
- 不采用 N14 的潜水能力或特殊育成帽，也不把 EH22 的夸张危险场景换成固定死亡概率。

## 生活循环

`AquaticLife` 作为服务器 AI 任务占用移动、朝向与跳跃控制。陆上先寻找可到达的干岸和木棒，再摘帽出航。木棒可以由玩家给，也可捡起地上实际掉落物；附近树叶或枯灌木可消耗一块取得一根枝条【原创采集规则】，遵守 `mobGriefing`。缺少材料时不会凭空生成桨。

`HatBoatRoute` 只在已加载区块内搜寻同一水面的路线，最多 400 个节点、半径 12 格；拒绝淹没水面、低水位和向下急流，不走直线穿岸。实际推进仍由帽船物理完成，划行会消耗体力、产生水花。睡着后不再划船，仍会顺流漂动。所有距离、时长和采样上限都是本项目平衡参数。

帽船寻找附近漂浮食物，移近后实际转移到库存。上限为 8 份、4 种堆叠【原创容量】，幼体上限仍为 5 只。父母和幼体从真实库存取食，优先照顾饥饿乘员，进食沿用原来的咀嚼、吞咽和营养结算。口干时在船边饮水；排泄需求会促使亲油返岸。不会仅播放吃饭动作就凭空增加营养。

放帽后船先稳住，亲油和附近自家幼体沿已有重力抛物线登船，不再从五格外瞬间变成乘员。帽内睡眠恢复体力，完成睡眠后沿用原有成长检查；睡眠进度与尚未落定的登船轨迹可保存。天亮、缺粮、下雨、需要排泄、幼体成年或临产选择岸边时，亲油寻找干岸。船靠近岸边后，先确认全家都有互不重叠的干燥落点，再归还同一帽子、安置家人和卸粮；临产找不到可达岸边时，继续使用既有船上分娩规则。

自然生成以水生个体为起点的家庭会配同亚种亲本，子代沿用既有 UUID 遗传抽取。介绍伴侣也遵守“水生只与水生配对”，不会先绑定一个无法繁殖的陆生伴侣。

## 危险、保存与回收

帽内的干燥保护只对实际乘员有效；帽子翻覆或水面淹过开口时立即失效。它不改变水生魔理沙的身体吸水率，不赋予游泳或潜水能力。翻覆会散落真实粮食和桨，乘员落水；失桨时停止主动划行并向岸求助。雨中仍会淋湿。

2026-10-16 按用户纠正：所有种类和形态只要身体实际入水或气泡柱，每 20 tick 扣 1 点生命（半颗心），不再等待湿度阈值；关闭 AI 也不免疫。离水后重置浸水计时，湿透与淋雨继续沿用既有阈值规则，浸水时不再叠加同一套湿度伤害。干燥帽内不属于身体入水。浸水、翻覆、失帽和救援都不改变水生亚种；戴回帽子仍为 1.5 倍。遗体额外保存亚种标记，继续用相同帽尺寸规则渲染，避免因共用 `marisa` 模型而缩成普通帽。

帽子继续使用原来的唯一饰物令牌。主动放帽不再被当成遭人抢饰物，旁观者能识别帽船里的主人。船、库存、亲缘乘员、岸边记忆和木棒随实体保存；卸载不触发替身船或“死亡”推断。亲油确认死亡后，玩家可从干岸救出剩余幼体并收回这顶有来源令牌的帽子；仅仅查不到主人时不会走这条回收路径。

## 操作与观察

| 操作 | 结果 |
| --- | --- |
| 木棍右击水生魔理沙 | 交给她一根真实木棒；已持棒则不消耗 |
| 在干岸潜行持木棍右击 | 从附近合适水面出航；未带桨时转移一根木棒 |
| 船上对亲油再次潜行持木棍右击 | 沿用已有的翻船操作 |
| 持食物右击帽船 | 存入一份；潜行最多存入八份，受余量限制 |
| 持木棍右击缺桨的帽船 | 补一根木棒 |
| 在干岸空手右击帽船 | 救援；距离不合适时先拉近 |
| 观察笔记查看水生个体 | 显示船况、木棒、粮食数量、幼体数量与当前行为 |

## 动作与资源

新增 `boat_paddle`、`boat_gather`、`boat_eat`、`boat_drink`、`boat_sleep`、`boat_wake`、`boat_board` 七段，只编入普通魔理沙模型，由水生生态状态触发。原有漂流、稳船、呼唤、安胎、分娩与帽中幼体动作保留。船体移动优先使用水上动作，避免漂行时误播陆上走路；船上受惊使用稳船姿势。

无需浏览器或游戏的当前预览入口为 [aquatic_preview.py](../standards/yukkuri-library/motions/variants/lore/aquatic_preview.py)，输出位于 `.local/previews/aquatic/`。运行时验证仍需关注连续昼夜、返岸路径、多人同步、繁殖中返岸和急流翻覆；离线图和 CI 构建均不替代这些实测。
