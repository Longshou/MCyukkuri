# 水生魔理沙的水上生活

> 本页规则大部分**未实现**，按[重构设计第 11 节生产计划](REFACTOR_DESIGN.md#11生产计划)在 WP4–6 重建；下线期间水生魔理沙按普通魔理沙生活。已接入、待试玩的只有[放下的帽子在水上](#放下的帽子在水上)（WP4a）与统一帽子尺寸。

水生魔理沙以自己的帽船为主要居所，在水上采食、育幼、休息和生产；靠岸只处理需要陆地的活动。设定来源包括 [水生魔理沙资料](../wiki/hakkei-reference/lore/species/marisa/aquatic-marisa.md)、N09／L25、N13 与 EH22 第 5、6 页。漂浮不等于免疫水伤，也不赋予游泳或潜水能力；N14 的潜水能力及固定死亡概率不采用。

物种事实不随实现下线：水生只与水生配对，水伤数值照旧，`aquatic_marisa` 变种（模型、贴图、创造栏、帽子物品）保留。帽船形态见[亚种与先天形态](SUBSPECIES_IMPLEMENTATION.md)。

## 帽船与日常

水生种常年生活在水上。船只沿已加载的平静水面航行，不穿岸、不走急流；划桨消耗体力。船的每个时刻只有一条操船指令在生效，优先级依次为救援、安全与靠岸、登船与照护、货物、日常；高优先级可抢占，每条指令都有期限，无进展就带原因交还。

无桨时仍可漂流、休息、照料和呼唤，也可用辫子手划【项目设计】：速度约为持桨的 35%、体力约 2 倍，仍随水流漂，不凭空获得木棍。玩家可交付真实木棍；也可从可接触的树叶或枯灌木取得一根，受 `mobGriefing` 约束。

岸边是自主活动偏好，不是移动禁区。闲逛优先选附近干燥的近水位置，找不到时仍可在内陆正常移动；拾取、觅食、照料、温度避难和逃跑沿用各自真实路径与危险检查，不要求目的地或每个路径节点靠水。已有出航行为仍主动寻找可达岸线。下雨时暂停主动出航与水上生活偏好；在帽船上遇雨先俯身盖住孩子，船长或乘员湿度达到 60 才请求真实靠岸，上岸后由普通避雨行为搜索可达遮蔽处，不要求遮蔽处靠水。雨中湿度每秒 +1.5，满 100 后每 200 tick 扣 1 血，比普通种积累慢、伤害间隔长；雨伤不产生位移。陆地速度降低 40%，陆地活动累计 600 tick 后降低 65% 并持续付出疲劳代价；回到干燥帽内逐渐恢复【项目设计】。

一次出航是短承诺段：找桨备粮、走到岸格、集合、放帽、先载幼体、船长最后上船，抵达后才上岸收帽；只有危险能打断。带幼体出航先把本趟每只幼体分为能跳、要被托、忙、缺席：忙的由船长等待或唤回，300 tick 仍忙就整趟取消并冷却，不留幼体独自在岸。单只幼体在登岸时落地失败只换落点或留在船上，不中止整次登岸。出航失败＝幼体放回岸上、收帽、冷却；登岸失败＝换一处泊位（最多两处），仍失败则继续漂着并把该区域在一段时间内标为不可靠岸。其他行为只能请求一次靠岸并收到接受／冷却／无泊位／忙的答复，遵守区域冷却，不各自触发靠岸。

在航时一次只跑一个活动（事件、威胁、分娩、生理、照料、天气、补给、社交、休息、空闲依次降低优先级）：高优先级抢占时低优先级的收到中断并停止，不自动恢复；每个活动有时限，连续 200 tick 无进展就结束并冷却。日常航路被其他帽船挡住时先停住并逐次延长退避，再重试真实水路。

无绳夜泊【项目设计，生态设计 A6】：夜里或雨雪时，船长在静水中找岸凹、芦苇／甘蔗或睡莲丛、头上有遮挡的位置，划过去，船头楔进去后放手，只靠岸卡住船；孩子进帽腔，船长俯身盖住并哼摇篮曲再睡。每 200 tick 检查漂移，离泊位超过 3 格或进了水流就醒来重新靠泊，最多两次，之后在静水中漂睡；水流中不睡觉。天亮睡醒后先把船推离岸边。

帽内空间与载重决定入船【项目设计，生态设计 A1／A3】：粮每份 0.5（粮袋最多 12 份、四种）、木桨 1、新生与赤油 2、小子油（≤0.30）3、子油（≤0.45）4，孕期船主 +2，总载重上限 12。入船条件是载重放得下且帽内有合法位置：体型按当前大小算级别，>0.45 的子油与亚成油不是常规乘员，只能占救援帽檐的临时位置。照料、如厕、初航保留、孤幼收容与救援预留都是带有期限的临时占位，到期自动释放；移动中的占位超时未完成会回到原处并记日志。孕程 ≥0.8 的船长改坐高座，把身前帽腔让给接生；吃水按载重下沉，摇晃与进水敏感度随载重变大，横滚 ≥15° 时存放在左侧帽檐的木棍每次晃动有 10% 滑入水中，成为漂浮的真实木棍。成长后超载会暂停新增乘员，直到进食、卸货或有人离船。

帽内只显示真实乘员和库存。粮只放在船长肩前两侧帽壁边的侧窝，左右交替，从任一岸边都能越过帽口看到对岸一侧，不暂放帽檐；放粮要先过得下。腾位从不弃粮：须经决策层（救援、接生）授权，外部登船先验证转移路径，再提交腾位和预约；顺序是饥饿的乘员先吃、让空闲孩子换位，最后把最不值钱的一份粮推到水里，成为可再拾取的漂浮物品，是真实损失。库存转移保留同一份食物与唯一帽饰凭据，收帽、翻覆、沉没和重载都不能复制或补回已消耗物资。

水生帽与普通魔理沙使用同一帽形，戴着、托着、展开、翻覆统一一个尺寸（用户裁决 Q3）：普通魔理沙帽的 1.4 倍（决定 R6，试玩时可改 `hat_vessel.json` 的 `scale` 这一个数值），幼体帽按自身体型同比、初航不换帽（`headwear/HatScale`）。水生帽与普通帽仍是不同物品。倒置为船时帽冠压扁并沉在水下，帽檐高出水面，帽内保持干燥。帽子是帽船本身，不是交互工具；油库里用辫子和嘴与物体互动。帽船属于水生魔理沙，陆生魔理沙不会靠落水凭空造船。

粮食来自实际拾取、采集或玩家交付。帽内家庭按正常进食结算；缺粮时先寻找可达漂浮食物和岸缘食源，确需陆地活动时走真实返岸、采集和复航过程，不补粮。夜间、雨雪与温度不适会寻找合适停宿水面或请求靠岸；帽子本身不是屋顶、火源或保温窝。睡眠、繁殖、关系和饥饿时钟均沿用各自系统的真实已加载时间。

库存按当前环境和乘员需要补充：冬季群系仍提高当下储备需求，饥饿乘员与未独立船长仍可触发真实补给；秋季群系使用日常目标，不为未来冬季额外囤粮。

## 家庭、照护与初航

帽船承接水生家庭的住所、携粮和亲子照护。亲油从真实库存取粮，停船靠近孩子，经实际接触交付；新生儿由亲油先嚼糜再喂，孩子吞咽后才获得营养。亲昵与安抚也要求识别、可达和近身接触；照护由友善主导，依恋不增加喂养或救援意愿。水生魔理沙只与水生魔理沙配对。

生殖行为只在岸上发生；水生母油随后回到水上，在自己的帽船中生产，不需要伴侣或靠岸。有伴侣时，对方可自行划到船边陪护；新生儿落在母船上空出的位置，母船没有位置时才落到靠在身边的父船上；产后母亲嫌自己一侧明显更重时，由母亲自己发起一次辫兜托举把一只赤油送到父船，照护主动让出；同一只两次几何拒绝就留在母船并记一次拒绝。漏接会使孩子真实落水，继续执行溺水伤害和救援规则。

具备固食、起跳和学习能力且体型达到成体的 0.20 后，子油才能在亲船导师陪同下初航。练习需使用自己的帽子和真实木桨，实际放帽、登船、短程划行、返回并收帽后才记录学会；中断不发奖励。完成初航后可以在亲船附近独立操帽和生活，但不因此提前离家或免除亲代照料。离家仍须满足原有年龄、营养成长与独立生活资格。

子油乘亲船时保留自己的头饰；搭乘亲帽与使用自己的帽子放船是不同状态。赤油不能自行跳帽，由亲油以真实接触和辫子托举移动。随亲、互助、返帽与收纳均检查亲缘、识别、真实位置和容量；未加载不等于死亡，不创建替身船或替代亲代。非亲生落水幼体只能通过实际救援预约和登船取得临时照护位置，靠岸交接后解除，不改写亲缘。

## 乘员移动

上船、下船、船间换乘、入水自爬、辫子托举和舱内换位都是同一种真实移动。能跳的个体用跳过帽檐；能咬檐的落水个体用攀爬（嘴咬帽檐，随后辫子勾檐，拉升并滑过）；不能跳的赤油用托举：载体的辫梢卷成兜托起，无辫种类或辫子够不到时降一步用嘴叼，仍不行则被拒绝。托举能力只有一条规则：被托者体积不超过载体的 24% 并按体力折算；辫子够得着的范围是以载体当前辫根为心、最短与最长伸展之间的壳，嘴按口含范围，沿整条曲线都要满足；接触目标还须位于身体正前方左右各 80° 的作业范围，先真实转身再接取，不能朝外背向托幼。岸上先找同时够到接取点、放下点的支撑站位并真实走到；船上先走到可达位置并转向。相同起止位置不是成功，同类物理失败三次停止本次会话，能力不足直接拒绝；下岸几何失败可请求最多两次真实重靠泊，每次最多 140 tick，不能以原地搬运刷新进展。

体能位移按体型与体力计算【项目设计】。`S = sqrt(clamp(实际体型, 0.06, 1.5))`；`F = (0.35 + 0.65×clamp(体力/80, 0, 1)) × sqrt(clamp(生命比例, 0.1, 1)) / (1 + 0.18×疼痛伤级 + 足烧附加0.3)`；在船上另有速度负载系数 `L = 1/(1 + 船载重/12)`；离船跳高与跳远不承受留在船内的货物重量。

| 上限 | 值（格，速度为格/tick） |
| --- | --- |
| 跳高／水平跳距 | `0.70×S×F`／`1.8×S×F`（用户裁决：成体上限改为最高 0.8 格、最远 1.0 格，未实现，见[待办](TODO.md#水生魔理沙模块重构)）；须成年或已会跳、体力至少8、清醒且未濒死 |
| 水平位移速度 | `0.10×S×F×L` |
| 攀爬上升 | `0.75×S×(0.65 + 0.35×F)` |
| 水中推进／拖带 | `0.055×S×F×L`；拖带取双方推进速度较小值的 `0.65` |

登船先真实走近可达帽檐，短跳到实际受支撑的檐面后挂船，再沿可走帽面进入最终位置；飞行与帽内步行分段计时，后段按实际行进方向转身。跳跃时长与峰高分别求解，至少 6 tick，按最大逐样步长和当前位移速度限幅，不对整条跳弧缓动；基础弧高取 `0.12×sqrt(实际体型) + 0.10×水平距离` 与可用跳高中的较小值，再按越檐净空向上搜索但不超能力上限。高差、距离或越檐弧超限时拒绝，先走向可达出发檐位、改由亲油托举或寻找低落差岸位。攀爬、托举分别使用水平速度的 `0.32`、`0.28`，托举再除以 `1 + 4×被托者/载体体积比`；两者不得短于片段 pull 窗口。服务端统一扫掠碰撞与每 tick 累计位移预算，受阻保留真实位置，不用终点赋值完成。出生推出是外力弹道，不授予赤油主动跳跃能力。

拒绝只有四类：确定不行（同一对锚点不再原样重试，交回决策层换锚点）、暂时不行（对方忙、船不稳，限时等待）、中途失去接触（如船被摇晃，按事件计数、有上限）、能力不足（体型、体力或容量不足，留下真实后果）。每个阶段有时限；一次移动中失败时，若身体正随船，就走回起点，不瞬移；在船外则当场放开，由重力与落水规则处理。转移期间同一条船同一时刻只有一个移动在进行，其余在接触阶段排队；被托身体随船摇晃、漂移和压舷。接触点只由这次移动本身给出，结束时撤销。

## 落水、救助与靠岸

身体实际入水或处于气泡柱时，普通个体每 20 tick、水生魔理沙每 60 tick 失去 1 点生命；关闭 AI 也不免疫。浸水时不叠加湿透伤害；浸水计时只在连续离水 40 tick 后才清零，攀爬时的短暂干 tick 抵消不了溺水伤害。干燥帽内不计入水；帽翻覆或水淹过开口会失去干燥保护。浮力只让幼体漂在水面，不提供独立航行；落水冲击、扑腾、呼救、疲惫和离水喘息按真实阶段表现。

自救不设操帽能力硬门槛，落水者应持续尝试向帽船或近岸移动、接触并攀上。每次落水事件最多 3 次打滑；某个入舷点被确定拒绝后不再在该点重试，改游向下一个入舷点，各点都被拒绝，或游向帽船超过 600 tick，同样转向岸：与体力耗尽一样朝最近岸边弱漂，仍可能溺亡。扶正翻覆的帽子要先游到帽檐外侧，再嘴咬帽檐翻转、辫子推另一侧；握点固定，实际移动受碰撞与单步距离限制，扶正进度跟随实际位移，水域检查沿最初接触的水面进行。爬回是嘴咬帽檐加辫子勾檐。链路缺口见[待办](TODO.md#水生魔理沙模块重构)。帽子随水流漂走时只能追踪已加载且凭据匹配的原帽，不加载区块或制造替代帽。不会攀缘的赤油等幼体仍需亲油实际接近、抓握并托上船，不能以自救替代幼体救援。

帽船只因真实外因翻覆（摇晃、推挤、碰撞与乘员重心已接入，见[放下的帽子在水上](#放下的帽子在水上)；其余待重建）：玩家连续摇船或击打、水淹过帽口、重载时被摇晃或水流带动的超载判定（负载超过上限 85% 后按负载占比和水流强度掷骰，项目设计），或非火焰的伤害。翻覆时乘员被甩出，现存粮食与木桨散成真实漂浮物，帽子最终帽冠朝上；扶正由落水的帽主自己完成。成长使某名乘员在帽内无合法位置、且冲突持续约 10 秒时，冲突中体型最大且能自救的那只被挤出，从帽檐一次越过入水，之后按普通落水处理；只有船只真实烧毁或沉没才清除帽饰凭据。船长死在船上时，帽子成为无主船，帽主的托管以死亡结束且不会被他者再戴，船只漂流，船上的孩子由亲属和邻船按照护公式接走；遗体留在船长位直到靠岸或被推入水尚未实现（见[待办](TODO.md#水生魔理沙模块重构)）。

每个入水的人对应一个落水事件，由真实入水处创建：翻覆时所有被甩出的乘员各一个，挤出、水上出生漏接、船体沉没各自创建。每个（救助者，事件）只做一次友善选择：`clamp(0.10 + 0.008×友善 + 0.10熟悉 + 0.10紧急, 0.05, 0.95)`，结果记在事件上，此后所有再次询问（包括船长重新上船后）都读取同一结果；依恋不改变概率。救助者只有四种：同船的亲油；翻船后同在水里的船长自己（先把最近的赤油推向帽檐，或先抢帽，随友善而定，决定一次）；邻船的非亲水生个体，拒绝者在旁观望；岸上的个体，只在落水者在辫长或口含范围内时从岸边捞起，不下水。接受施救后，船与孩子共用一个入舷点，孩子暂停独立自救；只有仍在续约的救助者能维持指引，真实移动开始后由这次移动控制身体。够到帽檐且能攀爬才走自爬，否则先检查辫兜托举及口含路径；持续无法接触会换入口，失败或指引失效后恢复自救。物理失败按救助者记在事件上，同一救助者三次后不再尝试，落水者继续呼救、自救或溺亡。事件在落水者上船、上岸或死亡时关闭。

靠岸由服务端按真实水路、船体、碰撞、位置和干地落点规划；能跳的幼体自行上岸，赤油由亲油逐只接下。任一步无法完成就保留现场，不瞬移乘员或直接归还帽子。水生个体可以短暂陆行，持续岸上活动会增加体力负担；回到自有帽船后负担逐步消退。回岸整理帽子不会改变亚种、恢复已散落物品或修复真实损坏。

## 放下的帽子在水上

已接入、待试玩（WP4a）。任何主人放下的帽子，只要帽体在水里就按本节漂浮；地上的接生帽照旧（重力落定、不可推、帽面水平）【项目设计】。数值在 `hat_vessel.json` 的 `afloat`。

- **浮力与吃水**：吃水 = 载重 ÷ 帽冠水线面积；乘员按体型内切圆身计体积，密度取水中挣扎时中性浸没 56% 对应的 0.59，空帽很轻，储粮随 WP4b 计入。帽子正放、翻覆都受浮力，上下以弹簧阻尼回到吃水位置；翻覆时帽檐浮在水面、帽冠朝上。
- **漂移与推动**：随原版水流漂移并受水阻衰减。水上帽子可被推：油库里与帽体按质量比各自让开，玩家与其他生物推时只有帽子让开；帽体外轮廓（帽檐）与身体不重叠，正在跳跃的身体按接触落定、不被推开。撞到方块会让前侧下压。
- **倾斜**：倾角来自乘员重心偏离中央（力矩 ÷ 水线面惯性矩）、被推与碰撞，随后回弹。玩家空手右击帽子按下近侧帽檐；正在摆动时顺着摆动方向加力，所以连续摇晃会越摇越大，单击不会翻。
- **翻覆**：阈值是帽檐外缘触到水面的倾角，吃水越深阈值越小，重载更易翻。倾角超过阈值持续 4 tick，或一次超过 1.5 倍，帽子朝最低一侧翻过去；每个乘员在实际位置离帽，带着转动的帽子在该点给它的速度被甩进水里，帽子帽冠朝上漂着，不再承载乘员。扶正、游泳和登船随 WP5 接入，此前被甩出者可能溺亡，这是真实后果。
- **帽内是干的**：帽子正放、整圈帽檐高于水面时，帽里的乘员不算入水，不湿、不溺。
- **帽主与帽子**：漂在水上的帽子是帽主的船而不是接生帽，帽主可以坐进去，不参与接生，也不会被当作接生后的帽子自动收回。帽子正放、空着且帽主就在近旁时可以收回戴上；翻覆的帽子要先扶正（WP5）。主动去收帽的水上意图、帽内走动与挤落、储粮随 WP4b–6。

## 演出与交互

水上动作、表情和帽体姿态随 WP4–6 重建；客户端只读同步的状态，不选片段、不延长片段。乘员的位置、木棍在哪里（船舷存放、辫梢、嘴里、不在船上）与船况都由服务端同步，客户端不按片段推断。演出缺口最后统一补，见[待办](TODO.md#美术opus)。

右击水生魔理沙本人交付木棍；食物右击船体直接写入真实储粮，普通一次 1 份、潜行最多 8 份，生存模式下只有实际接受才扣除。装满、种类已满或其他拒绝只提示，不晃船；空手和非食物右击船体才产生物理晃动。交付物品不会发出出航、初航、返岸、翻船、没收或拖船指令，这些行为由自主需求、实际水路和接触完成。头饰摘取、托管与水上禁用见[头饰](HEADWEAR.md)。
