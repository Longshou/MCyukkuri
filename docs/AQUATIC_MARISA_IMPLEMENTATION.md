# 水生魔理沙的水上生活

水生魔理沙以自己的帽船为主要居所，在水上采食、育幼、休息和生产；靠岸只处理需要陆地的活动。设定来源包括 [水生魔理沙资料](../wiki/hakkei-reference/lore/species/marisa/aquatic-marisa.md)、N09／L25、N13 与 EH22 第 5、6 页。漂浮不等于免疫水伤，也不赋予游泳或潜水能力；N14 的潜水能力及固定死亡概率不采用。

帽船与水生日常由 `subspecies/AquaticLife`、`HatBoatEntity` 和相关家庭／伤病组件负责；帽船状态、形态与通用接口见[亚种与先天形态](SUBSPECIES_IMPLEMENTATION.md)。路线、库存、亲缘、伤势与存档各自沿用领域权威数据，不另建平行状态。

## 帽船与日常

水生种常年生活在水上。船只沿已加载的平静水面寻路，不穿岸、不走急流；划桨消耗体力。无桨时仍可漂流、休息、照料和呼唤，但不凭空获得木棍。玩家可交付真实木棍；也可从可接触的树叶或枯灌木取得一根，受 `mobGriefing` 约束。

岸边是水生个体的自主活动偏好，不是移动禁区。闲逛会优先选附近干燥的近水位置，找不到时仍可在内陆正常移动；拾取、觅食、照料、温度避难和逃跑沿用各自真实路径与危险检查，不要求目的地或每个路径节点靠水。已有出航行为仍主动寻找可达岸线。下雨时暂停主动出航与水上生活偏好；在帽船上遇雨会请求真实靠岸，上岸后由普通避雨 Goal 搜索可达遮蔽处，不要求遮蔽处靠水。雨中湿度每秒 +1.5，满 100 后每 200 tick 扣 1 血，比普通种积累慢、伤害间隔长；雨伤不产生位移。陆地速度降低 40%，陆地活动累计 600 tick 后降低 65% 并持续付出疲劳代价；回到干燥帽内逐渐恢复【项目设计】。

帽船总容量为 12 份：食物 1、木桨 1、赤油 2、子油 4、亚成油 8；帽主驾驶位不计入，预约座位也占位。粮食、乘员和木桨共用容量，粮食最多四种堆叠。满载时不能靠重叠、临时座位或压缩角色突破上限；可让帽主将真实粮食暂放侧檐或抛到水面，暂放粮仍占空间。成长后超载会暂停新增乘员，直到进食、卸货或有人离船。

帽内只显示真实乘员和库存。粮堆占空间但不可站立，内座和帽檐位置必须有完整支撑；早期子油仍按 4 份占位。紧急救援可腾粮但不丢木桨，正常休息或照料只在确有安全位置时腾挪库存。库存转移保留同一份食物与唯一帽饰凭据，收帽、翻覆、沉没和重载都不能复制或补回已消耗物资。

水生帽与普通魔理沙使用同一帽形，比例为 1.5 倍；水生帽与普通帽仍是不同物品。倒置为船时帽冠压扁并沉在水下，帽檐高出水面，帽内保持干燥。帽子是帽船本身，不是交互工具；油库里用辫子和嘴与物体互动。帽船属于水生魔理沙，陆生魔理沙不会靠落水凭空造船；已在旧船上的陆生魔理沙仍可按原流程靠岸。

粮食来自实际拾取或采集。帽内家庭按正常进食结算；缺粮时先寻找可达漂浮食物和岸缘食源，确需陆地活动时走真实返岸、采集和复航过程，不补粮。夜间、雨雪与温度不适会寻找合适停宿水面或请求靠岸；帽子本身不是屋顶、火源或保温窝。睡眠、繁殖、关系和饥饿时钟均沿用各自系统的真实已加载时间。

库存按当前环境和乘员需要补充：冬季群系仍提高当下储备需求，饥饿乘员与未独立船长仍可触发真实补给；秋季群系使用日常目标，不为未来冬季额外囤粮。

## 家庭、照护与初航

帽船承接水生家庭的住所、携粮和亲子照护。亲油从真实库存取粮，停船靠近孩子，经实际接触交付；新生儿由亲油先嚼糜再喂，孩子吞咽后才获得营养。亲昵与安抚也要求识别、可达和近身接触；照护由友善主导，依恋不增加喂养或救援意愿。水生魔理沙只与水生魔理沙配对。

生殖行为只在岸上发生；水生母油随后回到水上，在自己的帽船中生产，不需要伴侣或靠岸。有伴侣时，对方可自行划到船边陪护；新生儿按真实容量分到双方帽中，余量不足时留在母船。漏接会使孩子真实落水，继续执行溺水伤害和救援规则。

具备固食、起跳和学习能力且体型达到成体的 0.20 后，子油才能在亲船导师陪同下初航。练习需使用自己的帽子和真实木桨，实际放帽、登船、短程划行、返回并收帽后才记录学会；中断不发奖励。完成初航后可以在亲船附近独立操帽和生活，但不因此提前离家或免除亲代照料。离家仍须满足原有年龄、营养成长与独立生活资格。

子油乘亲船时保留自己的头饰；搭乘亲帽与使用自己的帽子放船是不同状态。赤油不能自行跳帽，由亲油以真实接触和辫子托举移动。随亲、互助、返帽与收纳均检查亲缘、识别、真实位置和容量；未加载不等于死亡，不创建替身船或替代亲代。非亲生落水幼体只能通过实际救援预约和登船取得临时照护席位，靠岸交接后解除，不改写亲缘。

## 落水、救助与靠岸

身体实际入水或处于气泡柱时，普通个体每 20 tick、水生魔理沙每 60 tick 失去 1 点生命；关闭 AI 也不免疫。浸水时不叠加湿透伤害，离水后重置浸水计时。干燥帽内不计入水；帽翻覆或水淹过开口会失去干燥保护。浮力只让幼体漂在水面，不提供独立航行；落水冲击、扑腾、呼救、疲惫和离水喘息按真实阶段表现。

自救不设操帽能力硬门槛，落水者应持续尝试向帽船或近岸移动、接触并攀上；体力耗尽后朝帽船或最近岸边弱漂，仍可能溺亡。链路缺口见[待办](TODO.md)。帽子随水流漂走时只能追踪已加载且凭据匹配的原帽，不加载区块或制造替代帽。不会攀缘的赤油等幼体仍需亲油实际接近、抓握并托上船，不能以自救替代幼体救援。

翻船时先按真实乘员和状态处理落水，再散落现存粮食与木桨；只有船只真实烧毁或沉没才清除帽饰凭据。亲油遇到落水孩子后，按友善、熟悉程度与紧急程度作一次救助选择：`clamp(0.10 + 0.008×友善 + 0.10熟悉 + 0.10紧急, 0.05, 0.95)`。依恋不改变救援概率。接受后沿同一物理尝试重试，不在每次碰撞中重新抽签；失败、体力耗尽或真实危险仍可能导致孩子溺亡。一般落水救助也由友善、熟悉和紧急程度决定。

靠岸由服务端按真实水路、船体、碰撞、座位和干地落点规划；能跳的幼体自行上岸，赤油由亲油逐只接下。任一步无法完成就保留现场，不瞬移乘员或直接归还帽子。水生个体可以短暂陆行，持续岸上活动会增加体力负担；回到自有帽船后负担逐步消退。回岸整理帽子不会改变亚种、恢复已散落物品或修复真实损坏。

## 交互与场景边界

右击水生魔理沙本人才能交付木棍或食物：木棍按既有规则进入本人或船内库存，食物仍走通用喂食；右击船体只产生一次物理晃动，不交付物品，也不发出出航、初航、返岸、翻船、没收或拖船指令。这些行为由自主需求、实际水路和接触完成。头饰摘取、托管与水上禁用见[头饰](HEADWEAR.md#暂放帽船托管与真正失去)。

`/yukkuri scenario boat` 用于建立专项目标的真实初态，`/yukkuri aqdiag on|off` 输出服务端阶段诊断；观察笔记显示真实船况、乘员、容量、物资和行为阶段。展示读数不驱动寻路、登船、生产或救援。显式调试返岸入口与数字 ID 用法见[试玩场](DEVELOPMENT.md#清场与场景构造边界)，不属于普通玩家右键交互。

自主出航场景必须从干岸上的普通成体或真实亲子关系开始，只提供有限木棍与口粮，让普通生活需求和物种规则产生找桨、备粮、放帽、登船和出航动机；不得直接把船建在水上、指定 Goal 或延迟命令完成行为。返岸、翻覆、自救、载荷和接生等后半段目标可以从符合该目标的真实水面初态开始，但初态不算被测行为成功。场景入口和待复测项见[待办](TODO.md)。
