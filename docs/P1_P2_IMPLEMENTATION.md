# P1–P2：生活、住所与互动

> 专服、多人、成长家庭、家油巢卵及基础伤病的现行实现见 [核心玩法记录](CORE_GAMEPLAY.md)。

P1–P2 的最小玩法已实现。专服、双客户端竞争／晚加入、正常生存长时间游玩与规模性能仍待在游戏里验收。

本页描述当前实现。

## 生存操作

| 目标 | 操作与结果 |
| --- | --- |
| 发现个体 | 普通灵梦、魔理沙在指定平原、森林和草甸群系的干燥草地自然生成，受光照、原版生物生成和局部上限约束。家油暂不自然生成 |
| 观察 | 观察笔记右键个体，查看生活数值、家址、口中食物、饰品、六种倾向及它对当前玩家的记忆；对空气使用打开四页指南 |
| 喂食 | 手持苹果、面包、胡萝卜、曲奇、西瓜片或甜浆果右键，或把食物丢在干燥可达地面；一次取一件，含住、咀嚼、吞咽后才增加营养和生命 |
| 食盆 | 右键打开九格库存，存入食物。实际库存决定盆内显示；耗尽后寻找其他食源，取食遵守 `mobGriefing` |
| 安置 | 在有入口和屋顶处放草窝；笔记右键草窝选择位置，再潜行右键个体登记。每窝一名住户；个体也会寻找可达遮蔽 |
| 运输 | 携带箱右键收纳单只，右键有安全空间的方块放出；身份和生活数据保留。碰撞或水中放置失败时保留箱内个体 |
| 清洗与清扫 | 湿布对水源使用可补足八次水量，右键个体清洗。对沙厕使用清出实际积存的排泄物；满厕不再接收，缺少可用厕所时会在地面排泄 |
| 说话 | 空手右键温和说话，潜行空手右键冷淡说话。信任、恐惧和冷却按玩家分别记录，反复查看笔记不加好感 |
| 玩具 | 丢下毛线球，感兴趣且没有紧迫需求的个体会接近、探看并轻推，不吃掉玩具 |
| 饰物 | 潜行持剪刀右键取下饰物，再持实际取出的饰物右键原主人归还；帽子／蝴蝶结随状态显隐 |
| 学习 | 取得至少 10 信任且恐惧低于 30 后，持教学哨右键。完成三次课程学会短时等待；课程间隔至少 240 tick，离开、危险或紧迫需求会打断 |

观察笔记、食盆、草窝、沙厕、携带箱、湿布、毛线球、教学哨共八种物品有生存配方与配方书解锁。饰物来自实际取下，排泄物来自实际生活过程，均无凭空产出配方。配方以 `src/main/resources/data/mcyukkuri/recipe/` 为准。

## 生活与资源规则

生活数据只在实体已加载并实际模拟时推进，收纳、离线和卸载期间不补算；`AgeTicks` 是模拟年龄计数，不代表成长阶段已经实现。饥饿、精力、清洁、湿透、如厕需求、家址、进食进度与人格保存到实体 NBT。

一餐分 64 tick，45 tick 时吞咽结算。取食时从原库存扣除一件，吞咽前中断可落回一件，吞咽后不再退回；存档和运输保留嘴中物品及阶段。分享转移的是这一件实际食物，争抢也只允许一个赢家。有向关系只在对应参与者之间更新。

家址包含维度和方块坐标，寻找设施不强制加载区块。当前区域的家址被拆、被占用或不可达时会重新选择；区块暂未加载不等同于住所被拆。回巢休息包含入睡、恢复和醒来阶段。躲雨要求实际到达遮蔽处，不能只在屋檐附近停步。

短洗增加清洁且只带来少量湿透；雨淋与浸水有不同积累速度，持续湿透达到阈值后受伤。2026-10-16 按用户要求另设直接入水伤害：全部种类／形态的身体在水或气泡柱内每 20 tick 扣 1 点生命，不等待湿度阈值，关闭 AI 也适用；浸水期间不叠加湿透伤害。干燥帽内乘员不视为入水。普通种拒绝主动跨水，落水后尝试沿可达路径逃向干岸。火伤与其他危险优先中断进食、休闲和教学。

携带箱用一次性凭证引用完整个体，另存身份摘要；完整个体由世界 `SavedData` 托管。放出保留 UUID，并使凭证失效；复制旧箱子不能再次放出同一个体。该规则已做引擎内复制凭证检查和单人磁盘重启验证，双客户端竞争仍需专门验收。

## 个性与社交

好奇、社交、胆量、关怀、秩序、耐心分别保存先天值与后天经验。它们参与接近意愿、玩具选择、分食、竞争等待和课程时长。观察页显示当前综合倾向；投喂、洗净、实际交流、受伤等事件才更新相应记忆。

同伴关系保存在世界级有向表中。失饰影响观察者的识别，不删除既有关系；归还原饰物后恢复识别。（2026-10-18：原“金章例外”已由观察者智力判定取代，见[头饰](HEADWEAR.md)。）亲缘、配偶、家庭、完整 41 张情景卡、成长与繁殖属于 P3 及后续范围。

## 配置与实现入口

服务端配置 `mcyukkuri-server.toml` 的默认值是 MC 首版参数，不声称等于八景 U 原始数值。

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `life.hungerInterval` | 240 | 每消耗一点营养的加载 tick |
| `life.energyInterval` | 160 | 精力消耗间隔 |
| `life.hygieneInterval` | 300 | 清洁消耗间隔 |
| `life.wetDamageThreshold` | 60 | 身体离水时的持续湿透伤害阈值；不影响直接入水伤害 |
| `discovery.naturalSpawns` | true | 是否允许普通种自然生成 |
| `discovery.localSpawnCap` | 8 | 附近自然生成上限 |

生活与设施位于 `life/`，人格与行为位于 `social/`，生存工具位于 `item/`。公共实现不引用客户端类；渲染器读取同步后的行为、起始 tick、嘴中物品、饰物和对白。

新设施的制作源、角色嘴部挂点和咀嚼参数见 [care-facilities](../art/props/care-facilities/README.md)。四种角色的选定模型、骨架、19 个动作和贴图继续沿用 [运行来源登记](../art/runtime-sources.json)，未改变标准造型或确认指纹。设施是当前开发造型，实机审查不代替用户确认。
