## 本轮客户端画面

均为独立 `p0-preview` 世界中真实生成器产出的实体，拍摄时暂停 AI，场地由验收夹具提供树木与地面。它们验证实体组成和显示，不代表自然森林遭遇率或长期生存验收。为避免多种帽饰互相覆盖，生成位置至少间隔 2 格。模型本身未在本任务修改，截图不新增标准造型确认。
