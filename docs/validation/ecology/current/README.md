## 修复与边界

- 首轮缺少 GameTest 模板前缀注解，已补齐。野外排泄的规则检查曾在同一 tick 查询刚加入的实体，读到旧索引；现在在真实引擎推进后检查单份实物，同时保留动作前不结算的断言。
- 近处玩具在落地首帧调用寻路失败，立即取消互动。改为不足一格时先直接接近，远处才寻路；恢复了真实接触与好奇经验，保留原社交冷却。
- 教学入口补四格距离和视线检查，拒绝不占教学冷却。讲师夹具每次从实际位置走近听者后发指令，三次学习、等待和重载记忆均通过。
- 收容篮夹具按真实主手物品调用；没有回退收容任务的物品所有权修复。
- 擦脸原先只保证碰撞盒接触，模型面部仍有空隙。现在按双向同步同伴及实际嘴面深度补齐间隙，根变换同时覆盖身体附属；最后一次冻结客户端已复拍成体、幼体和家油场景，各对真实完成次数均为 1。
- 第一轮失败日志和逐 tick 玩具样本留在 `.local/ecology/gametest/`，没有用修复后结果覆盖失败报告。
