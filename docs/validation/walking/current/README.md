# 七种角色走动验收

日期：2026-09-13。本轮对应[走动配方与接入说明](../../../../art/source/standard-runtime/WALKING.md)，效果见[实机动图](../../../../art/source/standard-runtime/previews/current/walking.html)。

| 检查 | 结果与范围 |
| --- | --- |
| 数据一致性 | 七种现有角色分别通过 `validate_entity_assets.validate`；快照、运行资源、19 段动作、骨架、绑定、11 套贴图及来源指纹一致 |
| 动作采样 | 每种角色采样 121 个时点，油菊有实际左右位移，所有可见顶点有限，最低点不低于地面，首尾顶点一致；见 [mesh-checks.json](mesh-checks.json) |
| 构建 | 本轮生产修改初次 `build compileP0TestJava` 成功；后续新增夹具以既有 JDK 21 对完整七种快照编译成功 |
| 引擎运动 | 隔离 GameTest 通过；七种角色分别核对每 tick 0.004 格、0.04 格的实际移动均选中 `waddle`，静止恢复 `idle`，离地不自动走动；速度与位移见 [server-checks.json](server-checks.json) |
| 客户端姿态 | 实际 Java 模型左右两阶段顶点不同，家油搬运仍有步态、夹持点有限且存在；结束后待机顶点恢复；见 [client-checks.json](client-checks.json) |
| 实机录制 | 七种角色各录制约 8 秒慢走和停下，另录两种家油持有一份食物碎屑行走；所有搬运帧份数保持为 1；见 [game-captures.json](game-captures.json) |
| 关联资源 | 伤口导出、共点绑定及指纹检查通过；生活、家庭与家油资源的现有 `--check` 通过 |

实机使用 Minecraft 1.21.1、NeoForge 21.1.250 和项目已有 JDK 21。为了不覆盖同时开发的掠食种、亚种和其他接线，冻结了项目内此前完整的七种运行包，再编译本轮移动判定与客户端叠加逻辑，装入本轮七种模型、伤口和徽章数据。基础包及资源指纹见 [runtime.json](runtime.json)，完整日志、原始截图、状态时间线与可复现脚本位于 `.local/waddle/`。初次直接启动共享构建时，另一任务刚注册的 `remilia` 尚缺运行模型；全局资源脚本也因枚举已增加到九种而未通过。上述冻结结果不等价于整个当前工作副本通过，九种角色的合并验收由对应任务继续执行。

录制夹具清除随机目标后施加受控速度，由实际 `travel` 处理地面碰撞和摩擦，再由普通 `aiStep` 自行选动作；没有用 `playAction` 强制走动。客户端位置包在服务器停止后仍有短暂插值，因此最后两帧可能已显示待机而位置尚在收敛；持续移动区间与稳定停下分别核对。该检查证明普通移动的动画选择与渲染，不代替完整寻路、多人同步或玩家长时间体验。

已自行查看本轮正面、侧面、背面、斜面与左右极值，以及实机慢走、停下和搬运帧。未委派独立审查；动作是否达到用户希望的可爱程度仍待用户观察。标准库的既有造型确认不变。本轮启动的客户端和 GameTest 进程已结束。
