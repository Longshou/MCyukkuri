## 已发现并处理的问题

- 新增捕食种缺少固定具适配，伤口定位在固定姿态下读取空资源。捕食任务补齐两种角色的固定具、吊带、铁箱及制作源、导出登记，并增加九种完整资源覆盖检查。
- 普通剪茎只按弧根离地高度放置，某些两胎短茎的成熟幼体包围盒进入支撑地面。胎生任务改用成熟挂位的固定净空，并给抬高的弧根补可见直茎连接；瓶装变换不变。
- 旧核心测试把钝伤当作会漏馅的裂伤；现分别用真实普通伤害与锋刃伤害检查。
- 捕食场景的初始墙遮住了猎物，旧成功依赖随机漫游爬墙。现单独验证遮挡拒绝，再从实际可见的低障碍场景记录追逐、跨越和咬中。
- 家油退出和回地面只取窗口末帧，会混入后续回巢或跳跃。现连续记录真实退出、地面支撑、无穿透和 UUID 唯一性。
- 住所资源夹具允许工人随机离开唯一草的搜索范围。现用真实院墙限制场地，保留采收与搬运，并在成功或失败时清理夹具。
- 豆体子代正确成长后的碰撞宽度可能小于旧通用阈值。现按受孕时固定的形态核对精确宽高，同时要求实际长大。
- 豆体母体分娩时请求 `chewing_closed`，八套亚种仍只有旧的 11 种表情。亚种任务补齐五种新增表达的来源选择、快照和运行导出；客户端检查扩为八套乘 16 种全部解码与加载，螺壳维持 256×256，其余七套为 128×128，没有用默认表情掩盖缺图。
- 两客户端争抢携带时，一方成功后，另一方可能先收到实体移除同步再执行操作。旧脚本把此合法结果判失败；现仅在携带竞争允许这个明确结果，并仍要求至少一方发送实际互动、服务端只有一枚凭证且原母体从世界消失。旧轮失败和续程证据保留。
- 剪茎补拍夹具把父母放在相距五格处，超过真实受孕的三格上限。现改为相距两格，并保留真实受孕和实际剪切入口；拒绝时输出双方资格、识别和寻路诊断。

所有失败保留在各轮固定副本中；本页最终通过数量仅引用最终指定产物。

## 验收边界

受控夹具会设置初始个体状态、布置村落 POI，并在出生检查中缩短孕育时长。实际导航、互动包、物品扣除、身份账本、区块卸载、磁盘停服和客户端同步仍由游戏执行。

联合初态包含九种注册实体、豆体母体、螺壳魔理沙、徽章、明确设置的认知初值，以及通过真实家庭接口分配的暂停孕育。认知初值是验收夹具，不能当作自然生成分布的证据。恢复出生显式把孕育设为 200 tick、已进展 195 tick，随后由正式出生逻辑处理出口、子代身份与落地。剪茎补拍固定在完整视觉尺寸但尚未成熟的进度，便于稳定观察两个果实的挂接与地面净空。

本轮不代表默认速度多代生存、长期种群和平衡、大型模组包或可选模组兼容已经完成。技术视觉审查也不替代用户对新增造型的确认。
