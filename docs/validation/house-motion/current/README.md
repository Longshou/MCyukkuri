# 家油贴面头发动作修正

2026-09-13，针对两种家油左右伸展时头发与身体错位的反馈，修正 `scripts/export_runtime_models.py` 中的运行绑定配方。旧配方只有包覆发层随身体分段弯曲，发冠、太阳穴和刘海仍刚性绑定 `hair`；修正后所有贴面头发共用身体的连续双骨骼权重。独立侧发、帽子和蝴蝶结保持原挂点。

两份运行模型只有 `weights` 字段变化，灵梦重新绑定 2880 个三角面顶点，魔理沙 2268 个。静态几何、骨架、动作曲线、源 BBModel 与其他五种运行模型均保持一致。选定来源及配套导出的路径与指纹见 [来源登记](../../../../art/source/standard-runtime/provenance.json)。家油造型仍待用户确认，本轮不更新标准批准记录。

## 本轮检查

- 导出检查：七种模型、19 个动作、绑定、贴图和源指纹一致；生活、家庭与周边导出检查通过。
- 浏览器预览：两种家油的 19 个动作各取 25%、50%、75% 三个时刻，检查头发贴合；侧弯及横向体操另核对前、斜、背视角与待机。
- 独立数值审查：横向体操每 0.01 秒取样，共 237 帧，检查实际蒙皮后的头发顶点、三角面边中点及面心。对静止时在身体外部且间隙大于 0.005 单位的点，最大新增埋入约 0.003455 模型单位，位于魔理沙 t=0.60 秒的刘海面，当前预览不到一个像素。此检查不等于严格证明整个连续表面绝无相交。
- Minecraft 实机：两种家油 × 前、斜、背三个视角 × `side_bend`、`exercise_sides` 两段动作，共录制 360 帧，另采集回正待机画面。审查代表帧的贴合与帽根，未见此前的错位。客户端对七种模型的 133 段动作进行 798 次采样，动作复位、饰物显隐、咀嚼与 35 张行为贴图解码通过。
- `gradlew build compileP0TestJava` 通过。本轮只改运行绑定，没有重新执行服务器玩法 GameTest、多人或长期生存验收。

[实机动图](../../../../art/source/standard-runtime/previews/current/house-side-stretch.gif)按录制顺序每 100 毫秒播放一帧；左右分别为家油灵梦和魔理沙。原始截图只裁切取景，不改变宽高比例。多角度精选图为本目录 `reimu-*.png`、`marisa-*.png`；完整临时帧序列位于 `.local/house-motion/`。
