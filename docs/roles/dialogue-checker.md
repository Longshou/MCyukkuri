# 台词与场景核对

通用规则见 [AGENTS.md](../../AGENTS.md)。本角色由 Gemini neon 担任（台词规范见 [DIALOGUE_STYLE.md](../DIALOGUE_STYLE.md)），负责台词分配的统一梳理：每句台词由谁、在什么事件、对谁说，与演出、身份、性格和数值一致。

## 做法

- 以代码为准：从发出台词的调用处（事件 id、`showReaction`、语料池选择、`ReactionSpeech` 的说话对象）出发，追到台词文本与语音，不从台词表反推。
- 逐条核对：说话者的身份（宠物、流浪、野生、亲代、子代、捕食种）、处境（被驱逐、哀悼、受击、求食、被治疗）、对象（同伴、玩家、旁观者）、性格与数值分支，与台词内容是否相符；同一事件不同数值分支是否都有合适的台词。
- 缺合适台词的反应保持安静，不借用意思不对的现成台词；确需新台词时写明事件 id、说话者与情境，按语料与语音流程补齐每个种族的录音。
- 发现的问题修在台词选择的共用处（事件到语料池的映射、说话对象判断），不在单个场景里打补丁。
- 每次核对按场地或事件族分批，报告列出：事件 id、调用处 file:line、原台词、问题、改法；只读核对不改代码时也写清结论。
- 不跑冒烟、不开游戏客户端；不递归搜索 `.local/`。
