# 情绪链：不能慢慢来 → 甜化 → 非油症；取名即否定身份

代码在 `src/main/java/io/github/longshou/mcyukkuri/mind/`（`MindLife`、`Naming`）。每只油库里（野生、流浪、聚落、家油、宠物、捕食种）都有同一个 `unease`（不安，0–100），它是权威数值，登记为状态键 `mood.unease`。`PetLife.stress` 现在只是它的视图（读取取整，`addStress` 写进同一个值），旧存档的 `YukkuriPet.Stress` 在第一次读档时迁入。

## 1. 设定依据

| 来源 | 内容 | 项目处理 |
| --- | --- | --- |
| komicolle 40720 No.11518890「甜化與非油症」 | 只要感到不能慢慢来，内馅就会变甜；过于不能慢慢来会发疯，只能喊「油庫己」（ゆっくち），内馅变得非常难吃 | `unease` 驱动馅料甜度（`sweetness`）；顶点触发非油症：只会喊叫、馅料变难吃（foul） |
| No.11518802 身体构造 | 除非非油症病变或馅流失过多，不伤中枢馅不会死 | 非油症是可致死的终末病态（三个游戏日病程），不是靠伤害致死 |
| No.11518829 头饰与身份 | 失去头饰会造成极强压力与不能慢慢来的感觉；给油库里取名＝否定「灵梦是灵梦」，非常不能慢慢来，幼体甚至吐馅身亡 | 失饰是最强的持续压力源；取名反应见第 5 节，**按用户决定不致死** |
| 回帖 No.11519618 | 屎＝超级不能油库里，尸体＝永远不能油库里 | 附近的尸体、粪便是压力源 |
| wiki `hakkei-reference/world/resources-ecology.md` W 段、`individuals.md` 称名边界 | 甜化与非油症是常见写法（另有“馅料美味”的相反版本）；不把命名写成普遍死亡机制 | 冲突处以讲堂帖为准（取“难吃”版本）；命名不致死与 wiki 边界一致 |

讲堂帖没有给出阈值、病程、治疗方法。下面的数值、三阶段病程、"狂乱期可救、衰竭期不可救"、安抚减半等都是**项目设计**。

## 2. 数值与时间尺度

速率单位是“每分钟”（1200 tick，即 1/20 游戏日），每 100 tick 采样一次。

**持续压力（采样）**

| 条件 | 每分钟 |
| --- | --- |
| 营养 < 10 / < 25 | +3 / +1.5 |
| 伤口或灼伤（取较大等级） | +0.5 × 等级，至多 +3 |
| 馅 ≤ 6 份 | +1.5 |
| 感染或霉 | +0.5 |
| 没有头饰 | +3 |
| 惊慌中 / 威胁反应中（`Reactions.Threat`） | +2 / +1.5 |
| 体感寒冷 / 湿度 ≥ 60 | +1 / +1 |
| 流浪（`identity.kind=stray`） | +0.3 |
| 被聚落排斥（`SettlementSociety.dejected`） | +1 |
| 2.5 格内非亲属、非同聚落者 ≥ 6 / ≥ 10（宠物、有主、家油不计） | +1 / +2 |
| 6 格内看得见尸体 / 3 格内有粪便 | +1 / +0.5 |

**持续缓解（采样）**：基础 −1（与原宠物压力相同）；睡眠再 −1；在家（窝/住所内、窝位 3 格内、家油巢 4 格内、宠物主人 16 格内）再 −1；正在蹭蹭、被舔舔或被揉（接触中）−6。

**事件（`showReaction` 的事件名，同一事件有冷却）**

| 事件 | 变化 | 冷却 |
| --- | --- | --- |
| `family_died`、`birth_lost`（丧亲、产下死胎） | +30 | 600 |
| `lost_accessory`（失饰） | +15 | 600 |
| `settlement_hurt`、`settlement_submit`（被逐、被贬） | +8 | 600 |
| `wounded`（受伤、目睹漏馅） / `afraid`（受惊、被欺负） | +4 / +3 | 600 |
| `lost_parent` / `unrecognized` / `cold`（冷遇、风暴） | +5 / +3 / +2 | 1200 / 600 / 600 |
| `sole_burned`（底面烤伤） / `bitter`（苦、毒、辣入口） | +8 / +3 | 600 / 300 |
| 粉末戒断（`YukkuriLife` 成瘾，每 600 tick） | +2 | — |
| 听到同伴非油症的喊叫（8 格） | +1.5 | 200 |
| 吃下难吃的馅 / 辛辣 | +12 / +6 | — |
| 吃饭 / 甜食（非主人喂宠物；主人喂宠物仍走 `Sweets.eaten` 的 −4～−12） | −3 / −8 | — |
| `returned_accessory` / `treated` / `nuzzle_done` / `gentle`、`lesson_praised` / `leisure_done`、`toy` | −20 / −4 / −4 / −3 / −2 | 0–400 |

宠物系统原有的 `addStress`（考试、训斥、冷落、徽章社交等）原样写进 `unease`。`YukkuriLife.distress()`（情绪失禁的唯一压力读数，阈值 `DISTRESS_LEAK=80`）读的也是 `unease`，所以甜化很深（≥80）的任何个体都会失禁漏出。

**阶段**（`mood.mind_stage`）

| 阶段 | 条件 | 表现 |
| --- | --- | --- |
| `calm` | < 35 | 无 |
| `uneasy` | 35–60 | 偶尔（约 1/3 机会，每 3–6 分钟）说 `uneasy`（暂用 `mood_bad`：“不太能慢慢来呢……”） |
| `sweetened` 甜化 | ≥ 60 | 平时含泪（`teary`）；进入时 `droop`；每 1.5–3 分钟哭诉一次。馅甜度累积 |
| `non_yukkuri_frenzy` 非油症·狂乱 | ≥ 95 持续 1200 tick | 见第 3 节 |
| `non_yukkuri_withering` 非油症·衰竭 | 狂乱满 1 游戏日 | 见第 3 节 |

**馅料甜度**（`mood.sweetness`，0–100）：`unease ≥ 50` 时每分钟 +(unease−40)/20（60 时 +1，90 时 +2.5），`unease < 35` 时每分钟 −1。掉出的馅（`FillingResource.portion`）带 `Sweetness = 60 + 0.4 × 甜度`（`health.filling_sweetness`），≥ 85 时营养 6；非油症个体的馅 `Sweetness 5`、`Taste foul`、营养 3，同族和捕食种不到饥饿（营养 < 15）时不吃。捕食种选猎物时把甜度 ×0.6 从距离评分里减掉（更偏好甜化个体），非油症个体 +80（避开）。

**平衡**：有家有食的个体只有零星事件，基础与在家缓解每分钟 −2，长期停在 0 附近。失饰且无人安慰：先 +15，再每分钟净 +2（睡在家里约 0），约一个游戏日进入甜化、两个多游戏日接近非油症；家人蹭蹭每分钟 −6 能稳住。持续被捕食种盯着（威胁 +1.5，受惊每 30 秒 +3）十分钟左右才到 45 上下。

## 3. 非油症病程

1. **发病**：`unease ≥ 95` 连续 1200 tick（1 分钟）。日志 `[mind] ... non-yukkuri onset`。
2. **狂乱期（0–24000 tick）**：`FrenzyGoal`（优先级 1，只让给水、手术、宠物课程、进食中、分娩、牵绳）接管行动——在原地乱跳（`hop`）、挣扎（`struggle`）、乱窜，不再过日常生活（社交、筑巢、储粮、玩耍、平常的觅食与睡觉），只有饿极、困极、憋不住（`hasUrgentNeed`）时才去吃、睡、如厕，否则半天就会饿死；亲属来蹭蹭、舔舔或被人揉时也会停下来接受；每 3–6 秒喊一次。**所有台词都换成喊叫**（`YukkuriEntity.speak` 先经 `MindLife.voice`）：事件 `non_yukkuri`，「ゆっくち！ ゆっくち！ ゆっ、ゆっ、ゆっくちぃぃ！」（油库己！油库己！油、油、油库己——！）。表情 `dazed`。缓解只有一半效果；`unease` 被安抚到 < 70 即恢复为甜化（日志 `recovered`）。能把它拉回来的是蹭蹭／舔舔（每分钟 −3）、主人喂甜食（每块 −2～−6，按种类）、温柔说话等。
3. **衰竭期（24000–72000 tick）**：不可逆。多半在原地发抖或垂头（`tremble`／`droop`），每 10–20 秒喊一次，表情 `blank_cry`，每 2400 tick 生命 −0.2（不低于 1）。
4. **死亡**：发病满 72000 tick（三个游戏日），调用 `BodyLife.damageCore("non_yukkuri")`——讲堂帖说非油症是少数不必伤到中枢馅也会死的病变，这里由病变本身伤到中枢馅（死亡统一经过中枢馅，见 [伤病与遗体](INJURIES_AND_REMAINS.md)）。

## 4. 表现入口

- 行为 ID：`non_yukkuri`、`non_yukkuri_wither`（排在行为链最前）；表情由 `MindLife.face` 替换空闲时的默认脸。
- 观察标签：`不安NN`、`甜化NN`、`非油症`。
- 状态键：`mood.unease`（可写 0–100）、`mood.mind_stage`（可写 `frenzy|withering|recover`）、`mood.sweetness`（可写）、`mood.non_yukkuri_ticks`、`mood.unease_causes`（上一采样的各项每分钟速率）、`mood.namings`、`health.filling_sweetness`；`mood.stress` 是 `unease` 的取整。
- 存档：`YukkuriMind`（`Unease`、`Sweetness`、`Course`、`CourseTicks`、`BreakingTicks`、`Namings`、`Migrated`）。
- 日志：阶段变化、发病、恢复、衰竭、死亡、命名反应都以 `[mind]` 写入服务端日志；`/yukkuri status trace true` 时每次 ±1 以上的直接变化也会记录。

**对白事件**（项目原创、未配音、三语，分赤油／子油／成体三档，由 `scripts/build_speech_tiers.py` 的 `EMOTION` 表生成，再跑 `scripts/export_dialogue.py`；某个种族／档位没有台词时 `MindLife.pick` 回退到括号里的旧事件）：

| 事件 | 场合 | 回退 | 例（灵梦成体） |
| --- | --- | --- | --- |
| `uneasy` | 不安、甜化时的哭诉 | `mood_bad` | 「れいむ、ぜんぜんゆっくりできないよ……」／“灵梦一点都没法慢慢来哦……” |
| `non_yukkuri` | 非油症的喊叫（替换所有台词；优先级 3） | `afraid` | 「ゆっくち！ ゆっくち！ ゆっ、ゆっ、ゆっくちぃぃ！」／“油库己！油库己！……” |
| `renamed_upset` | 被取名（成体抗拒 / 幼体哭；优先级 3） | 成体 `request_sulk`，幼体 `afraid` | 「れいむはれいむよ！ そんななまえじゃないよ！ ゆっくりできないよ！」；赤油「れいみゅはれいみゅぢゃよぉぉ！ ゆっ、ゆっーっ！」 |

术语：讲堂帖的「油庫己」在中文台词里写作“油库己”，`wiki/glossary.md` 尚无条目（报告 Q4），建议入库。

## 5. 取名即否定身份（包 1）

给油库里的个人名字（原版命名牌右键，或 `/yukkuri name <目标> <名字>`，两者走同一个 `Naming.named`）：

| 对象 | 反应 |
| --- | --- |
| 幼体（赤油、子油） | `struggle` + 哭脸 + `renamed_upset`；吐出 1 份馅（第 3 次起 2 份；**馅 ≤ 3 份时不吐，所以不会致死**）；`unease` +25，之前每记着一次再 +10（单次至多 +50） |
| 成体 | `sulk`（第 3 次起 `hide_face` + 含泪）+ 生气脸 + `renamed_upset`（“不是那个名字”）；`unease` +12，每多一次 +6（至多 +30） |
| 用自己的种名（灵梦、れいむ、reimu……，名字里含种名即可） | 不算否定：高兴地自我介绍（`introduced`，“灵梦是灵梦喔”），`unease` −2 |
| 主人给自己的宠物取名 | 上述增量 ×0.6（项目设计；宠物线没有命名体系，考试里“问名字”时油库里答的就是种名） |

反复取名累积在 `mood.namings`（每游戏日忘掉一次）。命名牌照常写上名字；名字不改变种族、身份、亲缘。吐出的馅是真实的馅物品，附近目击者照常受惊。

## 6. 未做与后续

- 甜化的外观只有表情和动作，没有专门的贴图（例如脸色、汗）；如需要，交美术在表情集里加“甜化”脸。
- 非油症没有专属动作，借用 `hop`／`struggle`／`tremble`／`droop`。
- 甜度只影响掉落的馅与捕食种偏好；遗体（`RemainsEntity`）尚未记录死者的甜度与非油症（交 B 批“陈馅、遗体”包）。
- 头饰随身体成长／碎裂（包 6）、同类相食（包 7）落地后，应各自调用 `mind().add` 或沿用 `lost_accessory` 等事件，不要另建压力值。
- 家油的数值未单独平衡（家油不计拥挤）。
