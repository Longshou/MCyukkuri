# 油库里用语与演出台词规范

本文件为本仓库对白制作、润色与核对的统一规范，依据 Wiki（[对白总览](../wiki/hakkei-reference/dialogue/README.md)、[通用短语](../wiki/hakkei-reference/dialogue/common-phrases.md)、[种族口吻](../wiki/hakkei-reference/dialogue/species-variants.md)、[成长与语言](../wiki/hakkei-reference/dialogue/growth-stages.md)、[作品对白证据](../wiki/hakkei-reference/dialogue/evidence.md)）与用户定稿整理。

## 1. 世界观与语感总纲

- **万物拟人（“〇〇先生／先森”）**：食物、家、宝物、玻璃、头饰、自然物（太阳先生、雨先生、虫先生）与身体部位（彭彭先森、脚脚先森、嗯嗯先生）均可加「先生」（赤油写作「先森」）。
- **“油库里”泛用化**：作问候、评价安全舒适与开心时的核心词，动词／形容词／副词皆可用（`可以油库里`、`好能油库里`、`总觉得不能油库里`、`油库里地理解了`）；死别婉辞「永远油库里了」仅在确认对象死亡时使用。
- **叠词克制**：只选用资料中出现过的经典叠词（`嚼嚼`、`擦擦脸／渣渣脸`、`好甜好甜／搞甜搞甜`、`睡睡`、`暖乎乎`、`干干净净`、`蹦蹦`等），**不要频繁使用，也不要生造叠词堆砌**。
- **第三人称自称与自夸**：优先使用本名／种名（`{self}`）自称，幼小个体可用「窝」；得意或撒娇时可带「可爱的」「帅气的」「很能油库里的」等自夸修饰。
- **动作报幕与情绪直给**：边做边说出眼前意图（含偷吃、逃跑、躲藏）；情绪直接外露，被安慰后能很快恢复活泼与自信，不写绕弯的成人客套。
- **计数上限随数值变化**：普通个体初始上限随智力在 1–3 之间，练习后可达 `3 + 智力 / 15`；幼声上限为 2；帕秋莉初始即达 9。超过上限说「好多好多」。**不把计数上限写成固定不变的死值**。

## 2. 红线与情境约束

- **指代油库里一律用“油”不用“人”**：不得写「让人」「人家」「别人」「没人」「坏人」「好人」指代油库里（写作「真让油伤心」「别的油」「坏油」「没有人类先生收养」）。仅指代真正人类时才用「人类先生／大哥哥／大姐姐／饲主先生」。
- **礼貌与敬语边界**：一般野生油、幼体与嚣张个体不使用人类书面敬语或职场腔（「遵命」「感激不尽」等）。**生活经验丰富、对人类敬畏或高智力的个体（帕秋莉尤为常见）可使用尊敬人类的礼貌用语（含适度「您」）**。
- **禁止东方原作与超自然借词**：不出现幻想乡、神社、魔法、红魔馆、吸血鬼、秒级再生、凭空生成茶杯橘子等设定。
- **目击、识别与守恒**：
  - 智力 < 75 的观察者认不出失饰者（水生魔理沙例外），未认出时不得直呼名字或亲属称呼。
  - 称呼「饲主先生」「妈妈／爸爸／小贝比酱」必须对应真实关系；食物为空时不夸好吃；新鲜漏馅／献身馅不写臭味，馅与「嗯嗯」严格区分。
  - **宠物顶嘴分寸**：能听家规的普通宠物不会对饲主骂「粪人类／奴隶」，顶嘴应体现“自认很能油库里、拿油库里逻辑跟饲主讲道理”。

## 3. 固定词形与定稿用词

| 类别 | 规范词形 | 说明 |
| --- | --- | --- |
| 欢迎语 | 油库里洗跌一跌捏！ / 油库气洗切一切捏！ | D01 固定识别词形 |
| 幼语发音口音 | `先森`、`饭鲜笋`、`窝`、`介`、`惹`、`搞甜搞甜`、`幸胡`、`口怕` | 对发音不标准的书面化记录，**保留以体现赤油／子油不同口音**，不做机械全局替换 |
| 爱丽丝 | **都会派** | 统一使用「都会派」，不再混用「都市派」或「都凯哈」 |
| 蕾米莉亚 | 语尾 **咚**（句首 `呜——`） | 中文语尾统一用「咚」，日语保持 `のだ／なのだ` |
| 妖梦 | `miyo`（咪呦／妙） / `kinbao`（金寶） | 两种口癖严格互斥，各自保持不变 |
| 身体与排泄 | `彭彭`（肚皮）、`嗯嗯`、`嘘嘘`、`清爽啦` | 不混用肚子／便便／尿尿 |

## 4. 八种族口吻与表达重心

灵梦、魔理沙是最常见种族，同种同生长阶段也要准备多种不同句式与生活切入点；高频日常按种族与数值独立写句，低频事件采用基础共享多变体＋种族／数值特色微调。

| 种族 | 句首／短鸣 | 语尾（成油 / 幼语） | 关注重心与句式特色 |
| --- | --- | --- | --- |
| 灵梦 | 油、油呜、油油？ | 哟、哦、呢 / 惹哟、捏 | 语气软而直接，爱提暖和、软软、唱歌、悠闲处；撒娇黏人或耍赖 |
| 魔理沙 | 油、油呜 | 贼 / 惹杰、嗒杰 | 干脆豪爽，爱自夸、带头行动、找宝物与朋友 |
| 爱丽丝 | 油、油呜 | 哇、呢 / 哟、惹哇 | 「都会派」、整洁、体面、好看与持家 |
| 帕秋莉 | 姆啾 | 哇 / 惹哇 | 先观察再判断，操心存粮、天气与安全；高智或对人类敬畏时常带礼貌敬语 |
| 橙 | 油、喵 | 哟—— / 哟—— | 懂时「瓦卡鲁哟／瓦卡呜哟」，不懂时「瓦卡拉奈哟／瓦卡呐奈哟」，元气直率 |
| 妖梦 | 咪呦！ / 金寶！ | 妙、哦 / 咪呦、哦 | 认真一根筋、守规矩、护同伴、提观楼剑（木棍）；两口癖互斥 |
| 蕾米莉亚 | 呜—— | **咚** | 带点大姐头架势与孩子气威严，谈猎物、高处视野与护幼 |
| 芙兰 | 呜—— | 哦、呢 / 哦 | 跳跃天真，爱把行动说成玩游戏、看新鲜东西 |

特殊亚种（水生魔理沙、被炉魔理沙、螺壳魔理沙、家油、多毛灵梦、灵胖、不足油）均继承各自基础种族的声线与语尾，只按真实状态叠加对应话题。

## 5. 四档声线与多维选句标签

- **声线档位（`speechTier`）**：`baby`（0–1 极短句，眼前单一需求）、`juvenile`（1–2 短句，简单因果与对比）、`young`（亚成／保留幼声的成油，**不等于低智**）、`adult`（1–3 自然口语短句，不写议论文）。
- **多维选句优先级（`DialogueStyle`）**：由 `YukkuriEntity.speechStyleOrder()` 按个体五属性、身份、情绪与种族生成偏好链，在 `NativeDialogue.select` 中依次匹配 `variant`：
  - 性格与情绪细档：`cocky`（嚣张自利）、`polite`（敬畏礼貌，见于帕秋莉及高智／耐心的宠物）、`warm`（温厚关爱）、`proud`（喜悦／大胆）、`timid`（胆怯／低落／不安）、`plain`（默认平常）。
  - 身份标签：`pet`（宠物／居民伴侣／受管个体）、`stray`（流浪）、`wild`（野生家庭／聚落），支持组合标签（如 `pet_polite`、`stray_cocky`）。
  - 同句 8 格内避重、最近 16 句去重，确保常见个体轮换出丰富多样的表达。
