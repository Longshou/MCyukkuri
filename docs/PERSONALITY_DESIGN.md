# 五项行为属性与对象关系

实现状态：**已接入待试玩**。目标规则、公式与建议初值见[行为数值与成长设计](BEHAVIOR_BALANCE_DESIGN.md)。这里只说明当前数据入口与接线；行为差异及多代平衡仍需试玩。

## 属性与有效经历

`social/YukkuriPersonality` 拥有智力、友善、胆量、依恋、自制，先天值与有效值均为0～100。有效值等于先天值加累计经历修正，后天修正最多±20；实际完成的有效经历逐步累计，不由动画帧或反复查看增加。遗传只读取父母先天值，不遗传技能、压力和对象关系。

| 属性 | 当前用途 |
| --- | --- |
| 智力 | 学习、食物辨识、失饰识别和考试理解 |
| 友善 | 分享、照顾、帮助、救援、保护，以及冲突升级的相反倾向 |
| 胆量 | 危险退避距离、陌生接触观察和探索范围 |
| 依恋 | 寻伴、随亲和分离后的陪伴需求，不增加照料成功率 |
| 自制 | 已学规则的遵守概率、等待时长、一次承担的任务段数和冲突克制 |

出生按固定子代UUID抽取一次：普通轴取已知父母先天值平均加−10～10，未知双亲以50为基线。受限轴先按亲本合法区间归一化，再映射到子代区间。不足油的智力0～25、友善75～100；多毛灵梦的友善0～25、依恋75～100、自制0～25。生成、加载、场景写入和后天变化都遵守同一边界；灵胖不是先天不足，不套用不足油边界。

个体 NBT `YukkuriLife.Personality` 仅保存五轴 `Innate`、`Experience`、`ExperienceProgress`，以及短期对话冷却和最近决策。旧认知、知力、四科培养分、环境友善度、溺爱和独立攻击／利己／好奇数值不再保存。当前试玩阶段不做旧格式转换。

## 对象关系与压力

`life/YukkuriWorldData` 是唯一对象关系权威，跨维度存放在主世界。每条关系有方向，覆盖真实玩家、人类NPC及油库里：亲近度−100～100、恐惧0～100、最近互动时间。甲对乙的态度不自动成为乙对甲的态度。

每只个体最多记住64个对象。主人和进行中互动对象受保护；容量满时优先遗忘最久未互动的弱关系，再从其他较弱关系中选择。全部受保护时不新建记录。未加载不等于死亡，家谱与所有权独立保存。

喂食在真正吞咽时结算一次关系变化；受击、洗护、归还、安慰、亲昵等沿实际事件修改。正常相扑不当成攻击。真实完成排便会小幅减少已记住对象的恐惧，不提高亲近、不治疗伤口。恐惧0～29正常、30～59谨慎、60以上害怕；高亲近不能抹掉高恐惧。退回低档保留5点回差，档位随同一对象关系保存，重载不重置回差。

压力只有 `mind/MindLife.unease` 一个权威值，`PetLife.stress` 与状态命令只是同一值的读写入口，不再累加环境友善账本。

## 决策与持续

分享、照护和救援先检查身体、对象、实际物资与路径，再按友善公式在一次机会开始时抽取。依恋只用于寻伴和随亲。普通拒绝或失败保留冷却，照护拒绝至少等待一分钟；同一危险或任务执行中不反复重抽。

教学、进食、排便、亲昵、游具和家庭短动作沿已有完成点推进。自制决定开始时的等待或任务段数，普通需求波动不在每tick取消动作。火、溺水、真实追击、濒死及营养／精力低于15等紧急条件仍可中断。中断由原组件释放物资、会话或目标，未完成动作不伪造成功。

灵胖的成年锁定、体型安全切换和有限重试见[亚种与形态](SUBSPECIES_IMPLEMENTATION.md)。固定年龄阶段见[成长与寿命](GROWTH_BALANCE.md)。

## 试玩读数

`/yukkuri status <目标> raw` 的 `personality` 显示五属性、学习概率、遵守规则概率、等待tick和任务段数；`relations.objects` 显示对象UUID、亲近、恐惧和最近互动时间。观察笔记显示五属性与玩家关系。

在唯一试玩场使用“五属性读数对照”“亲近与恐惧独立”“特殊形态边界”，以及既有分享、亲子照护、翻船救援场景。先读起点，再看真实事件后的变化；概率行为单次没有发生不等于失效，需固定其余条件重开比较。
