# 性格与环境数值改版方案

2026-09-13，四项核心倾向、环境经历和灵胖发育已接入游戏。成长与寿命见[成长与寿命](GROWTH_BALANCE.md)，资源选用见[圆润运行包](../art/source/rounded-runtime/README.md)，当前验证范围见[本轮验收](validation/personality-deibu/current/README.md)。

## 当前实装

| 倾向 | 实际行为作用 |
| --- | --- |
| 利己性 | 是否尝试分食、争食等待时长，并参与欺负和领地冲突资格判断 |
| 攻击性 | 冲突升级、欺负和领地威吓，以及低利己个体保护熟悉同伴的意愿 |
| 依恋性 | 寻求陪伴与亲昵的阈值、接近已知玩家的倾向 |
| 自制力 | 等待取食和教学耗时，并抑制冲突升级 |

四项为0～100。新个体按固定身份初始化，取两次均匀采样的平均值，使中段较常见；后代只继承父母先天倾向，不带后天修正、关系和环境记忆。每轴有效经历至少间隔1200加载tick，同向累计8次才改变1点，后天修正限制±25。被攻击和成功欺负可逐渐提高攻击性，正常相扑完成可逐渐降低攻击性。

分享分数使用下文示例的基础权重，再加入双方营养差、亲代照顾和关系修正；达到50才尝试实际分食，**分数不是每tick抽取的百分比**。营养不高于20时不主动分享，不高于15时不因普通争食继续等待。身体条件、可达性、关系与任务互斥仍要满足。观察笔记显示四项数值、环境友善度和最近已记录的行为选择；床位交换、所有情景对白及更细的失散规划没有新增整套实现。

环境友善度初始50，独立于营养、性格和单一对象的好感。实际喂食、洗护、安慰、亲昵、受击、夺饰物和争食记录来源与贡献，保留最近16条。正面事件每1200加载tick最多接收一次、最多加4；负面事件至少间隔40tick、最多减12，并在随后6000tick阻止正面事件抵消刚发生的敌意。无互动时每1200tick向50恢复1点，独居不会自动形成恶劣环境。无行为主体的伤害和正常相扑不扣环境分。非玩家攻击只记环境，不占用玩家信任／恐惧表。

灵胖默认门槛为营养≥75、环境友善度<30、成年期间共同累计24000加载tick（约20分钟），条件中断每tick消退2tick。每个UUID固定0～99易感序号，默认低于30才转变；这是30%一生易感比例，**不会反复重抽直到人人变胖**。每20tick检查实际切换，落地、有空间且没有进食、繁殖、操作、考试等占用任务时才执行；NoAI暂停累计。上述数值是本轮可调游戏默认值，不是作品统计或用户指定的精确概率。

普通灵梦变为灵胖，多毛灵梦变为保留毛发的多毛灵胖，先天不足组合不转变。后天形态保留实体UUID、亲缘、性格、认知、归属、徽章和伤口，不加入出生抽取、不遗传，也未提供逆转手段。灵胖身体、碰撞与派生物使用1.5倍比例，小蝴蝶结保持普通灵梦的实际大小。

性格版本2独立保存四轴及经历冷却。旧体贴反向映射到利己性，合群映射到依恋性，守序／耐心的平均值映射到自制力，攻击性初值50；迁移只做一次，保留旧玩家关系、学习记录及好奇／大胆偏好。认知仍独立。伤口版本3保存表面指纹、空间锚点和法线，形态或三角面改变时重映射，并保留伤口身份、严重度和已释放材料量。

下方保留实装前的设计讨论，其中“建议”“待接入”描述历史方案；当前生效范围以上文及验收记录为准。

## 当前问题

当前六项是好奇、合群、大胆、体贴、守序、耐心，最终值0～100，默认先天20～80，经历修正上限±25。它们已有实际调用，但主要分散在活动抽取频率、少量阈值和等待时长上。例如体贴65允许主动尝试分食，守序65决定食物竞争时是否等待，大胆参与接近分数，耐心影响教学耗时。不能说这些值完全无效。

问题是同一个数值在不同模块的后果不够一致，玩家很难从几次行动看出个体差异；“守序”和“耐心”重叠，MBTI式命名也无法说明为什么这只抢食、那只愿意照顾孩子。单次喂食或受伤快速累积性格经验，缺乏对长期行为模式的表达。

改版目标是让每个核心数值至少改变两类可观察的行为选择，并让观察笔记能显示最近发生过的例子。

## 四个核心倾向

四项都使用0～100，描述长期倾向。建议以0～30、31～69、70～100显示低、中、高，初始分布以中段为主、保留少量极端个体。具体分布在接入时固定版本与随机种子，不能每次读取重抽。

| 倾向 | 低值表现 | 高值表现 | 直接影响的玩法 |
| --- | --- | --- | --- |
| 利己性 | 愿意轮流、分食和付出资源 | 抢先占有、囤积、索取，较少主动分享 | 食物分配、床位竞争、亲代分食、交换与求助回应 |
| 攻击性 | 冲突时求助、躲避或忍让 | 更愿意威吓、驱赶或反击 | 争食、领地、受欺负后的反应、保护亲友 |
| 依恋性 | 独处负担较小，倾向自己活动 | 更依赖熟悉同伴，主动贴近和寻回 | 跟随、失散、离巢、亲昵与陪伴需求增长 |
| 自制力 | 等待短、易插队，受挫后更易中断 | 能延迟满足，继续等待或完成任务 | 排队、教学参与、搬运任务、冲突升级前的克制 |

利己性低、攻击性高可以成为愿意保护同伴的个体；利己性高、攻击性低可以表现为偷偷占食或撒娇索取。高依恋不等于听话，高自制也不保证善良。种族与灵胖外形不会直接把四项设置为固定高低值。

认知能力继续沿用独立 `Cognition`。自制力决定是否愿意坚持学习，认知决定能否理解和掌握；学会等待与是否服从某个对象也分别判断。探索兴趣可作为已有偏好保留，不再强行把它同时当作智力或品行。

## 状态和关系分开保存

| 层次 | 数据 | 变化方式与用途 |
| --- | --- | --- |
| 身体需求 | 营养、体力、卫生等既有值 | 决定现在能做什么；紧急生存需求优先 |
| 短期情绪 | 紧张、受挫、陪伴需求、无聊 | 随事件上升，安稳时恢复；不直接改写先天倾向 |
| 对特定对象的关系 | 信任−100～100、恐惧0～100、同伴好感−100～100 | 保存互动对象与方向；不把甲喜欢乙自动写为互相喜欢 |
| 环境经历 | 环境友善度0～100，初始50 | 汇总近期受到的善待与敌意，供情绪恢复及灵胖条件使用 |
| 长期性格 | 上述四项0～100 | 跨多次有效经历缓慢变化；单次喂食不能立刻改变品行 |

环境友善度与营养独立：喂饱但持续欺负，仍可形成“营养好＋友善低”；独居且自给自足，不因缺少玩家喂食而被认定为恶劣环境。营养值不作为友善度的加分项，喂食行为中的善待记忆也不能无限抵消同一时段的伤害。

建议环境记录有效的照顾、分食、安慰、攻击、抢夺与排斥，保留事件来源、时间和正负贡献。只计实际完成或命中的事件，同一次动作不被多个模块重复结算；无互动、同伴好感为零、无聊和正常相扑均不自动扣分。敌意关系仅作为当前接触环境的辅助信号，不把离开现场多日的仇人永久算在附近。

## 行为应怎样体现数值

保留现有任务互斥、危险回避、路径与身体条件检查。条件允许后，再比较几种实际可执行的行动，不用一个阈值把同一类型永远锁死。

| 同一情景 | 性格影响 | 必须同时考虑的现实条件 |
| --- | --- | --- |
| 只剩一份食物 | 利己提高独占倾向，自制提高等待倾向；低利己更可能分享 | 自己和对方的饥饿程度、亲缘、关系、食物能否分配 |
| 同伴抢食 | 攻击提高反抗倾向，自制降低立即升级的倾向 | 双方体型与健康、恐惧、是否有退路；不能明知必死还机械攻击 |
| 幼体呼唤 | 依恋提高寻找亲友意愿，低利己提高主动照顾意愿 | 是否认得对方、距离、危险、自己是否正面临紧急需求 |
| 玩家教学 | 自制提高持续参与，信任影响接受，恐惧影响中断 | 认知能力独立决定学习结果；真正完成后才计入经验 |
| 长时间独处 | 高依恋更早寻伴、发出呼唤 | 无同伴可达时换成可行的自我活动，不无限寻路 |

可先用分配情景验证差异：其他条件相同时，定义 `分享倾向 = 50 − 0.7×(利己−50) + 0.25×(自制−50)`，结果限制在5～95，再叠加饥饿、关系与亲缘影响。利己20／自制70得到76，利己80／自制30得到24；这是调试用权重示例，不是已经生效的分享概率。一次决策只抽取一次，执行期间锁定意图，失败后有冷却，不能每 tick 重抽直到出现某个行为。

四项不直接决定固定台词。先确定实际发生的行为和情绪，再选用匹配的对白、表情与动作。观察笔记建议显示“偏独占，刚才抢先取食”“依赖亲友，失散后主动寻找”等简短记录，并允许展开看数值和对象。

## 灵胖形成的接线

用户已确定的必要条件是：灵梦种、已成熟、营养良好、环境友善度低，同时满足才有转变机会。规则源见[灵胖成长转变](../wiki/reimu-deibu-development.md)。

建议首轮调试用营养≥75、环境友善度<30，并要求两者在成年期间共同持续至少24,000个加载 tick（约20分钟）。只记录营养和低友善度同时满足的时间；中断后逐步消退，不能把很早的饥饿经历与后来的一次进食拼接成条件。阈值、持续时间、消退速度和转变概率仍是待接入参数，未写入正式规则的已确认参数。

长寿版不能每隔几秒无上限抽取一次，否则低概率最终会接近人人转变。接入时应设定一生的易感性或有限的累计转变机会，先明确目标发生比例；不能把“每次仅1%”误称为“一生仅1%”。转变保持同一实体 UUID、亲缘、性格、认知、伤病和所有权；后天形态与先天不足分别保存，出生时不重新抽灵胖。形态组合、可逆性与遗传仍待定义。

## 实施顺序与验收标准

先在现有争食、分食与教学接线，展示四项改变带来的行为差异；再接入亲昵、失散、领地和事件对白。为每种行为保留选择原因，便于修正看似随机的表现。随后加入环境经历与灵胖形态，统一存档、收纳、跨维度和客户端同步。

旧六项和六项出生记录先保留为迁移证据，不把旧数组直接当作新四项读取。低体贴可作为利己性的初始参考，合群可参考到依恋性，守序／耐心共同参考自制力；大胆不能直接等同攻击性，新攻击性需要结合已记录的冲突或采用固定身份的中性初值。迁移只做一次；MBTI标签退为旧资料说明，不再充当游戏行为类型。

验证时固定食物、距离、关系、健康与随机序列，仅改变一个倾向，比较至少两类行为。急迫饥饿应压过普通社交；被反复喂食不能刷满四项；攻击不能同时从伤害监听和事件结算扣两次环境分。保存、收纳、重进和亲代继承不得重抽个体。以上是接入的验收条件，本文未虚称已经运行这些测试。
