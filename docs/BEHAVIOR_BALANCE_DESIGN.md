# 行为、成长、遗传与认知

这是行为数值、成长、遗传和技能的规则说明；当前进度与试玩结论只维护在[待办](TODO.md)。

本文以当前源码为准。项目初值明确标为“待试玩平衡”；没有为旧存档做转换，也不保留另一套认知、人格或阶段权威数据。

## 数据模型与保存

### 五项行为属性

`social/YukkuriPersonality` 是个体行为属性的唯一所有者。五轴的先天值与有效值均为 0～100：

| 属性 | 已接入的主要作用 | 不承担的职责 |
| --- | --- | --- |
| 智力 | 学习、食物辨识、失饰辨识 | 不直接决定亲近或善恶 |
| 友善 | 分享、照料、帮助、救援、保护；低值更可能升级冲突 | 不替代对象关系或物种食性 |
| 胆量 | 危险退避距离、陌生接触与探索范围 | 不使不可达路径可达，也不忽略火和溺水 |
| 依恋 | 寻伴、随亲、分离后的陪伴需求 | 不提高喂养、救援或照料意愿 |
| 自制 | 学会规则后的遵守、等待时长、一次练习段数和冲突克制 | 不在每个 tick 重新取消已开始的动作 |

有效值为先天值加后天经历修正；后天修正最多 ±20。只有真实完成的经历才累计，连续 8 单位才改变一项属性 1 点。动画、查看、已学技能的重复使用都不增加经历。

NBT `YukkuriLife.Personality` 仅保存 `Innate`、`Experience`、`ExperienceProgress`，以及短期对话冷却和最近决策。旧认知分、四科培养分、环境友善度、溺爱及独立攻击／利己／好奇值均不是现行数据；当前试玩阶段不转换旧格式。

### 对象关系、压力与技能

`life/YukkuriWorldData` 是对象关系的唯一权威，存放在主世界且关系有方向。每个真实玩家、人类 NPC 或油库里都有独立的亲近度（−100～100）、恐惧（0～100）和最近互动时间；甲对乙的态度不会自动成为乙对甲的态度。每只个体最多保留 64 条关系，主人和进行中的对象受保护，容量满时优先遗忘最久未互动的弱关系。未加载不等于死亡，家谱和所有权也不随关系遗忘。

压力只有 `mind/MindLife.unease` 一项权威值。恐惧 0～29 为正常、30～59 为谨慎、60 以上为害怕；档位回退保留 5 点回差。高亲近不能清除高恐惧。真实事件直接修改关系，例如：

| 真实事件 | 亲近变化 | 恐惧变化 |
| --- | ---: | ---: |
| 完成喂食 | +8 | −5 |
| 温和交谈／回应请求 | +3 | −2 |
| 清洗 | +4 | −3 |
| 受击 | −20 | +25 |
| 被拿走／归还饰物 | −10／+6 | +12／−6 |

具体技能是 `YukkuriPet.KnownSkills` 保存的等待、使用食盆、定点如厕、按时就寝、识字、基础算术。技能、对象关系、压力和父母徽章都不遗传。

## 成长时钟、阶段与体型

年龄只在实体已加载、存活且正常更新时增加；暂停、未加载、收纳、冻结、睡眠跳夜和改世界日期都不补算。每游戏天为 24,000 个模拟 tick。

| 阶段 | 年龄区间 | 时长与资格 |
| --- | --- | --- |
| 赤油 | `0 ≤ age < 72,000` | 3 游戏天；依赖早期照护 |
| 子油 | `72,000 ≤ age < 216,000` | 6 游戏天；逐步自主进食和行动 |
| 亚成油 | `216,000 ≤ age < 336,000` | 5 游戏天；有独立生活年龄资格，但不能繁殖 |
| 成油 | `336,000 ≤ age < 1,056,000` | 30 游戏天；取得繁殖资格 |
| 老年 | `948,000 ≤ age < 1,056,000` | 成油期最后 15%；停止新的繁殖资格 |

总寿命为 44 游戏天；20 TPS 下约 14 小时 40 分钟。内部阶段只保存 `BABY`、`JUVENILE`、`ADULT`；亚成油由年龄区间导出，`growth.stage` 显示为 `subadult`，不另存平行阶段状态。

胎生和卵生从年龄 0 开始。茎生在茎上完成赤油期，落地时从 72,000 tick 的子油起点继续；自然家庭生成的孩子初始化到子油期中段（144,000 tick）。试玩场与状态工具写入的是实际年龄，不是只改阶段标签。

`FamilyLife` 每 tick 推进年龄，每 100 tick 才按营养尝试更新体型。`GrowthSize` 以连续营养曲线产生体型，阶段只限制当前可达到的上限；营养至少 35 才尝试扩体。营养不足、受伤和狭窄空间不会阻止年龄跨过阶段边界，只会让体型和对应移动能力暂时较小；体型不倒退，条件恢复后再继续成长。`mcyukkuri-family.toml` 的 `aging=false` 可关闭自然寿终。

## 体型规范

以下均为项目美术与运行适配值，以标准普通成体身体为 `1.00`，不含饰物；标准成体宽约 24 cm。数值不是八景原文的厘米换算。`GrowthSize` 读取的运行资源与制作源保持相同口径：

| 类型 | 赤体／幼体 | 子体 | 成体 |
| --- | --- | --- | --- |
| 普通种 | `0.10～0.20` | `0.20～0.80` | `0.80～1.20`，个体目标在此范围内，标准值 `1.00` |
| 家油（相对家油成体） | `0.32～0.50` | `0.50～0.80` | `0.80～1.00` |

胎生新生为 `0.14`，茎上实子从 `0.10` 长至 `0.20`、孕程 `0.15` 起可见且 `0.95` 长足，茎生落地为 `0.20` 的子体；家油卵生为相对家油成体的 `0.32`。普通成体的较大个体不自动成为 DOS。

相对移动速度沿同一曲线变化：赤体从出生大小到赤体上限线性为成体速度的 `0.45～0.55`，子体从赤体上限到成体下限线性为 `0.55～1.00`，成体为 `1.00`。这只定义成长带来的比例，不覆盖亚种、伤病或具体动作的额外速度修正。

多代人口稳定性是**未做**项：默认配置下，一组处在合适区域、具有真实食物与住所的家庭应能跨多代维持大致稳定的人口；现有五轴、固定时钟和繁殖约束不构成这个结论。完成实现后，用现有试玩场连续观察数个游戏日的成长、家庭和食物读数；不新增观察脚本，也不以 CI 或单次运行验收。

## 灵胖：成年时的一次判定

灵胖只适用于普通灵梦和多毛灵梦，不足形态不参与。亚成油期间，营养 `≥75` 且压力 `≥70` 必须连续维持一个已加载游戏日（24,000 tick）；在 `336,000` tick 的亚成→成年边界再次满足时，锁定结果。任一条件不足即清零，成年后不补判，也没有旧的终生随机易感抽签。

形态锁定不清除亲缘、关系、技能或性格。当前短动作结束或到达安全接缝后才尝试换体型；空间不足时等待附近可达的干燥位置，最多尝试 3 次且间隔至少 5 秒。失败则保持成油逻辑和当前可用体型，不强制瞬移、不反复判定。

## 遗传、特殊形态与胎数

### 先天属性与特殊形态

每个子代以固定 UUID 种子只生成一次五轴先天值。对每一轴，已知亲本先映射到各自合法区间的归一化位置，取均值后加 −10%～+10% 的扰动，再映射到子代合法区间；未知双亲使用区间中点。这使普通与特殊形态的亲本都能保留相对差异，而加载、运输、查看和重复结算不会重抽。

| 形态 | 属性边界 |
| --- | --- |
| 普通 | 五轴均为 0～100 |
| 不足油 | 智力 0～25、友善 75～100；其余三轴正常 |
| 多毛灵梦 `WASA_REIMU` | 友善 0～25、依恋 75～100、自制 0～25；智力和胆量正常 |

所有先天值、场景写入和后天变化都应用形态边界。后天经历不能越界累积；不足油可以学习但智力不超过 25，多毛可以改善自制但不超过 25。灵胖不套用不足油边界。特殊形态的出生入口和概率规则以 `SubspeciesLife` 为准，不在本页复制一套概率表。

### 胎数与母体大小

`family.offspringSizeInfluence` 默认 `0.70`，范围 `0～4`。普通茎生、胎生和辅助繁育先把母体成年目标体型 `0.8～1.2` 归一化为 `x`，再进行四次独立抽取：

```text
p = clamp(0.15 + c × x + (0.70 − c) × 0.5, 0, 1)
胎数 = 1 + 四次成功数，范围 1～5
```

其中 `c` 为上述配置值；`c=0` 时去除体型差异。家油卵生仍使用独立的 2～4 枚规则。胎数在受孕或辅助繁育时确定，已保存的胎次不会重抽。

## 认知、技能与教学

`cognition/Cognition` 只读五轴中的智力，不另存认知分、遗传快照或课堂计数。一次真实完成的未知技能只抽取一次：

```text
学习成功率 = clamp(0.15 + 0.0075 × 智力 − min(0.15, 0.003 × max(压力 − 30, 0)), 0.05, 0.95)
辨识食物成功率 = clamp(0.35 + 0.006 × 智力, 0.35, 0.95)
```

首次学会一项技能记录 8 单位智力经历，恰好使智力增加 1 点；已学技能的重复使用不再加分。食盆、如厕和就寝在真实生活事件完成时结算；等待、识字和算术在各自课程完成时结算。拒绝、中断和失效不写成完成。

油库里互教要求同一世界、双方可学习、非紧急、未进食、相距四格内、双向视线、非敌对且教师智力更高。合格教师是否主动发起课程只受友善的帮助概率影响。野外 `teach` 卡必须有真实课堂、正确成员顺序、一个来源和三次回应才确认示范；该卡没有可转授的具名技能，不额外生成通用认知分。

失饰辨识直接读智力：普通观察者达到 80 才能辨识，水生例外保留。项目中不足油保留听、看、进食和动作学习能力，但发声为含混声音；口读、口算和面谈记为 `cannot_answer`，动作题仍按真实技能结算。

## 行为选择、公式与连续性

数值只在一个真实选择机会开始时抽取，且所有资源、路径、身体和年龄资格都先检查。已开始的进食、排便、教学、亲昵、游具、上船、送食或家庭短动作沿原有完成点推进；普通需求波动不在每 tick 让其改选。火、溺水、真实追击、濒死，或营养／精力低于 15 等紧急情况可以中断，原组件负责释放物资、会话和目标，未完成不伪造成功。

| 规则 | 当前公式／边界 |
| --- | --- |
| 帮助、照料与救援 | `clamp(0.10 + 0.008×友善 + 关系加成[−0.10, +0.10] + 紧急+0.10, 0.05, 0.95)`；依恋不加分 |
| 陪伴 | `clamp(0.10 + 0.008×依恋, 0.10, 0.90)`，仅在已有可接近、非恐惧的同伴后参与选择 |
| 已学规则遵守 | 自制 0／20／50／70／80 对应 40%／65%／90%／98%／100%，区间线性插值 |
| 等待与练习 | 等待 `round((1 + 0.1×自制)×20)` tick；练习段数 `min(5, 1 + floor(自制/25))` |
| 探索与退避 | 探索倍率 `0.50 + 0.01×胆量`；退避距离 `max(0, 9 − 0.05×胆量 + 0.05×max(恐惧−30, 0))` |

友善主导给食、照护、帮助、救援和保护；低友善能产生真实拒绝，但不靠伪造完成来避免卡死。依恋只影响陪伴、随亲与稳定关系倾向。胆量只调整现实危险下的接近、退避与探索。自制决定等待和练习段数，不能使已衔住食物或正在托住孩子的个体每两秒放手。

## 试玩与未完成边界

在唯一试玩场清空后重开，读取 `/yukkuri status <目标> raw`：`personality` 显示五轴、学习概率、遵守规则概率、等待 tick 和任务段数；`relations.objects` 显示对象 UUID、亲近、恐惧与最近互动；成长读数检查 `growth.stage`、`growth.age_ticks`、`growth.stage_left_ticks`、`growth.growth_percent`、`growth.scale` 和 `growth.elder`。

优先复测“五属性读数对照”“亲近与恐惧独立”“特殊形态边界”和既有的成长、分享、亲子照护、翻船救援场景。概率行为必须固定其他条件后重复机会比较；一次没有发生不等于失效。行为分布、灵胖门槛、胎数影响与多代人口稳定性的进度统一见[待办](TODO.md)，不以读到参数代替试玩。
