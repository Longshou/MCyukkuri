# 油库里行为数值、成长与遗传设计

2026-10-20。实现状态：**已接入待试玩**。本页定义数值合并后的规则、行为影响幅度与持续性要求；数值初值尚未经过试玩平衡。

已确定的规则包括五项主属性、独立的对象亲近与恐惧、统一压力、成长阶段时长、特殊形态的属性上下限机制、友善主导照护，以及自由活动与紧急中断的职责。具体属性边界、概率、冷却、灵胖门槛和老年占比均为**项目设计的建议初值**，不代表已通过试玩。

## 1. 数据范围

个体只保留五项行为主属性，均为 0～100：

| 属性 | 主责 | 不承担的职责 |
| --- | --- | --- |
| 智力 | 理解、学习、食物辨识、失饰识别、处理约定 | 不直接决定善恶、亲近某人、服从某人 |
| 友善 | 分享、照顾、帮助、保护，以及侵占、欺负的相反倾向 | 不代替对象关系；不改变物种食性 |
| 胆量 | 面对陌生和危险时的接近、退避、探索范围 | 不使不可达路径可达，不让个体忽略溺水和火 |
| 依恋 | 寻伴、随亲、分离不舍、等待主人、维持熟悉关系 | 不增加喂养、救援、护卫、安慰和献身意愿 |
| 自制 | 等待、遵守已学规则、控制冲突升级、一次愿意承担多少任务 | 不在动作每一帧重新决定是否放弃 |

每个真实对象分别保存亲近度（−100～100）和恐惧（0～100），覆盖玩家、人类 NPC 和其他油库里，关系有方向。每只个体保留一项压力（0～100），统一承接不同来源的压力变化。营养、精力、生命、伤势、湿度、温度、便意等身体状态保留。

每只个体最多保留64份对象关系，优先保留主人、近期互动亲友和较强关系；正在进行会话的对象不淘汰。容量满时从其他记录中先淘汰最久未互动且关系较弱者，表现为逐渐遗忘陌生对象；没有可淘汰记录时不新建记录。确认死亡可清理，未加载不等于死亡。家谱和所有权独立保存，不随关系记录淘汰而消失。

认知、知力、攻击、利己、好奇、四科培养分、溺爱、环境友善度不再保留为平行数值。馅统只展示家谱关联的父母徽章取得记录，不参与属性、成功率、遗传、学习倍率、售价或本人徽章资格计算。父母资料缺失显示未知；父母有章不使子代获得徽章或技能。

训练只保留少量真实学习成果，如等待、使用食盆、定点如厕、按时就寝、识字、基础算术。学习完成次数只用于确认具体技能，不再形成另一套通用能力分。实际徽章考试档案保留。

## 2. 固定成长时钟

一游戏天按 24,000 个实际模拟 tick 计算。暂停、未加载、收纳或冻结期间不补算；睡觉跳过夜晚、修改世界日期不直接增加年龄。

| 阶段 | 本阶段天数 | 本阶段 tick | 从发育起点计算的年龄区间 |
| --- | ---: | ---: | --- |
| 赤油 | 3 | 72,000 | 0 ≤ age < 72,000 |
| 子油 | 6 | 144,000 | 72,000 ≤ age < 216,000 |
| 亚成油 | 5 | 120,000 | 216,000 ≤ age < 336,000 |
| 成油，含老年 | 30 | 720,000 | 336,000 ≤ age < 1,056,000 |

正常总寿命 44 游戏天；在 20 TPS 下是 14 小时 40 分钟。成年发生在第 14 天，即 336,000 tick。

老年范围建议沿用成油期最后 15%：从第 39.5 天／948,000 tick 开始，持续 4.5 天，包含在成油的 30 天内。老年不再繁殖，但仍能在身体允许时照顾亲友、学习、社交和生活。

阶段只按这个统一时钟变化，不再遗传成长时长，不保留 ±5% 成熟时间浮动，也不让营养积累成为第二条阶段时钟。营养和伤势影响体型发育、体力、健康和实际能力；营养不良不会把油永久卡在子油。

胎生、卵生从赤油起点开始。茎生沿用“在茎上完成赤体、落地为子油”的设定，落地从子油阶段起点计时，不再补赤油三天。自然生成和试玩场指定阶段时，明确初始化到相应年龄区间，不能只有阶段标签没有年龄。

阶段和资格分开：

- 赤油依赖软食、首便和早期行动照护；拒绝或失败的照护不伪造完成。
- 子油逐步掌握自主进食与行动，仍属于随亲照护阶段。
- 亚成具备独立生活的年龄资格，但实际离巢仍检查身体、生活能力与住所；不能繁殖。
- 成油可以繁殖；老年停止繁殖。
- 亚成仍是亲代的未成年子女，可被救援、接上亲船；不再因“尚未成年”被强制召回或要求所有亲船出航都等待它。
- 正在进行的上船、送食、学习或迁徙，不因阶段切换立即失效；新阶段资格在下一次选任务时生效。明确年龄禁令如老年不得新受孕立即生效，已有孕育另沿既有规则完成。

## 3. 灵胖只在成年转换时判定

适用普通灵梦与多毛灵梦；不足形态不参与。

建议初值：

| 条件 | 建议值 |
| --- | --- |
| 当前阶段 | 亚成油 |
| 高营养 | 营养 ≥75 |
| 高压力 | 压力 ≥70 |
| 共同维持时间 | 连续 1 游戏天，24,000 tick |
| 最终判定 | 亚成→成油的年龄边界，仍同时满足上述两项 |

只累积两项同时成立的时间，任一低于门槛就清零；非亚成阶段不积累。等价于：成年前最后一个游戏日持续营养充足、压力较高。

在 336,000 tick 的唯一成年回调中，用同一时刻的营养、压力与持续计数锁定结果。建议取消旧的 30% 终生易感抽签，满足条件就成为灵胖；未满足则正常成年，以后不补判。

普通灵梦成为灵胖，多毛灵梦成为保留毛发的多毛灵胖。形态变化不清除亲缘、关系、技能或性格。

正在咀嚼、抱托、救援或上船时，先锁定成年与形态结果，完成当前短动作或到安全接缝后应用新体型；不重新检查营养、压力，也不反复变回亚成。扩体空间不够时，在当前任务结束后寻找附近可安全到达的容纳点；最多尝试三次，每次至少间隔5秒。仍失败则保持成油逻辑和当前可用体型，标明“扩体空间受限”，不占用其他生活行为；只有位置或周围空间改变才唤醒下一次检查，最多每秒一次。不强制瞬移，不每 tick 寻路，不靠卡墙延长亚成期或获得第二次机会。生命危险仍立即响应。

## 4. 遗传与特殊形态

### 普通遗传

五项属性各自使用父母先天值的平均，加 −10～+10 的小幅扰动并限制到 0～100。只知道一方时以该方为基线，均未知时以 50 为基线。固定身份种子使同一个子代只抽取一次。

个体的后天变化只来自累计有效经历，单次互动主要改变关系与压力。后天属性修正最多 ±20；亲代的后天技能、关系和压力不遗传。特殊形态也能在各自上下限内变化，不锁定单一数值；先天值和最终有效值都必须满足形态边界，越界经验不暗中累积。

### 特殊形态建议属性边界

| 形态 | 属性边界 | 发声与其余属性 |
| --- | --- | --- |
| 不足油，三种外形共用规则 | 智力0～25、友善75～100 | 仅含混、不成句的发声；胆量、依恋、自制正常遗传 |
| 多毛灵梦 `WASA_REIMU` | 友善0～25、依恋75～100、自制0～25 | 智力、胆量正常遗传；保留自身声线与正常语言能力 |

边界保留形态倾向，范围内允许遗传差异与后天变化。不足油可以学得更好，但智力不超过25；多毛可以改善自制，但不超过25。生成受限轴时，将父母先天值先按各自合法区间归一化，再取平均与小幅扰动，最后映射到子代形态区间；未知亲本用区间中点。这样普通亲本也能生出范围内有差异的特殊个体，特殊亲本不会因反复缩放而每代压向边界。它们仍有独立的对象关系、恐惧和压力。多毛会黏亲友，但不因此变得乐于承担照料。

出生概率建议沿用低概率基线：不足 1/200，符合条件的灵梦多毛 1/160；多毛亲本时建议提高到 2%，不沿用原 25%。以上概率在基础物种及其他亚种互斥条件允许的候选中使用。三种不足外形等概率，不能与多毛或其他独立亚种叠加。当前“不足不可育、多毛可育”的规则保留。

普通双亲出生、茎生、人工辅助、异常孕育入口共用同一个子代属性与形态生成入口；新建自然个体和试玩场个体也必须应用对应形态的属性边界。运输、重载、查看或重复出生结算不重抽。

不足油的发声规则覆盖问候、讨食、受伤、求助、告别、亲昵、唱歌、教学、徽章场景和亲子互动：不输出完整对白字幕和正常台词音频；用含混音、表情和动作表达。发声替换不使送食、告别或求助动作失败。需要口头回答的考题应显示不能作答，不能按普通台词判成功；可以参加不依赖说话的动作与生活学习。先天外形不额外推定失明、失聪或不能进食。

## 5. 属性的实际影响幅度

以下为建议初值，比较时固定身体、距离、对象、技能与场景，只改变对应属性。概率只在一次有效选择机会开始时抽一次，不是每秒或每 tick 的触发率。

| 主属性与行为 | 低值20 | 中值50 | 高值80 | 作用边界 |
| --- | ---: | ---: | ---: | --- |
| 友善：普通帮助／分食意愿 | 26% | 50% | 74% | 自己不急饿、有真实资源、对方确有需要 |
| 友善：照顾已识别亲友，普通需要 | 36% | 60% | 84% | 熟悉关系只加10个百分点，依恋不加分 |
| 友善：照顾已识别亲友，急迫需要 | 46% | 70% | 94% | 急需再加10个百分点，仍不因依恋高而增加 |
| 智力：适龄基础课程成功率 | 30% | 52.5% | 75% | 正常压力、实际完成教学；口头能力另检查 |
| 依恋：自由活动时选择结伴娱乐的意愿 | 26% | 50% | 74% | 有可互动的亲近同伴时；否则正常独自消遣 |
| 自制：愿意排队或执行等待的时间 | 3秒 | 6秒 | 9秒 | 等完一个完整等待段再改计划；急迫生存需求除外 |
| 胆量：可见威胁开始主动退避的距离 | 8格 | 6.5格 | 5格 | 被追击、受击、落水等不等这个距离 |
| 胆量：普通探索范围，相对该年龄基准 | 70% | 100% | 130% | 只搜索现实可达区域，不扩张幼体活动能力 |
| 自制：已学生活规则的主动遵守意愿 | 65% | 90% | 100% | 只在有合适设施和非紧急的选择点判断 |

以各自合法区间内的示例值说明效果；这些不是固定属性：

- 不足油友善90：普通帮助意愿82%，照顾亲友92%；智力10：基础课程成功率约22.5%，复杂课程受理解门槛和发声能力限制。
- 多毛友善10：普通帮助意愿18%，照顾亲友28%；依恋90使有合适同伴时的结伴娱乐意愿约82%；自制10的普通等待段约2秒。低自制不会让它在已经衔住食物、托住孩子时每两秒放手。

智力对头饰识别采用清楚的能力分段：低于30时可误认带头饰的物体；30～79仍依赖头饰识别；80及以上可识别失饰个体。“低智力会误认带头饰物体”沿用 [2026-10-19 头饰裁决](DESIGN_DECISIONS.md#2026-10-19-试玩反馈的设定取向)，不改变正常戴饰个体可被识别的规则。水生魔理沙保留天生识别例外。低智力不足油可能认不出失饰者，但高友善会使其倾向困惑或回避，而不是主动欺负。

辅助影响设上限：熟悉关系对帮助意愿最多加10个百分点，目标已急迫需要帮助可再加10个百分点；压力对课程成功率最多减15个百分点。身体能力、真实危险、资源、物种和年龄属于资格条件，不用一串权重抵消。

## 6. 现有行为的影响与持续规则

“强”指能显著改变是否选择或选择方向；“中”指改变频率、等待、目标排序；“无”表示不额外接入人格评分。

### 生理、食物与安全

| 行为组 | 主因及影响程度 | 其他因素和限制 | 开始后的持续规则 |
| --- | --- | --- | --- |
| 觅食、找食盆、吃饭、咀嚼、吞咽 | 营养和真实食物：强；人格：无 | 智力只影响特定辨识食物的成功，胆量只影响探索可行区域 | 锁定一份食物；附近出现更好食物不重启一餐；紧急危险可打断 |
| 饮水、口干、辛辣处理 | 身体需求：强；人格：无 | 必须有可用饮水点，失败不能阻止其他可行生存行为 | 完成一次饮水；不被普通社交抢占 |
| 睡眠、回窝、醒来 | 精力、时间、住所安全：强 | 依恋只在多个安全睡位中偏向亲友附近 | 进入睡眠后不因想聊天或有人路过醒来；危险和急迫需求可唤醒 |
| 找厕所、排遗、无厕排遗 | 便意、便秘、已学技能：强；自制：中 | 自制影响提前等待，不允许无限忍住或凭空学会使用厕所 | 完整排遗一次才降便意和恐惧；不在用力中重新选厕所 |
| 便秘与幼体体操 | 身体需要、年龄与动作能力：强 | 友善影响是否主动陪孩子，幼体自身做体操不需要友善 | 完成一轮才给效果，低自制影响是否再做下一轮 |
| 清洗、治疗、接受护理 | 伤势卫生和对象关系：强 | 恐惧高可迟疑或拒绝；友善不决定自己是否值得治疗 | 接受后完成本轮，提供者真正伤害或强制分离才中断 |
| 避雨、避寒、避热、避火 | 实际暴露和危险：强 | 低智力也会避险；胆量不使其耐火耐水 | 锁定可达避难点，确认失效才换点；不在两个等价遮蔽间往返 |
| 捕食者、人类威胁、受到攻击 | 威胁现实性和身体能力：强；胆量：中 | 对象恐惧调整安全距离；好友正在攻击时同样避险 | 警报按同一威胁合并；逃离到安全条件保持一段时间才解除 |

### 家庭与亲友照护

| 行为组 | 主因及影响程度 | 其他因素和限制 | 开始后的持续规则 |
| --- | --- | --- | --- |
| 让食、分食 | 友善：强 | 自身营养、亲近关系、对方需求；无真实食物不能分享 | 已决定转交则完成同一口，不因为友善或营养轻微波动收回 |
| 亲代首餐、喂糜、日常喂子 | 友善：强 | 亲缘和辨认决定目标资格，孩子急饿提高紧迫性 | 喂养计划锁定一个孩子和一份食物；吞咽／交接处结束 |
| 首便护理、保暖、摇篮和帽内护理 | 友善：强 | 真实护理需求、接触位置与空间 | 亲代拒绝时孩子仍求助；另一亲本、亲属或玩家可介入，不伪造完成 |
| 舔伤安慰、安抚受惊亲友 | 友善：强 | 亲近与识别决定照顾谁；技能、身体决定能否接触 | 一轮安抚不中途重抽意愿；目标死亡、伤害或真正离场才取消 |
| 陆地护子、保护同伴、引开捕食者 | 友善：强 | 胆量与生命体力决定怎样执行；不做必死冲锋保证 | 一次危险事件只选一次救护意图；局势实质变化才换方案 |
| 水上救子、翻船先救子还是先自保 | 友善：强，依恋不加分 | 实际体力、可达船位、孩子危险程度 | 条件允许时把已托住的孩子放到安全处；实际危险可放弃，不每 tick 重选 |
| 饥荒献身 | 友善：强 | 必须满足原饥荒、身体、亲属和接受条件；亲近决定对象 | 保留实际询问与接受过程；不是普通高友善时随机死亡 |

照护意愿只由友善主导。依恋高可以表现为“要别人陪、跟着家人”，不能偷换成“愿意给家人食物或冒险救人”。低友善可以造成真实疏于照顾；避免卡死依靠求助、有限重试、其他照护者和实际后果，不强制低友善亲代照料成功。

### 自由活动与娱乐填充

“空闲”指没有正在承担的必要生活、照护、劳动、行程或外部指令任务的自由活动时段，不限于任务切换的一瞬间，也不等于没有运行任何 Goal。唱歌、听歌、散步、运动、玩具和可独自使用的设施都可以填充这段时间；执行娱乐期间仍属于自由活动，但本轮娱乐尚未结束时不重新选活动。

低依恋更偏向独自消遣，高依恋更偏向与亲近度较高的其他油库里共同娱乐。双方可用、愿意参与和设施容量仍是前提；结伴不等于必须身体接触，亲近但恐惧高时沿谨慎接近规则，不强行拉去玩。没有合适同伴时照常独处，不站着空等。低依恋也能接受好友邀请，不代表敌意或拒绝一切社交；友善仍独立决定帮助意愿。

每次只选一个完整娱乐段，如唱一段、滑一次或散步到一个点；自然结束后按依恋偏好选择下一段。新的必要任务在普通安全接缝接管，真实危险立即接管。不得在每 tick 的短暂无任务状态反复启动寻伴，也不保留独立寻伴倒计时来打断娱乐。

## 7. 关系与压力

亲近与恐惧独立选择行为，不相减成单一分数：

| 条件 | 行为 |
| --- | --- |
| 亲近高、恐惧低 | 主动接近、亲昵、接受教学 |
| 亲近高、恐惧中高 | 想接近但先观察，停顿后接近一小段；受对方突然逼近时后退 |
| 亲近低、恐惧低 | 冷淡、无视或拒绝；冲突时可能反抗 |
| 亲近低、恐惧高 | 保持距离、躲避或逃离 |

建议恐惧档位：0～29正常，30～59谨慎，60以上明显害怕。降回较低档时留5点回差，避免29/30附近抖动。胆量调节观察时长和安全距离，不消除对象恐惧。高亲近且害怕时，一次会话内最多完成“观察—尝试接近—决定停留或退出”一轮，最长约10秒；退出后对同一对象至少冷却30秒，不会无限前后踱步。一次真实善待或新的威胁可以提前改变选择，但同一事件只唤醒一次。

建议事件变化：

| 实际完成的事件 | 对来源对象亲近 | 对来源对象恐惧 |
| --- | ---: | ---: |
| 喂食 | +8 | −5 |
| 温柔交谈／安慰 | +3 | −2 |
| 清洗或有效治疗 | +4 | −3 |
| 归还头饰 | +6 | −6 |
| 实际救援成功 | +10 | −8 |
| 攻击 | −20 | +25 |
| 夺取头饰 | −10 | +12 |
| 一次真实排遗完成 | 不变 | 所有已记录对象的恐惧各−2，不低于0 |

同一事件只由实际完成／命中的结算点写一次，保留现有交谈和互动冷却；正常相扑不登记为敌意攻击。排遗中断、空动作、仅播放动画不产生淡化效果；不清除亲缘、所有权、技能、徽章或物品来源。

压力仍统一接收受伤、饥饿、寒冷、失饰、丧亲、受惊和安慰等现有输入；删除环境友善度及近期境遇账本。压力主要影响学习、冲突稳定性、情绪表现和病态，灵胖读取同一压力值。压力增加不等于任何当前行为都应取消；只有真实危险、病态接管或明确拒绝才中断。

## 8. 行为连续性规则

### 开始与继续分别判断

开始时：检查年龄、身体、空间、目标、资源和关系资格，再进行一次意愿判断，选定目标、方式和本次愿意完成的工作段。

进行时：保持已选意图、目标、真实物品和阶段，不重新抽意愿。属性缓慢变化、压力波动、新朋友经过、另一份食物出现、休闲计时到期，均不单独构成取消理由。

结束时：按真实接触、交接、吞咽、排遗或课程完成结算一次，然后进入冷却，才评估下一件事。拒绝不会通过每 tick 重抽自动变成接受。

### 可以立即打断的情况

- 溺水、着火、真实受击、明确的追击威胁、急性生命危险。
- 目标死亡、明确离场、必要资源确实消失、接触支撑失效或物理路线不可继续。
- 玩家真实收容、搬运、牵引、操作等控制行为，按原有规则接管。
- 非油症等实际病态接管；不以压力刚涨1点代替发病。
- 对方真实威胁或伤害导致明显恐惧升级，允许受害者立即退出接触。

真实危险允许按现场情况暂停、放弃或替换当前任务，不要求先做完当前一口、交接、救援或到达普通安全接缝。只有不妨碍避险时才顺手卸货或安置乘员；无法完成就按真实状态掉落、松开或救援失败，不凭空完成或复制资源。保护当前动作不提供无敌；紧急伤害仍然结算，并执行正确的中断回收。危险解除后重新检查旧任务的价值和可行性，可恢复，也可放弃失效任务；不能机械返回危险点。

### 普通需要在合适位置让步

下述动作保护只约束普通需求抢占；真实危险按上一节立即处理，可直接放弃任务。

- 吃饭：吞完或正确处理嘴里的当前一口再响应普通请求。
- 喂子：完成当前一份真实交接，不中途复制或收回。
- 排遗：完整排出或取消，本轮不因想聊天换厕所。
- 救援：尽可能把已经托住的孩子安置到当前安全落点；确实支撑失效则走真实滑落／失败。
- 帽船：当前跳跃、登船、座位交接和取帽阶段保持到安全接缝。
- 课程：完成一个示范／答题段再决定是否继续下一段。
- 建巢、采集、迁徙：到一次放料、卸货或安全停靠点处理普通需求，保留工程和行程。

低自制主要表现为不愿排长队、只愿做短课程、一次只接短工作段、在间歇拒绝下一轮；不表现为每几秒清掉当前任务。高自制也不能压过饥饿、体力耗尽和现实危险。

### 防止循环与饿死式坚持

- 非生存类普通任务启动建议营养≥40、精力≥35；继续阶段不沿用同一门槛，而在营养<15或精力<15等急迫状态下让出，恢复到营养≥30、精力≥30再接回原长任务。具体身体危险条件沿领域规则。
- 同级普通任务不抢占已开始任务；更高优先级只凭真实紧急理由抢占。
- 路线暂缓 `DEFERRED` 保留任务，不按失败清空；确认无路或主动寻路连续10秒没有进展，才换路。最多进行有限次数的真实重新规划，再放弃该目标并冷却。
- 普通同目标失败至少冷却30秒；日常照护拒绝建议冷却60秒，孩子首次跨入急需、物品首次到达或其他实质变化可以提前触发新评估。提前唤醒按事件身份／状态变化代次消费一次，“仍然很饿”“粮食仍在那里”不算新事件，不能持续绕过冷却。
- 同一危险的救子／自保选择缓存到本次危险结束；体力耗尽、船翻覆、孩子已安全等实质变化才重新选择可行方案。
- 双人活动共同结束并释放预约；一方被打断不会让另一方永远等。
- 无法执行的高优先级需要不霸占空任务，仍允许选择可行的求助、休息或撤离。
- 成年、老年、技能掌握和属性更新不直接清除当前任务；年龄禁令用于新的任务发起，现有短动作在安全边界结清。
- 暂停、卸载或收容不补发行为成果；恢复时保留真实资源和必要阶段，重查目标存在性，不把未知当死亡。

## 9. 算法口径与建议初值

用 `I/F/B/A/C` 分别代表智力、友善、胆量、依恋、自制，`P` 为压力。

1. 普通帮助／分享：`p = clamp(0.10 + 0.008F + relationBonus + needBonus, 0.05, 0.95)`。关系修正最多0.10，目标急需修正最多0.10；依恋不进入公式。先检查自身急饿和资源，不在不可执行时掷骰。
2. 有真实争执时的升级：`p = clamp(0.60 × (1 − F/100) − 0.003C, 0, 0.60)`。胆量、体型和生命决定是否存在可行的挑衅／反抗路径；不在无争执时不断抽攻击。
3. 基础课程：`p = clamp(0.15 + 0.0075I − min(0.15, 0.003 × max(P−30, 0)), 0.05, 0.95)`。只能在真实教学完成点判定一次；高难度知识另有能力与已学前提，不靠无限刷同一帧学会。
4. 食物辨识：`p = clamp(0.35 + 0.006I, 0.35, 0.95)`，同一目标本次探查只判一次，结果不能生成食物。失败后更换实际搜索目标或等待场景改变。
5. 自由活动方式：有合适亲近同伴时，结伴意愿`p = 0.10 + 0.008A`，其余选择独处；在一轮娱乐结束或真正进入自由活动时判一次。结伴候选为亲近度>0、恐惧<60、现实可达且当前可参与的其他油库里，按亲近度降序选，距离只用于同分排序；对方仍需独立接受。找不到或被拒绝后转独处，同对象至少冷却30秒；新的娱乐选择不绕过冷却。娱乐进行中不反复抽签或因更亲近者出现换人。
6. 等待段：`1 + 0.1C` 秒；明确长时指令拆为完整段，在段边界决定下一段，不每 tick 离开又回来。
7. 非追击威胁的退避距离：`9 − 0.05B` 格；高对象恐惧可增加安全距离。真实攻击、追击、落水和火不受该距离门槛保护。
8. 迁徙时胆量对领袖阈值的修正限制在±20%，保持灾害、饥荒和真实住所条件为主。
9. 繁殖许可违规仅在有实际求偶机会时判定一次：未获许可且已知规则时，违规概率复用`1 − p_rule(C)`，不另叠高压随机违规；高自制的稳定守规也适用于这条规则。成年、身体、对象关系等资格不能被概率绕过，实际病态接管单独处理。
10. 首次有效学会一项技能可给普通个体少量智力经历；重复使用已学技能不增加智力，形态受限轴可在边界内增长。普通性格仍采用“累计多次真实经历后才改1点”，不因看见／播放台词发经验。
11. 普通探索半径：年龄基准半径乘`0.50 + 0.010B`，最多上下浮动50%。仍依赖亲代的赤／子油，离亲半径再乘`1.20 − 0.004A`，依恋只作最多20%的收放；地图边界、危险、真实可达性和身体能力始终优先。
12. 已学生活规则的主动遵守：`p_rule(C)`在锚点`(0,0.40)、(20,0.65)、(50,0.90)、(70,0.98)、(80,1.00)、(100,1.00)`间线性插值。自制≥80时，已掌握、条件可行且没有真实紧急冲突的日常规则稳定遵守，不每次再留随机违规概率；压力波动不另扣守规概率。没学过先走原有自发生活；没有可用设施、便意已到极限等不记作性格违规。一经选定去厕所／食盆／睡位，本次任务不重抽。
13. 普通连续课程／可分段工作：一次愿意承担`1 + floor(C/25)`个完整工作段，上限5；低中高20／50／80分别为1／3／4段。工作段必须对应真实的一轮示范、一次放料或一次往返，不能任意切碎已经衔食、托举和跳跃的动作。限额到达只影响是否再接下一段，不销毁工程、负载或行程。
14. 群体非紧急合作任务复用帮助意愿，熟悉群体按关系修正处理；规则执行复用自制遵守意愿，不再叠一个合群分或服从分。个人必要采集、真实危险撤离及已接受任务的继续执行不使用该合作抽签。
15. 徽章题按真实任务评分：已学技能决定是否具备方法，必要理解门槛由智力承担，自制决定本次是否遵守，友善／胆量只在题目确实涉及该选择时参与。已经发生的正确动作不再用“考试成功率”二次推翻，错误动作也不靠能力骰子改判正确。

以上公式服务清楚的行为入口，不建立每 tick 对所有候选动作求总分的新系统。沿现有 Goal、家庭任务、帽船任务、事件会话及真实资源所有者实现。

## 10. 试玩场验证设计

仅使用现有油库里试玩场及其场景入口。数值样本、阶段和情境可直接指定，排除随机地形差异；游戏内完成验证，不在本机编译。

| 场景 | 应观察到的差异与不变量 |
| --- | --- |
| 五属性对照 | 同种、同龄、同营养和关系，仅改一个属性；低中高个体在上述频率／选择上有方向一致的区别；自制≥80在正常可行场景稳定守规，胆量20／50／80探索半径为70%／100%／130% |
| 自由活动 | 低依恋偏独处，高依恋偏与高亲近油库里结伴；无同伴正常消遣，娱乐中不抢占；拒绝不反复请求 |
| 紧急放弃 | 着火、受击、落水时能放弃采集、进食或不可继续的救援；物品与乘员按真实状态处理，避险后不盲目恢复旧任务 |
| 多毛亲代 | 经常找家人、讨陪伴，但主动喂子和护子明显少于高友善亲代；不能因高依恋获得照护加成 |
| 不足油 | 所有入口只含混发声；高友善能帮助，低智力不能绕过识别／语言题门槛；不因此停止生活 |
| 亲近且害怕 | 对同一对象停顿观察后尝试接近，受攻击能退避；不会无限前后抖动 |
| 恐惧淡化 | 善待降低对应对象恐惧；真实排遗降低记忆恐惧、不增加亲近；动画与中断不重复结算 |
| 一口饭和一份喂食 | 中途改压力、关系、友善或附近放新食物，不重启、不复制、不丢失当前一口；火与真实攻击能打断 |
| 水上救援与登船 | 属性改变、长成亚成、普通问候不掐断托举和跳跃；翻船、体力耗尽走真实失败路径 |
| 课程和等待 | 低自制少做下一轮，高自制等待更久；一轮动作都完整，紧急生理需求能退出 |
| 采集、筑巢和迁徙 | 中途吃睡后保留材料、目标与阶段；资源失效会有限重试而非无限站住 |
| 阶段边界 | 3／9／14／39.5／44日边界按规则变化，年龄不被营养或碰撞永久卡住；亚成可独立但不可繁殖 |
| 灵胖边界 | 成年前持续达标且转换当刻仍达标才转；差一个条件不转，成年后补喂或加压不补判；忙碌只延后形体应用，不改变已判结果 |
| 遗传和出生 | 所有出生路线共用规则；不足／多毛属性在合法区间内能变化、不越界；查看、运输和重载不重抽，技能和父母徽章不直接遗传 |

行为频率和失败率需要重复的独立机会观察；单次“发生过”不能证明概率平衡。必要的静态核对和远端 CI 只能证明接线、资源和编译层面，不能代替连续行为试玩。

## 11. 实现覆盖入口

以下列出本次改造涉及的领域入口。代码包均相对于 `src/main/java/io/github/longshou/mcyukkuri/`，实现沿用领域所有权与现有任务状态机。
