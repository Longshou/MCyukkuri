# 油库里展馆

展馆是唯一的试玩地图，也是唯一的测试入口：仓库里没有 GameTest 或别的测试地图，玩法效果都在这里亲自试。根目录 `启动动作博物馆.cmd` 用远端 CI 的现成运行产物启动游戏，不执行本机编译。

```text
启动动作博物馆.cmd            世界缺失或生成器改动后，先现场生成全新世界，再启动游戏
启动动作博物馆.cmd -Fresh     无论如何都生成全新世界（旧存档丢弃）
启动动作博物馆.cmd -Resume    保留已有世界，即使生成器已改
启动动作博物馆.cmd -Menu      进入 Minecraft 主菜单而不是直接进世界
```

## 一张图、一个入口、一份世界

- 世界由 `scripts/build_museum_full.py --install` 从数据包生成到 `.local/experimental-map/museum`，整体替换，不在旧存档上修补。`map-manifest.json` 记录生成器输入的哈希，启动器据此判断世界是否过期。
- 世界元数据（`level.dat`）取自 `.local/experimental-map/museum-seed/level.dat`，第一次从任一旧展馆存档复制即可；脚本不复制区块、实体或玩家。
- 运行配置是 `.local/experimental-map/museum-runtime.json`：`runtime`（CI 运行产物）、`java`，可选 `python`（装有 nbtlib 的解释器）。展馆命令（`command/Museum*.java`）改动后，需要用含这些命令的 CI 构建更新运行产物，否则数据包里的新命令会因为模组太旧而解析失败。
- 旧的“补洞”机制（`repair/*`、`REPAIR_REVISION`、结构解释器）已整体删除；旧版“真实家庭展区” `/yukkuri showcase`、多地图启动器与旧 manifest 同样不再存在。

## 展台牌与按钮

每个展台前挂同样格式的牌子（文字在 `scripts/museum_info.py`）：看点 / 操作 / 预计 / 没反应？，另有一行英文和一行日文。按钮悬浮标签带编号，牌子上的“按 1、2、3”对应它们；按钮下的灰字是“动作片段”或“真实行为”。

- **动作片段**：播放制作好的动作，播完自动归位。
- **真实行为**：只设置起始条件，之后由普通玩法运行；观察窗口里每 15 秒在动作栏提示“已观察 N / M 秒”，窗口结束只提示一句，**不会强行打断、不会回滚结果**（独立的新巢也保留）。要回到初始状态，按“重置本站”。
- 展台正面：只看型是 2 格高玻璃；可动手型（照料、商店、运输与动手角）是围栏加一扇双开橡木门，进去才能够到演员。
- 失败原因会发给附近的玩家：命令方块里的 `sendFailure` 没人看得见，所以 `command/MuseumCommands.java` 把拒绝原因同时发给 48 格内的玩家，函数里也有 `tellraw` 提示。

## 重置与现场

- 每个演示按钮先重置本展台（杀掉本台的补给物品、停止遗留的片段、演员回位、恢复体力/饥饿/膀胱），再设置时间天气，再开始。进入展台（`go/s/<id>`）时，若本台没有在进行真实行为，会清掉舞台上的杂物。
- “重置各展台”只处理舞台上的演员；**出生庭院、独立、家油庭院、帽船和聚落是真实的家庭，不被批量重置**。庭院的“换一对新油”和家油庭院的“重置家油庭院”只清本庭院自己的一家。
- 有真实过程时重置会被拒绝，并说明原因：出生、接生、落水、上岸、独立进行中。独立展台在进行中会拒绝再次开始。

## 校验与工具

本机不编译、不启动游戏，校验都是纯 Python：

- `python scripts/check_museum_pack.py`：生成数据包到临时目录，核对每条 `yukkuri ...` 命令都能在 Java 注册的命令树里走通，每个 `function` 引用都存在，每个展台都有传送函数、大厅入口和回路，每个远处观察台都有“回展台/回大厅”按钮，每块牌子都放得下（按中日韩宽度算）。
- `python scripts/render_museum_map.py`：从生成器数据画俯视布局图（默认写到 `.local/previews/museum/map.png`）。
- `python scripts/build_museum_full.py --pack-only --output .local/experimental-map/<新目录>`：只生成数据包。
- `python scripts/check_museum_contacts.py`：离线重放片段，核对接触距离。

游戏里随时可以按大厅东墙的“展馆自检”，核对演员数与按钮数。`MCYMUSEUM_BUILD_COMPLETE` 日志只表示建馆结束，不代表玩法验收。

制作脚本为 `build_museum_full.py`（布局与函数）、`museum_scenes.py`（展台与场景）、`museum_dsl.py`（场景词汇）、`museum_sites.py`（按钮、牌子、观察台）、`museum_info.py`（牌上文字与预设）、`museum_birth.py`、`museum_house.py`、`museum_hat_boats.py`、`museum_aquatic_rescue.py` 与 `museum_actions.py`；动作覆盖见 [动作目录](MOTION_MUSEUM_ACTIONS.md)。动态接触、长时间导航、多人干扰、重启恢复与帧耗时需要在可运行环境里实测。
