# 油库里动作博物馆

当前入口：根目录 `启动动作博物馆.cmd`，原来的 `启动实验地图.cmd` 也会进入这座馆。

展馆为 **44×32 格**，中央走廊两侧六组展台，顺时针参观。9 个固定演员演示 16 段短场景，精选 43 个动作（含待机）；不再铺设物品仓库、工厂和大批测试围栏。

```text
                 01 身体 → 02 日常 → 03 交流
入口 ──────────────────── 中央走廊
                 06 水边 ← 05 帽子 ← 04 家庭
```

| 展台 | 展示逻辑 | 场景按钮 |
| --- | --- | --- |
| 01 身体如何活动 | 先认识柔软身体的运动方式 | 走路与跳跃、伸展身体、一起做体操 |
| 02 悠闲的一天 | 吃、喝、睡、清洗构成生活节奏 | 好好吃一餐、睡觉与醒来、洗后甩甩水 |
| 03 表达与陪伴 | 从相遇到共同活动，再看情绪表达 | 相遇与蹭蹭、唱歌与伴奏、表情会说话 |
| 04 迎接新生命 | 亲本、接生帮手和初生幼油分工 | 安胎到产后、初生的醒来 |
| 05 魔理沙的帽子 | 帽子如何成为照料工具 | 摘帽·扶帽·戴回、独自摘戴帽子 |
| 06 水边的适应 | 普通帽子动作与水生动作的区别 | 水上姿态、水边扶帽、水边独自摘戴 |

## 操作

- 默认冒险模式，避免误拆展台。靠近展台，右键地面按钮播放；同一展台换节目会停止前一个，各展台独立。
- 每组展台旁都有“停止演示”，取消后续步骤并回到待机和原位。
- 入馆获得导览书，其中列全 56 个注册动作，标记哪些纳入展览。入口可补领。
- 回入口：`/function mcylab:home`；停止全部演示：`/function mcylab:stop_all`。
- 如需编辑地图，可手动执行 `/gamemode creative`。演示使用固定无敌演员，食盆、窝和蓝色水景仅帮助理解场景。

生育场景不会实际繁殖；水边展台演示姿态，不进行真实乘船或生产。这座馆用于看动作，不承担全部玩法验收。

## 动作适配

[完整动作清单](MOTION_MUSEUM_ACTIONS.md) 列出 56 个动作的中文名、ID、实际资源适配范围和是否展示，另列家油等内部行为片段。

生成时逐项读取基础模型与动作修订，检查演员确实有对应动画；普通与水生魔理沙按身份分开，初生动作只给幼体。家油、不足形态和捕食种的生育限制在清单中说明。当前缩壳命令存在回到待机的问题，本馆不放无效按钮。

## 文件与重建

- 可复用生成器：`scripts/build_showcase_map.py`，需要 Python 3.11+、`nbtlib`；支持已安装的 `.local/setup/python` 依赖。
- 本机运行配置：`.local/experimental-map/showcase-runtime.json`，记录已有 CI 运行产物、Java、游戏目录及世界名。
- 本轮独立存档：`.local/experimental-map/museum-20261016-v2/saves/MCyukkuri-Museum/`。原来的大地图与其他存档保留。
- 启动器 `scripts/launch_showcase_map.ps1` 直接启动已有运行产物，不自动编译；`-Menu` 进入标题界面。

生成另一份独立地图（输出目录必须尚不存在）：

```powershell
python scripts/build_showcase_map.py --seed-level .local/p0/gametest/world/level.dat --output .local/experimental-map/museum-new --catalog docs/MOTION_MUSEUM_ACTIONS.md
```

该命令只读取种子世界的 `level.dat` 元数据，不复制它的区块、实体或玩家。然后将本机运行配置中的 `game` 指向新目录，`world` 设为 `MCyukkuri-Museum`。首次进入由数据包生成展馆；日志中的 `MCYMUSEUM_BUILD_COMPLETE` 表示生成结束，`MCYMUSEUM_CHECK_PASS` 表示演员、按钮、动作命令及隐藏按钮线路检查通过。它们不替代人工观察动画效果。
