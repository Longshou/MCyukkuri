## 开始测试

1. 双击 `启动实验地图.cmd`。首次进入获得观察笔记、运输盒、清洗布、教学哨、徽章手册、食物和绿宝石。
2. 按中庭标牌选择分区。每区入口有返回按钮、操作说明、物资桶和补充物资按钮；实验区另有补样按钮。
3. 空手右键个体打开照料交互，手持观察笔记右键查看状态。分配住所时，用笔记右键巢，再潜行右键个体。
4. 展示区样本固定且无敌。每个展台的按钮能把同形态活体复制到器具区并传送玩家；同一份样本仍在加载范围内时不会重复补出。中庭第三排按钮演示当前加载展品的19段动作。
5. 活体实验保留正常 AI、饥饿和成长。补样不会删除原样本或重置亲缘记录；收纳、卸载后再补样可能产生新的个体。大量反复实验后可从原始 ZIP 解压为另一个新世界。
6. 遗体留在死亡地点。空手右键收集，手持遗体右键地面放下，再用铲子右键泥土上的遗体安葬；具体规则见[受伤与遗体](INJURIES_AND_REMAINS.md)。
7. 普通、稀毛、歪脸、豆形与家魔理沙可在照料菜单的饰物页取帽，手持帽子与原个体交互戴回。“帽托小幼油”“放下帽上幼油”按几何尺寸检查；豆帽只容得下小尺寸豆形幼油，家帽容不下正常初生家幼油。详细操作见[帽子交互](../art/source/hat-interactions/README.md)。

## 使用边界

这是已布置的人工实验场，不能把进图或按一次按钮视为所有机制验收通过。生育、教学、工厂流水线与事件仍检查真实条件；家庭妊娠默认需要6000个有支持的加载 tick，家油巢卵默认4000 tick。尚未配对、分配住所、提供食物或达到信任条件时，不会直接完成行为。七类遭遇与41张情景卡按现有条件触发，本图没有虚构的强制触发物品。DOS、尚未接入的素材和第三方兼容不在地图中。

地图数据包只使用当前模组已有注册内容和原版命令，不依赖 P0 测试模组。出生、亲缘、购买或收纳获得的个体属于当前存档，补物资按钮不会撤销这些记录。复制展品得到的是新身份的活体，不是展示个体的转移。

## 制作与复用

制作源为 `scripts/build_experimental_map.py`，输入固定运行目录的世界元数据；不复制旧世界区块、实体或 SavedData。生成全新目录后，由真实 Minecraft 客户端执行数据包完成场地与模板落地。脚本要求 `nbtlib`，本机安装在 `.local/experimental-map/python/`，没有改动全局 Python 环境。

```powershell
python scripts/build_experimental_map.py --runtime .local/play-readiness/runtime-20260913-115036 --output .local/experimental-map/new-build
```

脚本拒绝覆盖既有输出。生成目录中的 `saves/p0-preview/` 为待游戏首次生成的世界；已落地存档、ZIP、运行清单和本轮检查放在 `.local/experimental-map/release/`。本机启动使用普通客户端参数和正式主程序，不重新构建共享源码。运行日志位于 `.local/experimental-map/play/`，实际存档和普通客户端设置由 `run/` 管理。
