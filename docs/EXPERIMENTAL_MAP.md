# 油库里展馆

根目录 `启动动作博物馆.cmd` 启动的展馆，由一条西侧走廊连接 **五个展厅、27 个展台**。每个展台是一块 11×6 格的小舞台：固定、无敌的演员按按钮演出一段短故事（动作＋台词＋一行提示），旁边有“停止演示”。不铺物品仓库，不做测试围栏。

```text
 大厅 ─ 走廊（西）
   │
   ├─ A 厅 身体与日常 ── 01 身体 → 02 日常 → 03 表达 → 04 排泄与照料
   ├─ B 厅 家庭与成长 ── 05 新生命 → 06 嚼糜与首便 → 07 学起跳 → 08 长大与独立 → 09 家油
   ├─ C 厅 水生魔理沙 ── 10 帽子 → 11 水边 → 12 帽船一日 → 13 船上育儿 → 14 初航 → 15 落水与救援
   ├─ D 厅 人类社会   ── 16 考场 → 17 徽章 → 18 相亲 → 19 运输 → 20 野良应对 → 21 捕食种 → 22 商店与人类 → 23 动手角
   └─ E 厅 季节与聚落 ── 24 秋·储粮 → 25 冬·居巢 → 26 聚落（真实，东门外草地）→ 27 季节从哪来
```

每个展厅沿用动作博物馆的布局：中央走廊，北侧展台自西向东，南侧展台自东向西，顺时针参观。厅宽 30／45／45／60／30 格、深 32 格。大厅西墙的按钮可直接传送到各厅；每厅入口旁有“上一厅／下一厅／回大厅”。

## 展台与场景

“场景”是指令演出：`/yukkuri action` 播放真实的动作片段，`/yukkuri say` 播放真实的台词事件，用 `schedule` 串成故事。**不是自然行为**，不代表游戏里会这样触发。真实行为只在 23 号动手角和 26 号聚落。

落水与救援（15）按重做后的流程演出（亲油下沉近缘、孩子咬缘、蹿身滑入、身体顶正帽子；下沉与咬缘是项目原创，非作品设定），这几个场景和“摇船受惊”集中放在 `scripts/museum_aquatic_rescue.py` 一个文件里；这些动作与台词正在重做，名称变化时只需改那里。生成器会逐项核对动作片段和台词事件是否存在，名字对不上会在生成时报错，而不是做出一个静默失效的展台。

### 两处真实行为

- **动手角（23）**：围栏里是一只真实、自由行动的野生灵梦。按钮发给你 4 份弹珠汽水喷雾和 2 个运输篮（篮带 `can_place_on`，冒险模式也能对走廊和苔藓地面放出）。空手拿篮右键野生个体→它会挣扎拒绝；先用喷雾→约 4 秒后瘫软睡着→再装篮；对地面右键放出。装走的个体会登记成你的宠物。
- **聚落（26）**：走出 E 厅东门是 35×32 的围栏草地。“建立聚落”调用 `/yukkuri settlement spawn forest_led`，生成真实的族长聚落（洞穴住所、住户、族长），“增加威胁”“尝试迁居”调用对应的测试命令。需要足够大的空地；条件不够时命令会提示失败，属于正常。“清空草地”只清走草地范围内的油库里，聚落登记簿里的残留记录不会被删除。

## 操作

- 默认冒险模式，避免误拆展台。靠近展台，右键地面按钮播放；同一展台换节目会先停止上一个，各展台独立，可以同时开多个展台。
- 每组展台旁都有“停止演示”，取消后续步骤，演员回到待机和原位。
- 入馆获得导览书（五厅概要＋全部 110 个注册动作的目录），大厅西墙可补领。
- 回大厅：`/function mcylab:home`；停止全部演示：`/function mcylab:stop_all`。
- 如需编辑地图，可手动执行 `/gamemode creative`。演员固定、无敌；食盆、窝、绷带、运输篮等只是帮助理解场景的陈设。

## 刻意没有放进来的

| 内容 | 原因 |
| --- | --- |
| 完整宠物店、三座工厂、鬼威惨的施虐 | 体量大且依赖真实 NPC 与库存；商店展台只演示求买与成交。完整商店可在生存世界用 `/place template mcyukkuri:yukkuri_shop` 放置 |
| 伤口、馅料、遗体、安葬、冷冻柜、观察笔记、器具与游具 | 需要真实交互，不适合指令演出 |
| 失去幼体的悲伤（`bereaved`）、产道／生殖部四段身体结构、`shell_retract` | 不适合在导览里展示，或当前命令不生效（缩壳被通用收回判断转成待机） |
| 秋冬以外的季节生活、真实四季 | 季节由群系决定，一张超平坦地图里只能以说明牌示意 |
| 真实的繁殖、成长、水上生育 | 需要真实时间与条件；展台里的出生、成长、分娩都是演出，不会产生真实后代 |

## 动作适配

[完整动作清单](MOTION_MUSEUM_ACTIONS.md) 列出 110 个动作的中文名、ID、资源适配范围和展示位置，另列家油等内部行为片段。展馆演示其中 95 个（含待机），共 54 个场景。

生成时逐项读取基础模型与动作修订，检查演员确实有对应动画；普通与水生魔理沙按身份分开，初生动作只给幼体；台词事件按种族和年龄（成体／幼体）核对。

## 文件与重建

- 生成器：`scripts/build_museum_full.py`；展台与场景数据在 `scripts/museum_scenes.py`，场景词汇与实体写法在 `scripts/museum_dsl.py`，水上救援场景在 `scripts/museum_aquatic_rescue.py`，动作目录在 `scripts/museum_actions.py`。需要 Python 3.11+、`nbtlib`（支持 `.local/setup/python` 中已安装的依赖）。
- `scripts/build_showcase_map.py` 是另一座“生活馆”（真实 AI 的生态场景），与展馆互不依赖。
- 本机运行配置：`.local/experimental-map/museum-runtime.json`，记录 CI 运行产物、Java、游戏目录及世界名；旧的 `showcase-runtime.json` 保留给上一座馆。
- 启动器 `scripts/launch_showcase_map.ps1` 直接启动已有运行产物，不自动编译；`-Menu` 进入标题界面。

生成另一份独立地图（输出目录必须是 `.local/experimental-map` 下尚不存在的新目录）：

```powershell
python scripts/build_museum_full.py --seed-level .local/p0/gametest/world/level.dat --output .local/experimental-map/museum-new --catalog docs/MOTION_MUSEUM_ACTIONS.md
```

该命令只读取种子世界的 `level.dat` 元数据，不复制它的区块、实体或玩家。首次进入由数据包在约 30 秒内生成展馆（之后保存在存档里）。日志中的 `MCYMUSEUM_BUILD_COMPLETE` 表示生成结束，`MCYMUSEUM_CHECK_PASS` 表示演员、按钮、动作命令、台词命令、徽章写入和隐藏按钮线路检查通过。它们不替代人工观察动画效果。
