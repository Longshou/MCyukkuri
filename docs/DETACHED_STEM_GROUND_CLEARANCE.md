# 离身茎支撑面净空修正

2026-09-13。联合验收快照 `.local/port-integration/runtime-20260912-223539` 的非瓶装剪茎失败暴露了真实几何问题：两只实子、茎差异系数 `1.01972258` 时，第二只灵梦成熟后的底面为支撑顶面以下 `0.03790149` 格。原逻辑把弯茎根点直接移到离地 `0.02`，没有为悬挂实子的高度留下空间；将幼体包围盒外扩 `0.04` 后，确实与支撑块相交。

修正源为 `family/DetachedStemGeometry.java` 与 `client/DetachedStemRenderer.java`。非瓶装根高由当前胎数、茎差异系数及全部可能子种的成熟挂位推导，使最低底面至少离地 `0.05`；扣除既有 `0.04` 检查余量后还有 `0.01`。该高度不随生长或已出生数量变化，避免实子成熟、脱落时整条茎跳动。客户端补绘从原地面根点到抬高弧根的直茎，使根部仍连接地面。

此计算兼容同胎出现高帽魔理沙。因此复现样本中第二只灵梦的新底面为 `0.25334376`，并非仅把已知失败样本贴着地面抬起。培养瓶仍使用原网格导出的瓶根和瓶口；母体上的茎形、角色模型、子代比例、胎数及真实碰撞规则均未改变。新增直茎由上述 Java 源与现有 `FamilyRenderer.tube` 生成，没有另存一份网格或覆盖标准模型。基础形状及材质来源仍见[家庭素材](../art/props/family-life/README.md)与[器具素材](../art/props/operation-tools/README.md)。

本次独立 `compileJava`、`compileP0TestJava` 通过。直接调用当前 Java 几何的探针扫描了 1–5 胎、0.85–1.15 茎差异系数（步长 0.01）、九种母种、九种子种、每个挂点及三种进度，共 112995 个幼体位置；外扩后的最低底面为 `0.01`，培养瓶变换与修正前一致。[探针、输出、构建日志和源码/资源指纹](validation/detached-stem-ground/current/) 已归档。探针只证明几何下界，不代替世界碰撞或实际剪茎验收。

专用开发夹具 `DetachedStemIntegrationPreview` 位于 X=7000 附近独立台面，先通过正式 `conceive` 选取两胎，再使用正式 `cut` 转移原胎次。`integration-stem-setup` 的 `fullSize:false` 保持进度 0.5；默认 `fullSize:true` 使用 `duration-1`，实子已达到 0.30 完整显示尺寸，但尚未成熟，非瓶装的正式规则不会推进孕育，因此可在正常枯萎时限内采集。`integration-stem-view` 的 `side` 参数切换两个观察玩家的正面与侧面视角。夹具未写入伪造的同步计数、孩子类型或进度。

联合验收已在固定产物 `.local/port-integration/runtime-20260912-230707` 中完成真实剪茎，并通过原胎次两只幼体身份转移、第二只成熟底面净空的两项检查。实际场景进度为 `0.99983335`、茎差异系数为 `1.0197226`，第二只成熟底面为离地 `0.253343758`；报告和逐步记录见同目录证据中的 `stem-checks.json`、`stem-events.json` 与 `stem-preview.json`。参与修正的两份生产源和预览夹具与该冻结产物源码指纹一致。

[双客户端四张当前实机图](../art/props/operation-tools/previews/current/detached-ground/index.html) 已逐张核看：正面显示两只完整实子；侧面确认直茎连续接入弧茎，两只实子各自连接吊茎，低位实子底部明显离地，未见根部断开或实子互相嵌入。原图、逐帧状态、来源路径和指纹均随画廊保存。此结论仅覆盖该离身茎场景；同轮豆体母体分娩录像被观察玩家遮挡，不能用作有效分娩外观验收。造型仍待用户确认。
