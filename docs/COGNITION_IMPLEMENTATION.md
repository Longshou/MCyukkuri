# 智力、具体技能与教学

实现状态：**已接入待试玩**。当前规则见[行为数值与成长设计](BEHAVIOR_BALANCE_DESIGN.md)。智力属于 `YukkuriPersonality` 的五项属性；`Cognition` 只提供只读判断，不另存认知分、亲代快照或成功课堂账本。

## 当前数据与学习规则

- 智力为0～100，由先天值和累计后天修正组成；后天修正最多±20。特殊形态对先天值和有效值都有限制，不足形态智力为0～25。遗传由五属性共同入口处理，见[性格](PERSONALITY_DESIGN.md)。
- 六项真实技能为等待、使用食盆、定点如厕、按时就寝、识字、基础算术，由 `PetLessons` 保存到 `YukkuriPet.KnownSkills`。技能和父母徽章记录不参与遗传。
- 一次有效学习完成后只抽一次：`p = clamp(0.15 + 0.0075 × 智力 − 压力惩罚, 0.05, 0.95)`，压力惩罚为 `min(0.15, 0.003 × max(压力−30, 0))`。首次学会一项技能增加一点智力后天修正；使用已经学会的技能不重复增加。
- 食盆、如厕和就寝技能在对应真实生活事件完成时结算。玩家等待课、识字和算术课在各自任务完成时尝试学习。拒绝、失效或中断不会写成完成。
- 自制决定一次愿意练习的段数 `1 + floor(自制/25)`，上限5段；已经开始的示范在安全接缝结束，真实危险可中断。老人仍可学习；新生幼体先完成首便及基础行动能力。

## 教学与辨识接线

`Cognition.canTeach` 检查同世界、双方生活与行动资格、四格内、双向视线、可识别的非敌对关系，以及教师智力高于学生。教师在真实教学机会形成后按友善判断是否主动帮助；依恋不增加教学意愿。

野外 `teach` 事件沿用 `WildEventData` 的课堂状态。教师和学生的实际动作齐全、学习概率通过后，`commitTeaching` 核对活动场景、成员顺序、`responses == 3` 和 `sourceCount == 1`。该情景没有定义可转授的具体技能，因此只确认示范事实，不追加通用认知分或第二份课堂去重账本。

森林辨食概率为 `clamp(0.35 + 0.006 × 智力, 0.35, 0.95)`。一次实际目标搜索只选择一次辨识结果；事件与现有取食流程负责真实物品，判断函数不生成食物。

失饰识别直接读取智力，普通观察者达到80才认得出；水生识别例外保留，亲缘与徽章不能绕过门槛。详见[头饰](HEADWEAR.md)。

不足形态保留听、看、进食和动作学习能力，但所有发声统一为含混声音。徽章口读、口算和情境面谈记录 `cannot_answer`；动作题继续按实际技能与表现判断，见[宠物与商店](PET_SHOP.md)。

## 持久化与读数

五属性只保存于 `YukkuriLife.Personality`，出生固定档案由 `FamilyData` 保存后应用一次。卸载、收纳、重载和查看都不重抽先天属性，也不自动增长技能。当前试玩阶段不维护旧认知账本的迁移兼容。

`/yukkuri status <目标> raw` 的 `personality` 分组可查看五项有效属性、学习概率、守规概率和任务预算；图鉴显示五属性与等待技能，宠物档案显示六项已学技能。状态查询不改数值。
