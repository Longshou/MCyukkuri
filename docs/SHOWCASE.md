# 可交互测试场景

场景位于本机隔离测试世界 `.local/p0/server/p0-world/`，使用当前运行资源。启动后由一个客户端供用户操作；场景代码只在 `src/p0Test/` 开发夹具中，不进入开发 Jar。

## 看什么

| 区域 | 内容 | 启动方法 |
| --- | --- | --- |
| 蓝色区 | 灵梦与魔理沙五胎茎生 | 右键“茎生”标牌旁的按钮，约二十秒后依次出生 |
| 蓝色区右侧 | 幼体醒来成长 | 右键成长按钮；演示已提前准备年龄和营养，仍由真实睡醒触发 |
| 绿色区 | 巢卵孵化与搬料、藏身 | 右键孵化按钮，约十五秒后出生；旁边家油自行叼材料回巢 |
| 红色区 | 伤口、感染和治疗 | 先用绷带／草药右键个体，再按按钮开始照料计时 |

快捷栏已经放入观察笔记、苹果、绷带、草药、装水湿布、纸、碎屑、运输容器和同伴绳。默认创造模式，双击空格可飞行；`Esc` 释放鼠标。观察笔记对个体右键显示状态，空中右键显示指南。

按 `T` 输入 `/yukkuridemo family`、`/yukkuridemo house` 或 `/yukkuridemo care` 可快速移动。`/yukkuridemo reset` 重置这块隔离展示区和快捷栏，重新准备可触发的场景。

这是一组可重复观察的开发场景：初始条件、年龄和出生等待时间经过准备，不作为默认速度生存长测的证据。当前玩法和上一轮验收见 [核心玩法记录](CORE_GAMEPLAY.md)。

## 开发时重新打开

先用 JDK 21 运行 `./gradlew compileP0TestJava createP0ServerLaunchScript createP0ClientALaunchScript`。通过 `scripts/run_p0.py` 启动隔离 server 与 client-a，等待进入后向 server 发送 `core-load`，再发送 `core-tour`；向 client-a 发送 `show` 显示交互窗口。游戏内重置使用上面的命令。

程序默认隐藏自动验收窗口，`show` 是用户交互展示专用操作。关闭客户端后，可向本轮隔离 server 发送 `stop`，正常保存世界并停止进程。
