# 姿态金样

输入与期望取自提交 `9ceeb499f` 的原始 Java 实现：`YukkuriModel`、`BraidPose`、`YukkuriModelLoader` 和 `WoundSurface`。临时无界面程序只将 `renderPosed` 的绘制提交置空，其余客户端姿态流程与蒙皮按原代码执行；没有启动游戏客户端。期望不能由被测 `pose/` 代码重建。

- `marisa.json.gz`、`house_reimu.json.gz`：冻结的基础模型、适配、动作／家油／厕所修订、原始加载器合成结果与嘴部锚点。测试按实际加载顺序合成并比较序列化结果，包含家油不兼容修订的原有跳过行为。
- `golden.json.gz`：站立、行走、喂养、首便照料、辫子搬运、登船、怀孕、鼓腮、家油、厕所修订与表情，各在 0、0.37、1.1 秒的全部骨骼矩阵与顶点；另含伤口侧的紧凑轨道、摘帽姿态、局部矩阵输入、伤口变形后的静止顶点及权重。
- 鼓腮为显式注入输入：现有完整修订链无 `puff_surface` 或 `puff_envelope`，因此给旧蒙皮传入强度 0.65 与偏移 `(i % 7 - 3) * 0.025`；这只验证变形顺序，不表示运行资源已使用该鼓腮。
- 怀孕固定输入为腹部 0.7、收缩 0.4；刚性帽子／辫子分组与位移由旧客户端记录，测试作为显式输入使用。伤口为固定 UUID 的三级切伤，三角形 300，重心坐标 0.2／0.3，尺寸 1。

`PoseGoldenTest` 不加载 Minecraft，逐项允许误差最多 `1e-5` 模型单位，并跨帧复用合成缓存。该测试验证数值与调用顺序，不验证像素、GPU、帧时间、可读性或玩法；帧时间仍需用户运行截图。

`PoseBoundaryTest` 用错误骨骼名／数量、错误模型哈希、前向父骨骼引用与非有限坐标验证原有资源边界拒绝；不兼容修订不得先修改模型。它不检查几何穿插、视觉质量或玩法结果。
